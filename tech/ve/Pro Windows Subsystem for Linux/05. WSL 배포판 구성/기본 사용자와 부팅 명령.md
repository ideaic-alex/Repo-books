# 기본 사용자와 부팅 명령

`wsl.conf`의 마지막 두 섹션인 `[user]`와 `[boot]`는 WSL이 시작될 때 어떤 사용자로 실행할지, 그리고 시작할 때 어떤 명령을 자동으로 실행할지 정한다. 분량은 적지만 배포판을 운영하는 방식에 영향을 주는 설정이다.

---

## 1. 기본 사용자

- **`[user] default`**: WSL이 시작될 때 실행할 사용자를 지정한다.
- **내장 기본값**: root다.
- **실제 상황**: Ubuntu를 비롯한 대부분의 배포판은 Microsoft Store에서 설치할 때 sudo 권한이 있는 새 사용자를 만들어 기본 사용자로 설정해 둔다.

```ini
[user]
default = root
```

---

## 2. 시작할 때 명령 실행

- **`[boot] command`**: 문자열로 적은 명령을 WSL이 시작될 때 실행한다. Windows 10 빌드 21286에서 추가된 기능이다.
- **대체 효과**: `~/.bashrc`나 `/etc/profile`에 넣어 두던 번거로운 시작 스크립트를 대신할 수 있다.
- **권한**: 명령이 root로 실행되므로 시스템 환경을 크게 바꾸는 작업도 할 수 있다.
- **실행 시점의 한계**: WSL을 시작 메뉴나 Windows Terminal에서 직접 실행할 때만 동작한다. 백그라운드에서 WSL 작업을 돌리는 Windows 서비스나 Windows 작업 스케줄러로 자동화하는 방식을 대체하지는 못하고, 그 방식을 보완하는 기능이다.
- **집필 당시 상황**: 저자는 이 기능이 당시로서는 아주 새로운 기능이라고 설명한다.

```ini
[boot]
command = apt update && apt upgrade -y
```

## 3. 섹션별 한눈에 보기

| 섹션 | 대표 키 | 문서 |
|---|---|---|
| `[automount]` | `enabled`, `root`, `mountFsTab`, `options`, `crossDistro`, `ldconfig` | 자동 마운트, 마운트 옵션 문서 |
| `[network]` | `generateHosts`, `generateResolvConf`, `hostname` | 네트워크 문서 |
| `[interop]` | `enabled`, `appendWindowsPath` | 상호운용성 문서 |
| `[user]` | `default` | 이 문서 |
| `[boot]` | `command` | 이 문서 |
