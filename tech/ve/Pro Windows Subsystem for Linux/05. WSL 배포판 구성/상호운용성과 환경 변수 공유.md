# 상호운용성과 환경 변수 공유

WSL의 큰 특징은 리눅스에서 Windows 프로그램을, Windows에서 리눅스 프로그램을 실행할 수 있고 환경 변수도 서로 공유할 수 있다는 점이다. 이 문서에서는 `[interop]` 섹션과 `WSLENV` 변수를 다룬다. 더 깊은 활용법은 9장에서 이어진다.

---

## 1. interop 활성화

- **`enabled`**: 리눅스에서 Windows 프로그램을 실행할 수 있게 하는 설정이며 기본값은 `true`다. 예를 들어 WSL에서 메모장을 띄울 수 있다.
- **확장 기능**: Windows 빌드 20190부터는 UWP 앱 같은 Windows 앱 실행 별칭(app execution alias)도 WSL에서 실행할 수 있다.
- **끄는 이유**: Windows와 WSL 양쪽에 git이나 python을 설치해 두면 서로 충돌할 수 있다. 이럴 때 배포판을 Windows와 분리하려고 interop을 끈다.
- **임시 전환**: `wsl.conf`를 고치지 않고 현재 세션에서만 `/proc/sys/fs/binfmt_misc/WSLInterop`에 0 또는 1을 써서 끄고 켤 수 있다. 세션이 끝나면 원래대로 돌아오므로, 영구적으로 바꾸려면 `wsl.conf`에서 설정한다.

```bash
echo 0 > /proc/sys/fs/binfmt_misc/WSLInterop
echo 1 > /proc/sys/fs/binfmt_misc/WSLInterop
```

---

## 2. Windows PATH 덧붙이기

- **`appendWindowsPath`**: Windows의 PATH 항목을 WSL 배포판의 PATH 뒤에 붙여서 양쪽의 실행 파일을 모두 쓸 수 있게 한다. 기본값은 `true`다.
- **권장 방식**: 이 옵션은 끌 수 있지만, 책에서는 interop은 켜 둔 채로 두라고 권한다. 그러면 WSL에서 실행할 수 있는 Windows 프로그램이 배포판 PATH에서 찾을 수 있는 것으로 한정된다.

```ini
[interop]
enabled = true
appendWindowsPath = true
```

---

## 3. WSLENV 개념

- **`WSLENV`**: Windows와 WSL 양쪽에 존재하는 특수한 환경 변수로, 어떤 환경 변수를 공유할지 목록으로 정한다.
- **구분자**: WSL에서는 콜론(`:`), Windows에서는 세미콜론(`;`)으로 변수 이름을 나열한다. 각 이름 뒤에는 값을 어떻게 해석할지 알려 주는 플래그를 붙인다.
- **확인 방법**: Windows에서는 "시스템 환경 변수 편집" 화면에서, 리눅스에서는 `printenv`로 확인한다.
- **필요한 이유**: 같은 프로젝트를 리눅스와 Windows 양쪽에서 작업할 때 경로 같은 값을 공유하면 두 환경의 장점을 함께 쓸 수 있다.
- **전달되는 시점**: 환경 변수는 두 환경의 경계를 넘을 때만 전달된다. WSL의 변수는 WSL 세션에서 interop으로 Windows 명령을 실행할 때 전달된다. 반대로 Windows의 변수는 새 터미널을 열거나 `wsl.exe`로 명령을 실행할 때 전달된다.

---

## 4. WSLENV 플래그

| 플래그 | 의미 |
|---|---|
| `/p` | Windows 경로와 WSL 경로를 서로 변환 |
| `/l` | 경로 목록(리스트)임을 표시 |
| `/u` | Windows에서 WSL 방향으로만 공유 |
| `/w` | WSL에서 Windows 방향으로만 공유 |

- **경로 공유 예**: WSL에서 `PATHTOPROJECT`를 정의하고 `WSLENV`에 `/p` 플래그를 붙여 넣으면, Windows의 `cmd.exe`에서 `set PATHTOPROJECT`로 변환된 경로를 읽을 수 있다.
- **기존 값 유지**: `WSLENV`에 이미 값이 있으면 새 항목 뒤에 `:$WSLENV`를 이어 붙인다. 그러면 기존 값이 덮어써지지 않는다.
- **팁**: X 서버용 `DISPLAY` 변수를 `WSLENV`에 넣으면 다른 WSL 배포판과도 공유할 수 있다.

```bash
export PATHTOPROJECT=~/project
export WSLENV=PATHTOPROJECT/p
export WSLENV=PROJECTLIST/l:$WSLENV
```
