# 배포판 조회와 실행

설치된 WSL 배포판의 상태를 확인하고, 기본 배포판을 지정하고, 특정 배포판이나 사용자, 명령 하나로 실행하는 방법을 정리한다. 모든 관리 작업은 PowerShell에서 `wsl.exe`로 한다.

---

## 1. 배포판 목록 조회

- **전체 목록(list all)**: `wsl.exe --list --verbose --all`을 실행하면 이름(NAME), 상태(STATE), WSL 버전(VERSION)을 한 번에 볼 수 있다.
- **이름(NAME)**: 배포판을 구분하는 고유 이름이다. Store나 `.appx`로 설치하면 배포자가 정해 둔 이름이 붙고, `--import`로 설치하면 직접 정한다. 이후 대부분의 명령이 이 이름을 사용한다.
- **기본 배포판 표시**: 이름 옆에 별표(`*`)가 붙은 것이 기본 배포판이다.
- **상태(STATE)**: 셸을 열거나, 기존 셸에서 WSL을 호출하거나, 네트워크 경로(`\\wsl$\<배포판명>`)로 파일을 열면 배포판이 실행 상태가 된다.
- **버전 혼용**: WSL 1 배포판과 WSL 2 배포판을 한 시스템에 함께 둘 수 있고, 서로 변환할 수도 있다.
- **실행 중인 것만 보기(list running)**: `wsl.exe --list --running`

---

## 2. 기본 배포판

- **기본 배포판(default distro)**: `-d` 없이 `wsl.exe`를 실행했을 때 열리는 배포판이다.
- **바꿔야 하는 경우**: 서드파티 도구가 내부에서 `wsl.exe`를 호출하는 경우가 있다. 이럴 때는 그 도구에서 쓰려는 배포판을 기본으로 맞춰 두어야 한다.
- **변경 방법**: 등록된 이름을 정확히 입력해서 지정한다.

```powershell
wsl.exe --set-default Ubuntu-20.04
```

---

## 3. 특정 배포판 실행

- **이름으로 실행**: `wsl.exe --distribution <이름>`을 실행한다. 이름을 정확히 입력해야 하므로 먼저 목록을 조회해서 확인한다.
- **시작 메뉴 아이콘**: Store나 `.appx`로 설치한 배포판은 시작 메뉴 아이콘으로도 열 수 있다.
- **애플리케이션 별칭(application alias)**: 같은 방식으로 설치한 배포판은 `ubuntu2004.exe` 같은 별칭으로 PowerShell에서 실행할 수 있다. `--import`로 직접 설치한 배포판에는 이 별칭이 만들어지지 않는다.

---

## 4. 특정 사용자로 실행

- **`--user` 옵션**: 지정한 사용자 계정으로 배포판을 시작한다. 예를 들어 root로 들어갈 때 쓴다.
- **주의**: 해당 사용자가 배포판 안에 이미 있어야 한다. 없으면 오류가 난다.

```powershell
wsl.exe --distribution Ubuntu-20.04 --user root
```

---

## 5. 단일 명령 실행

- **`--exec`**: 셸에 들어가지 않고 명령 하나만 실행한다. 별도로 지정하지 않으면 기본 배포판에서 기본 사용자로 실행된다.
- **함께 쓰는 옵션**: `--distribution`으로 대상 배포판을, `--user`로 실행할 사용자를 함께 지정할 수 있다.

```powershell
wsl.exe --exec echo 'hello world'
wsl.exe --distribution Ubuntu-20.04 --exec cat /etc/os-release
wsl.exe --distribution Ubuntu-20.04 --user root --exec whoami
```

| 목적 | 옵션 |
|------|------|
| 전체 목록 + 상태 | `--list --verbose --all` |
| 실행 중 목록 | `--list --running` |
| 기본 지정 | `--set-default <이름>` |
| 특정 배포판 | `--distribution <이름>` |
| 특정 사용자 | `--user <사용자>` |
| 단일 명령 | `--exec <명령>` |
