# 3장. WSL 배포판 관리 (Managing WSL Distros)

WSL에는 리눅스 배포판을 관리하는 명령줄 도구가 내장되어 있고, 이 장은 그 도구들을 하나씩 살펴본다. 목록 조회와 실행부터 백업·복제, 제거, 커널 갱신, 외부 디스크 마운트까지 `wsl.exe` 중심의 관리 작업을 정리한 장이다.

---

## 1. 핵심 요점

- **조회**: `wsl.exe --list --verbose --all`로 이름, 상태, WSL 버전을 확인한다. 별표가 기본 배포판이다.
- **실행**: 기본 배포판, 이름 지정, 사용자 지정, `--exec` 단일 명령 실행을 조합할 수 있다.
- **종료**: `--shutdown`은 WSL 2 환경 전체, `--terminate`는 배포판 하나를 멈춘다. 설정 변경 후에는 shutdown이 필요하다.
- **버전 변환**: `--set-version`으로 WSL 1과 2 사이를 바꾼다. 진행 표시 없이 오래 걸릴 수 있다.
- **백업과 복제**: `--export`와 `--import`를 조합해 백업, 복원, 복제, 다른 버전 시험을 한다.
- **제거**: Store 설치 배포판은 앱 설정이나 `Remove-AppxPackage`, `--import` 설치본은 `--unregister`와 폴더 삭제로 지운다. Reset은 확인 없이 모든 데이터를 지운다.
- **커널**: Windows Update로 갱신되며 `--update`, `--update --status`, `--update --rollback`으로 관리한다.
- **디스크 마운트**: `--mount`로 물리 디스크 또는 파티션을 WSL 2에 붙인다. 주 Windows 디스크는 불가능하다.
