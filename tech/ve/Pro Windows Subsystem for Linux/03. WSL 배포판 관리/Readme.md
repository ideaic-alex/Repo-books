# 3장. WSL 배포판 관리 (Managing WSL Distros)

WSL에는 리눅스 배포판을 관리하는 명령줄 도구가 들어 있다. 이 장은 그 도구를 하나씩 살펴본다. 목록 조회와 실행, 백업과 복제, 제거, 커널 갱신, 외부 디스크 마운트까지 `wsl.exe`로 하는 관리 작업을 정리한다.

---

## 1. 핵심 요점

- **조회**: `wsl.exe --list --verbose --all`로 이름, 상태, WSL 버전을 확인한다. 이름 옆에 별표가 붙은 배포판이 기본 배포판이다.
- **실행**: 기본 배포판 실행, 이름 지정, 사용자 지정, `--exec`으로 명령 하나만 실행하는 방법을 필요에 맞게 조합해 쓴다.
- **종료**: `--shutdown`은 WSL 2 환경 전체를, `--terminate`는 배포판 하나를 멈춘다. 설정을 바꾼 뒤에는 shutdown이 필요하다.
- **버전 변환**: `--set-version`으로 WSL 1과 2 사이를 바꾼다. 진행 표시가 없고 오래 걸릴 수 있다.
- **백업과 복제**: `--export`와 `--import`를 함께 써서 백업, 복원, 복제, 다른 버전에서의 테스트를 한다.
- **제거**: Store로 설치한 배포판은 앱 설정이나 `Remove-AppxPackage`로 지운다. `--import`로 설치한 배포판은 `--unregister`를 실행한 뒤 폴더를 직접 삭제한다. Reset은 확인 없이 모든 데이터를 지운다.
- **커널**: 커널은 Windows Update로 갱신되며 `--update`, `--update --status`, `--update --rollback`으로 관리한다.
- **디스크 마운트**: `--mount`로 물리 디스크나 파티션을 WSL 2에 연결한다. Windows가 설치된 주 디스크는 연결할 수 없다.
