# 초기화와 제거

Store나 사이드로딩한 `.appx`로 설치한 배포판은 UWP 앱이므로 Windows 앱 설정에서 초기화하거나 제거할 수 있다. `--import`로 설치한 배포판은 등록 해제(unregister)로 지운다. 이 문서는 두 경로의 차이를 정리한다.

---

## 1. 앱 설정 열기

- **시작 메뉴 경로**: 배포판을 오른쪽 클릭하고 More, App Settings 순서로 선택한다.
- **설정 앱 경로**: 시작 버튼, 설정(톱니바퀴), Apps, Apps & features로 가서 배포판을 검색한다.
- **이 화면에서 할 수 있는 일**: 다른 드라이브로 옮기거나(가능하지만 권장하지 않는다) 제거할 수 있다. 옮기기 전에는 반드시 전체 백업(export)을 만들어 둔다.

---

## 2. 고급 옵션 화면

- **게시자와 버전(publisher/version)**: 배포판의 기본 정보다.
- **앱 저장 공간(app storage space)**: 배포자가 만든 원본 이미지의 크기다. 이 원본은 시스템에 보관되고, 새 업데이트가 나오면 백그라운드에서 갱신된다. 다만 이미 설치된 배포판에는 영향을 주지 않는다.
- **데이터 저장 공간(data storage space)**: 지금 쓰고 있는 설치본의 크기다. 압축을 푼 이미지에 사용자가 추가한 프로그램과 파일을 더한 값이다.
- **기존 설치본의 업데이트**: `apt` 같은 배포판의 패키지 관리자로만 한다. 갱신된 원본 이미지는 초기화할 때 새로 풀린다.

---

## 3. 초기화 (reset)

- **기능**: 설치본을 Store 게시자의 최신 원본 이미지 상태로 되돌려, 새로 설치한 것과 같은 상태로 만든다.
- **위험**: 확인 절차가 없다. `/` 아래의 모든 파일이 즉시 지워지고 복구할 수 없다.
- **사전 조치**: 중요한 파일은 `/mnt/c`를 통해 Windows 쪽으로 복사해 두거나, `wsl.exe --export`로 백업 이미지를 만들어 둔다.

---

## 4. Store 설치 배포판 제거

제거하는 방법은 세 가지다.

1. **시작 메뉴**: 배포판을 오른쪽 클릭하고 Uninstall을 선택한다.
2. **고급 옵션 화면**: Reset 대신 Uninstall을 누른다.
3. **PowerShell**: 패키지 전체 이름을 먼저 찾고, 그 이름으로 제거한다.

```powershell
Get-AppxPackage -Name "*ubuntu*" | Select PackageFullName
Remove-AppxPackage -Package <PackageFullName>
```

---

## 5. `--import`로 설치한 배포판 제거

- **등록 해제(unregister)**: `wsl.exe --unregister <이름>`을 실행하면 WSL에서 배포판이 제거된다.
- **폴더 정리**: 등록 해제를 해도 압축을 풀어 둔 폴더는 지워지지 않는다. 필요하면 PowerShell에서 `rmdir <폴더 경로>`로 직접 삭제한다.

```powershell
wsl.exe --unregister Ubuntu
rmdir C:\WSL\ubuntu-hirsute
```

| 설치 방식 | 제거 방법 |
|-----------|-----------|
| Store, `.appx` | 시작 메뉴, 앱 설정, `Remove-AppxPackage` |
| `--import` | `wsl.exe --unregister` 후 폴더 삭제 |
