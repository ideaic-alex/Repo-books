# 외부 디스크 마운트

Windows 빌드 20211부터 `wsl.exe`로 디스크와 디스크 이미지를 WSL 배포판에 직접 붙일 수 있다. 디스크에 저장된 파일뿐 아니라 실제 파일 시스템 자체에 접근하는 기능이다.

---

## 1. 기능과 제약

- **가능한 일**: 물리 디스크를 WSL 2에 연결해 리눅스 파일 시스템(예: ext4)을 그대로 읽고 쓴다.
- **제약**: C: 파티션이 들어 있는 주 Windows 디스크, 또는 그 디스크의 파티션은 마운트할 수 없다.
- **권한**: 마운트는 관리자 권한 터미널에서 해야 한다.

---

## 2. Windows에서 먼저 분리하기

드라이브 문자로 Windows에서 이미 보이는 디스크라면 먼저 Windows 쪽 사용을 끝내야 한다.

1. 시작 아이콘을 오른쪽 클릭해 디스크 관리(Disk Management)를 연다.
2. 하단에서 대상 디스크를 찾는다. 마운트된 파티션에는 드라이브 문자가 표시되어 찾기 쉽다.
3. 디스크를 오른쪽 클릭해 오프라인(Offline)으로 바꾼다.
4. 이때 디스크 번호를 적어 둔다. 마운트 명령에 필요하다.

---

## 3. 통째로 연결하기 (bare)

- **`--bare`**: 디스크를 WSL에 붙이기만 하고 파일 시스템은 마운트하지 않는다. 모든 파티션이 노출되어 이후 자유롭게 사용할 수 있다.
- **확인**: `lsblk`로 블록 장치와 파티션을 확인한다. 책의 예에서는 `sdg`와 그 파티션으로 나타났다.
- **번호 재확인**: `wmic diskdrive list brief`로 `\\.\PHYSICALDRIVE` 번호가 맞는지 점검할 수 있다.

```powershell
wsl.exe --mount \\.\PHYSICALDRIVE3 --bare
wsl.exe --exec lsblk
wmic diskdrive list brief
```

---

## 4. 파티션 단위로 마운트

- **장점**: `/dev` 노드를 따로 찾을 필요 없이 파티션을 지정하면 파일 시스템이 한 번에 로드된다.
- **옵션 정리**:

| 옵션 | 의미 |
|------|------|
| `--partition <번호>` | 마운트할 파티션 번호 |
| `--type <형식>` | 리눅스에서 부르는 파일 시스템 종류. 기본값은 ext4 |
| `--options <옵션>` | 리눅스 `mount -o`에 쓰는 마운트 옵션 |

```powershell
wsl.exe --mount \\.\PHYSICALDRIVE0 --partition 2
```
