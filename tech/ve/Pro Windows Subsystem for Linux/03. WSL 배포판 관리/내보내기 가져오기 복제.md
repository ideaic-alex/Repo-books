# 내보내기 가져오기 복제

배포판을 tar 이미지로 내보내(export) 백업하고, 그 이미지를 다시 가져와(import) 복원하거나 새 이름으로 복제하는 방법이다. 이 두 명령을 함께 쓰면 백업, 공유, 복제, 버전별 테스트를 모두 할 수 있다.

---

## 1. 내보내기와 백업 (export)

- **목적**: 패키지와 설정을 공들여 맞춰 둔 배포판을 정기적으로 백업하거나, 같은 프로젝트의 동료와 환경을 공유할 때 쓴다.
- **명령**: `wsl.exe --export <배포판명> <내보낼 파일명>`
- **특징**: 파일을 많이 읽고 쓰는 작업이라 오래 걸린다. 버전 변환 때와 마찬가지로 진행 표시가 없다.

```powershell
wsl.exe --export Ubuntu-20.04 C:\WSL\ubuntu-focal-backup.tar.gz
```

---

## 2. 가져오기와 복원 (import)

- **가져올 수 있는 이미지**: 웹에서 받은 리눅스 rootfs(예: Ubuntu 클라우드 이미지 사이트), 백업하려고 내보낸 WSL 이미지, 같은 이미지를 여러 배포판으로 쓰려고 내보낸 이미지를 가져올 수 있다.
- **기본 형식**: `wsl.exe --import <새 이름> <압축 해제 위치> <이미지 파일> --version <1|2>`

| 인자 | 의미 |
|------|------|
| 새 이름 | WSL에 등록할 고유 이름. `--list`와 Windows Terminal 드롭다운에 표시되고, 이후 모든 명령에서 이 이름을 쓴다 |
| 압축 해제 위치 | 배포판 파일을 저장할 폴더. Store로 설치할 때와 달리 직접 지정해야 한다 |
| 이미지 파일 | 가져올 rootfs 파일 |
| `--version` | 선택 사항. 생략하면 기본 WSL 버전으로 가져온다 |

- **폴더 조건**: 현재 Windows 사용자에게 읽기/쓰기 권한이 있어야 한다. C: 외의 드라이브도 쓸 수 있지만 네트워크 마운트 저장소는 권장하지 않는다.
- **기본 버전 지정**: 기본 버전을 WSL 2로 두려면 `wsl.exe --set-default-version 2`를 실행한다.
- **버전을 바꿔 가져오기**: WSL 1에서 내보낸 이미지를 `--version 2`로 가져오면 같은 환경을 두 버전에서 각각 시험해 볼 수 있다.

```powershell
wsl.exe --import Ubuntu-Groovy C:\WSL\Ubuntu-Groovy\ C:\Users\Hayden\Downloads\groovy.rootfs.tar.gz --version 2
```

---

## 3. 배포판 복제 (duplicate)

- **용도**: 잘 맞춰 둔 개발 환경은 그대로 두고, 복사본에서 설정 변경을 먼저 시험해 보고 싶을 때 쓴다.
- **절차**: 원본을 export한 뒤, 그 파일을 새 이름과 새 폴더로 import한다.

```powershell
wsl.exe --export Ubuntu-20.04 C:\WSL\ubuntu-focal-backup.tar.gz
wsl.exe --import Ubuntu-20.04-2 C:\WSL\Ubuntu-20.04-2\ C:\WSL\ubuntu-focal-backup.tar.gz --version 2
```

- **핵심**: 복제본의 이름과 폴더는 원본과 겹치면 안 된다. 이 방식은 같은 이미지로 서로 독립된 배포판을 여러 개 만들 수 있다는 점이 장점이다.
