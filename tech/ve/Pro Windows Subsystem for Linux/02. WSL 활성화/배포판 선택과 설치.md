# 배포판 선택과 설치

WSL을 켠 다음에는 리눅스 배포판(distro)을 설치해야 한다. 이 문서는 배포판을 고르는 기준, 기본 WSL 버전 지정, 설치 경로(스토어, 사이드로드, 명령줄 설치)를 정리한다.

---

## 1. 배포판 종류와 선택 기준

- 집필 시점 스토어 배포판: Ubuntu(20.04 LTS, 18.04 LTS 포함), Debian, Pengwin, Pengwin Enterprise, Fedora Remix for WSL, SUSE Linux Enterprise Server(15 SP1, 12 SP5), openSUSE Leap 15.2, Alpine WSL.
- **익숙한 도구**: Ubuntu, Debian, Pengwin은 `apt`(`.deb`), Fedora는 `dnf`, SUSE 계열은 `zypper`(`.rpm`)를 쓴다.
- **앱 지원**: 쓰려는 앱이 해당 배포판 저장소에 있는지 확인한다. 없으면 업스트림이 Ubuntu용 `.deb`나 자체 apt 저장소를 제공하는 경우가 많다.
- **운영 지원**: 유료 지원은 Ubuntu는 Canonical, Pengwin은 Whitewater Foundry가 제공한다.
- **WSL 전용 기능**: Ubuntu, Pengwin, Fedora Remix에는 오픈소스 유틸리티 모음인 wslutilities가 들어 있다.

---

## 2. 설치 전 고려: 기본 WSL 버전

- WSL 1과 2를 모두 켰다면 배포판을 어느 버전으로 설치할지 정할 수 있다.
- 스토어나 `.appx`로 설치하면 지정한 기본 버전을 따른다.
- 기본값은 `wsl.exe --set-default-version <버전>`으로 바꾼다. 설치 후 버전 변환은 책의 3장에서 다룬다.

---

## 3. wsl.exe로 설치 (빌드 20211 이상)

- 스토어 앱에서 검색하지 않고 명령줄에서 바로 설치한다.
- `--list --online`은 설치 가능한 배포판의 이름과 설명용 친숙한 이름(friendly name)을 두 열로 보여 준다.
- `-d`로 이름을 지정해 설치하면 새 터미널 창이 열리고 해당 배포판의 초기 설정(사용자 이름, 암호)이 진행된다.

```powershell
wsl.exe --list --online
wsl.exe --install -d Ubuntu-16.04
```

---

## 4. Microsoft Store 설치

- 권장되는 방법이다. Ubuntu 같은 무료 배포판은 계정 없이 받을 수 있다.
- 스토어에서 검색해 "Get", "Install", "Launch" 순으로 진행한다. 시작 메뉴나 실행 별칭(예: `ubuntu.exe`)으로도 실행한다.
- 첫 실행 때 배포판을 풀고 기본 비루트(non-root) 사용자를 만든다. 이 사용자는 Windows 계정과 별개다.
- 대부분의 배포판에서 이 사용자는 `sudo` 또는 `wheel` 그룹에 속해 `sudo`로 관리 명령을 쓸 수 있다. 자세한 내용은 4장에서 다룬다.

---

## 5. .appx 사이드로드(sideload)

- 스토어를 쓸 수 없을 때의 대안이다. 스토어 배포판은 `.appx` 형식이라 스토어 없이도 설치할 수 있다.
- **개발자 모드**: 설정의 업데이트 및 보안, 개발자용에서 "모든 원본의 앱 설치(느슨한 파일 포함)"를 켜야 한다. 위험 경고가 나타난다.
- **위험**: WSL용 `.appx`는 다른 스토어 앱처럼 격리되지 않고 Windows 대부분에 접근할 수 있다. `.exe`처럼 취급하고 출처를 검증해야 한다.
- 주요 배포판의 검증된 `.appx`는 Microsoft 문서의 수동 설치 페이지에서 받을 수 있고, GitHub 프로젝트 것은 평판을 확인한다.
- 설치는 파일 탐색기에서 `.appx`를 더블클릭하고 "Install"을 누르면 된다.
