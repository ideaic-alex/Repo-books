# .wslconfig와 커널 설정

WSL 2는 가벼운 가상 머신 구조이기 때문에 Hyper-V나 VirtualBox처럼 메모리와 프로세서 수 같은 자원을 지정하는 설정이 생긴다. 이런 WSL 2 전용 설정은 모든 배포판에 공통으로 적용되는 `.wslconfig` 파일에 적는다. 이 문서는 파일의 위치와 성격, 커널 교체, 커널 명령줄을 정리한다.

---

## 1. .wslconfig 파일

- **위치**: Windows 사용자 홈 폴더의 `.wslconfig`다.
- **적용 범위**: WSL 2의 모든 배포판에 전역으로 적용된다. 배포판별로 따로 쓰는 `/etc/wsl.conf`와 구분된다.
- **기본값**: 파일이 없으면 WSL 2 기본값이 적용되므로 기본값을 바꾸고 싶을 때만 만든다.
- **요구 조건**: 이 장의 설정은 WSL 2 전용이며 Windows 10 빌드 18980 이상에서 쓸 수 있다.
- **섹션**: 모든 항목은 `[wsl2]` 아래에 적는다.

---

## 2. 커널(kernel) 교체

- **기본 커널**: Microsoft가 제공하는 공식 WSL 2 커널이 `%SystemRoot%\system32\lxss\tools\kernel`에 있고, Windows Update 또는 `wsl.exe --update`로 갱신된다.
- **공식 커널의 특징**: WSL 2에 맞춘 최적화(예: 메모리 compaction)가 들어 있다.
- **교체 방법**: `.wslconfig`의 `kernel=`에 직접 만든 커널을 지정한다. 일반적인 리눅스 커널 대부분을 쓸 수 있다.
- **권장 사항**: 공식 소스를 기반으로 수정해 빌드한 커널을 쓰면 Microsoft의 최적화를 이어받는다. 그렇지 않으면 WSL 전용 최적화를 잃을 수 있다.
- **오픈소스**: 공식 커널 소스는 GitHub의 `microsoft/WSL2-Linux-Kernel`에 있어 특정 파일 시스템 등 필요한 기능을 넣어 맞춤 빌드할 수 있다.
- **한계**: 드라이버를 추가해도 WSL 2가 경량 가상화 컨테이너 안에 있어 해당 하드웨어가 보이지는 않는다.
- **경로 규칙**: 절대 경로여야 하므로 환경 변수는 피하고, 역슬래시는 `\\`로 이스케이프한다.
- **파일명**: `bzImage`는 압축 커널, `vmlinux`는 비압축 커널의 흔한 이름이며 WSL 2는 둘 다 부팅한다.

```ini
[wsl2]
kernel=C:\\Users\\Hayden\\bzImage
```

---

## 3. 커널 명령줄(kernel command line)

- **의미**: AppArmor 같은 보안 기능 활성화, 디버깅, 드라이버 옵션 조정 등 커널의 고급 요소를 설정하는 수단이다.
- **WSL 2에서의 제약**: 가상 머신이라 하드웨어 관련 드라이버 옵션은 제한된다. 대신 스레딩, 시스템 콜 처리, 네트워킹, RAM 디스크 관련 최적화는 가능하다. 가능한 옵션은 커널에 내장되었거나 모듈로 추가된 기능에 달려 있다.
- **`kernelCommandLine=`**: 기본 커널과 init를 읽는 내장 명령줄에 더할 매개변수만 지정한다. 예를 들어 `vsyscall=emulate`는 오래된 리눅스 배포판을 지원하는 용도다.
- **표기**: 따옴표 없이 `=` 뒤에 그대로 적는다.

```ini
[wsl2]
kernelCommandLine= vsyscall=emulate
```

---

## 4. 정리

| 키 | 기본값 | 의미 |
|---|---|---|
| `kernel` | 내장 공식 커널 | 사용자 지정 커널 절대 경로 |
| `kernelCommandLine` | 내장 명령줄 | 추가 커널 매개변수 |
