# 프로세서 메모리 스왑 설정

WSL 2의 자원 사용량은 `.wslconfig`로 제한하거나 늘릴 수 있다. 고사양 워크스테이션에서는 성능을 끌어올리고, 저사양 기기에서는 Windows 쪽에 자원을 남기도록 조절하는 것이 목적이다. 이 문서는 CPU 코어, 메모리, 스왑, 스왑 파일 위치, 사용하지 않는 메모리 반환(page reporting)을 정리한다.

---

## 1. 프로세서(processors)

- **기본 동작**: Windows 기기의 모든 코어를 사용한다.
- **`processors=`**: WSL 2가 쓸 코어 수를 제한해 나머지를 Windows 작업용으로 남긴다. 코어 수는 작업 관리자의 성능 탭에서 확인한다.
- **확인 방법**: 설정 후 `wsl.exe --shutdown`을 하고 다시 열어 `/proc/cpuinfo`에서 `processor`를 grep하면 적용 결과(예: 8코어 기기에서 4개)를 볼 수 있다.

```ini
[wsl2]
processors=4
```

---

## 2. 메모리(memory)

- **기본 동작**: 필요한 만큼 할당하고 작업이 끝나면 회수한다. Windows 빌드 20175부터 기본 상한은 가용 RAM의 50%와 8GB 중 작은 값이다.
- **늘리는 경우**: RAM 32GB 기기에서 16GB를 쓰게 하려면 `memory=`를 직접 지정해야 한다.
- **줄이는 경우**: 저사양 기기에서는 1GB로도 작은 셸과 터미널 작업은 충분하다. 다만 GUI 앱, NodeJS 같은 큰 프레임워크 개발, 대규모 컴파일은 느려지거나 실패할 수 있다. Chromium을 소스에서 빌드하려면 최소 4GB가 필요하다.
- **표기**: 정수 뒤에 `GB` 또는 `MB`를 붙인다.

```ini
[wsl2]
memory=12GB
```

---

## 3. 스왑(swap)

- **의미**: 메모리 수요가 실제 RAM을 넘을 때 쓰는 디스크 기반 보조 메모리다. `memory=` 값을 낮게 잡았거나 하드웨어 한계일 때 필요하다.
- **기본값**: Windows 기기 RAM의 25%를 가장 가까운 정수 GB로 올림한 크기다.
- **조정**: `swap=`으로 크기를 지정한다. RAM 집약 작업(Chromium 빌드)이나 8GB 미만 기기에서는 더 크게 잡는 것이 도움이 된다. 디스크에 쓰므로 RAM보다 느리다.
- **끄기**: `swap=0`으로 비활성화할 수 있으나 일반적으로는 권장되지 않으며 일부 앱에서 메모리 부족이 생길 수 있다. 다만 스왑을 아직 지원하지 않는 Kubernetes 개발에서는 배포 환경을 흉내 내려고 끄기도 한다.

```ini
[wsl2]
swap=6GB
```

---

## 4. 스왑 파일 위치(swapfile)

- **기본 경로**: `%USERPROFILE%\AppData\Local\Temp\swap.vhdx`이며 WSL 2가 자동 생성하므로 미리 만들 필요가 없다.
- **`swapfile=`**: 저장 위치를 바꾼다. 커널 경로처럼 절대 경로이고 역슬래시를 이스케이프해야 한다.

```ini
[wsl2]
swap=4GB
swapfile=C:\\wslswap.vhdx
```

---

## 5. 페이지 보고(page reporting)

- **기본 동작**: WSL 배포판이 쓰지 않는 메모리를 풀어 Windows에 돌려준다. 이는 Microsoft의 WSL 2 커널 패치에 의존하므로 맞춤 커널도 공식 소스에서 빌드하길 권한다.
- **원리**: 리눅스 커널은 메모리를 페이지로 나눠 프로세스에 매핑한다. 게스트로 실행될 때 사용하지 않는 페이지를 하이퍼바이저에 알리는 API가 있어, 그 메모리를 Windows 응용 프로그램이나 다른 WSL 프로세스가 다시 쓸 수 있다.
- **조건**: CPU가 거의 유휴일 때만 일어난다. 디버그 콘솔로 이 과정을 볼 수 있다.
- **수동 compaction**: root 권한으로 `/proc/sys/vm/compact_memory`에 1을 써 직접 유발할 수 있다.
- **끄기**: `pageReporting=false`로 두면 WSL이 한번 확보한 메모리를 반환하지 않고 유지한다.

```bash
echo 1 | sudo tee /proc/sys/vm/compact_memory
```
