# 패키지 찾기

배포판에는 수만 개의 패키지가 있어서, 무엇이 있는지와 정확한 이름이 무엇인지 알기 어렵다. 이 문서는 터미널, 텍스트 UI, 그래픽 UI 세 가지 방식으로 패키지를 찾고 설치하는 방법을 정리한다.

---

## 1. 찾기가 어려운 이유

- **방대한 규모**: 일반적인 리눅스 배포판은 수만 개의 패키지를 제공한다. 개발 도구, 라이브러리, 데이터베이스, 웹 서버, 문서 도구, 과학 도구, 게임, 생산성 도구가 모두 들어 있다.
- **이름이 불확실하다**: 패키지 이름은 배포판마다 다르거나 직관적이지 않을 수 있다.
- **사례**: GNOME Web의 예전 이름은 Epiphany다. 그런데 `sudo apt install epiphany`를 실행하면 전혀 다른 게임(보울더 대시 복제판)이 설치된다. 브라우저의 패키지 이름은 `epiphany-browser`다.

---

## 2. 터미널에서 검색 (apt search)

- **명령**: `apt search <키워드>`. 정확한 패키지 이름을 몰라도 소프트웨어 이름으로 찾을 수 있다.
- **결과가 많을 때**: 파이프(`|`)로 `less`에 연결하면 화면 단위로 넘겨 가며 볼 수 있다.
- **텍스트 스트림 도구**: `less`, `tail`, `cat`, `sed`, `grep` 같은 도구는 익숙해질수록 쓸모가 크다. 사용법은 `man <명령>`으로 확인한다.

```bash
apt search lynx
apt search gnome | less
man tail
```

---

## 3. 텍스트 사용자 인터페이스 (aptitude)

- **개념**: 메뉴와 마우스를 쓸 수 있는 터미널 UI로 패키지를 검색, 설치, 업그레이드, 제거한다. Ubuntu, Debian, Pengwin, Kali에서 쓸 수 있다.
- **설치와 실행**: 다른 패키지처럼 설치하고, 관리자 권한으로 실행한다. Windows Terminal이 마우스를 지원하므로 aptitude에서도 마우스가 동작한다.
- **빠져나오는 팁**: 리눅스 프로그램에서 빠져나오지 못하겠다면 `:q`, `Ctrl-C`, `Ctrl-X`를 차례로 시도해 본다.

```bash
sudo apt -y install aptitude
sudo aptitude
```

---

## 4. 그래픽 사용자 인터페이스 (synaptic)

- **전제 조건**: WSL에서 GUI를 쓰려면 X 서버를 직접 설정해야 한다. 책을 쓸 당시에는 공식 GUI 지원이 2021년 후반에 나올 예정이었다. X 서버 설정 방법은 커스터마이징을 다루는 장에서 설명한다.
- **설치와 실행**: X 서버가 동작하면 `synaptic`을 설치하고, apt와 마찬가지로 관리자 권한으로 실행한다.
- **기능**: 이름이나 설명으로 검색할 수 있고, 범주나 설치 상태별로 찾아볼 수 있다. 설치하거나 제거할 패키지를 골라서 처리한다.
- **적용 흐름**: 적용(Apply)을 누르면 설치, 업그레이드, 제거할 패키지 목록이 나온다. 승인하면 변경이 진행되고, 끝나면 완료 대화상자가 뜬다.

```bash
sudo apt install synaptic
sudo synaptic
```

| 방식 | 도구 | 특징 |
|------|------|------|
| 명령줄 | `apt search` | 가볍고 빠름, 파이프와 조합 |
| 텍스트 UI | `aptitude` | 메뉴와 마우스, X 서버 불필요 |
| 그래픽 UI | `synaptic` | X 서버 필요, 가장 입문자 친화적 |
