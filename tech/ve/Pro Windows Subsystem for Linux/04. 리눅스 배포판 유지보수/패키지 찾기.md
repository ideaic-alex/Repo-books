# 패키지 찾기

배포판에는 수만 개의 패키지가 있지만 무엇이 있는지, 정확한 이름이 무엇인지 알기 어렵다. 터미널, 텍스트 UI, 그래픽 UI 세 가지 방식으로 패키지를 찾고 설치하는 방법을 정리한다.

---

## 1. 찾기가 어려운 이유

- **방대한 규모**: 일반적인 리눅스 배포판은 수만 개의 패키지를 제공하며 개발 도구, 라이브러리, 데이터베이스, 웹 서버, 문서 도구, 과학 도구, 게임, 생산성 도구가 포함된다.
- **이름의 불확실성**: 패키지 이름은 배포판마다 다르거나 직관적이지 않을 수 있다.
- **사례**: GNOME Web은 예전 이름이 Epiphany인데, `sudo apt install epiphany`를 하면 전혀 다른 게임(보울더 대시 복제판)이 설치된다. 브라우저는 `epiphany-browser`다.

---

## 2. 터미널에서 검색 (apt search)

- **명령**: `apt search <키워드>`. 정확한 패키지명을 몰라도 소프트웨어 이름으로 찾을 수 있다.
- **결과가 많을 때**: 파이프(`|`)로 `less`에 연결해 쪽 단위로 넘겨 본다.
- **텍스트 스트림 도구**: `less`, `tail`, `cat`, `sed`, `grep` 같은 도구는 익숙해질수록 강력해지며, 사용법은 `man <명령>`으로 확인한다.

```bash
apt search lynx
apt search gnome | less
man tail
```

---

## 3. 텍스트 사용자 인터페이스 (aptitude)

- **개념**: 메뉴와 마우스를 지원하는 터미널 UI로 패키지를 검색, 설치, 업그레이드, 제거한다. Ubuntu, Debian, Pengwin, Kali에서 쓸 수 있다.
- **설치와 실행**: 일반 패키지처럼 설치하고, 관리자 권한으로 실행한다. Windows Terminal이 마우스를 지원해 aptitude에서도 마우스가 동작한다.
- **빠져나오기 팁**: 리눅스 프로그램에서 막혔을 때 `:q`, `Ctrl-C`, `Ctrl-X`를 차례로 시도해 본다.

```bash
sudo apt -y install aptitude
sudo aptitude
```

---

## 4. 그래픽 사용자 인터페이스 (synaptic)

- **전제 조건**: WSL에서 GUI를 쓰려면 X 서버를 직접 구성해야 한다(책 집필 시점에는 공식 GUI 지원이 2021년 후반 예정). 구성은 사용자 정의 장에서 다룬다.
- **설치와 실행**: X 서버가 동작하면 `synaptic`을 설치하고, apt와 같이 관리자 권한으로 실행한다.
- **기능**: 이름이나 설명으로 검색하고, 범주나 설치 상태로 탐색하며, 설치·제거할 패키지를 선택한다.
- **적용 흐름**: 적용(Apply)을 누르면 설치, 업그레이드, 제거 목록이 확인용으로 나오고, 승인하면 변경이 진행되며 완료 대화상자가 뜬다.

```bash
sudo apt install synaptic
sudo synaptic
```

| 방식 | 도구 | 특징 |
|------|------|------|
| 명령줄 | `apt search` | 가볍고 빠름, 파이프와 조합 |
| 텍스트 UI | `aptitude` | 메뉴와 마우스, X 서버 불필요 |
| 그래픽 UI | `synaptic` | X 서버 필요, 가장 입문자 친화적 |
