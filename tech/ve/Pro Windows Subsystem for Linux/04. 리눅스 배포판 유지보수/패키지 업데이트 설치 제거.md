# 패키지 업데이트 설치 제거

`apt` 계열 배포판(Ubuntu, Debian, Pengwin, Kali 등)에서 패키지를 갱신하고, 설치하고, 지우고, 남은 의존성을 정리하는 기본 흐름이다.

---

## 1. 업데이트와 업그레이드의 구분

- **업데이트(update)**: 저장소에서 최신 패키지 메타데이터를 내려받아 설치된 패키지와 비교하고, 업그레이드 가능한 것이 몇 개인지 알려 준다. 패키지 자체는 바뀌지 않는다.
- **업그레이드(upgrade)**: 실제로 새 버전을 적용한다. 변경 계획(업그레이드, 신규, 불필요해질 패키지)을 보여 주고 확인을 받는다.
- **순서**: 먼저 update로 목록을 갱신하고 그다음 upgrade를 한다.

```bash
sudo apt update
sudo apt upgrade
```

---

## 2. 확인 프롬프트와 -y

- **기본 동작**: 진행 여부를 `[Y/n]`으로 묻는다. 대문자 Y가 기본값이라 Enter만 눌러도 진행된다.
- **비대화형**: `-y` 플래그를 붙이면 묻지 않고 자동 승인한다. 설치와 업그레이드 모두 마찬가지다.
- **예시 상황**: 책의 예에서는 158개 패키지의 새 버전과 12개의 신규 의존성이 한꺼번에 처리되었다.

```bash
sudo apt -y upgrade
```

---

## 3. 설치 (install)

- **명령**: `sudo apt install <패키지명>`.
- **동작**: 패키지와 의존성을 함께 설치하며, 변경 내용을 알리고 허락을 구한다. `-y`로 자동 승인할 수 있다.
- **예**: Ubuntu에 기본 포함된 nano 대신 neovim을 쓰고 싶을 때.
- **패키지 이름을 모르면**: 다음 문서의 검색 방법을 쓴다.

```bash
sudo apt -y install neovim
```

---

## 4. 제거 (remove)

- **명령**: `sudo apt remove <패키지명>`.
- **의존성 주의**: 여러 프로그램이 의존하는 패키지를 지우면 그것에 기대는 프로그램들도 함께 제거된다. 대화형 실행에서는 apt가 제거 또는 방치될 패키지를 미리 경고한다.
- **남는 것**: 제거한 패키지의 의존성 중 다른 곳에서 쓰이지 않는 것이 남을 수 있다.

```bash
sudo apt remove neovim
```

---

## 5. 방치된 의존성 정리 (autoremove)

- **발생 경우**: 패키지를 지웠거나, 업그레이드로 어떤 의존성이 더는 필요 없게 되었을 때.
- **정리**: `apt`가 이를 감지하고, `autoremove`로 한꺼번에 제거할 수 있다. 책의 예에서는 neovim을 지운 뒤 남은 의존 패키지들이 정리되었다.

```bash
sudo apt autoremove
```

| 목적 | 명령 |
|------|------|
| 목록 갱신 | `sudo apt update` |
| 새 버전 적용 | `sudo apt upgrade` |
| 설치 | `sudo apt install <이름>` |
| 제거 | `sudo apt remove <이름>` |
| 불필요 의존성 정리 | `sudo apt autoremove` |
