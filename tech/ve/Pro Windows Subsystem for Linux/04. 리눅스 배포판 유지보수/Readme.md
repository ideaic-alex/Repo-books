# 4장. 리눅스 배포판 유지보수 (Linux Distro Maintenance)

WSL에 설치한 리눅스 배포판은 설치한 뒤에 직접 관리해야 한다. 이 장에서는 배포판을 업데이트하고 업그레이드하는 방법, 패키지를 설치하고 제거하고 검색하는 방법을 다룬다. 마지막으로 용도에 맞는 Ubuntu WSL 이미지를 직접 만드는 과정을 안내한다.

---

## 1. 핵심 요점

- **갱신 책임 분리**: 커널과 WSL 플랫폼은 Windows Update가 갱신한다. 배포판 안의 패키지는 사용자가 배포판 전용 도구로 직접 갱신한다.
- **자동 업그레이드 없음**: 직접 명령을 실행하거나, 서비스, 작업 스케줄러, `[boot]` 옵션으로 자동화한다.
- **패키지 관리자**: 배포판마다 다르다(`apt`, `dnf`, `zypper`, `yum`, `apk`). 이 책은 가장 흔한 `apt`를 중심으로 설명한다.
- **apt 기본 흐름**: `update`로 패키지 목록을 갱신하고 `upgrade`로 새 버전을 적용한다. 패키지는 `install`로 설치하고 `remove`로 제거하며, 더는 필요 없는 의존성은 `autoremove`로 정리한다. `-y`를 붙이면 확인 없이 진행한다.
- **패키지 찾기**: 명령줄에서는 `apt search`를 쓴다. 텍스트 UI 도구로는 `aptitude`, 그래픽 도구로는 `synaptic`이 있으며 `synaptic`은 X 서버가 필요하다.
- **직접 만든 이미지**: `debootstrap`으로 기본 이미지를 만들고 `chroot`로 손본다. 그 폴더를 tar로 묶어 `wsl.exe --import`로 가져온다.
