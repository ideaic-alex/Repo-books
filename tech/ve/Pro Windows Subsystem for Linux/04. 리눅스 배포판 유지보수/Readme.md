# 4장. 리눅스 배포판 유지보수 (Linux Distro Maintenance)

WSL에 설치한 리눅스 배포판은 설치 후에 직접 관리해야 한다. 이 장은 배포판 업데이트와 업그레이드 방법, 패키지 설치·제거·검색을 다루고, 마지막으로 용도에 맞는 나만의 Ubuntu WSL 이미지를 만드는 과정을 안내한다.

---

## 1. 핵심 요점

- **갱신 책임 분리**: 커널과 WSL 플랫폼은 Windows Update가, 배포판 내부 패키지는 사용자가 배포판 전용 도구로 갱신한다.
- **자동 업그레이드 없음**: 수동 실행하거나 서비스, 작업 스케줄러, `[boot]` 옵션으로 자동화한다.
- **패키지 관리자**: 배포판마다 다르다(`apt`, `dnf`, `zypper`, `yum`, `apk`). 책은 가장 흔한 `apt`를 중심으로 설명한다.
- **apt 기본 흐름**: `update`로 목록 갱신, `upgrade`로 적용, `install`과 `remove`, 불필요한 의존성은 `autoremove`. `-y`로 자동 승인한다.
- **패키지 찾기**: `apt search`, 텍스트 UI `aptitude`, 그래픽 `synaptic`(X 서버 필요).
- **사용자 정의 이미지**: `debootstrap`으로 기본 이미지를 만들고 `chroot`로 손본 뒤 tar로 묶어 `wsl.exe --import`로 가져온다.
