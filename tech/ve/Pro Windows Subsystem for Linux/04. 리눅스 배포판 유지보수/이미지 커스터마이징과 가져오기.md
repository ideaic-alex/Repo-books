# 이미지 커스터마이징과 가져오기

부트스트랩한 Ubuntu 이미지 안에서 `chroot`로 설정과 패키지를 손본다. 그런 다음 tarball로 묶어 Windows로 옮기고, WSL 배포판으로 가져와 제대로 동작하는지 확인하는 단계다.

---

## 1. chroot로 이미지 안에서 작업

- **chroot**: 지정한 폴더를 루트로 삼아, 그 안의 이미지에서 명령을 그대로 실행한다. 관리자 권한(root 또는 sudo)이 필요하다.
- **형식**: `sudo chroot <이미지 폴더> <실행할 명령>`.
- **apt 캐시 정리**: 메타데이터는 시간이 지나면 만료되어 공간만 차지한다. 이미지를 다시 쓰거나 다른 사람과 공유할 계획이라면 미리 비워 둔다.

```bash
sudo chroot /tmp/wslchroot/ apt clean
```

---

## 2. 언어와 인코딩 설정

- **필요한 이유**: 새 이미지에는 기본 언어 설정이 없다.
- **절차**: `dpkg-reconfigure locales`를 실행하면 생성할 언어와 인코딩을 묻고, 이어서 시스템 기본값을 묻는다. 미국 영어라면 `en_US`와 UTF-8을 고르고, 기본값으로는 `en_US.UTF-8`을 고른다.
- **다른 언어**: 다른 언어를 고르거나 여러 언어를 함께 선택할 수 있다. 일부 비라틴 문자는 별도의 ISO 인코딩이 필요할 수 있다.

```bash
sudo chroot /tmp/wslchroot/ dpkg-reconfigure locales
```

---

## 3. 저장소와 패키지 추가

- **software-properties-common**: `add-apt-repository`를 제공하는 패키지다. 이 명령으로 추가 저장소를 쉽게 켤 수 있다.
- **universe와 multiverse**: 이 저장소를 켜면 apt, aptitude, synaptic에서 훨씬 많은 패키지(서드파티 소프트웨어 포함)를 쓸 수 있다.
- **명령 연결**: `&&`로 여러 명령을 차례로 실행할 수 있다.
- **메타 패키지(meta-package)**: `gis-workstation`은 의존성 기능을 이용해 수십 개의 GIS 도구를 한 번에 설치한다. 책에서는 약 3GB가 추가되었다.

```bash
sudo chroot /tmp/wslchroot/ apt install software-properties-common
sudo chroot /tmp/wslchroot/ add-apt-repository universe && sudo chroot /tmp/wslchroot/ add-apt-repository multiverse
sudo chroot /tmp/wslchroot/ apt install gis-workstation
```

---

## 4. rootfs tarball 만들기와 이동

- **폴더로 이동**: 이미지 폴더 안으로 들어가 `ls -a`로 보면, 일반 Ubuntu의 루트 파일 시스템과 같은 구조가 보인다.
- **압축**: 폴더 내용을 `tar.gz`로 묶는다. 이미지가 크면 몇 분이 걸린다.
- **Windows로 옮기기**: `/mnt/c` 아래에 `C:\WSL` 같은 폴더를 만든다(Windows 사용자에게 쓰기 권한이 있는 곳이면 어디든 괜찮다). 그리고 진행 상황을 보여 주는 `rsync`로 tarball을 옮긴다. `cp`나 `mv`로 옮겨도 된다.

```bash
cd /tmp/wslchroot/
sudo tar --ignore-failed-read -czf /tmp/ubuntu-gis-wsl.tar.gz *
mkdir /mnt/c/WSL
sudo rsync --progress --remove-source-files /tmp/ubuntu-gis-wsl.tar.gz /mnt/c/WSL/
```

---

## 5. WSL로 가져오기와 검증

- **Windows 쪽으로 전환**: 현재 WSL 셸에서 `cmd.exe`를 호출해 Windows 명령 프롬프트로 나온다.
- **가져오기**: `wsl.exe --import`에 이름(예: `Ubuntu-GIS`), 저장할 폴더, tarball, WSL 2 버전을 지정한다.
- **실행 확인**: `wsl.exe --distribution Ubuntu-GIS`로 시작하면 root 사용자로 들어간다. `cat /etc/os-release`로 Ubuntu 20.04 LTS focal인지 확인한다.
- **Windows Terminal**: 터미널을 껐다 다시 켜면 새 배포판이 드롭다운 메뉴에 자동으로 나타난다.
- **응용 프로그램 확인**: X 서버를 설정했거나 나중에 공식 GUI 지원이 들어오면, `qgis` 같은 GIS 애플리케이션이 동작하는지 시험해 볼 수 있다.

```powershell
wsl.exe --import "Ubuntu-GIS" C:\WSL\Ubuntu-GIS C:\WSL\ubuntu-gis-wsl.tar.gz --version 2
wsl.exe --distribution Ubuntu-GIS
```
