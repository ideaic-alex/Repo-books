# 효과적인 프롬프트로 AI의 잠재력 끌어내기

2장은 같은 AI라도 프롬프트에 따라 결과가 크게 달라진다는 점을 다룬다. 좋은 프롬프트의 조건을 정리하고, 5W1H 질문 틀로 AI와 함께 제품 기획서(PRD)를 쓰는 법을 배운다. 그다음 그 기획서를 바탕으로 프레임워크, 기능, 디자인, 검증의 4단계 전략을 따라 프리랜서 마케터용 포트폴리오 웹페이지를 완성한다.

---

## 1. 핵심 요점

- 좋은 프롬프트의 조건은 길이가 아니라 명확성, 구체성, 맥락이다. "멋진 홈페이지"처럼 모호하면 AI가 모든 것을 임의로 정한다.
- 5W1H(Why, Who, What, When, Where, How)는 기획의 뼈대이고, 소프트웨어 PRD에서는 What과 How를 특히 강조한다.
- 범용 질문 템플릿에 무엇을, 주요 기능, 누구를, 왜를 채우면 AI가 상세한 PRD를 써 준다. PRD는 곧 좋은 프롬프트다.
- PRD를 한꺼번에 코드로 바꾸지 말고 기능별로 나눠 단계마다 확인한다.
- 4단계 전략은 프레임워크, 기능, 디자인, 검증이며 모든 단계에서 요청, 생성, 검토, 수정을 반복한다.
- 섹션마다 고유 이름을 붙이면 필요한 부분만 정확히 고칠 수 있다.
- 기능 단계에서는 실제 데이터를 구체적으로 주고, 디자인 단계에서는 WordPress 테마 같은 참고 자료를 준다.
- 검증은 AI에게 PRD 대조와 링크 점검을 맡기고 지적된 개선점을 고치면 마무리된다.
