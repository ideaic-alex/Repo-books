# 마케팅 포트폴리오 3단계 디자인과 4단계 검증

이 문서는 4단계 전략의 뒤쪽 절반이다. 뼈대와 내용이 갖춰진 포트폴리오에 참고 디자인을 입히고(3단계), AI에게 점검을 맡겨 빠진 곳과 깨진 링크를 고쳐 완성한다(4단계). 마지막에는 장 전체의 핵심 낱말과 복습 문제를 정리한다.

비유하면 가게 인테리어와 개업 전 점검이다. 취향에 맞는 사진을 들고 가서 "이런 느낌으로"라고 말해야 시공이 정확하고, 문을 열기 전에 불이 켜지는지 문이 열리는지 하나씩 확인해야 손님을 받을 수 있다.

---

## 1. 3단계 디자인: 참고 자료를 주고 입히기

이제 디자인을 적용한다. 1단계에서 잠깐 디자인을 입혔듯 "멋진 디자인을 적용해 줘"라고 요청할 수도 있다. 하지만 "예쁘게 해 줘"라고만 하는 것보다 참고할 구체적 예시를 주면 결과의 질이 크게 좋아진다. 3단계 프롬프트의 핵심이 AI에게 더 나은 디자인을 만들 참고 자료를 주는 것이다. 참고할 것을 고르기 어렵다면 AI에게 살펴볼 만한 디자인을 추천해 달라고 해도 된다.

이 책은 세계에서 가장 널리 쓰이는 웹사이트 제작 플랫폼 WordPress의 테마(Theme, 미리 만들어진 디자인 묶음)를 참고로 쓴다. WordPress는 콘텐츠 성격에 맞는 분류별 테마를 제공하고, 그중 '포트폴리오' 분류가 있어 알맞은 디자인을 고를 수 있다. 책은 WordPress 외에도 다른 플랫폼, 템플릿 갤러리, 디자인 자료를 마음대로 참고해도 된다고 한다.

### 요청과 생성

```text
Select one WordPress theme that best suits this portfolio and restyle the
entire page after it, updating the colors and fonts to match the theme.
Use different color tones for each section to make them easily
distinguishable. Apply the design directly to the HTML document.
```

테마를 하나 골라 전체를 그 스타일로 바꾸고, 색과 글꼴을 맞추고, 섹션별로 색조를 달리하라는 요청이다. 책에서는 Claude가 Kalium이라는 WordPress 테마를 따라 페이지를 새로 입혔다. "섹션별로 색조를 구분하라" 같은 추가 지시를 상세하게 줄수록 일관되고 전문적인 디자인이 나온다.

### 검토: 공개해서 브라우저로 확인

아티팩트 위 Copy 버튼 옆 메뉴에서 Publish artifact를 고르고 Publish and copy link를 눌러 포트폴리오 웹페이지의 링크를 만든다. 복사한 링크를 브라우저 주소창에 붙여 넣어 요청한 대로 디자인이 구현됐는지 확인한다. 이 단계에서는 디자인만 적용하고 결과를 검토한다. 세부 수정은 4단계에서 다루므로 지금은 전체 구조와 디자인이 의도대로 나왔는지만 보면 된다.

잘 만든 포트폴리오처럼 보이더라도 작동하지 않는 링크나 빠진 요소가 있을 수 있다. 다음 단계가 이런 세부를 점검하고 바로잡는 일이다.

## 2. 4단계 검증: AI에게 점검 맡기기

웹페이지 품질을 점검할 때 모든 항목을 혼자 확인할 필요는 없다. AI에게 검토를 맡기면 오류와 누락을 자동으로 찾아내고 개선 방법까지 제안한다. 단순 확인을 넘어 웹페이지를 더 높은 수준으로 함께 다듬을 수 있다.

이 단계는 무엇보다 중요하다. 디자인과 기능이 아무리 인상적이어도 링크가 작동하지 않거나 내용이 빠지면 실제로는 쓸 수 없는 페이지다. 테스트는 결과물이 "정말 쓸 수 있는 상태"가 되기 위한 마지막 관문이며 품질을 보장하는 핵심이다.

### 요청: 기능 점검

```text
Please review whether every part of the portfolio webpage is properly
implemented. Check that it was built according to the PRD and that each
link works without any issues.
```

PRD대로 만들어졌는지, 링크가 문제없이 동작하는지 점검해 달라는 요청이다.

### 검토: 개선점 확인

Claude가 찾아낸 개선점을 살핀다. 책의 예에서는 개선이 필요한 세 곳이 지적됐다. 경우에 따라 Claude가 웹페이지를 자동으로 고쳐서 결과를 보여 주기도 한다. 그때는 곧바로 검토 단계로 가서 고쳐진 결과를 확인하면 된다.

### 수정: 지적된 부분 고치기

```text
Address and fix the three areas for improvement that were identified,
and complete a perfect portfolio for transitioning to freelance work.
```

잠시 기다리면 Claude가 포트폴리오를 고친다. 마지막으로 결과를 검토하면 연락처까지 제대로 동작하는 완성된 포트폴리오 웹페이지가 나온다.

## 3. 이 실습에서 얻은 것

체계적으로 쓴 PRD를 완전히 동작하는 웹페이지로 바꾸는 전 과정을 겪었다. 4단계 전략 덕분에 복잡한 프로젝트도 작은 단위로 나눠 관리할 수 있었고, 오류와 누락 가능성을 크게 줄였다. 특히 두 가지가 효과를 냈다.

- 섹션마다 고유한 이름을 붙여서 필요한 부분만 정확히 고칠 수 있었다.
- WordPress 테마 같은 구체적 참고 자료를 제시해서 전문적인 디자인을 만들 수 있었다.

웹 환경에서 AI와 효율적으로 협력하는 법을 익혔으니, 다음 3장에서는 한 걸음 더 나아가 Claude Code로 더 고급 프로젝트에 도전한다.

## 4. 장 마무리: 핵심 낱말 여섯 개

- 4단계 포트폴리오 전략은 AI에게 프레임워크, 기능, 디자인, 검증 순서로 웹페이지 제작을 요청하는 것이다.
- 웹페이지는 각각 하나의 주제를 맡은 섹션들로 구성된다.
- 프레임워크 단계에서는 기능과 디자인을 더하기 전에 기본 HTML 구조만으로 뼈대를 세운다.
- 기능 단계에서는 실제 데이터를 채우고 기능을 더한다.
- 디자인 단계에서는 색, 배치, 시각 요소를 적용해 전체 품질을 높인다.
- 검증 단계에서는 완성된 웹페이지를 점검해 빠진 기능과 오류를 고친다.

## 5. 복습 문제

답은 09장에 있다.

1. 포트폴리오 웹사이트를 만드는 4단계 전략의 올바른 순서를 고르시오.
   - 디자인 적용, 기본 프레임워크 구축, 핵심 기능 추가, 완성도 점검
   - 기본 프레임워크 구축, 디자인 적용, 핵심 기능 추가, 완성도 점검
   - 기본 프레임워크 구축, 핵심 기능 구현, 디자인 적용, 완성도 점검
   - 핵심 기능 구현, 기본 프레임워크 구축, 완성도 점검, 디자인 적용
2. 효과적인 프롬프트 작성법이 아닌 것을 고르시오.
   - 5W1H 템플릿으로 체계적으로 질문한다.
   - 시간을 아끼려고 모든 기능을 한 번에 요청한다.
   - 개별 수정을 위해 섹션마다 ID를 붙인다.
   - WordPress 테마 같은 구체적인 참고 자료를 제시한다.
3. 섹션에 고유한 이름을 붙이는 이점이 아닌 것을 고르시오.
   - 원하는 부분만 골라 수정할 수 있다.
   - 전체 코드를 다시 만들 필요가 없다.
   - AI가 어디를 고칠지 분명히 이해한다.
   - 디자인이 자동으로 좋아진다.
