# 요약과 핵심 개념

4장은 세 덩어리로 이뤄진다. 웹에서 PRD와 단계별 프롬프트를 만들어 Claude Code로 할 일 앱을 완성하는 실습, 세션과 컨텍스트를 관리하며 오래 일하는 법, 그리고 이미지와 @ 기호와 관리 명령으로 프로젝트를 다루는 법이다. 이 문서는 세 덩어리를 한 번에 되짚고 핵심 용어를 정리한다.

---

## 1. 장 전체 흐름

| 순서 | 주제 | 결과 |
|---|---|---|
| 1 | 웹에서 PRD 작성, 5단계 프롬프트로 변환 | 기획은 웹에서, 구현은 Claude Code에서 나누는 작업 흐름 |
| 2 | 5단계 실행 (기본 구조, 카테고리, 대시보드, 다크 모드, 마무리) | 순수 HTML, CSS, JavaScript 할 일 관리 앱 완성 |
| 3 | /status, /model, /help | 세션 상태, 모델, 명령 목록 확인 |
| 4 | --resume, -c, /resume, Shift + Tab | 저장된 대화를 이어가고 반복 승인을 줄임 |
| 5 | /context, /compact | 컨텍스트 사용량을 점검하고 압축해 공간 확보 |
| 6 | 스크린샷 전달과 @ 기호 | 데스크톱 버전 UI 제작, 파일과 폴더 즉시 분석 |
| 7 | /config, /doctor, /export | 설정 관리, 환경 진단, 대화 기록 저장 |

## 2. 핵심 개념 정리

| 개념 | 한 줄 설명 |
|---|---|
| PRD | 제품의 목적, 사용자, 기능, 기술 사양을 정리한 요구사항 문서 |
| 단계별 프롬프트 | PRD를 여러 단계로 나눠 단계마다 구체적 목표를 주는 프롬프트 설계 방식 |
| localStorage | 브라우저에 데이터를 저장해 새로고침 뒤에도 남기는 기능 |
| 세션 | 사용자와 Claude Code가 주고받는 대화 상태. 프로젝트 폴더에 자동 저장된다 |
| --resume, -c, /resume | 저장된 대화를 목록에서 고르거나, 최근 대화를 바로 이어가거나, 실행 중에 고른다 |
| 자동 승인 모드 | Shift + Tab으로 켜서 세션 동안 모든 수정을 자동 승인한다 |
| 컨텍스트 | Claude Code가 기억하는 대화와 작업 정보 전체. 가득 차면 자동 압축된다 |
| /context, /compact | 사용량을 확인하고, 대화를 요약해 공간을 비운다 |
| 멀티모달 AI | 텍스트와 이미지 등 여러 정보를 함께 이해하는 AI |
| @ 기호 | 파일이나 폴더를 프롬프트에 즉시 불러오는 참조 방법 |
| /config, /doctor, /export | 설정 확인과 변경, 환경 진단, 대화 기록 저장 |

## 3. 자주 놓치는 점

- 책의 PRD와 프롬프트는 예시일 뿐이다. 생성 결과가 달라도 형식을 따라 단계별로 실행하면 같은 경험을 얻는다.
- 웹에서 만든 프롬프트는 메모장에 저장해 두고 복사해 쓴다. Claude Code는 파일을 직접 만들고 고치므로 더 구체적으로 써야 한다.
- 터미널을 닫아도 대화는 지워지지 않고 프로젝트 폴더에 저장된다. 다시 열 때는 --resume이나 -c를 쓴다.
- 자동 압축은 작업 중간에 정보를 빠뜨릴 수 있다. 작업 단위가 끝날 때 /context로 확인하고 직접 /compact를 한다.
- 압축해도 시스템 프롬프트, 도구, 메모리 파일은 유지된다. Ctrl + O로 요약 전문을 보며 중요한 내용이 남았는지 확인한다.
- 이미지는 끌어다 놓으면 [Image #1]로 들어간다. 모바일 UI를 데스크톱용으로 바꿀 때는 새 폴더에 저장하게 해 이전 결과를 지킨다.
- 파일을 찾으라고 시키는 것보다 @ 기호로 직접 가리키는 편이 빠르다.
- /config 기본값과 요금제별 모델과 토큰 한도는 책이 쓰인 시점 기준이며, 바뀔 수 있다.
