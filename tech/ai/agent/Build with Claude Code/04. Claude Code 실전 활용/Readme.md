# Claude Code 실전 활용

4장은 Claude 웹과 Claude Code를 묶어 더 체계적인 개발 흐름을 경험하는 장이다. 웹에서 PRD와 단계별 프롬프트를 만들고, Claude Code에서 다섯 단계로 실행해 할 일 관리 앱을 완성한다. 그 과정에서 세션 재개, 자동 승인, 컨텍스트 압축, 이미지와 @ 기호 참조, 설정과 진단과 내보내기 같은 실전 명령을 자연스럽게 익힌다.

---

## 1. 핵심 요점

- 기획은 Claude 웹에서 하고 구현은 Claude Code에서 한다. 웹에서 PRD를 쓰고 5단계 프롬프트로 바꿔 메모장에 저장해 둔다.
- 순수 HTML, CSS, JavaScript로 할 일 앱을 다섯 단계에 걸쳐 만든다. 기본 구조, 카테고리, 대시보드, 다크 모드, 내보내기와 접근성 순이다.
- /init, /status, /model, /help는 프로젝트를 시작할 때 쓰는 기본 명령이다.
- 대화는 프로젝트 폴더에 자동 저장되므로 --resume, -c, /resume으로 며칠 뒤에도 이어서 일할 수 있다.
- Shift + Tab으로 자동 승인 모드를 켜면 반복되는 권한 요청을 건너뛴다.
- /context로 컨텍스트 사용량을 보고 /compact로 압축한다. 자동 압축에 맡기기보다 작업 단위가 끝날 때 직접 하는 편이 안전하다.
- 스크린샷을 끌어다 놓으면 요구사항을 설명 없이 전할 수 있고, @ 기호로 파일과 폴더를 즉시 참조한다.
- /config로 설정을 관리하고, /doctor로 환경을 진단하며, /export로 대화 기록을 파일로 남긴다.
