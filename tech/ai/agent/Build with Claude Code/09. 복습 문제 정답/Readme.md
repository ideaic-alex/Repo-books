# 복습 문제 정답

부록은 1장부터 8장까지 각 절 끝에 놓인 복습 문제의 정답을 한곳에 모은 것이다. 이 폴더는 그 정답을 장별로 다시 정리했다. 문제 본문은 각 장 폴더의 문서 끝에 있으니, 먼저 풀어 본 뒤 여기서 확인하는 순서를 권한다.

---

## 1. 핵심 요점

- 정답은 1장부터 8장까지 장과 절 순서대로 실려 있다. 장마다 먼저 푼 뒤 맞춰 보는 용도로 쓴다.
- 1장에는 AI 도구 유형을 나눈 표 채우기가, 4장과 5장에는 명령과 상황을 짝짓는 표 채우기가 있다.
- 3장은 설치, 손글씨 인식, CLAUDE.md 세 절의 정답이 문제 순서대로 맞춰져 있다.
- 5장은 커스텀 명령이 파이썬이 아니라 마크다운(.md) 파일이며 .claude/commands 폴더에 저장된다는 점을 바로잡는다.
- 6장은 API 키를 코드에 박지 말고 .env 파일과 .gitignore로 지키라는 점을 확인한다.
- 7장은 읽기 전용 에이전트로 버그 수정이나 새 파일 생성이 안 되는 이유를 설명한다.
- 원서의 정답 쪽은 목록 번호가 쪽 경계에서 깨져 있어 일부 문장은 문제와의 대응이 불확실하다. 그 부분은 문서에서 밝혔다.
