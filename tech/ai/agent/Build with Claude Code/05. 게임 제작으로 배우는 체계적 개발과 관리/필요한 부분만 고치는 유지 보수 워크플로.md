# 필요한 부분만 고치는 유지 보수 워크플로

AI와 개발하다 보면 한 부분만 바꾸고 싶은데 시스템 전체를 다시 만들게 되는 일이 있다. 기능이 나뉘지 않고 통째로 얽혀 있기 때문이다. 이 문서는 명령을 독립된 md 파일로 관리해 필요한 부분만 골라 고치는 방법을 두 사례로 익힌다. 하나는 기존 명령의 수정, 다른 하나는 새 명령의 추가다.

비유하면 조립식 가구다. 서랍 하나가 불편하면 그 서랍만 바꾸면 되고, 새 선반이 필요하면 선반만 끼우면 된다. 통짜로 만든 가구는 하나를 고치려 해도 전부 다시 만들어야 한다.

---

## 1. 기존 명령만 수정하기: 상대 평가 등급

교사 모드 대시보드에는 등급(Grade) 열이 있는데, 모든 플레이어가 C로 분류되는 문제가 있다. `/create-report`(교사 모드 보고서를 만드는 명령)가 평균 점수를 기준으로 절대 평가를 했기 때문이다. 이 명령을 상대 평가로 바꾼다. 상위 비율에 따라 등급을 나눈다.

```text
.claude/commands/create-report.md를 다음과 같이 수정해 줘.
등급 표시를 상위 비율 기준 상대 평가로 바꿔 줘.
- 상위 20%: A
- 상위 40%: B
- 상위 70%: C
- 하위 30%: D
```

수정 후 Claude Code를 재시작하고 `/create-report`를 실행하면 플레이어 등급이 다시 매겨진 성적표가 나온다. 이 작업에서 바뀐 것은 명령 파일 하나뿐이고, 게임과 다른 명령은 건드리지 않았다.

## 2. 새 명령 추가하기: /export-report

전체 명령 묶음에 새 명령을 더해 일부 기능만 확장할 수도 있다. 이번에는 교사 모드에서 만든 대시보드 데이터를 외부 파일로 내보내는 `/export-report`를 추가한다. `teacher_report.html`을 읽어 CSV나 PDF로 저장하고, 이 명령을 `teacher-dashboard.md`에도 넣어 통합 명령에 포함시킨다.

```text
.claude/commands/export-report.md 파일을 새로 만들어 줘.
teacher_report.html을 읽어서 CSV 또는 PDF로 저장하고,
이 명령을 teacher-dashboard.md에도 추가해 줘.
```

만든 뒤 재시작해 `/teacher-dashboard`를 실행하면 `Study-03` 폴더에 `report_detailed.csv`가 생긴다. 더블클릭해 열면 학생들의 평가 보고서가 정리되어 있다.

## 3. 절 전체 정리

이 절에서 퀴즈 게임에 데이터 저장, 통계, 리더보드를 구현하고 효율적인 관리 자동화를 만들었다. 여러 커스텀 명령을 이어 문제 추가, 검증, 통계 분석, 보고서 생성을 자동화했고, 통합 명령으로 매일 업데이트를 한 번에 처리하는 법을 배웠다. 교사 모드에서는 여러 플레이어의 점수를 자동으로 모아 비교하는 대시보드를 만들었다. 이때 필요한 명령을 Claude Code가 직접 만들게 했고, 기능을 부분 수정하거나 확장할 수 있는 유연한 구조도 경험했다. 반복 작업을 줄이고 AI가 일상적 관리와 검증을 돕는 지속 가능한 개발 환경이 만들어진다.

핵심 세 가지는 다음과 같다. 유지 보수는 완성된 프로젝트를 계속 관리하고 개선하는 과정이다. 기능을 모듈로 나누면 전체 구조는 두고 필요한 부분만 고칠 수 있다. 명령을 연결하면 한 번의 요청으로 순서대로 실행되고, 통합 명령은 여러 작업을 한 명령으로 묶어 반복되는 개발과 유지 보수 흐름을 자동화한다.

## 4. 복습 문제

정답은 부록 [09. 복습 문제 정답](../09. 복습 문제 정답/복습 문제와 정답.md)에 있다.

- 틀린 설명을 고른다. 하나, 여러 커스텀 명령을 연결해 한 번의 요청으로 실행할 수 있다. 둘, 통합 명령은 여러 개별 명령을 묶어 한 번에 실행한다. 셋, 개별 명령 파일만 고쳐도 부분 업데이트가 된다. 넷, 명령을 모듈화하면 유지 보수가 쉬워진다. 다섯, 커스텀 명령은 반드시 파이썬 스크립트로 써야 한다.
- 빈칸을 채운다. 커스텀 명령은 (__) 파일 형식으로 저장하고, 명령 파일은 (__) 폴더에 둔다. 만들어진 명령 목록을 확인할 때는 (__) 명령을 쓴다.
