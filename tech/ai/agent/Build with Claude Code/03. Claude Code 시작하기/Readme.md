# Claude Code 시작하기

3장은 웹 브라우저의 Claude에서 한 걸음 나아가 터미널에서 돌아가는 Claude Code를 직접 설치하고 써 보는 장이다. Claude Code를 설치해 로그인하고 첫 대화를 나눈 뒤, 말만으로 손글씨 숫자 인식 프로그램을 만든다. 이어 CLAUDE.md 설정 파일과 폴더 계층 구조를 익혀 같은 프로그램을 웹 버전으로 넓힌다.

---

## 1. 핵심 요점

- Claude Code는 터미널에서 실행되며 답변만 하지 않고 파일을 직접 만들고 고치고 프로그램도 실행한다.
- Windows에서는 먼저 Git을 설치하고 PowerShell에서 설치 명령을 실행한다. macOS와 Linux는 curl 명령을 쓰고 설치 후 사용법은 거의 같다.
- 로그인은 월 구독 계정이 가장 무난하다. API 계정은 토큰 과금이라 초보자에게 부담이 될 수 있다.
- 데스크톱 앱과 Cowork도 있지만 책은 고급 기능과 원리 이해를 이유로 터미널 방식을 택했다.
- 프롬프트 한 줄로 MNIST 기반 손글씨 인식 프로그램을 만들고, 배치 파일로 더블클릭 실행까지 만든다.
- 파일 저장과 코드 실행 때마다 권한을 묻는다. 한 번만 허용할지, 세션이나 프로젝트 단위로 허용할지 고를 수 있다.
- CLAUDE.md는 프로젝트의 구조, 규칙, 명령을 담아 매 세션 자동으로 읽히며 /init으로 만든다. 길면 컨텍스트를 낭비하므로 간결하게 쓴다.
- 루트와 하위 폴더에 CLAUDE.md를 나눠 두는 계층 구조로 공통 규칙은 한 번만 쓰고 버전별 규칙은 따로 관리한다.
