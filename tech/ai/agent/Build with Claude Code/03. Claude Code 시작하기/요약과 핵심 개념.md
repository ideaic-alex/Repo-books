# 요약과 핵심 개념

3장은 세 덩어리로 이뤄진다. Claude Code를 설치하고 첫 대화를 나누는 일, MNIST 손글씨 인식 프로그램을 대화만으로 만드는 일, CLAUDE.md와 폴더 계층으로 프로젝트를 관리하며 웹 버전까지 넓히는 일이다. 이 문서는 세 덩어리를 한 번에 되짚고 핵심 용어를 정리한다. 가격, 메뉴, 화면 문구는 책이 쓰인 시점 기준이다.

---

## 1. 장 전체 흐름

| 순서 | 주제 | 결과 |
|---|---|---|
| 1 | Git과 터미널 준비, Claude Code 설치 | 터미널에서 claude를 입력해 실행할 수 있는 환경 |
| 2 | 초기 설정, 로그인, 첫 대화, 종료 | 구독 계정으로 연결하고 /exit 또는 Ctrl+C 두 번으로 종료 |
| 3 | 데스크톱 앱, Cowork, 터미널을 고른 이유 | 세 가지 사용 형태와 터미널 중심 학습의 근거 |
| 4 | 프로젝트 폴더 준비와 MNIST 손글씨 인식 | 프롬프트 한 줄로 만든 GUI 프로그램과 권한 확인 방법 |
| 5 | 배치 파일 | Claude Code 없이 더블클릭으로 실행하는 .bat 파일 |
| 6 | /init과 CLAUDE.md, 계층 구조 | 루트와 하위 폴더별 설정 파일, 데스크톱과 웹 두 버전 |
| 7 | 웹 버전 실행과 localhost | 브라우저에서 돌아가는 손글씨 인식 |

## 2. 핵심 개념 정리

| 개념 | 한 줄 설명 |
|---|---|
| 터미널 | 글자 명령으로 컴퓨터와 직접 대화하는 창. Windows는 PowerShell |
| Claude Code | 터미널에서 파일을 만들고 고치며 프로그램을 실행하는 AI 코딩 도구 |
| Git | 버전 관리 프로그램. Windows에서 Claude Code를 쓰려면 먼저 설치 |
| 구독 계정 로그인 | 월 구독료만 내는 방식. API 계정은 토큰 과금, 서드파티는 클라우드 경유 |
| Cowork | 개발자가 아닌 사람이 대화로 문서, 조사, 스프레드시트, 발표 자료를 만드는 기능 |
| OCR과 손글씨 인식 | 글자를 디지털로 바꾸는 기술과 그중 변동이 큰 손글씨 분야 |
| MNIST | 손글씨 숫자 이미지 7만 장(28 곱하기 28 픽셀 흑백) 데이터셋 |
| 배치 파일 | 여러 Windows 명령을 모아 한 번에 실행하는 .bat 텍스트 파일 |
| 권한 선택지 | Yes, 거절하며 방향 지시, 프로젝트에서 항상 허용 등 파일 작업 허락 범위 |
| CLAUDE.md | 프로젝트 구조, 규칙, 명령을 적어 두고 실행 때 자동으로 읽히는 설정 파일 |
| /init | 현재 폴더를 분석해 CLAUDE.md를 자동으로 만드는 명령 |
| 전역 CLAUDE.md | 홈 디렉터리의 .claude 폴더에 두는, 모든 프로젝트에 적용되는 파일 |
| 계층 구조 | 공통 규칙은 루트, 전문 규칙은 하위 폴더의 CLAUDE.md에 두는 방식 |
| localhost와 포트 | 내 컴퓨터 자신을 가리키는 주소와 프로그램별 연결 통로 번호 |

## 3. 자주 놓치는 점

- 터미널은 어느 폴더에서 열었느냐가 작업 범위를 정한다. 작업 폴더를 먼저 정확히 고르고 claude를 실행한다.
- 종료 명령은 /exit이다. /quit은 책의 복습 문제에서 틀린 방법으로 제시된다.
- 책의 실습은 유료 구독을 전제한다. API 계정으로 로그인하면 토큰 과금이라 초보자는 비용이 예상보다 커질 수 있다.
- 같은 프롬프트라도 결과가 조금씩 다르다. 생성된 파일 이름과 출력은 직접 확인한다.
- 코드 저장, 패키지 설치, 코드 실행 때마다 확인을 구하는 것은 정상이다. 번거로우면 세션 동안 허용을 고른다.
- CLAUDE.md는 길수록 좋지 않다. 매 세션 읽히므로 길면 컨텍스트를 차지해 지시 이행이 흐려진다.
- CLAUDE.md는 이전 대화 전체를 저장하지 않는다. 구조, 규칙, 명령 같은 핵심 맥락만 담는다.
- 계층 구조는 일관성과 중복 제거가 장점이지 토큰 자동 절감이 아니다.
- 웹 버전 실행 중 오류가 나면 터미널의 오류 메시지를 복사해 Claude Code에 넘겨 해결을 맡긴다.
