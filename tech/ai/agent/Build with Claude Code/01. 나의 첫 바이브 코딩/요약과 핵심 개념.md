# 요약과 핵심 개념

1장은 두 덩어리로 이뤄진다. 먼저 바이브 코딩이 무엇이고 AI 코딩 도구가 어떤 유형으로 나뉘는지를 보고, 이어서 Claude 아티팩트로 첫 웹페이지를 만들어 직접 체험한다. 마지막에 2장부터 필요한 유료 요금제를 정리한다. 이 문서는 전체를 한 번에 되짚고 핵심 용어를 모은다.

---

## 1. 장 전체 흐름

| 순서 | 주제 | 결과 |
|---|---|---|
| 1 | 바이브 코딩의 정의와 웹 챗봇의 한계 | 대화로 코드를 만들되 복사와 붙여 넣기, 파일 접근의 한계를 확인 |
| 2 | 모델 선택형과 전용 모델형 | 렌터카와 자기 차 비유로 두 도구 유형과 비용 구조를 구분 |
| 3 | AI의 발전사 | 신경망, 딥러닝, 트랜스포머, LLM으로 이어지는 흐름 이해 |
| 4 | 아티팩트로 시작 페이지 제작 | 날짜, 시간, 검색창이 있는 페이지를 대화만으로 완성 |
| 5 | 공개와 맞춤 | 공유 링크를 만들고 디자인을 Google 스타일로 변경 |
| 6 | 요금제 비교 | 2장부터 Pro 이상이 필요하고 3장 이후는 Max를 고려 |

## 2. 핵심 개념 정리

| 개념 | 한 줄 설명 |
|---|---|
| 바이브 코딩 | 아이디어를 자연어로 설명하고 AI가 낸 코드를 검토하며 고쳐 가는 개발 방식 |
| LLM | 방대한 글과 코드를 학습해 사람의 말에 맞는 코드를 만드는 대규모 언어 모델 |
| 모델 선택형 | 한 도구에서 여러 모델을 고르는 방식. 도구 구독료가 따로 들 수 있다 (Cursor, Antigravity) |
| 전용 모델형 | 특정 모델 전용 도구를 설치해 쓰는 방식. 모델 비용만 내고 로컬 파일에 접근 (Claude Code, Gemini CLI) |
| CLI와 GUI | 글자 명령으로 조작하는 방식과 마우스로 화면을 조작하는 방식 |
| 아티팩트 | 대화창 옆에서 결과물을 바로 실행해 보여 주는 Claude의 작업 공간 |
| 공개(Publish) | 결과물을 공유 링크로 온라인에 내는 기능 |
| 맞춤(Customize) | 만든 결과 위에 디자인이나 기능을 덧붙여 고치는 과정 |
| HTML, CSS, JavaScript | 웹페이지의 뼈대, 모양, 동작을 맡는 세 가지 재료 |
| 트랜스포머 | 2017년 Google 연구팀이 발표한 구조로 오늘날 대규모 언어 모델의 기반 |

## 3. 자주 놓치는 점

- 바이브 코딩은 한 번에 완벽한 결과를 받는 방법이 아니다. 요청하고 확인하고 고치는 반복이 핵심이다.
- 모델 선택형은 모델 값에 도구 구독료가 더해질 수 있다. 전용 모델형은 모델 비용만 낸다. 다만 도구마다 정책이 달라 미리 확인해야 한다.
- 도구의 겉모습이 달라도 본질은 같은 LLM 엔진 위의 인터페이스다. 기본적인 코딩은 어느 모델을 써도 결과가 비슷하다.
- 공개한 페이지에서는 외부 링크가 막혀 검색이 되지 않을 수 있다. 이때는 HTML 파일을 내려받아 브라우저에서 연다.
- 막연한 요청은 AI가 모든 것을 임의로 정하게 만든다. 구체적으로 요청할수록 만족스러운 결과가 나오고, 이것이 2장의 주제다.
- 2장부터는 Pro 이상의 유료 구독이 필요하다. 요금과 기능은 책이 쓰인 시점 기준이므로 실제 가입 전에 공식 사이트를 확인한다.
