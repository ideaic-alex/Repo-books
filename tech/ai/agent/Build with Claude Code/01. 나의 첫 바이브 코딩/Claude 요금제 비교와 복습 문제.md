# Claude 요금제 비교와 복습 문제

1장의 마지막 부분은 앞으로의 실습을 이어 가려면 어떤 Claude 요금제가 필요한지를 정리하고, 장 전체를 복습 문제로 확인한다. 지금까지는 무료 요금제로 따라 할 수 있게 짜였지만, 2장부터는 유료 구독이 필요하다.

비유하면 헬스장 회원권을 고르는 일과 같다. 가끔 가볍게 운동하면 체험권으로 충분하고, 매일 오래 하려면 상위 회원권이 편하다. 어떤 것이 나에게 맞는지는 쓰는 양이 정한다.

---

## 1. 왜 유료 요금제가 필요한가

무료 요금제는 사용량에 한도가 있다. 수십 번 메시지를 주고받으면 대화가 끊길 수 있고, 접속이 몰리는 시간에는 우선순위가 낮아 속도가 느려지거나 이용이 제한될 수 있다.

그래서 책은 2장부터 Pro 이상의 유료 구독을 요구한다. 3장 이후의 실습은 토큰(Token, AI가 읽고 쓰는 글의 단위로 사용량을 재는 기준) 사용량이 더 많으므로 Max 요금제도 고려하라고 한다. Claude Code로 바이브 코딩을 하면 대화를 아주 많이 하게 되므로 쓰는 패턴에 맞는 요금제를 고르는 것이 중요하다. 요금제는 언제든 올리거나 내릴 수 있다.

## 2. 구독하는 방법

구독 절차는 다음과 같다.

- Claude 채팅 창 아래쪽의 프로필을 누르고, 나오는 목록에서 Upgrade plan 메뉴를 고른다.
- Pro나 Max 중 예산에 맞는 요금제를 고른다. Pro로 시작하면 Buy Pro Plan 버튼을, Max를 사려면 Subscribe to Max Plan 버튼을 누른다.
- 결제 정보를 입력해 구독을 마친다. 결제 설정 화면에서 Pro 구독이 활성화되었는지 확인할 수 있다.

Max를 구독하면 Max (20x) 옵션으로 올릴 수 있고, 이것이 모든 요금제 중 사용 한도가 가장 높다. 책의 팁에 따르면 Max (20x)는 Max를 선택한 뒤 200달러 옵션을 고르면 되고, 3장 이후의 실습에는 Max 이상을 권한다.

## 3. 요금제 비교

아래 표는 책이 정리한 세 요금제(Max는 두 단계)의 가격과 사용 한도와 특징이다. 가격과 기능은 책이 쓰인 시점 기준이며, 실제 정책은 Claude 공식 사이트에서 다시 확인해야 한다.

| 요금제 | 월 요금 | 사용량 | 특징과 어울리는 사람 |
|---|---|---|---|
| Free | 0달러 | 제한적 | 고급 모델 사용 불가. 가끔 가벼운 대화를 하는 사람 |
| Pro | 20달러 | Free의 약 5배 | 모델 선택 가능, Claude Code 사용 가능. 업무에 Claude를 꾸준히 쓰는 일반 사용자 |
| Max (5x) | 100달러 | Pro의 약 5배 | Pro 기능에 우선 접근과 웹 검색. Claude Code로 다양한 주제와 장기 프로젝트를 하려는 사람 |
| Max (20x) | 200달러 | Pro의 약 20배 | Max 기능에 최대 사용량. Claude Code를 가장 높은 한도로 쓰려는 사람 |

## 4. 장 마무리: 핵심 낱말 네 개

원서는 1장 두 번째 절을 네 개의 낱말로 닫는다.

- 아티팩트는 Claude가 코드를 만들고 실시간 미리보기를 보여 주는 작업 공간이다.
- 프롬프트는 AI에게 전하는 요청이나 지시다.
- 공개(Publish) 기능은 만든 결과물을 온라인으로 공유하고 공유 링크를 만든다.
- 맞춤(Customize)은 기존 디자인 위에 추가 수정을 하는 과정이다.

## 5. 복습 문제

답은 이 책의 09장에 있다. 먼저 스스로 풀어 본다.

1. AI 비서의 발전 순서로 맞는 것을 고르시오.
   - 딥러닝, 신경망, 트랜스포머, LLM
   - 신경망, 딥러닝, 트랜스포머, LLM
   - 트랜스포머, 딥러닝, 신경망, LLM
   - LLM, 트랜스포머, 딥러닝, 신경망
2. Claude Code 같은 CLI 기반 모델의 특징이 아닌 것을 고르시오.
   - 로컬 파일 시스템에 직접 접근할 수 있다.
   - 프로젝트 전체를 통합해 관리할 수 있다.
   - 터미널 명령으로 작업을 수행한다.
   - 도구 사용료와 AI 모델 비용을 둘 다 내야 한다.
3. 코드나 문서를 만들 때 Claude에서 쓰는 특별한 작업 공간으로 맞는 것을 고르시오: 프롬프트, 아티팩트, 터미널, CLI.
4. 만든 웹페이지를 다른 사람과 공유하려면 반드시 (__) 버튼을 눌러야 한다.
5. 이미 공개한 웹페이지를 수정하려면 반드시 (__) 버튼을 눌러야 한다.
6. 웹 챗봇형, 모델 선택형, 전용 모델형이라는 세 분류에 각각 대표 도구를 채워 넣으시오. 설명은 다음과 같다. 웹 챗봇형은 설치 없이 웹에서 바로 쓰며 복사와 붙여 넣기가 필요하다. 모델 선택형은 여러 언어 모델 중에서 고를 수 있으며 추가 비용이 들 수 있다. 전용 모델형은 특정 언어 모델을 설치해 쓰며 로컬 파일에 직접 접근한다.
7. 다음 설명에 맞는 개념(용어)을 고르시오.
   - 아이디어를 대화하듯 AI에게 설명하면 AI가 코드를 제안하고, 사람이 검토하고 다듬어 완성하는 새로운 개발 방식
   - 프로그래밍 과정에서 질문에 답하고 옆에서 코드를 같이 써 주는 가상의 파트너
   - 렌터카처럼 여러 LLM 중에서 골라 쓰는 AI 코딩 도구
   - 자기 차처럼 특정 모델을 설치해 깊이 쓰는 AI 코딩 도구

참고(노트 작성자): 원서는 도구 분류 표 채우기와 용어 고르기(6번, 7번)를 첫 절 끝에, 나머지 다섯 문제(1번부터 5번)를 장 끝에 따로 싣고 있다. 이 노트는 한곳에 모아 번호를 새로 매겼으므로 09장의 정답 번호와 다를 수 있다. 09장의 정답은 문제 내용으로 대조한다.
