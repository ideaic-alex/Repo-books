# 나의 첫 바이브 코딩

1장은 바이브 코딩이 무엇인지 알아보고, 곧바로 Claude 웹 화면에서 첫 웹페이지를 만들어 본다. AI 코딩 도구를 웹 챗봇형, 모델 선택형, 전용 모델형으로 나눠 비교하고, AI가 신경망에서 LLM까지 발전해 온 줄기를 짧게 훑는다. 그런 다음 코드를 한 줄도 쓰지 않고 날짜, 시간, 검색창이 있는 시작 페이지를 만들고 공개 링크로 공유하며 디자인까지 바꿔 본다. 마지막으로 2장부터 필요한 유료 요금제를 비교한다.

---

## 1. 핵심 요점

- 바이브 코딩은 아이디어를 자연어로 설명하면 AI가 코드를 제안하고 사람이 검토하고 다듬는 개발 방식이다. 이 말은 2025년 2월 Andrej Karpathy가 만들었다.
- LLM은 자연어와 방대한 코드를 함께 학습했기 때문에 사람의 말을 코드로 바꿀 수 있다.
- 웹 챗봇은 설치가 필요 없지만 코드를 복사해 붙여 넣어야 하고 내 컴퓨터 파일에 접근하기 어렵다.
- 모델 선택형(Cursor, Antigravity)은 렌터카처럼 모델을 고르지만 도구 구독료가 따로 들 수 있고, 전용 모델형(Claude Code, Gemini CLI)은 자기 차처럼 모델 비용만 내며 로컬 파일을 직접 다룬다.
- 도구는 달라 보여도 모두 같은 LLM 엔진 위의 인터페이스이며, 이 책은 Claude와 Claude Code를 쓴다.
- Claude 아티팩트는 대화로 웹페이지를 만들고 바로 확인하는 작업 공간이다. Publish artifact로 공유 링크를 만들고 요청 한 줄로 디자인을 바꿀 수 있다.
- 구체적으로 요청할수록 결과가 좋아진다. 이것이 2장 프롬프트 전략으로 이어진다.
- 2장부터는 Pro 이상의 유료 구독이 필요하고, 3장 이후는 Max 요금제를 권한다(요금은 책이 쓰인 시점 기준).
