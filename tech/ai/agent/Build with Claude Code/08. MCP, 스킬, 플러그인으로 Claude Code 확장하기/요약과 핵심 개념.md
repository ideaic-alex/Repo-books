# 요약과 핵심 개념

8장은 다섯 덩어리로 이뤄진다. MCP의 개념과 Notion 연결, 로컬 MCP와 Sequential Thinking, 스킬과 플러그인과 마켓플레이스, GitHub MCP, 그리고 Vercel과 Supabase를 이용한 배포와 데이터베이스 연결이다. 하나의 쇼핑 목록 앱이 만들어지고, 테스트되고, 보관되고, 배포되고, 데이터베이스에 연결되는 흐름으로 이어진다.

---

## 1. 장 전체 흐름

| 순서 | 주제 | 결과 |
|---|---|---|
| 1 | Notion MCP 연결 | 원격 MCP를 설치하고 인증해, 최신 변경 사항을 Notion 문서로 자동 저장 |
| 2 | Sequential Thinking MCP | 로컬 MCP 설치와 명령 구조 이해, 일반 추론 85줄 대 순차 추론 222줄 비교 |
| 3 | 스킬 만들기와 쓰기 | code-review 스킬 생성, vibeindex 스킬로 필요한 MCP와 스킬 추천 |
| 4 | 플러그인과 마켓플레이스 | 쇼핑 목록 앱 제작, Playwright로 테스트 9개 통과, document-skills로 pptx 생성 |
| 5 | GitHub MCP | 토큰으로 설치하고 `shopping-list-app` 저장소에 업로드 |
| 6 | Vercel 배포 | 404 오류를 `index.html`로 해결하고 공개 URL 확보 |
| 7 | Supabase 연동 | `shopping_items` 테이블 생성, 추가와 체크와 삭제가 데이터베이스에 실시간 반영 |

## 2. 핵심 개념 정리

| 개념 | 한 줄 설명 |
|---|---|
| MCP | AI 모델이 외부 데이터, 도구, 서비스와 연결하는 표준 통신 규약 |
| 클라이언트-서버 모델 | 요청하는 쪽(Claude)과 실제 작업을 처리하는 쪽(MCP 서버)을 나눈 구조 |
| 원격 MCP | 외부 서버의 MCP에 URL로 연결한다. 설정이 쉽고 인증이 필요하다 |
| 로컬 MCP | 내 컴퓨터에서 MCP 서버를 직접 실행한다. 인터넷 없이도 되고 사생활 보호에 좋다 |
| `--` 구분 기호 | Claude Code 옵션과 MCP 서버 실행 명령을 가르는 기호 |
| 범위(`-s`) | local은 현재 프로젝트, project는 팀 공유, user는 내 모든 프로젝트 |
| 인증 | 연결하려는 사람이 권한 있는 사용자인지 확인하는 절차 |
| 에이전트 스킬 | `.claude/skills/이름/SKILL.md`에 저장되어 맥락에 따라 자동 호출되는 프롬프트 |
| 커스텀 명령 | `.claude/commands/`에 저장하고 `/명령`으로 직접 부르는 프롬프트 |
| 플러그인 | MCP와 스킬 등을 묶어 하나의 기능으로 제공하는 꾸러미 |
| 마켓플레이스 | 플러그인과 스킬을 찾고 설치하는 공유 공간. `/plugin`으로 접근 |
| Playwright | 웹사이트를 브라우저로 자동 테스트하는 도구. 내부는 MCP 서버다 |
| add, commit, push | 올릴 파일 담기, 로컬 저장소에 확정, 원격 저장소로 올리기 순서 |
| Vercel | GitHub에 올린 코드를 자동 빌드하고 배포하는 클라우드 플랫폼 |
| Supabase | 설치 없이 쓰는 클라우드 데이터베이스 플랫폼. API가 자동 생성된다 |
| 데이터베이스 테이블 | 데이터를 행과 열로 저장하는 구조. 엑셀 시트 한 장과 비슷하다 |

## 3. 자주 놓치는 점

- 원격 MCP 설치 명령은 Claude Code를 시작하기 전에 터미널에서 실행한다. 인증은 Claude Code 안의 `/mcp`에서 한다.
- Notion은 브라우저 로그인으로 인증하고, GitHub는 설치 명령에 토큰을 넣는 방식이다. 인증 방법은 서비스마다 다르다.
- GitHub 토큰과 Supabase 토큰은 화면에 한 번만 보이고 비밀번호와 같다. 책 실습에서는 만료를 30일로 두었다. 글이나 저장소에 그대로 적지 않는다.
- 스킬과 커스텀 명령은 둘 다 md 파일 프롬프트지만, 스킬은 부르지 않아도 맥락에 따라 자동 실행된다.
- 플러그인으로 설치한 Playwright도 안쪽은 MCP 서버라서 `claude mcp list`에 나타난다.
- add, commit, push 순서는 바뀌면 안 된다. GitHub MCP를 쓰면 Claude Code가 이 순서를 대신 처리한다.
- Vercel 배포에서 404가 나오면 서버 문제가 아니라 시작 페이지 `index.html`이 없어서일 가능성이 크다.
- 로컬 스토리지는 그 브라우저에만 남는다. 다른 기기와 공유하려면 클라우드 데이터베이스가 필요하다.
- Supabase 무료 요금제는 프로젝트 2개까지이고 7일간 활동이 없으면 일시 중지된다. 이런 조건은 책이 쓰인 시점 기준이다.
- 이 장의 화면 문구, 메뉴 이름, 마켓플레이스와 플러그인 이름은 책이 쓰인 시점 기준이며 바뀔 수 있다.
