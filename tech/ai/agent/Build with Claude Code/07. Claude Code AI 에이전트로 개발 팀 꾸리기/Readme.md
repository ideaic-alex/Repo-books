# Claude Code AI 에이전트로 개발 팀 꾸리기

7장은 Claude Code의 서브에이전트 기능으로 혼자서도 개발 팀을 꾸리는 방법을 배우는 장이다. 먼저 코드 리뷰, 최적화, UX 디자인을 맡는 에이전트를 하나씩 만들어 협업시키며 프로젝트를 개선한다. 그다음 기획, 백엔드, 프런트엔드, 품질 보증, AI 통합 에이전트로 팀을 구성해 AI 공감 일기와 PDF 요약 AI를 만든다.

---

## 1. 핵심 요점

- 에이전트는 목표와 규칙에 따라 스스로 판단해 일하는 AI다. 개발자는 무엇을 이룰지 정하고 에이전트는 어떻게 할지 정한다.
- 서브에이전트는 .claude/agents/ 폴더의 마크다운 파일 하나이며, name, description, tools, model 필드로 역할과 권한과 모델을 정한다.
- 가장 쉬운 생성 방법은 Claude Code에게 에이전트를 말로 설명하는 것이다. 직접 파일을 써도 된다.
- 검토 담당은 읽기 전용(Read, Grep, Glob)으로, 수정 담당은 Edit, Write, Bash를 더해 역할을 나눈다.
- 모델은 어려운 분석은 opus, 대부분은 sonnet, 단순 작업은 haiku가 맞고, 비용이 걱정되면 sonnet으로 시작한다.
- 여러 에이전트를 시키면 Claude Code가 의존 관계를 보고 직렬 또는 병렬로 돌린다. 충돌에 대비해 작업 전 백업을 해 둔다.
- 기획, 백엔드, 프런트엔드, QA, AI 통합 에이전트 다섯이 하나의 PRD를 두고 이어 달려 앱을 만든다. 필요한 에이전트만 골라 쓴다.
- 5W1H로 요구사항과 역할을 정리해 프롬프트에 담으면 팀이 같은 방향으로 일한다.
