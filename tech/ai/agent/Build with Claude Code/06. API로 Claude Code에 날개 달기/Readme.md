# API로 Claude Code에 날개 달기

6장은 지금까지 미리 준비한 데이터에만 기대던 프로그램에 진짜 AI의 힘을 붙이는 장이다. API가 무엇인지, 어떤 AI 모델을 어떻게 고르는지, API 키를 어떻게 안전하게 다루는지를 배운다. 그 위에서 냉장고 사진을 읽어 재료를 알아보고 레시피를 추천하는 웹 앱 FridgeChef를 이미지 인식 API와 텍스트 생성 API로 만든다.

---

## 1. 핵심 요점

- API는 내 프로그램과 외부 AI 서비스를 잇는 다리다. 앱은 화면과 요청 조율을 맡고, 인식과 생성은 AI 모델이 맡는다.
- 이미지 인식이나 문장 생성 모델을 직접 만들려면 방대한 데이터와 컴퓨터가 필요하므로 만들어진 모델을 API로 쓰는 편이 효율적이다.
- OpenRouter는 여러 회사의 모델을 한곳에서 비교하고 키 하나로 바꿔 쓰게 해 준다. 학습 단계에서는 무료 모델이 좋은 출발점이다.
- API 키는 인증, 사용량 추적, 요금 청구에 쓰이는 비밀 열쇠이며 발급 화면에서 한 번만 볼 수 있다.
- 키는 .env 파일에 두고 .gitignore에 등록해 GitHub에 올라가지 않게 한다. 키를 프롬프트나 코드에 직접 쓰지 않는다.
- 무료 모델은 요청 수 한도가 있고 입력이 학습에 쓰일 수 있다. 모델 이름은 정확히 입력해야 한다.
- FridgeChef는 PRD를 세 단계(재료 인식, 레시피 생성, 프로필과 저장)로 나눠 만들고 단계마다 확인했다.
- 만든 앱은 로컬 환경에서만 돌아가는 프로토타입이다. 실서비스에는 배포와 데이터베이스가 더 필요하다.
