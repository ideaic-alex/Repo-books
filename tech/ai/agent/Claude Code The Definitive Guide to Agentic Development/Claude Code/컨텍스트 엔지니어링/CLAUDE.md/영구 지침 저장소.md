# 영구 지침 저장소

출처에서 **영구 지침 저장소(Persistent Instruction Repository)**로서의 `CLAUDE.md`는 단순한 설정 파일이나 문서를 넘어, 세션이 종료되면 사라지는 단기 대화 맥락을 보완하고 프로젝트와 조직의 지식을 세션을 넘어 유지해 주는 **지속성 레이어(Persistence Layer)** 역할을 수행합니다.

---

## 1. 다단계 계층구조와 가산적 로드 체계 (Hierarchy & Additive Loading)

영구 지침 저장소는 적용 범위와 우선순위에 따라 다단계 계층구조로 구성되며, Claude Code 실행 시 모든 상위 저장소의 지침이 **가산적(Additive)**으로 중첩되어 자동 로드됩니다.

1. **조직/시스템 수준 (Managed / System Directory)**
   - macOS의 `/Library/Application Support/ClaudeCode/CLAUDE.md`나 Linux의 `/etc/claude-code/CLAUDE.md` 위치에 배포됩니다.
   - 개별 개발자나 프로젝트 설정으로 오버라이드할 수 없으며, 조직 차원의 보안 정책, 규정 준수 규칙, 범조직 코딩 표준을 영구 보관합니다.
2. **사용자 수준 (User Scope)**
   - `~/.claude/CLAUDE.md`(사용자 홈 디렉터리)에 위치합니다.
   - 특정 프로젝트에 국한되지 않고, 개인 개발자가 선호하는 주력 언어, 코딩 스타일, 커밋 메시지 작성 규칙 등을 전역 영구 저장소로 보유합니다.
3. **프로젝트 수준 (Project Root Scope)**
   - 리포지토리 루트의 `CLAUDE.md` 파일로, 버전 관리 시스템(VCS)에 커밋되어 팀 전체가 공유합니다.
   - 프로젝트 고유의 빌드/테스트 명령, 아키텍처 제약, 환경 특이점 등 지속적으로 필요한 지침을 저장합니다.
4. **하위 디렉터리 수준 (Subdirectory Scope)**
   - 특정 하위 디렉터리 내에 작성되며, 에이전트가 해당 모듈/디렉터리 영역에서 작업할 때 국소 지침 저장소로 추가 반영됩니다.

---

## 2. 컨텍스트 효율성과 지침 저장소 관리 체계

`CLAUDE.md`에 담긴 모든 지침은 매 요청(turn)마다 시스템 프롬프트를 통해 로드되므로, 컨텍스트 예산 관리가 핵심 품질 요소로 작용합니다.

- **@path 임포트 시스템을 통한 모듈화**: 루트 영구 저장소를 슬림하게 유지하면서 깊이 있는 아키텍처 가이드나 API 규격을 제공하기 위해 `@docs/architecture.md` 같은 참조 임포트 문법을 사용합니다.
- **500줄 가이드라인과 콤팩트 지침 (Compact Instructions)**: 영구 지침 저장소가 500줄을 초과하면 지침 간의 주의력(attention) 분산 및 경합이 발생합니다. 컨텍스트 사용량이 한계에 도달해 **자동 축소(Auto-compaction)**가 발동될 때도 반드시 보존되어야 하는 핵심 규칙은 `Compact Instructions` 헤더 하위에 배치하여 손실을 방지합니다.
- **반복 에러 패치 (Targeted Error Patching)**: 에이전트가 폐기된 모듈 경로를 참조하는 등 프로젝트 내에서 반복 실수를 할 경우, 해당 에러에 대한 직접 수선 지침을 영구 저장소에 추가함으로써 동일 실수의 재발을 영구 차단합니다.

---

## 3. 제도적 기억(Institutional Memory)과 지식의 복리 성장 (Compounding)

- **세션 종료 업데이트 루프 (End-of-Session Updates)**: 세션이 끝날 때마다 Claude에게 "이번 작업에서 새로 파악한 프로젝트 특이사항이나 해결책을 `CLAUDE.md`에 제안해달라"고 요청합니다.
- **조직 지식의 복리 효과**: 원래 선임 엔지니어의 머릿속에만 파편화되어 있던 노하우(예: 특정 테스트 DB 포트 번호, 미세한 라이브러리 버그 워크어라운드)가 영구 지침 저장소로 문서화되고 리포지토리에 커밋됩니다. 이를 통해 한 개발자의 발견이 팀 전체의 맥락이 되며, 새로운 세션이 시작될 때마다 에이전트의 수행 능력이 **복리로 성장(Compounding)** 하게 됩니다.

---

## 4. 확장된 영구 지침 저장소 스펙트럼

출처에서는 `CLAUDE.md` 외에도 에이전트 생태계 전반을 관아우르는 영구 지침 저장소 패턴을 제시합니다:

- **AGENTS.md (이종 에이전트 간 오픈 표준)**: Claude Code뿐만 아니라 20개 이상의 다양한 AI 코딩 에이전트 도구가 함께 사용하는 오픈 표준 영구 지침 파일로, 도구 중독(Lock-in) 없이 팀 차원의 지침을 공유할 때 활용됩니다.
- **서브에이전트 지속성 메모리 (Subagent Persistent Memory)**: 특정 역할을 수행하는 서브에이전트 전용 저장소(`~/.claude/projects/{project}/agent-memory/{agent-name}/MEMORY.md`)로, 메인 세션의 컨텍스트를 더럽히지 않으면서 에이전트 고유의 노하우를 세션 간 유지합니다.

---

🛠️ `CLAUDE.md` 영구 저장소의 컨텍스트 비용을 제로(0)로 최적화해 주는 `disable-model-invocation: true` 스킬 설정법이나, 특정 이벤트 발생 시 자동으로 동적 컨텍스트를 주입하는 `SessionStart` 훅 활용법에 대해서도 살펴볼까요?
