# Claude Code 데스크톱 활용

10장은 Claude Code를 Claude 데스크톱 앱과 모바일 앱 안에서 쓰는 방법을 다룬다. 로컬 워크트리 모드와 클라우드 모드를 오가며 코딩 에이전트 여러 개를 병렬로 돌리고, 따로 자란 브랜치를 하나로 병합하는 과정을 HookHub 예제로 보여 준다. 순차적인 단일 작업에서 조율된 멀티 에이전트 작업으로 넘어가는 감각을 익히는 것이 목표다.

---

## 1. 핵심 요점

- 데스크톱 앱의 Code 탭은 터미널 버전과 같은 엔진과 설정(CLAUDE.md, MCP 서버, 훅)을 공유한다.
- 로컬 워크트리 모드는 내 컴퓨터에서만 돌고, 클라우드 모드는 Anthropic 컨테이너에서 저장소를 복제해 커밋과 풀 리퀘스트까지 처리한다.
- 깃 워크트리는 에이전트마다 별도 브랜치와 디렉터리를 줘서 서로 간섭하지 않게 하고, 마음에 안 들면 지우면 흔적이 남지 않는다.
- 시연에서는 연구, UI 애니메이션, 히어로 재설계 세 작업을 로컬 둘과 클라우드 하나로 동시에 진행했다.
- 병합은 임시 통합 브랜치에서 하고 충돌을 푼 뒤, 로컬에서 실행해 본 다음에 푸시를 승인한다.
- 모바일 앱에서도 같은 흐름이 되며 모든 실행은 클라우드에서 일어난다. 기본 클라우드 구성에는 MCP 서버, 훅, 출력 스타일이 없다.
- 병렬 에이전트는 독립적이고 범위가 분명한 작업에서 잘 맞는다. 얽힌 기능, 공유 상태, 작은 작업, 높은 조율 비용, 탐색적 작업에서는 역효과가 난다.
