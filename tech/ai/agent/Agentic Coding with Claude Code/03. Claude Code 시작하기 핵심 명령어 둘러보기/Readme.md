# Claude Code 시작하기 핵심 명령어 둘러보기

3장은 Claude Code를 일상 작업에 맞게 설정하는 장이다. 요금과 인증 방식을 고르고, 슬래시 명령으로 세션을 조종하고, 사용자와 프로젝트 수준의 설정을 나누고, IDE 안에서 쓰는 법을 본다. 그 위에 긴 작업을 안전하고 일관되게 만드는 훅, 메모리(CLAUDE.md), 되감기, 스킬 기반 사용자 지정 명령을 실습으로 쌓는다.

---

## 1. 핵심 요점

- 인증 방식이 곧 결제 방식이다. API 키는 종량제, 구독은 월 정액, 서드파티 클라우드는 클라우드 업체가 청구한다.
- API 키에서는 `/cost`로 토큰 비용을, 구독에서는 `/usage`로 사용 현황을 본다. 키 노출과 에이전트 동시 실행에는 지출 한도로 대비한다.
- `/clear`와 `/compact`는 컨텍스트 부패를 막는 기본 도구이며, 설정은 사용자, 프로젝트, 로컬 세 층으로 겹쳐 적용된다.
- 훅은 정해진 시점(PreToolUse, PostToolUse, Notification, UserPromptSubmit, Stop)에 자동 실행되며, 실습에서는 Stop에 알림음 스크립트를 연결한다.
- 메모리는 CLAUDE.md 파일로 관리한다. 관리형 정책, 사용자, 프로젝트, 규칙, 로컬의 다섯 단계로 우선순위가 정해지고, 위쪽은 탐색하며 아래쪽은 지연 로딩한다.
- `#`로 메모리를 더하고 `/init`으로 기존 코드베이스에서 CLAUDE.md를 만든다.
- 되감기는 체크포인트로 코드와 대화를 되돌리는 안전망이다. Bash 명령과 외부 수정은 못 되돌리므로 Git을 대신하지 못한다.
- 스킬은 `.claude/skills/이름/SKILL.md`로 정의하고, 인자를 받으며, `allowed-tools`로 최소 권한을 줄 수 있다.
