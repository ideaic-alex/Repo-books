# 출력 스타일과 상태줄 사용자 지정

8장은 Claude Code가 사용자와 소통하는 방식을 소비하는 데서 설계하는 데로 옮겨 가는 장이다. 출력 스타일(Claude Code가 답을 어떤 모양과 말투로 내놓을지 정하는 설정 파일)로 응답 구조와 워크플로를 정하고, 상태줄(터미널 아래에 늘 떠 있는 정보 한 줄)을 스크립트로 만들어 세션 상태를 보이게 한다. 마지막에는 이 둘로 역할이 다른 여러 세션을 팀처럼 운용하는 구상을 소개한다.

---

## 1. 핵심 요점

- 출력 스타일은 마크다운 파일 하나로 정의하며, 사용자 범위와 프로젝트 범위 두 곳에 둘 수 있다.
- 스타일을 고르면 기본 소프트웨어 엔지니어링 지침이 스타일 지침으로 바뀐다. 모델은 같고 시스템 프롬프트만 달라진다.
- YAML 형식 응답은 들여쓰기와 키 구조로 의존 관계, 범위, 우선순위를 담아서 순차 나열과 다른 사고를 유도한다.
- 스타일에 "HTML 파일로 저장하고 브라우저로 열어라" 같은 워크플로를 적으면 매번 지시하지 않아도 된다.
- 같은 저장소에서 스타일이 다른 세션을 병렬로 띄워 리뷰, 설명, 디버그 같은 전용 세션을 만들 수 있다.
- 상태줄은 stdin으로 받은 JSON을 읽고 stdout으로 출력하는 스크립트이며, 현재 스타일과 마지막 사용자 프롬프트를 보여 줄 수 있다.
- 마지막 프롬프트는 `transcript_path`가 가리키는 JSONL 기록에서 사용자 메시지만 걸러 찾는다.
- 이름, 스타일, 컨텍스트를 가진 여러 인스턴스를 전문 팀원처럼 쓰는 구상이 에이전틱 코딩의 다음 모습으로 제시된다.
