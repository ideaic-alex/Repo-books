# 온보딩과 CLAUDE.md 데이터 카탈로그

큰 코드베이스에서 Claude Code가 가장 가치 있게 쓰이는 곳 중 하나는 코드를 쓰는 일이 아니다. 새 팀원이 시스템을 익히도록 돕는 일이다. 이 문서는 코드베이스 탐색을 통한 온보딩과, 한 데이터 인프라 팀이 CLAUDE.md를 기존 데이터 카탈로그 대신 쓴 사례를 설명한다.

---

## 1. 전통적인 온보딩의 문제

큰 프로젝트에 합류한 새 팀원은 보통 몇 주의 온보딩을 거친다.

- 일부는 낡은 문서를 읽는다.
- 동료에게 질문해서 한창 일하는 사람을 방해한다.
- 파일을 반쯤 무작위로 열어 보며 코드를 탐색한다.
- 시간이 쌓이면서 어느새 스며들 듯 머릿속 모델을 천천히 만든다.

## 2. Claude Code로 온보딩 시간을 줄인다

새 개발자는 세션을 시작해서 코드베이스에 대해 바로 질문할 수 있다. 원문이 드는 질문의 예는 이렇다.

- 이 시스템에서 인증은 어떻게 동작하는가
- 결제 처리 로직은 어디에 있고 어떤 외부 서비스를 호출하는가
- Order 모듈과 Fulfillment 모듈은 어떤 관계인가
- 이 프로젝트에 데이터베이스 커넥션 풀이 두 종류인 이유는 무엇인가

Claude Code는 Explore 서브에이전트를 보내 관련 코드를 읽고, 실제 코드베이스에 근거한 답을 준다. 낡았을 수도 있는 문서에 근거하지 않는다. 답은 특정 파일, 특정 함수, 특정 패턴을 가리키고, 코드만큼 최신이다.

## 3. 무엇을 대체하고 무엇은 대체하지 못하는가

이 방식은 온보딩 질문의 상당 부분에서 데이터 카탈로그, 아키텍처 위키, 동료에게 묻는 일을 대신한다. 온보딩에 필요한 사람 사이의 관계와 문화적 맥락까지 대신하지는 않는다. 다만 "이 코드가 어떻게 동작하나?" 같은 질문에서는 Claude Code가 어떤 사람 멘토보다 빠르고 정확하고 참을성이 있다는 것이 원문의 평가다.

잘 가꾼 CLAUDE.md가 있는 팀은 이 효과가 더 커진다. 새 개발자는 Claude Code의 탐색에서 나온 코드 기반 답변과 CLAUDE.md에 담긴 조직의 지식을 함께 얻는다. 이 조합은 수작업으로 제공하려면 시니어 엔지니어의 몇 주를 써야 했을 온보딩 경험이다.

---

## 4. CLAUDE.md가 데이터 카탈로그를 대체한 사례

CLAUDE.md의 뜻밖의 쓰임새가 하나 있다. 코드 스타일이나 빌드 명령과는 무관하다. 한 데이터 인프라 팀이 CLAUDE.md 파일로 온보딩용 기존 데이터 카탈로그와 탐색 도구를 대체할 수 있음을 발견했다.

새 데이터 사이언티스트가 합류하면 Claude Code로 방대한 코드베이스를 탐색하도록 안내했다. Claude Code는 다음 일을 했다.

- CLAUDE.md 파일을 읽는다.
- 특정 작업에 관련된 파일을 찾아 낸다.
- 데이터 파이프라인 의존성을 설명한다.
- 어느 상위 데이터 소스가 어느 대시보드로 이어지는지 이해하도록 돕는다.

전통적으로 별도 데이터 카탈로그 도구에 있던 정보는 아무도 갱신을 기억하지 않아 늘 낡아 있었다. 이제 그 정보가 코드 옆에 있고, Claude Code의 일반적인 작업 흐름 속에서 함께 관리된다.

## 5. 지속적 개선 루프

이 팀은 반복 루프로 이것을 강화했다. 작업 세션이 끝날 때마다 Claude에게 완료한 작업을 요약하고 개선점을 제안하게 했다. 대상은 코드만이 아니다. CLAUDE.md 문서와 작업 흐름 지침 자체도 포함된다. 세션마다 프로젝트의 조직 지식이 다듬어졌다. CLAUDE.md는 한 번 하고 다시는 반복되지 않을 문서화 스프린트가 아니라 실제 사용에서 자연스럽게 자랐다.

## 6. 왜 잘 동작하는가

CLAUDE.md는 모든 세션의 시작에 충실하게 읽힌다. 6개월 묵은 위키 페이지와 달리, CLAUDE.md는 마지막으로 갱신한 세션만큼 최신이다. 데이터 모델이 코드만큼 복잡한 대규모 코드베이스에서는, 어떤 테이블이 어떤 중간 변환을 거쳐 어떤 대시보드로 이어지는지 아는 것이 핵심 지식이다. CLAUDE.md는 전통적인 도구가 지향하지만 좀처럼 이루지 못하는 살아 있는 데이터 카탈로그가 된다.

## 7. 정리

- 새 팀원은 Claude Code에게 코드베이스에 대해 직접 질문하며 온보딩 시간을 줄일 수 있다.
- 답변은 실제 코드에 근거하므로 문서보다 최신이다.
- 사람 사이의 관계와 문화적 맥락은 대체되지 않는다.
- CLAUDE.md는 세션 끝마다 개선하면 데이터 카탈로그를 대신하는 살아 있는 문서가 된다.
