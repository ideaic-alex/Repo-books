# 환경 변수 참조

Claude Code는 70개가 넘는 환경 변수를 지원한다. 이 문서는 그중 가장 자주 쓰는 것을 기능별로 묶어 정리한다. API 연결, 모델, 프록시, 컨텍스트 압축, 기능 플래그, 헤드리스와 CI, 출력, 디버깅, 세션 동작, 텔레메트리 순서다.

환경 변수는 셸에서 직접 지정해도 되고, settings.json의 `env` 키로 주입해도 된다. 헤드리스(headless) 모드는 화면 없이 터미널이나 CI에서 실행하는 방식이다.

---

## 1. API와 인증

| 변수 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic에 직접 접근할 때 쓰는 API 키 |
| `CLAUDE_CODE_USE_BEDROCK` | 클라우드 제공자 Bedrock 연동을 켠다 (값 1) |
| `CLAUDE_CODE_USE_VERTEX` | 클라우드 제공자 Vertex AI 연동을 켠다 (값 1) |
| `ANTHROPIC_BASE_URL` | API 기본 URL을 바꾼다 |
| `CLAUDE_CODE_AUTH_TOKEN` | 인증 토큰을 덮어쓴다 |

## 2. 모델 설정

| 변수 | 설명 |
|---|---|
| `ANTHROPIC_MODEL` | 기본 모델을 덮어쓴다 |
| `ANTHROPIC_SMALL_FAST_MODEL` | 가벼운 작업(Haiku 급 작업)에 쓸 모델 |
| `CLAUDE_CODE_MAX_TOKENS` | 응답 하나당 최대 토큰 수 |
| `CLAUDE_CODE_MAX_THINKING_TOKENS` | 생각(추론)에 쓸 최대 토큰 수 |

## 3. 프록시와 네트워크

| 변수 | 설명 |
|---|---|
| `HTTP_PROXY` / `HTTPS_PROXY` | HTTP(S) 프록시 URL |
| `NO_PROXY` | 프록시를 거치지 않을 도메인 목록 (쉼표로 구분) |
| `ANTHROPIC_PROXY_URL` | Anthropic 전용 프록시 URL |

## 4. 컨텍스트와 압축

| 변수 | 설명 |
|---|---|
| `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` | 자동 압축(auto-compaction)이 시작되는 기준 비율. 기본값 95 |
| `CLAUDE_CODE_CONTEXT_LIMIT` | 컨텍스트 윈도의 최대 크기 |

자동 압축은 컨텍스트 윈도가 어느 정도 차면 대화를 요약해 공간을 비우는 기능이다. 기본값 95는 윈도가 95% 찼을 때 시작한다는 뜻이다. 이 값을 낮추면 더 일찍 압축이 시작된다.

## 5. 기능 플래그

| 변수 | 설명 |
|---|---|
| `ENABLE_TOOL_SEARCH` | MCP 도구 검색과 지연 로딩(deferred loading)을 켜거나 끈다 |
| `CLAUDE_CODE_ENABLE_AGENT_TEAMS` | 실험 기능인 에이전트 팀을 켠다 |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` | 텔레메트리와 필수가 아닌 네트워크 호출을 끈다 |

## 6. 헤드리스와 CI

| 변수 | 설명 |
|---|---|
| `CLAUDE_CODE_ENTRYPOINT` | 헤드리스 환경에서는 `cli`로 지정한다 |
| `CLAUDE_CODE_BUDGET_TOKENS` | 헤드리스 세션의 토큰 예산 |
| `CLAUDE_CODE_MAX_TURNS` | 헤드리스 모드에서 허용하는 최대 대화 턴 수 |

토큰 예산과 최대 턴 수는 화면 없이 도는 세션의 사용량 상한을 정하는 변수다.

## 7. 출력과 포맷

| 변수 | 설명 |
|---|---|
| `CLAUDE_CODE_OUTPUT_FORMAT` | 헤드리스 모드의 출력 형식. `text`, `json`, `stream-json` |
| `CLAUDE_CODE_HIDE_TOOL_OUTPUT` | 터미널에 도구 출력이 표시되지 않게 숨긴다 |

## 8. 디버깅과 진단

| 변수 | 설명 |
|---|---|
| `CLAUDE_CODE_DEBUG` | 디버그 로그를 켠다 (값 1) |
| `CLAUDE_CODE_LOG_LEVEL` | 로그 상세 수준을 정한다 |
| `CLAUDE_CODE_VERBOSE` | 자세한 출력을 켠다 |

## 9. 세션과 동작

| 변수 | 설명 |
|---|---|
| `CLAUDE_CODE_SKIP_CLAUDE_MD` | CLAUDE.md 파일을 불러오지 않는다 (값 1) |
| `CLAUDE_CODE_THINKING_MODE` | 생각 모드. `enabled`, `disabled`, `budget` |
| `CLAUDE_CODE_THINKING_BUDGET` | 확장 생각(extended thinking)에 쓸 토큰 예산 |

## 10. 텔레메트리

| 변수 | 설명 |
|---|---|
| `CLAUDE_CODE_DISABLE_TELEMETRY` | 사용 텔레메트리를 끈다 (값 1) |
| `CLAUDE_CODE_TELEMETRY_ENDPOINT` | 텔레메트리를 수집할 엔드포인트를 직접 지정한다 |

텔레메트리를 끄는 방법은 두 가지가 있다. `CLAUDE_CODE_DISABLE_TELEMETRY`는 사용 텔레메트리만 끄고, 기능 플래그 절의 `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`는 텔레메트리와 필수가 아닌 네트워크 호출까지 함께 끈다.
