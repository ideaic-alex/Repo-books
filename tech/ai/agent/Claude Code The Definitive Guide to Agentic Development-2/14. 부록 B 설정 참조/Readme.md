# 부록 B 설정 참조

Claude Code를 설정할 때 찾아보는 참조 부록이다. settings.json의 키, 설정 범위와 우선순위, 환경 변수, 도구 목록, 훅 스키마, MCP 설정 형식을 표로 정리한다. 처음부터 읽는 장이 아니라 필요한 항목을 찾아보는 용도다.

이 노트에서는 원문의 표를 기능별 문서로 다시 묶고, 키마다 왜 필요한지와 함께 쓰는 키의 관계를 풀어 적었다.

---

## 1. 핵심 요점

- **스키마 한 줄**: settings.json에 `$schema`를 넣으면 에디터가 자동완성과 검증을 해 준다.
- **권한 평가 순서**: Deny, Ask, Allow 순으로 보고 모든 범위를 통틀어 처음 일치한 규칙이 이긴다.
- **다섯 개의 범위**: Managed, CLI, Local, Project, User 순으로 강하다. 권한 규칙은 덮어쓰기가 아니라 평가 순서를 따른다.
- **샌드박스와 deny 규칙의 병행**: 샌드박스로 bash 실행 범위를 좁히고, 비밀 파일은 deny 규칙으로 따로 막는다.
- **관리자 전용 키**: 훅, 권한 규칙, MCP 서버, 마켓플레이스를 조직 차원에서 잠글 수 있다.
- **환경 변수 70개 이상**: API, 모델, 프록시, 압축, 헤드리스, 디버깅, 텔레메트리 등으로 묶인다.
- **훅의 세 핸들러**: command, prompt, agent가 있고, 종료 코드 2는 차단, 0은 성공이다.
- **MCP 설정**: `.mcp.json`에서 로컬은 `command`, 원격은 `url`을 쓰고 비밀 값은 `${VAR}`로 참조한다.
