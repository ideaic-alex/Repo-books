# 키보드 단축키와 여러 줄 입력

Claude Code의 입력 창에서 쓰는 단축키와, 프롬프트를 여러 줄로 쓰는 방법을 정리한다. 마우스 없이 터미널에서 일하는 도구이다 보니 단축키를 익히면 속도 차이가 크다.

부록 A는 단축키를 탐색과 제어, 세션과 모델, 도구와 출력의 세 묶음으로 나눈다. 여기서도 같은 순서로 보되, 모드 전환처럼 앞선 문서와 이어지는 내용은 연결해서 설명한다.

---

## 1. 탐색과 제어

| 단축키 | 동작 |
|--------|------|
| Enter | 프롬프트 전송 또는 확인 |
| Ctrl+C | 현재 입력이나 생성을 취소 |
| Ctrl+D | Claude Code 세션 종료 |
| Up / Down | 프롬프트 기록 탐색 |
| Left / Right | 권한 대화상자와 메뉴에서 탭 전환 |
| Esc Esc (두 번) | 되돌리기(rewind) 메뉴를 연다. 코드나 대화를 복원하거나, 선택한 메시지부터 요약한다 |
| Shift+Tab | 권한 모드 순환 (plan, default, auto-edit, full-auto 순서이며, 에이전트 팀이 켜져 있으면 delegate 모드도 포함) |

Ctrl+C는 입력 중인 글이나 진행 중인 생성을 멈추는 키이고, 세션 자체를 끝내는 키는 Ctrl+D다. 둘을 헷갈리지 않도록 구분해서 기억해야 한다.

Esc를 두 번 누르면 열리는 되돌리기 메뉴는 슬래시 명령 `/rewind`와 같은 기능이다. 잘못된 방향으로 작업이 진행됐을 때 코드와 대화를 이전 시점으로 돌릴 수 있고, 선택한 메시지부터 요약하는 선택지도 있다.

Shift+Tab은 권한 모드를 한 칸씩 넘긴다. 순서는 플랜 모드, 기본, 자동 편집 허용, 전체 자동 허용이며, 에이전트 팀이 활성화되어 있을 때는 위임(delegate) 모드가 순환에 끼어든다.

## 2. 세션과 모델

| 단축키 | 동작 |
|--------|------|
| Alt+P / Option+P | 입력 중인 프롬프트를 지우지 않고 모델을 바꾼다 |
| Alt+T / Option+T | 확장 사고(extended thinking) 모드를 켜고 끈다 (먼저 `/terminal-setup` 실행) |

Alt+P의 장점은 프롬프트를 쓰다가 "이건 더 강한 모델로 돌려야겠다" 싶을 때 입력을 날리지 않고 모델만 바꿀 수 있다는 점이다. Alt+T는 확장 사고 모드를 토글하는데, 터미널이 이 키 조합을 제대로 넘기도록 `/terminal-setup`을 먼저 실행해야 한다.

## 3. 도구와 출력

| 단축키 | 동작 |
|--------|------|
| Ctrl+R | 명령 기록을 거꾸로 검색한다 |
| Ctrl+G | 프롬프트를 기본 텍스트 편집기에서 편집한다 |
| Ctrl+O | 도구 사용과 실행 내용을 자세히 보여 주는 verbose 출력을 켜고 끈다 |
| Ctrl+B | 실행 중인 작업을 백그라운드로 보낸다 (tmux 사용자는 두 번 눌러야 한다) |
| Ctrl+T | 작업 목록 표시를 켜고 끈다 (터미널 상태 영역에 최대 10개) |
| Ctrl+L | 터미널 화면을 지운다 (대화 기록은 유지) |
| Ctrl+V / Cmd+V (iTerm2) / Alt+V (Windows) | 클립보드의 이미지를 붙여 넣는다 |

### 3.1 Ctrl+R 기록 검색

검색어를 입력하면 일치하는 기록이 나타난다. 이때 키별 동작은 다음과 같다.

- Ctrl+R을 다시 누르면 다음 일치 항목으로 넘어간다.
- Tab 또는 Esc를 누르면 그 항목을 입력 창에 가져와 수락한다.
- Enter를 누르면 수락하고 곧바로 실행한다.
- Ctrl+C를 누르면 검색을 취소한다.

### 3.2 화면과 입력 보조

Ctrl+L은 화면만 깨끗하게 지우고 대화 기록은 지우지 않는다. 대화까지 지우려면 `/clear`를 써야 한다. Ctrl+G는 긴 프롬프트를 평소 쓰는 편집기에서 작성하고 싶을 때 쓴다. Ctrl+O는 Claude가 어떤 도구를 어떻게 썼는지 상세하게 보고 싶을 때 켠다.

### 3.3 Ctrl+B와 tmux

Ctrl+B는 실행 중인 작업을 백그라운드로 밀어 보낸다. tmux의 기본 접두 키도 Ctrl+B이기 때문에, tmux 안에서는 두 번 눌러야 Claude Code에 전달된다. 백그라운드 작업의 동작은 「배시 모드와 백그라운드 작업」 문서에서 이어서 다룬다.

### 3.4 이미지 붙여넣기

이미지 붙여넣기는 운영체제와 터미널마다 키가 다르다. 기본은 Ctrl+V이고, iTerm2에서는 Cmd+V, Windows에서는 Alt+V를 쓴다.

## 4. 여러 줄 입력 방법

프롬프트를 여러 줄로 쓰려면 Enter가 아닌 다른 방법으로 줄을 바꿔야 한다. Enter는 전송 키이기 때문이다.

| 방법 | 단축키 | 적용 환경 |
|------|--------|-----------|
| 빠른 탈출 | `\` + Enter | 모든 터미널에서 동작 |
| macOS 기본 | Option+Enter | macOS 기본값 |
| Shift+Enter | Shift+Enter | iTerm2, WezTerm, Ghostty, Kitty에서 바로 동작 |
| 제어 시퀀스 | Ctrl+J | 줄바꿈 문자로 여러 줄 입력 |
| 붙여넣기 모드 | 그대로 붙여넣기 | 코드 블록, 로그를 자동 감지 |

가장 확실한 방법은 줄 끝에 `\`를 쓰고 Enter를 누르는 것이다. 어떤 터미널에서든 동작한다. Shift+Enter가 가장 자연스럽지만 기본으로 지원하는 터미널이 정해져 있다. 목록에 없는 터미널, 즉 VS Code 터미널, Alacritty, Zed, Warp에서는 `/terminal-setup`을 실행해 Shift+Enter 바인딩을 설치해야 한다.

긴 코드나 로그를 그대로 붙여 넣으면 붙여넣기 모드가 자동으로 알아차려서 줄바꿈이 전송으로 처리되지 않는다.

## 5. 자주 쓰는 조합 요약

- 계획만 먼저 세우고 싶다: Shift+Tab으로 플랜 모드로 순환한다.
- 방향이 틀어졌다: Esc를 두 번 눌러 되돌린다.
- 오래 걸리는 작업이 시작됐다: Ctrl+B로 백그라운드로 보낸다.
- 지난 프롬프트를 다시 쓰고 싶다: Ctrl+R로 검색한다.
- 터미널에서 줄바꿈이 안 된다: `/terminal-setup`을 실행한다.
