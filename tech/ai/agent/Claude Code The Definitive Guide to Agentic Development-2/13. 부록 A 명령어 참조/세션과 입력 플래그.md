# 세션과 입력 플래그

CLI 플래그 중에서 세션을 이어 가고, 모델과 에이전트를 고르고, 권한 모드를 정하는 옵션을 모았다. 부록 A에서는 "Session and Input" 묶음에 해당한다.

플래그는 `claude` 뒤에 붙여서 시작 방식을 바꾸는 옵션이다. 같은 `claude`라도 어떤 플래그를 붙이느냐에 따라 이전 대화를 복사해서 갈라질 수도 있고, 특정 PR에 연결된 세션으로 돌아갈 수도 있다.

---

## 1. 플래그 일람

| 플래그 | 설명 |
|--------|------|
| `--continue`, `-c` | 가장 최근 대화를 이어 간다 |
| `--resume`, `-r <id>` | 세션을 ID 또는 이름으로 다시 연다 |
| `--fork-session` | 대화 기록을 유지한 채 새 세션 ID를 만든다 (`--resume` 또는 `--continue`와 함께 사용) |
| `--from-pr <number>` | 특정 pull request에 연결된 세션을 다시 연다. PR 번호나 URL을 받는다 |
| `--session-name <name>` | 현재 세션에 이름을 붙인다 |
| `--model <model>` | 기본 모델을 덮어쓴다 |
| `--agent <name>` | 커스텀 에이전트를 메인 스레드로 실행한다 (agent 설정보다 우선) |
| `--agents <json>` | JSON으로 커스텀 서브에이전트를 동적으로 정의한다 |
| `--permission-mode <mode>` | 권한 모드를 정한다 (default, plan, auto-edit, full-auto, bypassPermissions) |
| `--teleport` | 웹 세션을 로컬 터미널에서 다시 연다 |
| `--teammate-mode <mode>` | 에이전트 팀의 표시 방식을 정한다 (auto가 기본, in-process, tmux) |

## 2. 세션 이어 가기와 갈라지기

### 2.1 `--continue`와 `--resume`

`-c`는 가장 최근 대화, `-r`은 ID나 이름으로 고른 대화를 이어 간다. CLI 명령어 문서에서 본 것과 같은 기능이다.

### 2.2 `--fork-session`

세션을 이어 가되 원래 세션을 건드리고 싶지 않을 때 쓴다. 이 플래그를 붙이면 기존 대화 기록은 그대로 가져오면서 새 세션 ID가 만들어진다. 즉 원본 세션은 그대로 남고, 복제본에서 다른 방향의 실험을 해 볼 수 있다. 단독으로는 쓰지 않고 `--resume`이나 `--continue`와 함께 쓴다.

```bash
claude --resume <id> --fork-session
claude -c --fork-session
```

### 2.3 `--from-pr <number>`

코드 리뷰 때처럼 어떤 pull request와 연결된 작업 세션이 있을 때, 그 PR 번호(또는 URL)로 세션을 찾아 다시 연다. 세션 ID를 외우지 않아도 PR을 기준으로 맥락을 되살릴 수 있다.

### 2.4 `--session-name <name>`

현재 세션에 이름을 붙인다. 이름을 붙여 두면 나중에 `claude -r <name>`으로 바로 돌아올 수 있다. 시작한 뒤에 이름을 바꾸고 싶다면 슬래시 명령 `/rename`을 쓴다.

## 3. 모델과 에이전트 고르기

### 3.1 `--model <model>`

기본 모델 대신 다른 모델로 이번 실행을 시작한다. 시작한 뒤에는 `/model`로 바꿀 수 있다.

### 3.2 `--agent <name>`

커스텀 에이전트를 메인 스레드, 즉 지금 대화를 이끄는 주체로 실행한다. 설정에 지정된 agent가 있어도 이 플래그가 우선한다.

### 3.3 `--agents <json>`

파일을 따로 만들지 않고 JSON 한 덩어리로 서브에이전트를 그 자리에서 정의한다. 일회성 실행이나 스크립트에서 서브에이전트 구성을 코드로 넘길 때 유용하다.

## 4. 권한 모드 지정

`--permission-mode <mode>`는 시작할 때의 권한 모드를 정한다. 쓸 수 있는 값은 default, plan, auto-edit, full-auto, bypassPermissions 다섯 가지다. 각 모드의 동작은 「권한 플래그와 권한 모드」 문서에서 자세히 정리한다.

```bash
claude --permission-mode plan
```

## 5. 웹과 팀 관련 옵션

### 5.1 `--teleport`

웹에서 시작한 세션을 로컬 터미널로 가져와 이어 간다. 슬래시 명령 `/teleport`와 짝을 이루는 기능이다.

### 5.2 `--teammate-mode <mode>`

여러 에이전트가 팀을 이룰 때 화면에 어떻게 보여 줄지 정한다. 값은 세 가지다.

- `auto`: 기본값이다.
- `in-process`: 같은 프로세스 안에서 표시한다.
- `tmux`: tmux 창으로 나누어 표시한다.
