# 배시 모드와 백그라운드 작업

Claude를 거치지 않고 셸 명령을 바로 실행하는 배시 모드(`!` 접두), 오래 걸리는 명령을 뒤로 보내는 백그라운드 실행, 다음 프롬프트를 추천해 주는 프롬프트 제안, 복잡한 작업을 추적하는 작업 목록을 다룬다. 모두 터미널 작업 흐름을 매끄럽게 만드는 기능이다.

이 중 백그라운드 작업과 프롬프트 제안은 환경 변수로 끌 수 있고, 작업 목록은 환경 변수로 세션 간에 공유할 수 있다. 각 환경 변수가 무엇을 하는지도 함께 정리한다.

---

## 1. 배시 모드: `!` 접두

입력 맨 앞에 `!`를 붙이면 Claude가 해석하지 않고 셸 명령을 그대로 실행한다.

```bash
! npm test
! git status
! ls -la
```

### 1.1 특징

- 명령의 출력이 대화 컨텍스트에 추가된다. 그래서 실행 직후 "이 결과를 보고 고쳐 줘"라고 바로 이어 말할 수 있다.
- 진행 상황과 출력을 실시간으로 보여 준다.
- Claude가 명령을 해석하거나 승인할 필요가 없다. 사용자가 직접 입력한 명령이기 때문이다.
- 오래 걸리는 명령은 Ctrl+B로 백그라운드에 보낼 수 있다.
- 기록 기반 자동 완성이 된다. 명령 앞부분만 입력하고 Tab을 누르면, 현재 프로젝트에서 이전에 `!`로 실행한 명령 중에서 완성해 준다.

### 1.2 언제 쓰나

`git status`처럼 결과만 확인하면 되는 짧은 명령이나, 테스트를 돌려 그 결과를 Claude에게 보여 주고 싶을 때 쓴다. Claude에게 "git status 실행해 줘"라고 시키면 해석과 승인 과정을 거치지만, `!`는 그 과정을 건너뛰어 빠르다.

## 2. 백그라운드 배시 명령

Claude Code는 배시 명령을 백그라운드로 돌릴 수 있다. 이 경우 고유한 작업 ID를 즉시 돌려주고, 명령은 비동기로 계속 실행된다. 그 사이 Claude와 사용자는 다른 일을 이어 갈 수 있다.

### 2.1 백그라운드로 보내는 방법

- Claude에게 명령을 백그라운드로 실행해 달라고 프롬프트로 요청한다.
- 이미 실행 중인 배시 호출을 Ctrl+B로 백그라운드로 옮긴다. tmux 사용자는 Ctrl+B를 두 번 누른다.

### 2.2 동작 방식

- 출력은 버퍼에 쌓이고, Claude가 `TaskOutput` 도구로 가져온다.
- 각 백그라운드 작업은 추적과 조회를 위한 고유 ID를 가진다.
- Claude Code가 종료되면 작업은 자동으로 정리된다.

### 2.3 흔히 백그라운드로 보내는 명령

| 분류 | 예 |
|------|----|
| 빌드 도구 | webpack, vite, make |
| 패키지 관리자 | npm, yarn |
| 테스트 러너 | jest, pytest |
| 개발 서버 | 계속 떠 있어야 하는 서버 프로세스 |
| 오래 걸리는 프로세스 | docker, terraform |

### 2.4 끄는 방법

환경 변수 `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`을 설정하면 이 기능이 꺼진다. 실행 중인 백그라운드 작업을 확인하고 관리하려면 슬래시 명령 `/tasks`를 쓴다.

## 3. 프롬프트 제안

Claude가 응답을 마치면, 대화 기록과 git 기록을 바탕으로 한 회색 추천 문장이 입력 창에 나타난다.

### 3.1 사용법

- Tab을 누르면 제안을 입력 창에 채워 넣고, Enter를 누르면 수락과 동시에 전송한다.
- 다른 글자를 입력하기 시작하면 제안이 사라진다.

### 3.2 비용과 제약

제안은 백그라운드 요청으로 만들어지며 프롬프트 캐시를 재사용하므로 추가 비용이 거의 없다. 다만 다음 경우에는 건너뛴다.

- 캐시가 식어 있을 때(cold)
- 첫 번째 턴과 관련된 경우(원문은 "after the first turn"이라고만 적어 정확한 조건이 모호하다)
- 비대화형 모드일 때
- 플랜 모드일 때

### 3.3 끄는 방법

환경 변수 `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false`를 설정하거나, `/config`에서 토글한다.

## 4. 작업 목록

Claude는 여러 단계로 이뤄진 복잡한 작업을 할 때 작업 목록을 만들고, 이 목록은 터미널 상태 영역에 보인다.

- Ctrl+T로 목록 표시를 켜고 끈다. 최대 10개 작업이 표시된다.
- Claude에게 직접 부탁해서 모든 작업을 보거나 지울 수 있다.
- 작업 목록은 컨텍스트 압축(compaction)을 거쳐도 유지된다. 대화가 압축되어도 해야 할 일의 진행 상황을 잃지 않는다는 뜻이다.
- 환경 변수로 세션 간에 작업 목록을 공유할 수 있다.

```bash
CLAUDE_CODE_TASK_LIST_ID=my-project claude
```

같은 `CLAUDE_CODE_TASK_LIST_ID` 값으로 여러 세션을 띄우면 같은 작업 목록을 함께 쓴다.

## 5. 환경 변수 정리

| 환경 변수 | 효과 |
|-----------|------|
| `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` | 백그라운드 작업 기능을 끈다 |
| `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false` | 프롬프트 제안을 끈다 |
| `CLAUDE_CODE_TASK_LIST_ID=<이름>` | 여러 세션이 같은 작업 목록을 공유한다 |
