# 세션 선택기와 Vim 모드

세션 선택기(session picker)에서 쓰는 단축키와, 입력 창을 vim처럼 편집하게 해 주는 Vim 모드의 명령을 정리한다. 부록 A의 뒷부분에 해당하며, 마지막 부분에는 텍스트 객체(Text Objects) 표도 들어 있다.

세션이 많이 쌓이면 원하는 것을 찾는 일이 번거로워지고, 긴 프롬프트를 고칠 때는 편집 기능이 아쉬워진다. 두 기능이 각각 이를 해결한다.

---

## 1. 세션 선택기

슬래시 명령 `/resume`을 입력하거나, 인자 없이 `claude --resume`을 실행하면 대화형 세션 선택기가 열린다.

| 키 | 동작 |
|----|------|
| Up / Down | 세션 사이를 이동한다 |
| Left / Right | 묶인 세션 그룹을 펼치거나 접는다 |
| Enter | 강조된 세션을 선택해 다시 연다 |
| P | 세션 내용을 미리 본다 |
| R | 강조된 세션의 이름을 바꾼다 |
| / | 검색해서 세션을 거른다 |
| A | 현재 디렉터리와 모든 프로젝트 사이를 전환한다 |
| B | 현재 git 브랜치의 세션만 보여 준다 |
| Esc | 선택기 또는 검색 모드를 빠져나간다 |

### 1.1 찾는 요령

세션이 많을 때는 필터 키를 먼저 쓴다. A는 현재 디렉터리의 세션과 모든 프로젝트의 세션 사이를 오간다. B는 지금 작업 중인 git 브랜치에서 만든 세션만 남긴다. 기능 브랜치마다 작업 세션이 따로 있다면 B가 가장 빠르다. 내용이 헷갈리면 P로 미리 본 다음 Enter로 연다.

### 1.2 이름 바꾸기

선택기 안에서 R을 눌러 이름을 바꿀 수 있다. 이름을 붙여 두면 이후 `claude -r <name>`으로 곧바로 열 수 있다.

## 2. Vim 모드

`/vim` 명령으로 켜거나, `/config`에서 영구적으로 설정할 수 있다. 켜면 입력 창이 vim의 NORMAL 모드와 INSERT 모드를 갖는다. vim에 익숙한 사용자가 긴 프롬프트를 빠르게 고칠 수 있게 해 준다.

### 2.1 모드 전환

| 명령 | 동작 | 시작 모드 |
|------|------|-----------|
| Esc | NORMAL 모드로 들어간다 | INSERT |
| i | 커서 앞에서 삽입 | NORMAL |
| I | 줄 맨 앞에서 삽입 | NORMAL |
| a | 커서 뒤에서 삽입 | NORMAL |
| A | 줄 맨 끝에서 삽입 | NORMAL |
| o | 아래에 새 줄을 열고 삽입 | NORMAL |
| O | 위에 새 줄을 열고 삽입 | NORMAL |

### 2.2 이동 (NORMAL 모드)

| 명령 | 동작 |
|------|------|
| h/j/k/l | 왼쪽/아래/위/오른쪽으로 이동 |
| w | 다음 단어 |
| e | 단어 끝 |
| b | 이전 단어 |
| 0 | 줄의 시작 |
| $ | 줄의 끝 |
| ^ | 공백이 아닌 첫 글자 |
| gg | 입력의 시작 |
| G | 입력의 끝 |
| f{char} | 다음에 나오는 해당 글자로 점프 |
| F{char} | 이전에 나온 해당 글자로 점프 |
| t{char} | 다음에 나오는 해당 글자 바로 앞으로 점프 |
| T{char} | 이전에 나온 해당 글자 바로 뒤로 점프 |
| ; | 마지막 f/F/t/T 이동 반복 |
| , | 마지막 f/F/t/T 이동을 반대 방향으로 반복 |

NORMAL 모드에서 커서가 입력의 맨 앞이나 맨 끝에 있어 더 움직일 수 없으면, 화살표 키는 커서 이동 대신 명령 기록을 탐색한다. 즉 입력 창의 경계에서는 Up/Down이 이전 프롬프트를 불러오는 동작으로 바뀐다.

### 2.3 편집 (NORMAL 모드)

| 명령 | 동작 |
|------|------|
| x | 글자 삭제 |
| dd | 줄 삭제 |
| D | 줄 끝까지 삭제 |
| dw/de/db | 단어 삭제 / 단어 끝까지 / 뒤로 |
| cc | 줄 변경 |
| C | 줄 끝까지 변경 |
| cw/ce/cb | 단어 변경 / 단어 끝까지 / 뒤로 |
| yy/Y | 줄 복사(yank) |
| yw/ye/yb | 단어 복사 / 단어 끝까지 / 뒤로 |
| p | 커서 뒤에 붙여넣기 |
| P | 커서 앞에 붙여넣기 |
| >> | 줄 들여쓰기 |
| << | 줄 내어쓰기 |
| J | 줄 합치기 |
| . | 마지막 변경 반복 |

### 2.4 텍스트 객체

텍스트 객체는 d, c, y 같은 연산자 뒤에 붙여 쓰는 명령이다. `i`가 붙으면 구분자를 뺀 안쪽만, `a`가 붙으면 구분자까지 포함한 주변 전체를 대상으로 삼는다. 예를 들어 `ci"`는 큰따옴표 안쪽을 지우고 바로 입력 상태로 들어가고, `da(`는 괄호까지 함께 지운다.

| 명령 | 대상 |
|------|------|
| iw / aw | 단어 안쪽 / 단어 주변 |
| iW / aW | 공백으로 나뉘는 덩어리(WORD) 안쪽 / 주변 |
| i" / a" | 큰따옴표 안쪽 / 주변 |
| i' / a' | 작은따옴표 안쪽 / 주변 |
| i( / a( | 소괄호 안쪽 / 주변 |
| i[ / a[ | 대괄호 안쪽 / 주변 |
| i{ / a{ | 중괄호 안쪽 / 주변 |

긴 프롬프트에서 따옴표나 괄호로 묶인 부분만 고쳐 쓸 때 편하다.

## 3. 정리

세션 선택기는 키 하나로 보기 범위(현재 디렉터리, 모든 프로젝트, 현재 브랜치)를 바꿔 가며 세션을 찾는 도구이고, Vim 모드는 입력 창에 vim의 모드 전환, 이동, 편집, 복사 명령을 가져온 기능이다. 두 기능 모두 슬래시 명령(`/resume`, `/vim`)으로 바로 진입한다.
