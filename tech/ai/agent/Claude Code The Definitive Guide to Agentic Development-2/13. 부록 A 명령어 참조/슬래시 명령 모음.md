# 슬래시 명령 모음

대화형 세션 안에서 `/`로 시작하는 슬래시 명령을 입력하면 Claude Code 자체를 조작할 수 있다. 컨텍스트 정리, 모델 전환, 세션 관리, 훅 설정 같은 일이 모두 여기서 이루어진다. 이 문서는 부록 A의 슬래시 명령 표를 용도별로 묶어 설명한다.

원문 표는 알파벳 순서에 가깝게 나열되어 있지만, 쓰는 목적에 따라 나누어 보는 편이 기억하기 쉽다.

---

## 1. 전체 표

| 명령 | 설명 |
|------|------|
| `/help` | 사용할 수 있는 명령과 단축키를 보여 준다 |
| `/clear` | 대화 기록을 지우고 새로 시작한다 |
| `/compact` | 대화를 수동으로 압축해 컨텍스트 공간을 되찾는다 |
| `/config` | 설정을 열거나 관리한다 |
| `/context` | 현재 컨텍스트 사용량을 색깔 격자로 보여 준다 |
| `/copy` | 마지막 어시스턴트 응답을 클립보드에 복사한다 |
| `/cost` | 토큰 사용 통계를 보여 준다 |
| `/desktop` | CLI 세션을 데스크톱 앱으로 넘긴다 (macOS/Windows) |
| `/doctor` | 흔한 문제를 점검하는 진단을 실행한다 |
| `/agents` | 사용할 수 있는 서브에이전트를 나열한다 |
| `/export [filename]` | 대화를 파일 또는 클립보드로 내보낸다 |
| `/hooks` | 훅을 보고, 추가하고, 삭제하는 대화형 메뉴 |
| `/ide` | 현재 세션을 IDE 확장에서 연다 |
| `/init` | 현재 프로젝트에 CLAUDE.md를 만든다 (빌드 시스템, 테스트 프레임워크, 패턴을 분석) |
| `/mcp` | MCP 서버 상태와 서버별 토큰 비용을 보여 준다 |
| `/model` | 세션 도중 모델을 바꾼다. Opus에서는 좌우 화살표로 effort 수준을 조절한다 |
| `/permissions` | 권한 규칙을 보고 관리한다 |
| `/plan` | 프롬프트에서 바로 플랜 모드로 들어간다 |
| `/rename` | 현재 세션의 이름을 바꾼다 |
| `/resume` | 이전 세션 목록을 보고 다시 연다 (세션 선택기가 열린다) |
| `/rewind` | 대화나 코드를 되돌리거나, 선택한 메시지부터 요약한다 |
| `/sandbox` | 샌드박스 상태와 설정을 보여 준다 |
| `/stats` | 일별 사용량, 세션 기록, 연속 사용일, 모델 선호도를 시각화한다 |
| `/statusline` | 터미널의 상태 표시줄 UI를 설정한다 |
| `/tasks` | 백그라운드 작업을 나열하고 관리한다 |
| `/teleport` | 웹의 원격 세션을 다시 연다 (구독자 전용) |
| `/terminal-setup` | 여러 줄 입력과 단축키를 위한 터미널 키 바인딩을 설치한다 |
| `/vim` | vim 방식 편집 모드를 켠다 |

## 2. 용도별로 묶어 보기

### 2.1 컨텍스트와 비용 관리

컨텍스트 윈도(context window)는 Claude가 한 번에 기억하고 다룰 수 있는 대화량의 한계다. 이 한계를 관리하는 명령이 가장 자주 쓰인다.

- `/context`: 지금 컨텍스트를 얼마나 쓰고 있는지 색깔 격자로 보여 준다. 컨텍스트가 어디에 쓰이는지 눈으로 확인할 때 좋다.
- `/compact`: 대화를 수동으로 압축해서 공간을 되찾는다. 대화가 길어지기 전에 직접 정리하는 용도다.
- `/clear`: 대화 기록을 모두 지우고 처음부터 시작한다. 전혀 다른 작업으로 넘어갈 때 쓴다.
- `/cost`: 토큰 사용 통계를 보여 준다.
- `/mcp`: MCP 서버 상태와 서버별 토큰 비용을 보여 준다. MCP 도구가 컨텍스트를 얼마나 잡아먹는지 알 수 있다.
- `/stats`: 일별 사용량, 세션 기록, 연속 사용일, 모델 선호도를 그래프로 보여 준다.

### 2.2 세션 다루기

- `/resume`: 이전 세션을 나열하고 고른다. 세션 선택기가 열리며, 선택기에서 쓰는 키는 「세션 선택기와 Vim 모드」 문서에 정리했다.
- `/rename`: 현재 세션에 이름을 붙이거나 바꾼다. 이름을 붙여 두면 `claude -r <name>`으로 찾기 쉽다.
- `/rewind`: 대화와 코드를 이전 시점으로 되돌린다. 선택한 메시지부터 요약하는 기능도 있다. Esc를 두 번 눌러도 같은 메뉴가 열린다.
- `/export [filename]`: 대화를 파일이나 클립보드로 내보낸다.
- `/copy`: 마지막 응답만 클립보드에 복사한다.
- `/tasks`: 백그라운드로 돌고 있는 작업을 나열하고 관리한다.

### 2.3 모델과 모드

- `/model`: 세션 도중에 모델을 바꾼다. Opus를 쓸 때는 좌우 화살표로 effort(추론에 쓰는 노력) 수준을 조절한다.
- `/plan`: 프롬프트에서 곧바로 플랜 모드로 들어간다. 읽기 전용으로 계획을 먼저 세울 때 쓴다.
- `/permissions`: 권한 규칙을 보고 관리한다.
- `/sandbox`: 샌드박스 상태와 설정을 본다.

### 2.4 프로젝트 설정과 확장

- `/init`: 프로젝트에 CLAUDE.md를 만든다. 빌드 시스템, 테스트 프레임워크, 코드 패턴을 분석해서 내용을 채운다.
- `/hooks`: 훅(hook)을 관리하는 대화형 메뉴다. 훅은 특정 시점에 자동으로 실행되는 스크립트를 말하며, 이 메뉴에서 보고, 추가하고, 삭제한다.
- `/agents`: 사용할 수 있는 서브에이전트를 나열한다.
- `/config`: 설정을 열거나 관리한다.

### 2.5 환경 연결

- `/ide`: 현재 세션을 IDE 확장에서 연다.
- `/desktop`: CLI 세션을 데스크톱 앱으로 넘긴다. macOS와 Windows에서 쓸 수 있다.
- `/teleport`: 웹에서 시작한 원격 세션을 다시 연다. 구독자 전용이다.
- `/terminal-setup`: 여러 줄 입력과 단축키를 위한 터미널 키 바인딩을 설치한다.
- `/statusline`: 터미널의 상태 표시줄 UI를 설정한다.
- `/vim`: vim 방식 편집 모드를 켠다.

### 2.6 도움과 진단

- `/help`: 사용 가능한 명령과 단축키를 보여 준다.
- `/doctor`: 흔한 문제를 점검하는 진단을 실행한다. 설치나 환경이 이상할 때 가장 먼저 해 볼 만하다.

## 3. 같은 일을 하는 다른 길

슬래시 명령에는 플래그나 단축키와 겹치는 기능이 많다.

| 하고 싶은 일 | 슬래시 명령 | 다른 방법 |
|--------------|-------------|-----------|
| 세션 다시 열기 | `/resume` | `claude --resume` |
| 웹 세션 가져오기 | `/teleport` | `claude --teleport` |
| 플랜 모드 진입 | `/plan` | `--permission-mode plan`, Shift+Tab |
| 되돌리기 메뉴 | `/rewind` | Esc 두 번 |
| 모델 바꾸기 | `/model` | `--model`, Alt+P |
| vim 모드 켜기 | `/vim` | `/config`에서 영구 설정 |

시작할 때 정할 수 있는 것은 플래그로, 실행 도중에 바꿀 것은 슬래시 명령이나 단축키로 처리한다고 생각하면 된다.
