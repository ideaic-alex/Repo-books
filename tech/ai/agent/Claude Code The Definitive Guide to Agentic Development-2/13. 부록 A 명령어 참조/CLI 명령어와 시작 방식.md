# CLI 명령어와 시작 방식

터미널에서 `claude`를 어떻게 띄우느냐에 따라 Claude Code의 동작이 크게 달라진다. 이 문서는 부록 A의 첫 표인 CLI 명령어를 풀어 쓴 노트다. 대화형으로 쓰는 방법, 한 번만 실행하고 끝내는 방법, 이전 대화를 이어 가는 방법을 차례로 정리한다.

명령어 자체는 몇 개 되지 않지만, 뒤에 나오는 플래그와 조합하면 거의 모든 사용 방식이 여기서 출발한다. 먼저 이 일곱 가지 형태를 익혀 두면 이후 문서를 읽기 편하다.

---

## 1. 명령어 한눈에 보기

| 명령어 | 하는 일 |
|--------|---------|
| `claude` | 현재 디렉터리에서 대화형 REPL을 시작한다 |
| `claude "task"` | 첫 프롬프트를 넘기면서 대화형 REPL을 시작한다 |
| `claude -p "task"` | 비대화형(헤드리스) 모드로 실행하고, 응답을 출력한 뒤 종료한다 |
| `claude -c` | 현재 디렉터리에서 가장 최근 대화를 이어 간다 |
| `claude -c "task"` | 가장 최근 대화를 이어 가면서 새 프롬프트를 보낸다 |
| `claude -r <id>` | 특정 세션을 ID로 다시 연다 |
| `claude -r <name>` | 특정 세션을 이름으로 다시 연다 |

REPL은 입력을 받고, 실행하고, 결과를 보여 주는 일을 반복하는 대화형 입력 창을 말한다. 터미널에서 Claude Code와 주고받는 화면이 바로 이 REPL이다.

## 2. 대화형으로 시작하기

### 2.1 `claude`

아무 인자 없이 실행하면 지금 서 있는 디렉터리를 작업 위치로 삼아 대화형 REPL이 열린다. 가장 기본적인 시작 방식이며, 프롬프트를 하나씩 보내면서 결과를 보고 방향을 바꾸는 작업에 어울린다.

### 2.2 `claude "task"`

따옴표 안에 첫 프롬프트를 적어 함께 넘기면, REPL이 열리자마자 그 작업부터 시작한다. 입력 창이 뜨기를 기다렸다가 같은 문장을 붙여 넣는 수고를 줄여 준다. 여기서도 결과는 계속 대화형으로 이어지므로, 첫 결과를 본 뒤 이어서 지시를 보낼 수 있다.

```bash
claude
claude "이 저장소 구조를 설명해 줘"
```

## 3. 한 번만 실행하고 끝내기: `-p`

`claude -p "task"`는 비대화형 모드, 흔히 헤드리스(headless) 모드라고 부르는 방식이다. 화면 없이 터미널에서 한 번 실행하고, 응답을 출력한 뒤 곧바로 종료한다. 사람이 중간에 끼어들지 않으므로 스크립트나 CI/CD 파이프라인에 넣어 쓰기 좋다.

이 모드에서 쓸 수 있는 출력 형식, 턴 제한, 시스템 프롬프트 교체 같은 옵션은 별도 문서인 「시스템 프롬프트와 출력 제어 플래그」에서 다룬다. 여기서는 `-p`가 헤드리스 모드로 들어가는 스위치라는 점만 기억하면 된다.

```bash
claude -p "테스트 실패 원인을 한 줄로 요약해 줘"
```

## 4. 이전 대화 이어 가기: `-c`와 `-r`

작업은 한 번에 끝나지 않는 경우가 많다. 세션(session)은 하나의 대화와 그 기록을 가리키는데, 이를 다시 열어서 이어 가는 방법이 두 가지 있다.

### 4.1 가장 최근 대화: `-c`

`claude -c`는 현재 디렉터리에서 가장 최근에 나눈 대화를 이어 간다. 어제 하던 일을 그대로 다시 시작할 때 가장 빠르다. 원문 표에는 `claude -c "task"`도 있는데, 이어 가면서 곧바로 새 프롬프트를 보내는 형태다.

### 4.2 특정 세션 고르기: `-r`

`claude -r <id>`는 세션 ID로, `claude -r <name>`은 세션 이름으로 특정 세션을 다시 연다. 최근 대화가 아니라 며칠 전의 다른 작업으로 돌아가고 싶을 때 쓴다. 이름으로 찾으려면 미리 세션에 이름을 붙여 둬야 하는데, 이름을 붙이는 방법은 「세션과 입력 플래그」 문서와 슬래시 명령의 `/rename`에서 다룬다.

```bash
claude -c
claude -c "방금 고친 부분에 테스트도 추가해 줘"
claude -r <name>
```

## 5. 어떤 방식을 고를까

| 상황 | 알맞은 방식 |
|------|-------------|
| 새 작업을 대화하면서 진행 | `claude` 또는 `claude "task"` |
| 스크립트나 파이프라인에서 결과만 필요 | `claude -p "task"` |
| 방금 하던 작업을 이어서 진행 | `claude -c` |
| 여러 세션 중 특정 작업으로 복귀 | `claude -r <id>` 또는 `claude -r <name>` |

`-c`와 `-r`은 짝으로 기억하면 쉽다. `-c`는 "가장 최근 것을 이어서(continue)", `-r`은 "골라서 다시 열기(resume)"다. 둘 다 이전 대화의 기록을 가져오므로, 처음부터 설명을 반복하지 않아도 된다.
