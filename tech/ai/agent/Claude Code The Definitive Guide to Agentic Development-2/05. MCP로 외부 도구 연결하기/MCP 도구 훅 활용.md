# MCP 도구 훅 활용

훅(hook)은 Claude Code가 도구를 쓰기 전후에 끼어들어 스크립트를 실행하는 장치다. MCP 도구에도 똑같이 훅을 걸 수 있다. MCP 호출은 외부 서비스로 나가는 요청이라서, 기록하고 걸러내고 검증할 수 있는 지점이 있으면 보안과 컨텍스트 관리에 큰 도움이 된다. 이 문서는 MCP 도구 이름 규칙, 그리고 이를 이용한 로깅, 변환, 검증 세 가지 패턴을 다룬다.

---

## 1. 이름 규칙: mcp__서버이름__도구이름

훅은 `mcp__servername__toolname`이라는 명명 규칙으로 MCP 도구에 접근한다. PreToolUse 훅과 PostToolUse 훅이 다른 도구와 똑같은 정규식(regex) 기반 매칭으로 특정 MCP 도구를 잡아낼 수 있다.

| 매처(matcher) | 가로채는 대상 |
|---|---|
| `mcp__analytics__.*` | analytics MCP 서버의 모든 도구 |
| `mcp__.*__write.*` | 모든 MCP 서버에 걸친 쓰기 작업 |
| `mcp__memory__.*` | memory 서버의 모든 작업 |

이 패턴은 서버 단위, 도구 단위, 서버를 가로지르는 정책을 모두 표현할 수 있을 만큼 유연하다.

### 이중 밑줄은 임의가 아니다

`mcp__server__tool`의 이중 밑줄 형식은 Claude Code가 내부적으로 MCP 도구에 이름 공간(namespace)을 붙이는 정확한 형식이다. analytics 서버의 `get_price_history`라는 도구를 Claude가 호출하면 내부 도구 이름은 `mcp__analytics__get_price_history`가 된다.

훅 매처는 이 전체 이름을 대상으로 한다. 그래서 서로 다른 서버에 이름이 같은 도구가 있어도 훅은 둘을 구분해서 처리할 수 있다.

## 2. 로깅 훅

MCP에서 가장 바로 가치가 나오는 훅은 로깅 훅이다. 모든 MCP 도구 호출의 서버, 도구, 파라미터, 시각을 파일에 쓰거나 모니터링 서비스로 보낸다. 외부 서비스에 접근한 흔적이 평소에는 보이지 않는데, 이렇게 하면 감사 기록(audit trail)이 생긴다.

규제 산업에서는 선택이 아니라 필수다. MCP 서버가 금융 데이터 소스나 고객 데이터베이스에 연결된다면, Claude가 보낸 모든 질의의 감사 가능한 로그는 컴플라이언스 요구 사항이다. `mcp__.*`에 거는 PreToolUse 훅과 로깅 명령 하나면 몇 줄 설정으로 해결된다.

## 3. 변환 훅

PostToolUse 훅은 Claude가 MCP 도구의 출력을 처리하기 전에 그 출력을 변환할 수 있다. 두 가지 방향이 모두 쓸모 있다.

- **줄이기**: MCP 도구가 Claude에게 필요한 양보다 많은 데이터를 돌려줄 때 유용하다. 큰 API 응답에서 관련 필드만 걸러 주는 훅은 컨텍스트 소비를 줄이고, Claude가 중요한 부분에 집중하게 돕는다.
- **보강하기**: 반대로 빈약한 출력에 메타데이터나 서식을 덧붙이는 훅은 MCP 서버를 고치지 않고도 Claude의 해석을 좋게 만든다.

## 4. 검증 훅

MCP 도구에 거는 PreToolUse 훅은 요청이 외부 서비스에 닿기 전에 입력을 검증할 수 있다. 예를 들어 데이터베이스 질의 MCP 도구가 받는 문장이 SELECT인지(허용), DROP TABLE인지(거부) 확인하는 훅이 있다. MCP 서버 코드를 수정하지 않고도 치명적인 실수를 막는다.

이것은 다층 방어(defense in depth)다. MCP 서버도 자체 입력 검증을 갖춰야 한다. 훅은 서버가 놓칠 수 있는 부분을 잡아내는 두 번째 층이다.

## 5. 한눈에 보기

| 훅 종류 | 시점 | 하는 일 | 효과 |
|---|---|---|---|
| 로깅 | PreToolUse | 서버, 도구, 파라미터, 시각 기록 | 감사 기록, 컴플라이언스 |
| 변환 | PostToolUse | 출력 필터링 또는 보강 | 컨텍스트 절약, 해석 개선 |
| 검증 | PreToolUse | 위험한 입력 차단 | 파괴적 실수 방지 |

세 가지 모두 MCP 서버를 수정하지 않고 Claude Code 쪽 설정만으로 붙일 수 있다는 점이 장점이다.
