# 데스크톱 앱

데스크톱 앱은 IDE도 터미널도 아닌 독립된 화면에서 Claude Code를 돌리는 방식이다. 시각적인 diff 검토, git 워크트리로 격리된 병렬 세션, 여러 권한 모드, 파일 첨부, 외부 서비스 커넥터, 로컬과 원격 실행 환경을 모두 지원한다. 이 문서는 앱의 구성과 권한 모드, diff 검토 방식, 병렬 세션, 원격 실행을 설명한다.

---

## 1. 세 개의 탭

앱은 작업을 세 개의 탭으로 나눈다.

- **Code 탭**: 주 작업 공간이다. 터미널의 에이전트 기능을 그래픽 화면으로 옮겨 놓았다. 프로젝트 폴더를 고르고, 권한 모드를 정하고, 모델을 선택한 뒤 프롬프트를 입력하면 된다.
- **Cowork 탭**: 백그라운드에서 자율적으로 일하는 작업을 위한 곳이다. Claude가 혼자 계속 작업하고, 사용자는 진행 상황을 보다가 필요할 때 방향을 잡아 준다.
- **Chat 탭**: 파일 시스템 접근이 필요 없는 질문에 쓰는 일반적인 대화 화면이다.

## 2. 권한 모드

앱은 모드 선택기로 권한을 조절한다. 세션 중 Claude에게 얼마나 많은 자율성을 줄지가 모드에 따라 달라진다.

| 모드 | 동작 | 언제 쓰나 |
|---|---|---|
| Ask | 파일 수정과 명령 실행마다 승인을 받는다. diff를 보고 변경을 하나씩 수락하거나 거절한다 | 기본값이다. 내 코드베이스에서 Claude의 판단을 믿기 전까지는 이 모드가 맞다 |
| Code | 파일 수정은 자동 수락하고, 터미널 명령을 실행하기 전에는 묻는다 | 파일 변경을 믿을 수 있을 때 더 빠르게 반복하고 싶을 때 |
| Plan | 읽기 전용 작업과 플랜 작성만 허용한다. 파일 수정도 명령 실행도 없다 | 순수한 분석과 계획 |
| Act | 터미널의 --dangerously-skip-permissions와 같다. 아무 확인 없이 실행한다 | 샌드박스 환경에서만 쓴다 |

세션 도중에 모드를 바꿀 수 있다. 예를 들어 Plan 모드로 접근 방식을 정리하고, Code 모드로 바꿔 실행한 다음, 마지막 검증 단계에서는 Ask 모드로 내려가는 흐름이 가능하다.

## 3. 시각적 diff 검토

Claude가 파일을 수정하면 추가된 줄과 삭제된 줄 수를 보여 주는 diff 통계 표시가 나타난다. 이것을 클릭하면 전체 diff 뷰어가 열린다. 왼쪽에는 파일 목록이, 오른쪽에는 변경 내용이 보인다.

검토 방법은 이렇다.

1. 특정 줄을 클릭해서 코멘트를 입력하고 Enter를 누른다.
2. 여러 곳에 코멘트를 남긴다.
3. 한꺼번에 제출한다.
4. Claude가 코멘트를 읽고 요청한 대로 고친 뒤, 결과가 새 diff로 나타난다.

책은 이것을 "읽으며 검토하는 방식"이 아니라 "대화하며 검토하는 방식"이라고 부른다. 문제가 있는 곳을 가리키기만 하면 고치는 일은 Claude가 한다.

## 4. git 워크트리로 격리한 병렬 세션

앱의 세션마다 프로젝트의 격리된 복사본이 git 워크트리로 따로 생긴다. 사이드바에서 "New session"을 누르면 두 번째, 세 번째, 열 번째 작업을 병렬로 시작할 수 있다. 한 세션의 변경은 커밋하기 전까지 다른 세션에 영향을 주지 않는다.

워크트리는 기본적으로 프로젝트의 .claude/worktrees/ 디렉터리에 저장된다. 설정에서 저장 위치와 브랜치 접두사를 바꿀 수 있어서, Claude가 만든 브랜치를 정리해 두기 편하다.

이렇게 하면 데스크톱 앱이 병렬 처리 화면이 된다. 예를 들면 이런 식이다.

- 한 세션은 인증 모듈을 리팩터링한다.
- 다른 세션은 결제 흐름의 테스트를 쓴다.
- 세 번째 세션은 버그를 조사한다.

세션마다 자기 git 브랜치에서 작업하므로 서로 완전히 분리된다. 작업이 끝나면 브랜치를 각각 검토하고 따로 머지하면 된다.

## 5. SSH와 원격 세션

### SSH 연결

앱은 SSH로 원격 머신에 연결할 수 있다. 환경으로 "Local" 대신 SSH 연결을 고르면 Claude Code가 원격 머신에서 돌면서 그 머신의 명령을 실행하고 파일을 고친다. 특정 하드웨어, 운영체제, 개발 환경이 필요해서 내 로컬 머신으로는 다룰 수 없는 코드베이스에 쓸모 있다.

### Remote 환경

오래 걸리는 작업에는 Remote 환경을 고른다. 원격 세션은 Anthropic이 관리하는 클라우드 인프라에서 돌고, 앱을 닫거나 컴퓨터를 꺼도 계속 진행된다. 진행 상황은 데스크톱 앱, 웹, 모바일 앱 어디에서든 볼 수 있다. 클라우드 세션은 다음 문서에서 자세히 다룬다.

## 6. 커넥터

앱은 외부 서비스를 연결하는 커넥터를 지원한다. 버전 관리 플랫폼, 팀 메신저, 프로젝트 관리 시스템이 대상이다. 앱 설정에서 구성하며, 연결하면 Claude Code가 PR, 이슈, 메시지, 작업 같은 프로젝트 바깥의 맥락을 알게 된다.

책은 커넥터 생태계가 아직 성장 중이라고 말한다. 그래도 방향은 분명하다. Claude Code가 코드와 팀의 소통 및 조율 도구를 잇는 중심 허브가 되어 간다는 것이다.
