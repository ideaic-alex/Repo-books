# 웹과 모바일의 클라우드 세션

Claude Code는 브라우저 안에서 완전히 클라우드로 돌릴 수도 있고, 그렇게 돌고 있는 세션을 휴대폰에서 지켜볼 수도 있다. 로컬 환경을 준비할 필요가 없고, 내 컴퓨터가 꺼져 있어도 일이 계속된다. 이 문서는 웹 화면의 동작, 네트워크 접근 수준, 세션 공유, 클라우드 세션이 어울리는 상황과 한계, 모바일 앱의 역할을 정리한다.

---

## 1. 웹에서 쓰는 Claude Code

웹 화면은 로컬 설정이 필요 없는 클라우드 호스팅 환경이다. 사용 순서는 간단하다.

1. 버전 관리 계정을 연결한다.
2. 저장소를 고른다.
3. 작업을 시작한다.

그러면 저장소가 Anthropic이 관리하는 가상 머신(VM)에 복제되고, 환경이 구성되며, Claude가 코드베이스 전체에 접근해서 실행한다.

diff 보기는 데스크톱 앱과 같다. Claude가 무엇을 바꿨는지 정확히 보고, 특정 줄에 코멘트를 달고, 변경이 준비될 때까지 반복한다. 만족스러우면 화면에서 바로 풀 리퀘스트(PR)를 만든다. 변경은 원격의 브랜치로 푸시되어 리뷰를 기다리는 상태가 된다.

## 2. 네트워크 접근 설정

클라우드 세션의 네트워크 접근은 세 단계로 나뉜다.

| 수준 | 의미 |
|---|---|
| limited (기본값) | 허용된 기본 도메인만 접근한다. 패키지 레지스트리, API 엔드포인트 같은 기반 시설이 해당한다 |
| full | 인터넷에 제한 없이 접근한다 |
| none | 완전히 오프라인이다 |

네트워크 설정은 보안 프록시가 통제한다. 밖으로 나가는 연결은 모두 이 프록시를 거친다. 버전 관리 플랫폼 접근은 별도의 프록시가 처리하기 때문에, 네트워크를 어떻게 설정해 두었든 저장소 작업은 정상적으로 된다.

## 3. 세션 공유

클라우드 세션은 세 가지 공개 수준으로 공유할 수 있다.

- **Private**: 나만 볼 수 있다.
- **Team**: 내 조직의 구성원이 볼 수 있다.
- **Public**: 링크를 가진 사람은 누구나 볼 수 있다.

공유된 세션에서는 다른 사람이 Claude가 작업하는 과정을 지켜보고, 대화 기록을 읽고, 결과로 나온 변경을 확인할 수 있다. 코드 리뷰, 시간대가 다른 사람과 하는 페어 프로그래밍, 팀원에게 작업 방식을 보여 주는 데 쓸모 있다.

## 4. 클라우드 세션이 어울리는 경우

책은 세 가지 상황에서 클라우드 세션이 빛난다고 정리한다.

1. **오래 걸리는 작업**: 로컬 머신을 붙잡아 두는 작업이다. 큰 리팩터링을 시켜 놓고 브라우저를 닫은 뒤 한 시간 뒤에 확인하면 된다.
2. **로컬에 없는 저장소**: 동료의 프로젝트를 아무것도 복제하지 않고 검토할 수 있다.
3. **병렬 실행**: 서로 다른 작업으로 클라우드 세션을 여러 개 띄우고, 브라우저 탭 하나에서 전부 지켜본다.

### 한계

현재 클라우드 세션은 가장 널리 쓰이는 코드 호스팅 플랫폼에 있는 저장소에서만 동작한다. 다른 호스팅 플랫폼은 아직 클라우드 실행을 지원하지 않는다.

## 5. 모바일 앱

모바일 앱은 클라우드 세션을 감시하고 지시를 내리는 화면이다. 휴대폰에서 작업을 시작하고, 진행 상황을 지켜보고, 후속 프롬프트로 방향을 조정하고, 결과가 나오면 검토할 수 있다.

책은 현실적인 선을 긋는다. 휴대폰 키보드로 복잡한 프롬프트를 쓰게 되지는 않는다. 대신 출퇴근 길에 오래 걸리는 작업의 상태를 확인하고, Claude가 던진 확인 질문에 답하고, 소파에 앉아 PR을 승인하는 정도는 충분히 할 수 있다.

모바일 앱은 웹과 같은 세션 인프라에 연결된다. 그래서 데스크톱이나 터미널에서 시작한 세션을 모바일에서 볼 수 있고, 그 반대도 된다.

## 6. 화면별 역할 정리

| 화면 | 잘하는 일 |
|---|---|
| 웹 | 로컬 설정 없이 저장소를 열고 작업하고 PR까지 만든다 |
| 모바일 | 이동 중에 클라우드 세션을 확인하고, 질문에 답하고, 승인한다 |
| 데스크톱 Remote 환경 | 로컬 앱으로 시작하되 실행은 클라우드에 맡긴다 |

세 가지는 모두 같은 클라우드 세션을 바라보는 서로 다른 창이다. 이 점이 다음 문서에서 다룰 화면 간 이동의 바탕이 된다.
