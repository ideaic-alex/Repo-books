# 압축 지침

Claude Code의 **컨텍스트 엔지니어링(Context Engineering)** 체계에서 **압축 지침(Compact Instructions)**은 긴 대화 세션 중 맥락이 축소되더라도 에이전트의 핵심 규칙과 제약 조건을 손실 없이 유지해 주는 **최후의 맥락 보호 메커니즘**입니다.

---

## 1. 배경: 자동 축소(Auto-Compaction)와 정보 손실 위험

- **자동 축소의 발동**: 대화가 길어지고 읽어들인 파일, CLI 명령 결과, 중간 추론 등이 누적되어 컨텍스트 윈도우가 약 **95% 용량**에 도달하면 Claude Code는 자동으로 맥락 압축(Auto-compaction)을 트리거합니다.
- **손실적 압축(Lossy Compression)**: 축소 과정에서 오래된 도구 출력과 과거 대화 이력이 요약·압축되는데, 이 과정에서 이전의 세부 지침이나 제약 조건이 유실(lossy)될 위험이 있습니다. 이로 인해 에이전트가 세션 초반에 전달받은 중요 규칙을 잊어버리거나 이미 해결한 문제를 다시 푸는 맥락 표류(Context Drift) 현상이 발생합니다.

---

## 2. `Compact Instructions`(압축 지침)의 작동 메커니즘

- **`CLAUDE.md` 내의 특별 섹션**: `CLAUDE.md` 파일 하위에 **`Compact Instructions`**라는 헤더를 두고 작성된 내용은 자동 축소 프로세스에서 **특별 대우(Special Treatment)**를 받습니다.
- **명시적 보존(Explicit Preservation)**: 대화 이력 전체가 압축·요약되더라도 `Compact Instructions` 헤더 하위의 내용은 요약 손실 없이 **원형 그대로 명시적으로 보존됩니다**.

---

## 3. `Compact Instructions`에 담아야 할 3가지 핵심 정보

출처에서는 자동 축소 후에도 에이전트의 올바른 작동을 보장하기 위해 다음 항목들을 이 섹션에 배치하도록 권장합니다:

1. **최우선 절대 제약 조건 (Critical Constraints)**
   - 세션이 아무리 오래 진행되더라도 절대로 위반해서는 안 되는 핵심 규칙 (예: "운영 DB 직접 수정 금지", "특정 레거시 모듈 참조 금지")
2. **복잡한 현재 작업 설명 (Current Task Description)**
   - 일반적인 요약 과정에서 미세한 뉘앙스가 손실되면 작업 방향이 오염될 수 있는 복잡한 요구사항
3. **이전 단계의 핵심 결정 사항 (Key Decisions)**
   - 세션 초반 탐색 및 계획 단계에서 합의되어 이후 모든 구현 작업에 영향을 미치는 주요 설계/아키텍처 결정

---

## 4. 컨텍스트 엔지니어링이라는 더 큰 맥락에서의 종합적 위상

**압축 지침**은 단독으로 작동하는 것이 아니라, Claude Code의 다층적 컨텍스트 관리 시스템 내에서 다른 수단들과 상호보완적으로 작동합니다.

- **상시 로드 비용과의 밸런스**: `CLAUDE.md`에 포함된 일반 지침은 매 turn마다 상시 비용(Always-On Cost)을 소비하지만, `Compact Instructions`는 세션이 극도로 길어져 95% 임계점에 다다랐을 때 에이전트가 "정체성과 최우선 규칙"을 잃지 않도록 방지하는 **안전망 역할**을 합니다.
- **다른 수술적 맥락 제어 도구와의 연계**:
  - **수동 집중 압축 (`/compact Focus on...`)**: 80% 시점에서 사용자가 직접 원하는 초점을 지정하여 선제적으로 맥락을 요약합니다.
  - **수술적 부분 복원 (`/rewind` -> "Summarize from here")**: 시행착오가 발생한 특정 시점 이후의 대화만 수술적으로 잘라내어 요약합니다.
  - `PreCompact` 훅: 자동/수동 압축이 시작되기 직전 외부 프로세스를 통해 상태를 저장하거나 필요한 맥락을 주입합니다.
  - `Compact Instructions`: 위의 동적 제어 도구들과 달리, `CLAUDE.md`라는 정적 영구 지침 저장소 내에서 **자동 축소에 대한 면역을 선언하는 유일한 표준 구문**입니다.

---

💡 자동 축소가 실행되기 전 특정 시점에 선제적으로 상태를 저장하고 맥락을 주입해 주는 `PreCompact` **훅 작성법**이나, 압축 임계값을 조정하는 `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` **환경변수 설정**에 대해서도 자세히 알아보시겠어요?
