# 모델 바꾸기와 버전 확인

폐기된 코드가 나오거나 답이 부실할 때 가장 빠른 방법은 다른 모델을 써 보는 것이다. Copilot은 코드 제안과 채팅 응답에 쓸 AI 모델을 여러 개 고르게 해 준다. 모델마다 장단점이 있고, 학습된 시점도 달라서 최신 모델일수록 낡은 코드를 낼 가능성이 낮다.

이 문서는 모델을 바꾸는 방법, 모델이 얼마나 최신인지 알아보는 방법, 그리고 모델을 바꿀 때 주의할 비용 문제를 정리한다.

---

## 1. 모델 바꾸기

채팅 인터페이스에서 모델을 바꾸는 방법은 간단하다. 사용 중인 채팅 화면의 드롭다운 목록에서 쓰고 싶은 모델 이름을 고르면 된다.

앞에서 난수 시드 함수를 만들 때 폐기된 방법이 나온 사례(그림 7-1)는 GPT-4o 모델로 생성한 것이었다. 더 최근 모델인 Gemini 2.5 Pro로 바꿔 같은 프롬프트를 주면, 폐기된 rand.Seed 대신 새 표준인 rand.NewSource 함수를 쓰는 코드가 나온다. 또 메인 채팅에서 Seed 함수가 폐기되었는지 물으면 rand.Seed가 Go 1.20부터 폐기되었다고 정확히 답한다.

| 항목 | GPT-4o | Gemini 2.5 Pro |
| --- | --- | --- |
| 난수 시드 코드 | 폐기된 rand.Seed 사용 | 새 방식인 rand.NewSource 사용 |
| "Seed가 폐기됐나?" 질문 | 폐기 사실을 알지 못함 | Go 1.20부터 폐기되었다고 정확히 답함 |

같은 질문이라도 모델의 학습 시점에 따라 결과가 갈린다는 점을 보여 주는 비교다.

## 2. 어느 모델이 더 최신인지 아는 법

다른 모델을 골랐을 때 그것이 더 최신인지는 어떻게 알까. 보통 모델 목록은 새 모델이 나오면 갱신되고, 한동안 Preview 표시가 붙는다. 웹 검색이나 Hugging Face 같은 사이트에서 어느 모델이 더 최근인지 찾아볼 수도 있다. 또 Copilot을 통해 모델에게 직접 물어서, 학습 당시 어떤 것의 어느 버전이 최신이었는지 알아볼 수도 있다.

## 3. 모델에게 "현재 버전"을 묻기

Copilot이 폐기 사실을 몰랐으므로, Copilot이 Go의 최신 버전을 몇이라고 아는지 알면 도움이 된다. 채팅에서 "As of your last training date, what was the current version of Go?"라고 물어본다.

> 질문의 틀을 잘 잡아야 한다: 질문을 "As of your last training date..."로 시작하는 데는 이유가 있다. 그냥 "What version of Go is current?"라고 하면, 내 PC에 설치된 Go 버전을 확인하는 방법을 알려 줄 가능성이 높다.

이 책의 사례에서 활성 모델은 마지막 학습 업데이트가 2023년 10월이고, 그 시점의 최신 안정 버전은 Go 1.21.1이라고 답했다.

### 왜 1.21.1을 알면서 1.20 폐기는 모를까

당연한 의문이다. 1.21.1이 최신인 줄 알면서 1.20에서 폐기된 것은 왜 모를까. 우리가 물은 것은 모델이 마지막으로 학습되었을 때 어떤 버전이 최신이었는가였다. 학습할 때 저장소들에서 어떤 버전을 썼는가를 물은 것이 아니다. 실제로 에디터 안에서 주석으로 비슷한 질문을 여러 번 하면 답이 제각각 나올 가능성이 높다. 에디터에서 돌아오는 답은 학습 데이터에 담긴 버전 언급을 바탕으로 하기 때문이다.

그렇다면 채팅의 답이 모델이 아는 가장 최신 버전이고 모델은 다양한 다른 버전으로 학습되었다면, 그 정보로 얻는 것은 무엇일까. 채팅에서 돌아온 버전 정보는 모델의 학습 데이터에 담길 수 있는 가장 최신 버전을 알려 준다. 따라서 학습만으로 생성된 코드는 그 버전 이후의 폐기 사항이나 새 기능, 버전별 변경을 반영하지 못한다.

| 질문한 것 | 알 수 있는 것 |
| --- | --- |
| 채팅: 마지막 학습 시점의 최신 버전 | 학습 데이터에 담길 수 있는 가장 최신 버전 (책의 사례는 2023년 10월, Go 1.21.1) |
| 에디터 주석으로 같은 질문 | 학습 데이터에 있던 버전 언급에 따라 답이 매번 달라질 수 있음 |

> 결과는 모델마다 다를 수 있다: 모든 모델이 최신 버전 질문에 확정적인 답을 주지는 않는다. 그런 정보에 접근할 수 없다고 하거나, 직접 찾아보라고 권하는 모델도 있다. Copilot을 확장해 언어나 플랫폼의 최신 버전을 알아내게 할 수도 있다. 10장에서 Go의 최신 버전을 알아내는 확장 구현을 안내한다.

이런 사정을 알면 다른 모델로 바꾸거나, 다음 문서에서 설명하는 방법으로 Copilot이 업데이트를 이해하도록 도울 수 있다.

## 4. 프리미엄 요청 주의

모델 교체가 좋은 해법일 때가 있다. 다만 일부 고급 모델의 사용은 프리미엄 요청(premium requests)으로 집계된다는 점을 기억해야 한다. 이런 모델을 쓰면 사용 한도가 더 빨리 줄고, 요금제(plan)에 따라 추가 비용이 생길 수 있다.

특정 모델만 쓸 수 있도록 제한되어 있거나, 쓰는 모델이 신기능을 학습하지 못했다면 어떻게 할까. 그때 쓸 수 있는 방법이 예시로 가르치기다.
