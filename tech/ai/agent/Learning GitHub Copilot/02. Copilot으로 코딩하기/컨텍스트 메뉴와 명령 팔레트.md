# 컨텍스트 메뉴와 명령 팔레트

채팅 창에 지시문을 적지 않아도 IDE 메뉴에서 바로 Copilot 기능을 실행할 수 있다. 이 문서는 별(스파클) 아이콘, 우클릭 컨텍스트 메뉴, 터미널의 메뉴, 명령 팔레트(Command Palette)를 정리한다. 채팅 관련 옵션의 자세한 내용은 3장에서 다룬다.

---

## 1. 여기서 말하는 컨텍스트의 뜻

이 절의 "컨텍스트"는 Copilot이 제안을 위해 모으는 정보(문맥)가 아니다. IDE의 컨텍스트 메뉴(우클릭 메뉴)에 있는 Copilot 항목을 가리킨다. 같은 단어가 두 가지 뜻으로 쓰이니 헷갈리지 않아야 한다.

| 용어 | 뜻 |
|---|---|
| 컨텍스트(문맥) | Copilot이 제안을 만들려고 모으는 정보(파일 이름, 코드, 주석 등) |
| 컨텍스트 메뉴 | IDE에서 우클릭할 때 나오는, 대상에 맞는 Copilot 메뉴 |

---

## 2. 스파클 아이콘과 Quick Fix

앞의 그림들에서 줄 앞에 작은 네 꼭지 별 두 개가 붙어 있는 것을 봤을 것이다. 이 모양은 스파클 아이콘이라 부르며 Copilot뿐 아니라 AI 일반을 가리키는 기호다. IDE에서 이 아이콘은 보통 Copilot과 상호작용할 수 있는 링크라는 표시다. 클릭하면 고급 옵션이 담긴 메뉴가 열린다.

책의 사례에서는 함수 정의가 미완성일 때 아이콘이 나타났다. 시스템은 아직 작성 중인 함수와 고장 난 함수를 구분하지 못한다. 그래서 Copilot은 완성을 제안하면서 고쳐 주겠다고도 한다. 아이콘을 누르면 팝업 메뉴가 열리고(그림 2-16) Quick Fix 옵션이 나온다. 다른 IDE에서는 이 아이콘이 안 보일 수도 있다.

### "Fix using Copilot"을 완성 대용으로

"Fix using Copilot"은 가끔 코드 완성 제안 대신 쓸 수 있다. 선택하면 시스템이 동작하는 상태가 되도록 일부 코드를 만든다. 다만 전체 완성을 항상 기대할 수는 없다.

---

## 3. 코드가 완성되면 늘어나는 메뉴

함수 구현을 마치는 등 Copilot이 다룰 데이터가 많아지면 메뉴에 옵션이 더 늘어난다(그림 2-17). 메뉴의 항목과 그 대상은 IDE의 어느 부분에서 작업하는지에 따라 달라진다.

| 작업 위치 | 메뉴의 Explain이 가리키는 대상 | 메뉴 구성 |
|---|---|---|
| 에디터 | 에디터의 코드 | 코드용 옵션 |
| 터미널 | 에디터가 아니라 터미널의 내용 | 터미널 전용 옵션이 따로 있음(그림 2-18) |

터미널 옵션은 채팅 옵션이라서 다음 장에서 설명한다. 결국 컨텍스트 메뉴는 지금 하는 일에 맞는 Copilot 기능의 부분집합만 보여 준다고 이해하면 된다.

---

## 4. 명령 팔레트로 접근하기

VS Code 계열 IDE에는 설치된 확장과 관련된 명령에 빠르게 접근하는 명령 팔레트가 있다.

| 항목 | 내용 |
|---|---|
| 여는 키 | `Meta-P` 또는 `F1` |
| 쓰는 법 | 열린 대화상자에서 확장, 명령, 심볼, 파일 이름을 스크롤하거나 입력해 찾는다 |
| Copilot 명령 찾기 | Copilot 확장이 설치되어 있으면 `Copilot`이라고 입력한다(그림 2-19) |
| 실행 | 목록의 항목을 명령으로 실행한다. 예로 Explain 기능을 실행해 볼 수 있다(그림 2-20) |
| 부수 효과 | 이 목록은 내가 쓸 수 있는 Copilot 명령 전체를 확인하는 데도 좋다 |

읽는 법: 메뉴에서 어떤 기능이 있는지 모르겠으면 명령 팔레트에 `Copilot`을 입력해서 전체 목록을 먼저 훑어본다.

---

## 5. 접근 경로 비교

| 방법 | 장점 | 적합한 때 |
|---|---|---|
| 스파클 아이콘 | 문제가 있는 줄 바로 옆에서 실행 | 미완성이거나 고장 난 코드를 고칠 때 |
| 우클릭 컨텍스트 메뉴 | 선택한 대상에 맞는 기능만 보임 | 선택한 코드를 설명하거나 리뷰할 때 |
| 명령 팔레트 | 모든 Copilot 명령을 한눈에 찾음 | 메뉴 위치를 모르거나 전체 기능을 살펴볼 때 |

Explain이나 Fix 같은 표준 기능 외에도, 컨텍스트 메뉴로 Copilot에게 중요한 일을 하나 더 시킬 수 있다. 코드를 검토해 피드백을 주는 일이며 다음 문서에서 다룬다.
