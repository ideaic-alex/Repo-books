# Copilot으로 코딩하기

GitHub Copilot은 AI 도우미처럼 쓰는 도구라서, 도우미에게 어떻게 묻고 어떻게 지시하는지 아는 것이 먼저다. 이 장은 IDE 안에서 Copilot과 소통하는 두 방식 중 인라인 모드, 즉 에디터와 메뉴에서 바로 쓰는 방식을 다룬다. 예시는 VS Code 기준이다.

인라인 제안을 받고 고르는 법, 대안 제안을 여는 법, 주석으로 지시하고 질문하는 법, 컨텍스트 메뉴와 명령 팔레트, 코드 리뷰와 커밋 메시지, IDE 설정까지 정리한다. 채팅 방식은 3장과 4장에서 이어진다.

---

## 1. 핵심 요점

- Copilot의 인라인 모드는 에디터에서 치는 동안 고스트 텍스트로 제안을 보여 주며, Tab으로 전체를 받아들이고 계속 치면 버린다.
- 같은 컨텍스트라도 제안은 매번 달라질 수 있으므로 완성도와 맞는 정도를 직접 확인한다.
- `Ctrl-Enter`로 대안 목록을 열 수 있고, 제안을 받아들이기 전에 쓸 때 결과가 가장 좋다. 이미 쓴 코드에는 코드를 선택해야 한다.
- 주석은 컨텍스트이자 지시문이다. 코드를 만들라는 주석은 코드로, 설명이나 질문은 주석으로 답이 온다.
- 스파클 아이콘, 우클릭 컨텍스트 메뉴, 명령 팔레트(`Meta-P` 또는 `F1`)로 채팅 없이 기능을 실행한다.
- Review and Comment로 로컬 코드를 리뷰받을 수 있고, 규칙은 `settings.json`이나 `.github/copilot-review-guidelines.md`로 지정한다.
- 커밋 메시지도 스파클 아이콘으로 제안받고, 코드 완성은 상태 표시줄이나 설정에서 켜고 끈다.
