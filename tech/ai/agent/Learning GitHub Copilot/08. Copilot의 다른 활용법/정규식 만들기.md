# 정규식 만들기

정규 표현식(정규식)은 문자열이 어떤 패턴과 맞는지 검사하는 짧고 난해한 문자열이다. 필요할 때 정확하게 만들어야 하지만 만드는 과정은 답답하다. 문자, 숫자, 기호를 조합해 대상 문자열에 두루 맞는 식을 찾는 일은 시간이 많이 들고, 여기에 식을 꼼꼼히 검증하는 테스트까지 짜야 하다 보니 많은 개발자가 다른 코드나 Stack Overflow에서 비슷한 것을 찾아다 쓰는 쪽을 택한다.

이 문서는 Copilot에게 정규식을 요청하는 두 가지 예(사회보장번호, 국제 전화번호)를 정리한다.

---

## 1. 사회보장번호 검사 식

프롬프트를 "Create a regular expression to validate a SSN"이라고 준다. SSN은 미국 사회보장번호(Social Security number)다. Copilot은 구현 제안과 설명으로 답한다.

```text
^\d{3}-\d{2}-\d{4}$
```

Copilot이 곁들인 설명을 표로 풀면 다음과 같다.

| 조각 | 의미 |
| --- | --- |
| `^` | 문자열의 시작 |
| `\d{3}` | 숫자 정확히 3개 |
| `-` | 하이픈 글자 그대로 |
| `\d{2}` | 숫자 정확히 2개 |
| `-` | 또 하나의 하이픈 |
| `\d{4}` | 숫자 정확히 4개 |
| `$` | 문자열의 끝 |

종합하면 `XXX-XX-XXXX` 형식(X는 숫자)인지 확인하는 식이다. 읽는 법은 왼쪽부터 조각을 하나씩 끊어 보는 것이다. `^`와 `$`가 양 끝을 잡아 주기 때문에, 중간에 다른 글자가 끼어 있으면 맞지 않는다고 판정한다.

## 2. 사용 예제도 함께 받는다

Copilot은 Python에서 쓰는 예까지 곁들인다.

```python
import re
def validate_ssn(ssn):
    pattern = r"^\d{3}-\d{2}-\d{4}$"
    return bool(re.match(pattern, ssn))
# Test the function
print(validate_ssn("123-45-6789"))  # True
print(validate_ssn("123-456-789"))  # False
```

식만 받는 것이 아니라 맞는 입력과 틀린 입력으로 시험해 볼 호출도 같이 받는다. 정규식을 만들 때 가장 번거로운 검증 단계가 한 번에 해결되는 셈이다.

## 3. 언어에 맞는 함수로 요청하기

정규식을 쓰는 함수를 현재 코딩 중인 언어로 받을 수도 있다. `phone.js`라는 JavaScript 파일에서 어떤 국제 전화번호든 검사하는 함수를 원한다고 하자. 프롬프트는 "create a function to validate any global phone number using a regular expression"이다. Copilot은 다음과 같은 JavaScript를 만든다.

```javascript
function validatePhoneNumber(phoneNumber) {
    const phoneRegex = /^\+(?:[0-9] ?){6,14}[0-9]$/;
    return phoneRegex.test(phoneNumber);
}
// Example usage:
console.log(validatePhoneNumber("+1234567890")); // true
console.log(validatePhoneNumber("1234567890")); // false
```

코드는 짧지만 정규식 자체는 간단하지 않다. 이 식은 맨 앞에 `+`가 있어야 하고, 숫자 사이에 공백이 하나씩 끼어도 허용하며, 숫자는 모두 합쳐 7~15개여야 한다. Copilot은 이번에도 호출 예를 함께 제공했고, 그 예가 의도와 다르면 제안을 거부하고 더 자세한 프롬프트로 다시 요청하면 된다.

| 예 | 요청 | 얻는 것 |
| --- | --- | --- |
| 사회보장번호 | "Create a regular expression to validate a SSN" | 식, 조각별 설명, Python 사용 예 |
| 국제 전화번호 | "create a function to validate any global phone number using a regular expression" (`phone.js`에서) | JavaScript 함수와 호출 예 |

## 4. 정리

- 정규식은 요청 한 줄로 만들 수 있고, 조각별 설명을 받으면 읽고 검증하기 쉽다.
- 맞는 입력과 틀린 입력을 함께 보여 주는 사용 예를 받아 바로 시험한다.
- 식을 쓰는 함수 전체를 현재 파일의 언어로 요청할 수 있다.
- 예제가 의도와 다르면 제안을 거부하고 프롬프트를 더 구체적으로 고쳐 다시 요청한다.
