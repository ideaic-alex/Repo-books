# 정리

이 장은 Copilot Chat을 IDE에서 쓰는 방법을 기본부터 짚었다. 채팅 창 여는 법, 응답 읽는 법, 세션 관리, 프롬프트 요령, 입력창 컨트롤, 세 가지 보조 창구, 슬래시 명령, 참여자, 변수, 맞춤 지침, 환각 대처까지 다뤘다.

---

## 1. 인라인 제안과 채팅의 비교

채팅은 대화 형태의 입력과 출력에서 인라인 코드 완성보다 훨씬 넓은 자유도를 준다. 대신 읽어야 할 내용이 많아지고, 더 많은 컨텍스트를 분석하고 더 긴 제안을 만들기 때문에 응답이 느려지는 비용이 따른다.

| 구분 | 인라인 제안 | 채팅 |
| --- | --- | --- |
| 성격 | 에디터에서 바로 보이는 즉각적인 코드 제안 | 질문과 대화 |
| 장점 | 빠르다. 대화가 필요 없다 | 훨씬 유연하다. 설명과 더 많은 결과를 얻는다 |
| 단점 | 대화를 할 수 없다 | 내용이 길고 응답 시간이 더 걸린다 |

## 2. 언제 무엇을 쓰나

에디터에서 코드를 쓰는 데 집중하고 대화가 필요 없다면, 즉시 나오는 코딩 제안만 보면 되고 채팅을 열 필요는 없다. 반대로 Copilot에게 무언가를 물어야 하거나 인라인 상호작용으로는 부족한 결과가 필요하다면 채팅이 강력한 도구다. 채팅 참여자와 채팅 참조(변수)를 더하면 관심 있는 부분에 Copilot을 집중시킬 수 있어 특히 효과적이다.

## 3. 다음 장으로

여기까지로 Copilot이 무엇이고 어떻게 상호작용하는지에 대한 핵심 이해가 갖춰졌다. 다음으로는 IDE에서 쓸 수 있는 편집과 자율 워크플로 같은 고급 기능으로 넘어간다. 이 기능들은 시간과 수고를 줄여 주고 인상적인 자동화를 해 준다.
