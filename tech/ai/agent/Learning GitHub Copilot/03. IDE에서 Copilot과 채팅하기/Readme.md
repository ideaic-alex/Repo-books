# IDE에서 Copilot과 채팅하기

인라인 제안이 지금 쓰는 코드에 맞춰 짧게 코드를 얹어 준다면, Copilot Chat은 코딩에 관한 이야기를 동료와 나누듯 자유롭게 주고받는 창구다. IDE에 Copilot을 설치하면 채팅이 함께 들어오며, 설명 요청, 개선 제안, 테스트 생성 같은 일을 대화로 처리할 수 있다.

이 장은 VS Code 기준으로 채팅 창을 여는 법과 응답 읽는 법, 세션 관리와 프롬프트 요령을 다룬다. 이어서 입력창의 컨트롤, 인라인 채팅과 Quick Chat, 터미널 채팅, 슬래시 명령, 채팅 참여자, 채팅 변수, 맞춤 코드 생성 지침, 환각 대처까지 정리한다.

---

## 1. 핵심 요점

- 채팅의 기본 모드는 Ask 모드이고, 같은 창에서 Edit와 Agent 모드로도 넘어간다. 이 장은 Ask 모드만 다룬다.
- 응답의 "Used N reference"를 펼쳐 Copilot이 어떤 파일을 참고했는지 확인한다. 기본 컨텍스트는 현재 열린 파일이다.
- 응답 속 코드는 Apply, Insert at Cursor, Copy 등으로 에디터에 옮긴다. Insert at Cursor는 선택한 코드를 덮어쓴다.
- 주제가 바뀌면 새 세션을 시작하고, 프롬프트는 일반에서 구체로, 예시를 곁들여 반복해서 다듬는다.
- 슬래시 명령(`/explain`, `/tests` 등)은 흔한 요청의 지름길이고, `@` 참여자와 `#` 변수는 컨텍스트 범위를 넓은 수준과 세부 수준에서 각각 정한다.
- 에디터 인라인 채팅과 터미널 채팅은 `Meta-I`, Quick Chat은 IDE 맨 위의 간이 창이다.
- `.github/copilot-instructions.md` 같은 맞춤 지침으로 코드 생성 방식을 길들일 수 있다. 인라인 제안에는 적용되지 않는다.
- 환각은 항상 가능하다. 없는 함수나 API를 의심하고, 실행과 테스트로 검증하며, 질문은 작게 쪼갠다.
