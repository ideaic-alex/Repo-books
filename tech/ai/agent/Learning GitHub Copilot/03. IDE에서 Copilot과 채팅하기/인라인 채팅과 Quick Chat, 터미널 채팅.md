# 인라인 채팅과 Quick Chat, 터미널 채팅

메인 채팅 창만이 채팅의 전부는 아니다. 코드 바로 옆에서 짧게 묻는 에디터 인라인 채팅, 에디터와 상관없는 질문을 빠르게 던지는 Quick Chat, 터미널 안에서 명령어를 물어보는 터미널 채팅이 있다. 상황에 맞는 창구를 고르면 화면을 오가는 수고가 줄어든다.

이 문서는 세 가지 창구의 호출 방법, 동작 방식, 쓰임새 차이를 정리한다.

---

## 1. 네 가지 채팅 창구 비교

| 창구 | 호출 | 위치 | 어울리는 용도 |
| --- | --- | --- | --- |
| 메인 채팅 창 | Copilot 아이콘 메뉴 | 에디터 오른쪽 창 | 긴 대화, 긴 답변 |
| 에디터 인라인 채팅 | `Meta-I` | 에디터의 커서 위치 | 선택한 코드에 대한 짧은 질문과 즉석 수정 |
| Quick Chat | 단축키 또는 Copilot 아이콘 메뉴 | IDE 맨 위 | 현재 코드와 무관한 빠른 질문 |
| 터미널 채팅 | 터미널에서 `Meta-I` | 터미널 | 명령어 질문 |

같은 `Meta-I`라도 에디터에 있느냐 터미널에 있느냐에 따라 열리는 대화 상자가 다르다. 읽는 법은 간단하다. 지금 커서가 어디 있는지가 곧 창구를 정한다.

## 2. 에디터 인라인 채팅

### 2.1 호출과 생김새

Copilot 통합은 에디터 안에서 쓰는 간소한 채팅 창을 제공한다. 에디터의 어느 위치에서든 `Meta-I` 조합으로 부를 수 있다. 메인 채팅 대화 상자의 축소판으로, 화면을 많이 차지하지 않도록 설계되었다. 컨텍스트 추가를 빼면 컨트롤이 메인 창과 같고, 같은 프롬프트나 질문을 보낼 수 있다. 예를 들어 앞에서 메인 창에 한 질문을, 코드를 선택한 뒤 여기서 똑같이 물어 볼 수 있다.

```text
How does this code work?
```

### 2.2 답이 잘릴 때

좁은 창이라서 Copilot은 보여 줄 수 있는 만큼만 답을 보여 준다. 스크롤하거나 대화 상자를 키우면 더 볼 수 있지만, 그래도 전체가 안 보일 수 있다. 이때 View in Chat 버튼을 누르면 메인 채팅 창에 전체 응답이 열린다. 거기서 스크롤해 읽고, 꼬리 질문을 하고, 코드를 선택해 복사하거나 삽입할 수 있다.

View in Chat 옆의 둥근 화살표는 재생성(regenerate) 버튼이다. 이 기호는 어디서든 Copilot에게 답을 다시 만들게 해서 다른, 어쩌면 더 나은 답을 받아 볼 때 쓴다.

### 2.3 에디터 코드를 직접 바꾸는 요청

인라인 대화 상자에서 시작한 작업은 에디터의 코드를 바로 고치기도 한다. 예를 들어 이렇게 요청하면 선택한 코드에 대한 문서화 주석이 인라인으로 만들어진다.

```text
document the selected code
```

| 요청의 성격 | 결과가 나타나는 곳 | 예 |
| --- | --- | --- |
| 에디터의 실제 코드를 바꾸는 요청 | 에디터에 인라인으로 적용되어, 받아들일지 검토한다 | 선택 코드 문서화 |
| 현재 코드의 대안을 묻는 요청 | 인라인 채팅 창(짧으면) 또는 메인 채팅 출력 영역 | Go로 번역, 최적화 |

즉 "이 코드를 바꿔 줘"는 에디터에서 직접 반영되고, "이 코드의 다른 버전을 보여 줘"는 채팅 쪽에 나온다.

---

## 3. Quick Chat

현재 에디터의 코드와 관계없는 질문이거나, 전체 채팅 창으로 옮길 만큼의 일이 아닐 때가 있다. 이럴 때 Quick Chat을 쓴다. IDE 맨 위에 간단한 채팅 대화 상자가 팝업으로 뜬다.

대화 상자 자체는 인라인 에디터의 것과 비슷하지만 에디터 안에 위치하지 않는다. 프롬프트로 Copilot과 상호작용한 뒤 하던 일로 곧바로 돌아갈 수 있다. 단축키로 부르거나, VS Code 상단의 Copilot 아이콘을 눌러 부른다. 그 아이콘 메뉴에는 메인 채팅 창 열기, Quick Chat 열기, 에디터 인라인 채팅 열기가 들어 있다.

---

## 4. 터미널 채팅

터미널에 특화된 채팅도 있다. VS Code 같은 환경에서 터미널에 있을 때 같은 `Meta-I`를 누르면 터미널로 향하는 프롬프트를 입력하는 대화 상자가 뜬다.

예를 들어 다음처럼 묻는다.

```text
How do I commit my changes with Git?
```

그러면 터미널에서 실행해야 할 명령어가 제시되고, 이를 바로 실행하거나 채팅에서 출력을 보는 등의 옵션을 고를 수 있다.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 제안된 명령 실행 | 터미널 채팅 대화 상자의 실행 옵션 |
| 출력을 채팅에서 보기 | 채팅에서 보는 옵션 |
| 메인 채팅에서 터미널 질문 | `@terminal` 참여자 사용 |

`@terminal`은 [슬래시 명령과 채팅 참여자](%EC%8A%AC%EB%9E%98%EC%8B%9C%20%EB%AA%85%EB%A0%B9%EA%B3%BC%20%EC%B1%84%ED%8C%85%20%EC%B0%B8%EC%97%AC%EC%9E%90.md)에서 설명한다.
