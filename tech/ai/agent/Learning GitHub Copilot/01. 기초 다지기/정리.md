# 정리

1장은 Copilot이 무엇이고 어떻게 동작하는지, 쓸 때 무엇을 조심해야 하는지, 어떤 요금제가 있는지를 훑었다. 이 문서는 장 끝의 결론을 바탕으로 핵심을 다시 묶고, 다음 장으로 넘어가는 길을 안내한다.

---

## 1. 이 장에서 다룬 것

| 주제 | 핵심 내용 |
|---|---|
| Copilot이란 | 클라우드 기반 생성형 AI 코딩 도구 |
| 동작 원리 | LLM, 컨텍스트 수집, 프롬프트 합성, 후처리, 결과 표시의 반복 |
| 고려할 점 | 시의성, 관련성, 완전성, 정확성, 개인정보, 보안 |
| ChatGPT와의 차이 | 코딩 영역 특화와 개발 환경, GitHub 통합 |
| 요금제와 설치 | Free, Pro, Pro+, Business, Enterprise와 지원 IDE |

## 2. 가져갈 세 가지

저자는 이 장에서 기억할 핵심을 세 가지로 모은다.

| 번호 | 핵심 | 풀어 쓰면 |
|---|---|---|
| 1 | AI는 코더의 일을 크게 단순화하고 뒷받침할 수 있다 | 반복적인 코드 작성과 학습 부담을 덜어 준다 |
| 2 | 최상의 결과를 얻는 데는 컨텍스트가 으뜸이다 | 파일 이름, 주석, 열린 파일, 구체적인 프롬프트가 결과를 좌우한다 |
| 3 | 제안과 답을 검토하고 평가할 최종 책임은 여전히 사용자에게 있다 | 가장 중요한 항목이다 |

Copilot은 자기 일을 아주 잘하지만 우리가 주는 컨텍스트와 쓰는 모델의 능력 및 훈련 데이터만큼만 좋다. 사람 코더와 마찬가지로 이 변수들이 결과가 얼마나 완전하고 관련 있고 정확한지(또는 아닌지)를 좌우한다.

## 3. 다음 장 안내

Copilot으로 코드를 완성하는 표준적인 방법은 여러 가지다. 2장에서는 코딩하는 IDE 인터페이스에서 Copilot의 코드 완성을 쓰고 다루는 법을 본다. 그것을 이해하면 도구를 한 단계 높여 쓰는 데 도움이 되고, 책의 나머지 부분에 필요한 기초가 갖춰진다.

2장은 조수와 어떻게 일하고 소통해야 하는지에서 출발한다. 조수에게 질의하고 필요한 것을 지시하는 법, 응답에 이어서 묻거나 여러 제안 중에서 고르는 법, 빠른 제안과 긴 설명 중 어느 쪽 소통이 나은지, AI를 코딩 작업에 가장 잘 활용하는 법이 그 질문들이다. 그 요령은 이 장에서 본 IDE 통합에서 출발한다.
