# 기초 다지기

이 장은 GitHub Copilot을 쓰기 전에 알아야 할 바탕 지식을 다룬다. Copilot이 무엇인지, 어떤 모델과 어떤 컨텍스트로 답을 만드는지, 쓸 때 어떤 점을 조심해야 하는지, ChatGPT와는 무엇이 다른지, 어떤 요금제가 있고 어디에 설치하는지를 차례로 정리한다. 이 노트는 책의 서술 시점을 따르므로 Copilot의 기능, UI, 요금제 수치는 이후 바뀌었을 수 있다.

핵심 메시지는 세 가지다. AI는 코딩을 크게 도울 수 있고, 컨텍스트가 결과의 질을 가르며, 제안을 검토할 최종 책임은 사용자에게 있다.

---

## 1. 핵심 요점

- Copilot은 클라우드 기반 생성형 AI 코딩 도구다. GitHub가 관리하는 클라우드를 거쳐 LLM이 컨텍스트와 프롬프트로 새 결과를 만든다.
- LLM은 방대한 데이터로 훈련되어 다음 토큰을 예측한다. 기본은 OpenAI 모델이고 Claude, Gemini 같은 다른 계열도 쓸 수 있다.
- 현재 파일, 파일 이름, 커서 앞뒤, 주석, 열린 파일, 로컬 인덱스가 자동으로 컨텍스트가 된다. 이것이 프롬프트로 합성되어 LLM에 가고, 후처리를 거쳐 IDE로 돌아온다.
- 시의성, 관련성, 완전성, 정확성 문제가 있을 수 있다. 모델은 훈련 시점까지만 알고, 환각이 나올 수 있다.
- 개인정보는 가입 옵션으로 제어하고, 공개 코드와 일치하는 제안은 차단할 수 있다. 보안 검사는 빠른 패턴 스캔이라 완전하지 않다.
- Copilot은 프로젝트에 새로 들어온 숙련 개발자처럼 다뤄야 한다. 자세히 알려 줄수록 좋아지고, 결과는 항상 검토한다.
- 요금제는 Free, Pro, Pro+, Business, Enterprise 다섯 가지다. 프리미엄 요청은 모델 배수에 따라 소모된다.
- VS Code, JetBrains, Visual Studio 등 여러 IDE를 지원하며 Language Server SDK로 다른 편집기에도 연결할 수 있다.
