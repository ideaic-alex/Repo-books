# Copilot과 ChatGPT 비교

ChatGPT 같은 챗봇으로도 코드를 만들 수 있는데 굳이 Copilot을 써야 하는지 궁금할 수 있다. 책의 답은 물론 써도 된다는 것이다. 다만 두 접근과 인터페이스에는 핵심적인 차이가 있다. 이 문서는 원서의 비교표를 한국어로 풀어 정리한다. ChatGPT는 코드를 만들 수 있는 범용 AI 애플리케이션을 대표해서 쓴 것이다.

---

## 1. 한 줄 차이

둘이 같은 기반 모델을 쓰는 경우도 있으나 역할이 다르다. Copilot은 코딩 영역에만 초점을 두고 그 일을 돕는 기능을 제공한다. ChatGPT는 어떤 분야든 폭넓게 겨냥하며 개발 환경과의 통합 수준이 같지 않다. Copilot은 생성형 AI를 아주 영역 특화로 구현한 것이고, ChatGPT 같은 범용 채팅 도구는 영역이 없는 폭넓은 구현이다.

## 2. 비교표

| 항목 | GitHub Copilot | ChatGPT |
|---|---|---|
| 주된 기능 | 코드 또는 코드 관련 프롬프트를 이해하고 생성 | 어떤 자연어든 이해하고 생성 |
| 주된 사용자 인터페이스 | 코드 편집기, 채팅 | 채팅 |
| 개발사 | GitHub(OpenAI와 함께) | OpenAI |
| 주된 사용 사례 | 코드와 코드 문서를 작성하고 보강 | 텍스트 생성을 포함한 대화형 응답 |
| 요금 모델 | 구독 기반이며 프리미엄 모델은 사용량을 추적 | 사용량 기반과 구독 기반 |
| 훈련 데이터 | 코드 저장소, 문서 | 다양하고 폭넓은 텍스트 콘텐츠 |
| 공개 API | 텔레메트리, 모니터링, 라이선스 관리로 한정 | 상호작용을 위한 폭넓은 API |

표를 읽는 법은 간단하다. 왼쪽 Copilot 열은 코드 편집기 안에서 코딩을 돕는 데 모여 있고, 오른쪽 ChatGPT 열은 대화와 텍스트 생성 전반에 퍼져 있다. 공개 API 항목에서 Copilot이 제한적이라는 점은 외부 프로그램이 Copilot과 직접 상호작용하는 용도가 아니라는 뜻이다.

## 3. 어떤 점이 Copilot의 강점인가

ChatGPT도 코드 생성에 쓸 수 있다. 그러나 개발 환경과의 통합, 코딩에 대한 집중, GitHub 지원과 기능은 Copilot에 있고 ChatGPT에는 없다.

| Copilot에만 있는 이점 | 설명 |
|---|---|
| 개발 환경 통합 | IDE 안에서 코드를 쓰는 흐름 그대로 제안을 받는다 |
| 코딩 집중 | 코드 구문과 구조에 맞춘 응답에 초점이 있다 |
| GitHub 지원과 기능 | 저장소, 풀 리퀘스트, 이슈 등 GitHub 작업과 연계된다 |

정리하면 범용 챗봇과 비교했을 때 Copilot의 차별점은 모델 성능 자체보다 개발 환경과 GitHub에 붙어 있다는 통합 부분에 있다.
