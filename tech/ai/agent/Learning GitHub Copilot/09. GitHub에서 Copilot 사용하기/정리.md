# 정리

이 장은 Copilot이 GitHub 웹 인터페이스와 어떻게 이어져 있는지를 다뤘다. 직접 연결 덕분에 Copilot은 저장소, 이슈, PR 같은 GitHub의 일상적인 도구 안에서 바로 쓸 수 있다.

연결의 대부분은 Copilot 채팅 인터페이스를 통해 이뤄진다. 이 문서는 장 전체를 짧게 되짚는다.

---

## 1. 장 전체 요약

- GitHub 저장소 안에는 채팅 대화창을 여는 곳이 여러 군데 있고, 자연어로 Copilot과 대화할 수 있다.
- 이슈, PR, 수정 작업을 하다가 새 Copilot 채팅을 시작하면 Copilot이 그 항목을 컨텍스트로 알아보고 관련 질문을 시작점으로 제안한다.
- 더 구체적인 답을 원하면 파일을 컨텍스트로 추가한다. PR의 코드 diff를 볼 때는 개별 파일을 붙이거나, 특정 수정이 있는 파일의 일부만 참조하라고 지시할 수도 있다.
- Copilot은 PR에서 변경 사항을 요약해 전체 설명 코멘트로 만들어 준다. 이 요약에는 특정 변경으로 가는 링크가 들어가서 PR 작성 수고를 줄인다.
- 이슈를 요약하고 이슈에 기반한 질문에 답하는 일도 돕는다.
- Copilot은 PR의 리뷰어로 추가되어 참여할 수 있다. 자동 리뷰어로서 사람 리뷰어처럼 PR 본문에 피드백과 제안을 남긴다.

## 2. 기능별 정리

| 기능 | 어디서 | 핵심 |
|---|---|---|
| 저장소 채팅 | 저장소 Code 페이지의 Copilot 아이콘, `https://github.com/copilot` | 보조형과 몰입형, 저장소가 기본 컨텍스트 |
| 인덱싱 | 채팅을 열면 자동 | 모델 학습에 쓰지 않음, 권한 있는 사용자만 혜택 |
| Autofix | 코드 스캔 경고 화면 | Generate fix로 수정안을 만들고 커밋하면 초안 PR이 열림 |
| PR 리뷰어 | PR의 Reviewers 영역 | Copilot이 피드백을 게시 |
| 링크 생성 | 채팅 | URL로 열 수 있는 작업의 링크를 만든다 |
| PR 요약 | PR 설명 영역의 Copilot 아이콘 | 유료 요금제에서 변경 요약 생성 |
| 변경 탐색 | Files changed 탭 | Ask Copilot은 파일, Attach to current thread는 diff 단위 |
| 이슈 요약 | 이슈 화면의 채팅 | 요약과 다음 단계 제안, 결과는 직접 검증 |
