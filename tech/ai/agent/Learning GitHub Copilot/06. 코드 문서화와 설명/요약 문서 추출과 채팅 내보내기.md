# 요약 문서 추출과 채팅 내보내기

처음 보는 프로젝트의 핵심을 빨리 파악하고 싶을 때 Copilot에게 프로젝트의 문서 정보를 뽑아 달라고 할 수 있다. 이 문서는 그 방법과, 채팅에서 얻은 결과를 복사하거나 내보내는 방법을 정리한다.

---

## 1. 코드에서 핵심 문서 뽑기

앞에서 쓴 Java Swagger 프로젝트에 다음 프롬프트를 준다.

```text
@workspace extract the key documentation from the code
```

Copilot은 프로젝트의 여러 파일에서 정보를 모았다. 읽은 파일은 아래와 같다.

| 읽은 파일 |
|---|
| pom.xml |
| README.md |
| 관련 *.java 파일 |

이 파일들을 바탕으로 프로젝트 구조, 의존성, Swagger 설정, 테스트에 관한 상위 수준의 요점이 나왔다. 코드베이스의 중요한 부분을 빠르게 파악해야 할 때 특히 쓸 만하다. 여기서는 파일 하나가 아니라 프로젝트 전체의 문서를 모으는 일이므로 @workspace를 쓰는 것이 맞다. 앞 문서의 "파일을 지정하라"는 규칙은 문서 결과물을 요구하는 경우에 해당하고, 이 요약 추출은 범위를 넓게 잡는 경우다.

## 2. 채팅 내용 가져가기

생성된 문서나 설명을 다른 곳에 옮기려면 채팅 내용을 꺼내야 한다. 방법이 몇 가지 있다.

| 방법 | 동작 |
|---|---|
| 대화 위에서 우클릭 후 Copy | 현재 대화 하나를 복사한다 |
| 우클릭 후 Copy All | 현재 채팅의 모든 대화를 복사한다 |
| 채팅 왼쪽 위의 Views and More Actions(점 세 개) | 채팅을 현재 IDE의 새 편집기 탭으로 열거나 독립 창으로 띄운다 |
| 명령 팔레트에서 Chat: Export Chat (VS Code 또는 codespace) | 대화를 JSON 형식으로 내보낸다 |

Chat: Export Chat을 쓰려면 먼저 채팅 패널의 대화 안에 커서가 활성화돼 있어야 한다.

## 3. 복사본은 마크다운이다

복사로 얻는 텍스트는 마크다운 형식이다. 채팅 패널에서 보이던 모양 그대로 보려면 `.md` 확장자로 저장한 뒤 마크다운을 보여 주는 도구로 열어야 한다. 그냥 붙여넣으면 표나 제목이 기호 그대로 보일 수 있다.

## 4. 정리

- 프로젝트 요약은 @workspace에 "핵심 문서를 추출해 줘"라고 시킨다.
- 결과를 보관하려면 Copy나 Copy All로 마크다운을 얻거나, VS Code에서는 Chat: Export Chat으로 JSON을 받는다.
- 이것으로 문서화 기능의 소개가 끝나고, 다음 문서부터는 코드를 설명하는 기능을 다룬다.
