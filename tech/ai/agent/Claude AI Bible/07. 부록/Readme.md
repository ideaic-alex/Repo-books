# 부록 개요 (Appendices) 용어, 프롬프트, 템플릿, 설정, FAQ

스티븐 클리어(Stephen Clear)의 『Claude AI Bible』 뒷부분은 본문을 읽은 뒤 책상 옆에 두고 꺼내 보는 참고 자료다. 부록 A부터 G까지 일곱 개로, 용어집, 바로 쓰는 프롬프트, 스킬 견본, MCP 서버 레시피, 설정 지도, 자주 묻는 질문, 더 읽을거리가 들어 있다. 저자는 책을 한 번 처음부터 끝까지 읽은 뒤 필요할 때마다 찾아보는 참고서로 쓰라고 권한다. 책은 여섯 부로 오르막을 이루며, 앞의 1~3부는 Claude를 이해하고 잘 쓰는 법, 4~5부는 직접 만드는 도구와 개발자 플랫폼, 6부는 활용 사례와 한계다. 뒤쪽에 놓인 부록이 그 모두를 받쳐 준다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 목록과 템플릿이 많은 부록이므로 항목을 통째로 옮기지 않고 구조와 용도를 설명하며 대표 항목만 새 예시로 보였다.

> **이 부를 한 문장으로**
> 본문에서 배운 것을 필요할 때 바로 꺼내 쓰도록, 용어와 프롬프트와 템플릿과 설정과 답을 한곳에 모아 둔 참고 자료다.

> **참고(노트 작성자)** 부록에 나오는 모델 이름, 요금제, 기능 상태, 설정 키, MCP 서버는 모두 책이 쓰인 2026년 기준이며 이 노트가 검증하지 않았다. 책 자신도 최신 수치는 공식 문서와 지원 센터를 믿으라고 권한다.

---

## 0. 먼저 알아 둘 것

- 책의 신호 표지: Mission(지금 해 볼 일), Trap(돈, 데이터, 시간을 잃을 실수), Operator's Edge(잘 모르는 지름길), From the Trenches(현장 이야기), 장 끝의 The Takeaways(다섯 줄 요약).
- 시작 조건: 기본은 Claude 계정, 프롬프트 장부터는 Pro 요금제, Cowork부터는 데스크톱 앱, Claude Code부터는 터미널 사용이 필요하다.
- 면책: 책의 예시는 운영 환경에 읽지 않고 붙이는 스크립트가 아니라 공부하고 고쳐 쓰는 자료다.

## 4. 이 부의 흐름 요약

부록 A에서 말을 익히고 B와 C에서 일을 시키는 틀을 얻는다. D는 Claude에게 손을 달아 줄 때의 안전 수칙을, E는 설정의 위치를 알려 준다. F는 흔한 의문에 압축해 답하고, G는 이 모두가 바뀔 때 어디서 최신을 확인할지 마무리한다. 여러 부록에 일관되게 흐르는 메시지는 두 가지다. 결과는 초안이므로 검증하고, 행동을 맡길 때는 최소 권한과 사람의 확인을 둔다.
