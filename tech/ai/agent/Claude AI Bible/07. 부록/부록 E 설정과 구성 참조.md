# 부록 E 설정과 구성 참조 (Settings and Configuration Reference)

부록 E는 Claude를 어디서 어떻게 설정하는지 한 장으로 묶은 지도다. 제품마다 설정 위치가 다르고 메뉴 이름과 위치는 제품이 바뀌며 달라지므로, 책은 "무엇이 있고 대략 어디 있는지"를 알려 주는 안내로 읽고 정확한 경로는 현재 화면이나 공식 문서에서 확인하라고 한다.

> **쉽게 말하면**
> 계정, 말투, 개인정보, Cowork, Claude Code, API 키라는 여섯 군데의 스위치가 어디 있는지 알려 주는 안내도다.

> **참고(노트 작성자)** 설정 이름과 `settings.json` 키는 책이 "설명용 예시"라고 밝힌 것이며 노트가 검증하지 않았다. 실제 스키마는 공식 문서로 확인해야 한다.

## 1. 설정 지점 한눈에 보기

| 항목 | 용도 | 비고 |
|------|------|------|
| 계정 설정 | 요금제와 결제, 표시 이름, 연락 메일, 언어, 로그인과 2단계 인증 | Team·Enterprise는 관리자가 일부를 조직 단위로 통제해서 보이는 항목이 줄어든다 |
| 사용자 지정 지침 | 모든 대화에 걸쳐 적용되는 기본 답변 방식("간결하게", "영국식 영어로") | 개인화 또는 환경설정이라는 이름으로 나오기도 한다 |
| 스타일 설정 | 어조와 형식을 조절 | 대화별, 프로젝트별로 전역 기본값을 덮어쓸 수 있다 |
| 프로젝트 지침 | 해당 프로젝트 전체에 적용되는 시스템 프롬프트 역할 | 한 작업 묶음에만 맞는 맥락은 여기에 둔다 |
| 개인정보·데이터 | 대화가 모델 개선에 쓰일지 선택, 메모리 관리, 데이터 내보내기·삭제 | 기본값과 선택지는 공식 문서에서 확인. 민감한 작업 전에 가장 먼저 볼 곳 |
| Cowork 작업 공간 | Claude가 내 컴퓨터에서 일할 위치와 만질 수 있는 범위(샌드박스 경계) | 데스크톱 앱 안에 있다 |
| Cowork 커넥터 | 외부 서비스 연결의 활성화와 권한 | 권한 범위를 작업에 필요한 만큼만 좁게 |
| Cowork 예약 작업 | 정해진 주기로 자동 실행되는 작업 | 지켜보지 않아도 실행되므로 각 작업의 허용 범위를 점검 |
| Claude Code 설정 파일 | 기본 모델, 권한, 훅, 환경 변수 | 사용자 수준(모든 프로젝트)과 프로젝트 수준(저장소와 함께 팀 공유) |
| `CLAUDE.md` | 프로젝트 규칙, 빌드·테스트 명령 등을 자동으로 읽히게 | 설정 파일과 별개이며 똑같이 중요하다 |
| API 키 | API와 Agent SDK 이용에 쓰는 비밀 값 | 개발자 콘솔에서 관리, 채팅 구독과 별개 |

## 2. Claude Code 설정 예시의 읽는 법

책의 `settings.json` 예시는 모양을 보여 주기 위한 것이다. 키 이름은 책이 쓴 대로이며 검증하지 않았다.

| 키 | 보여 주려는 것 |
|------|----------------|
| `model` | 기본으로 쓸 모델 선택 |
| `permissions.allow` | 읽기, 특정 폴더 수정, 특정 명령 실행처럼 허용할 일을 구체적으로 나열 |
| `permissions.deny` | `.env`, 비밀 폴더처럼 읽지 못하게 막을 대상. 허용 규칙이 넓어도 자격 증명 접근을 막아 준다 |
| `hooks` | 도구 사용 뒤처럼 정해진 순간에 자동 실행할 명령(예: 파일 수정 뒤 린트) |
| `env` | 비밀은 파일에 값을 쓰지 않고 환경 변수에서 가져온다 |

교훈은 세 가지다. 포괄 허용 대신 허용과 거부를 구체적으로 나눈다, 자동화는 훅으로 건다, 비밀은 환경 변수에 둔다.

## 3. API 키 관리 수칙

- 키는 비밀이므로 환경 변수나 비밀 관리 도구에 두고, 커밋하는 코드나 공유하는 설정 파일에 쓰지 않는다.
- 유출이 의심되면 즉시 교체한다.
- 콘솔에서 지출 한도, 사용량, 팀 작업 공간을 관리한다. 첫날 지출 한도를 걸어 두는 것이 가장 싼 보험이다.

## 핵심 정리

- 설정은 계정, 사용자 지정 지침, 개인정보, Cowork, Claude Code, API 키 여섯 곳에 흩어져 있다.
- 범위가 넓은 곳(프로젝트 지침, 예약 작업, 커넥터)일수록 권한을 좁게 잡는다.
- Claude Code는 허용과 거부 목록, 훅, 환경 변수로 구성하고 비밀은 파일에 넣지 않는다.
