# 4부 개요 (Part IV) 빌더 도구

스티븐 클리어(Stephen Clear)의 『Claude AI Bible』 4부는 "The Builder's Toolkit"으로, Claude를 직접 쓰는 단계에서 Claude에게 일을 시키고 확장하는 단계로 넘어가는 네 개 장이다. 터미널 에이전트인 `Claude Code`(13장), 반복 작업을 포장하는 `Skill`(14장), 여러 조각을 묶어 배포하는 플러그인과 마켓플레이스(15장), 외부 도구와 데이터를 잇는 표준 `MCP`(16장)를 차례로 다룬다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책은 Claude 제품 가이드이므로 명령어, 설정 키, 파일 경로, 모델 이름, 수치는 책이 쓰인 시점 기준이며 노트가 검증하지 않았다. 실제로 적용할 때는 공식 문서와 현재 제품 화면으로 확인한다.

> **이 부를 한 문장으로**
> 에이전트에 일을 맡기는 법(`Claude Code`), 우리 방식을 가르치는 법(`Skill`), 묶어서 나누는 법(플러그인), 바깥 세계와 잇는 법(`MCP`)을 배우되, 모든 단계에서 최소 권한과 사람의 검토를 지키는 부다.

---

## 0. 먼저 알아 둘 것

- **터미널과 git**: 13장은 터미널 명령과 git의 기본(커밋, 되돌리기)을 안다고 전제하고 설명한다. 코딩 경력이 없어도 쓸 수 있다는 것이 책의 입장이다.
- **JSON 설정과 마크다운**: 설정 파일과 `SKILL.md` 예시가 나오므로 중괄호 구조와 마크다운 문법을 눈으로 읽을 수 있으면 충분하다.
- **보안이 이 부의 공통 주제**: 권한 설정, 플러그인 점검, MCP 서버 범위와 프롬프트 인젝션이 장마다 반복된다.

## 2. 4부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| `Claude Code` | 터미널에서 파일을 읽고 고치고 명령을 실행하는 Claude 에이전트 |
| `CLAUDE.md` | 프로젝트 루트에 두어 세션마다 자동으로 읽히는 상시 지침 파일 |
| 훅(hook) | 에이전트 동작의 특정 시점에 자동으로 실행되는 명령 |
| 서브에이전트 | 별도 맥락에서 좁은 일을 처리하고 요약만 돌려주는 일꾼 |
| `Skill` | `SKILL.md`가 든 폴더. 설명이 맞는 작업에서 Claude가 불러 쓴다 |
| 플러그인 | `Skill`, MCP 서버, 슬래시 명령, 에이전트를 묶은 설치 단위 |
| 마켓플레이스 | 플러그인 카탈로그. 출처를 추가해 쓴다 |
| `MCP` | AI와 외부 도구를 잇는 열린 프로토콜 |
| 프롬프트 인젝션 | 데이터에 섞인 문장으로 모델의 행동을 조종하려는 공격 |
| 최소 권한 | 일에 필요한 가장 좁은 접근만 주는 원칙 |

## 3. 이 부의 흐름 요약

13장은 에이전트를 쓰는 방법과 통제 습관(계획, 커밋, diff 검토)을 세운다. 14장은 그 에이전트에게 반복 업무의 "우리 방식"을 `Skill`로 가르친다. 15장은 `Skill`과 연결과 명령이 여럿 모였을 때 플러그인으로 묶어 마켓플레이스로 배포하되, 설치 전 점검과 거버넌스를 갖추게 한다. 16장은 그 모든 것 밑에서 외부 도구를 잇는 `MCP`를 설명하고, 연결이 곧 권한이라는 점에서 보안 원칙을 정리한다.
