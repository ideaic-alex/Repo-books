# 2부 개요 (Part II) 대화의 기술

스티븐 클리어(Stephen Clear)의 『Claude AI Bible』 중 2부 "The Craft of Conversation"은 네 개 장으로, Claude와 일상적으로 대화할 때 결과를 좌우하는 기술을 다룬다. 명확한 프롬프트 쓰기(5장), 추론 깊이와 출력 형식 같은 조절 장치(6장), 반복되는 맥락을 붙잡아 두는 프로젝트·메모리·지식(7장), 결과물을 작업 표면에 올려 다듬는 아티팩트(8장)가 이어진다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 기능 이름, 한도, 모델 이름과 동작에 대한 서술은 책이 쓰인 시점 기준이며 노트 작성자가 검증하지 않았다. 해당 내용이 나오는 곳에 `참고(노트 작성자)`로 표시했다.

> **이 부를 한 문장으로**
> 분명한 프롬프트, 난이도에 맞춘 조절 장치, 상시 맥락, 함께 다듬는 작업 표면, 이 네 가지를 함께 쓰는 것이 대화의 기술이다.

---

## 0. 먼저 알아 둘 것

- **코딩이 필요 없다**: 책은 이 부의 기법 대부분이 일반 앱에서 쓰인다고 한다. 일부(온도, prefilling 등)는 API에서만 만져 볼 수 있다.
- **제품 기능은 변한다**: Project, Memory, 아티팩트의 한도와 제공 범위는 바뀔 수 있다. 책도 최신 내용은 공식 문서를 확인하라고 안내한다.
- **3부 이후와 연결**: 에이전트, MCP, Claude Code 같은 주제는 이 부에서 짧게 언급만 되고 뒤에서 다뤄진다.

## 2. 2부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 프롬프트 | Claude에게 주는 지시와 맥락 |
| 시스템 프롬프트 | 대화 전체에 지속적으로 적용되는 지침 |
| few-shot | 원하는 결과의 견본을 한두 개 보여 주는 방식 |
| 확장 사고 (extended thinking) | 답하기 전에 모델이 내부적으로 더 따져 보는 기능 |
| 컨텍스트 | Claude가 답할 때 볼 수 있는 모든 내용 |
| 프롬프트 체이닝 | 큰 일을 단계로 나눠 앞 출력을 뒤 입력으로 넘기는 방식 |
| 프롬프트 인젝션 | 외부 텍스트에 숨은 지시가 Claude를 조종하는 위험 |
| Project | 지침, 지식 파일, 대화를 묶은 작업 공간 |
| Memory | 대화 사이에 Claude가 기억하는 사실 |
| 아티팩트 (artifact) | 대화창 옆 패널에 띄우는 지속되는 결과물 |

## 3. 이 부의 흐름 요약

5장은 상대의 추측을 줄이는 프롬프트 쓰기의 기본을 세우고, 6장은 그 아래에서 깊이, 형식, 입력 구성, 모델 등급을 난이도에 맞추는 장치를 소개한다. 7장은 반복되는 맥락을 Project와 지식 베이스에 두어 매번 설명하는 비용을 줄이고 Memory와 공유의 경계를 짚으며, 8장은 결과물을 아티팩트로 만들어 제자리에서 고치는 방법과 그 한계를 정리한다. 결국 네 장은 하나의 흐름으로, 분명하게 말하고, 조절하고, 맥락을 붙잡고, 작업 표면 위에서 다듬는 순서다.
