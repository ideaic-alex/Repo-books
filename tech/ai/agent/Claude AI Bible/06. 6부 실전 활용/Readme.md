# 6부 개요 (Part VI) 실전 활용

스티븐 클리어(Stephen Clear)의 『Claude AI Bible』 6부는 지금까지 배운 부품을 현장에 적용하는 마지막 부분이다. 21장은 열두 업종의 활용 사례를 보여 주고, 22장은 Claude의 한계와 위험, 그리고 앞으로를 솔직하게 다룬다. 이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다.

> **이 부를 한 문장으로**
> 반복되는 기계적 작업은 Claude에게 맡기고 판단, 검증, 책임은 사람이 쥐되, 그 경계를 어디에 그을지 한계를 알고 정하는 방법을 배우는 부분이다.

> **참고(노트 작성자)** 책에 나오는 수치, 사례, 규제와 법률 관련 서술은 책의 주장이며 노트가 검증하지 않았다. 의료, 법률, 금융 분야 내용은 책이 설명하는 활용 방식일 뿐 전문적 조언이 아니다.

---

## 0. 먼저 알아 둘 것

- **앞 부분의 도구들**: Projects, Cowork, Skills, 커넥터와 MCP, Claude Code, API(Batch API 포함)가 사례에 섞여 나온다. 이름만 알아도 읽을 수 있고, 각 도구의 자세한 설명은 앞 부의 장에 있다.
- **합성 사례**: 책은 사례의 회사와 인물이 익명화된 합성이라고 밝힌다.
- **최신 정보 확인**: 요금, 한도, 데이터 정책은 바뀔 수 있어 책도 공식 문서를 확인하라고 거듭 말한다.

## 2. 6부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 환각 | 모델이 그럴듯하지만 사실이 아닌 내용을 만들어 내는 것 |
| 근거 인용 | 주장마다 원문 출처를 달게 해 확인을 쉽게 하는 방식 |
| 초안 지원(draft-assist) | AI가 초안을 쓰고 사람이 검토해 보내는 방식 |
| 데이터 최소화 | 작업에 꼭 필요한 데이터만 외부 도구에 넣는 원칙 |
| 과잉 자동화 | 위험을 따지지 않고 사람 검토를 너무 일찍 빼는 것 |
| 기술 퇴화 | 사람이 검토를 안 하게 되어 오류를 알아보는 능력을 잃는 것 |

## 3. 이 부의 흐름 요약

21장은 법무부터 비영리까지 열두 사례로 "기계적인 일은 에이전트, 판단은 사람"이라는 분업과 검증을 싸게 만드는 설계를 보여 준다. 22장은 그 반대편에서, 모델이 무엇을 못 하고 왜 환각이 생기는지, 데이터와 자동화의 선을 어디에 그을지, 앞으로의 방향을 어디까지 믿을지를 정리하며, 한계를 아는 운영자가 오래 신뢰받는다는 결론으로 책을 마무리한다.
