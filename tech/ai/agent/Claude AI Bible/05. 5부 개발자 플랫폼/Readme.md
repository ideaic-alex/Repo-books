# 5부 개요 (Part V) 개발자 플랫폼

스티븐 클리어(Stephen Clear)의 『Claude AI Bible』 5부는 채팅 제품을 쓰는 사람에서 Claude로 직접 무언가를 만드는 사람으로 넘어가는 부분이다. 17장은 Anthropic API, 18장은 Claude Agent SDK, 19장은 도구 사용·컴퓨터 사용·비전, 20장은 에이전트와 자동화를 끝까지 만들어 내는 법을 다룬다. 책에 따르면 5부는 터미널에서 명령을 실행하고 짧은 코드를 읽을 수 있는 독자를 대상으로 한다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. API 파라미터, SDK 함수명, 모델 ID, 가격, 한도는 책이 쓰인 시점 기준이며 노트가 검증하지 않았다. 실제로 쓰기 전에 공식 문서를 확인하기를 권한다.

> **이 부를 한 문장으로**
> 호출 하나로 되는 일은 호출로, 순서를 아는 일은 워크플로로, 순서를 모르는 일만 에이전트로 풀고, 어느 쪽이든 비용·검증·사람 승인·작은 피해 범위로 안전하게 만드는 법이다.

---

## 0. 먼저 알아 둘 것

- **토큰**: 비용과 길이를 재는 단위. 입력 토큰과 출력 토큰으로 나뉘며 출력이 더 비싸다고 책은 말한다.
- **API 키**: 요청이 나에게서 왔고 나에게 청구된다는 것을 증명하는 비밀 문자열. 코드에 붙이지 않고 환경 변수 등에 둔다.
- **MCP**: 앞선 장에서 다룬, 도구와 데이터를 공통 규격으로 연결하는 프로토콜. 18장에서 SDK가 이를 지원한다고 나온다.
- **코드 예시**: 책의 예시는 주로 Python이지만 노트에서는 개념을 보이는 짧은 의사코드만 썼다.

## 2. 5부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| `Messages API` | 대화와 설정을 보내면 Claude의 다음 메시지를 돌려받는 기본 호출 |
| 상태 없음(stateless) | API가 호출 사이에 아무것도 기억하지 않아 기록을 직접 보내야 하는 성질 |
| 프롬프트 캐싱 | 반복되는 긴 앞부분을 재사용해 비용과 지연을 줄이는 기법 |
| `Batch API` | 급하지 않은 대량 작업을 비동기로 싸게 처리하는 방식 |
| 에이전트 루프 | 모델이 결정, 도구 실행, 관찰, 반복을 거듭하는 순환 |
| 도구 사용 | Claude가 실행을 요청하고 내 코드가 실행해 결과를 돌려주는 협상 |
| 컴퓨터 사용 | 스크린샷을 보고 클릭·입력하는 방식으로 화면 프로그램을 조작하는 기능 |
| 멱등성 | 같은 작업을 두 번 해도 한 번과 같은 결과가 되는 성질 |
| 평가(eval) | 대표 입력과 정답으로 이뤄진 자동화 테스트 세트 |
| 피해 범위(blast radius) | 시스템이 완전히 오작동했을 때 입힐 수 있는 최악의 손해 규모 |

## 3. 이 부의 흐름 요약

17장에서 API로 요청 하나를 안전하고 싸게 보내는 법을 익히면, 18장에서 그 호출을 반복하며 스스로 일하는 에이전트의 루프와 권한 통제를 배운다. 19장은 그 루프의 부품인 도구 사용을 원리부터 설명하고, 화면을 조작하는 컴퓨터 사용의 위험과 읽기 전용에 가까운 비전을 더한다. 20장은 이 모두를 패턴, 신뢰성, 평가, 피해 범위 축소, 단계적 출시로 묶어 오래 믿을 수 있는 자동화로 만든다. 부 전체에 걸쳐 책이 되풀이하는 말은 가장 단순한 방법을 쓰고, 안전장치와 사람 게이트를 함께 설계하라는 것이다.
