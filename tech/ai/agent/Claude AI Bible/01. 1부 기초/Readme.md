# 1부 개요 (Part I) 기초 (Foundations)

스티븐 클리어(Stephen Clear)의 『Claude AI Bible: The Complete Guide to Mastering Claude, Claude Code, Claude Cowork, MCP, AI Agents, Automation …』는 Claude 제품군을 실무자의 관점에서 안내하는 가이드북이다. 1부는 네 개 장으로, Claude가 어떤 철학으로 만들어졌는지, 모델 가족을 어떻게 고르는지, 다른 AI와 어떻게 비교하는지, 계정과 요금제를 어떻게 설정하는지를 다룬다. 뒤쪽의 Claude Code, MCP, 에이전트를 읽기 전에 필요한 바탕이다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책의 모델 이름, 요금제, 기능 상태는 책이 서술한 시점(2026년 판) 기준이며 노트가 검증하지 않았으므로 바뀔 수 있다. 책 스스로도 가격, 한도 같은 세부는 공식 문서에서 확인하라고 한다.

> **이 부를 한 문장으로**
> Claude의 성격과 모델 가족을 이해하고, 다른 AI와 증거로 비교하며, 요금제와 계정을 올바르게 설정하는 출발 준비다.

---

## 0. 먼저 알아 둘 것

- **채팅 제품과 API는 다르다**: 사람이 앱에서 대화하는 것과 프로그램이 모델을 호출하는 것은 별개의 계정이다(4장).
- **숫자는 스냅샷이다**: 모델 버전, 컨텍스트 창 크기, 요금제 이름은 시간이 지나면 달라진다. 개념은 오래가고 세부는 빨리 변한다는 것이 책의 태도다.
- **저자의 경험담이 섞여 있다**: 3장의 경쟁 모델 평가처럼 책의 서술은 저자의 경험과 의견을 포함한다.

## 2. 1부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| Constitutional AI | 글로 쓴 원칙에 비추어 모델이 자기 출력을 비판·수정하게 하는 훈련 방식 |
| RLHF | 사람의 선호로 모델을 조정하는 기법 |
| token | 모델이 읽고 쓰는 텍스트 조각 단위 |
| context window | 모델이 한 번에 다루는 총 텍스트 범위 |
| hallucination | 그럴듯하지만 거짓인 내용을 만들어 내는 현상 |
| agent | 목표를 받아 계획·도구 사용·점검을 반복해 수행하는 AI 시스템 |
| 확장 사고 | 답하기 전에 단계별로 추론할 여유를 주는 모드 |
| 프롬프트 캐싱 | 반복되는 고정 문맥을 싸게 재사용하는 API 기능 |
| custom instructions | 모든 대화에 적용되는 개인 설정 |
| API 계정 | 코드로 모델을 호출하는 종량제 계정. 채팅 구독과 별개 |

## 3. 이 부의 흐름 요약

1장은 Claude의 성격이 어디서 왔는지와 기본 용어를 세운다. 2장은 그 모델이 세 등급으로 나뉘어 있음을 보이고 일에 맞게 고르는 법을 알려 준다. 3장은 시야를 넓혀 다른 AI와 증거에 기반해 비교하는 방법을 다룬다. 4장은 실제로 시작하기 위한 요금제, 개인정보, 계정 구분을 정리하며, 특히 구독과 API의 차이를 뒤쪽 구축 장의 전제로 놓는다.
