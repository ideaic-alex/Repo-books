# 핵심 정리

이 문서는 1부(1장부터 4장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 모델 이름, 요금제, 기능 상태는 책이 서술한 시점(2026년 판) 기준이며 노트가 검증하지 않았다.

---

## 1. 한눈에 보는 요점

- **Claude는 판단 기준을 가진 동료에 가깝다**: Anthropic은 안전을 앞세운 공익법인이고, 원칙에 비추어 스스로 고치게 하는 Constitutional AI로 일관성과 아첨 저항을 얻었다고 책은 설명한다.
  - *쉽게 말하면*: 시키는 대로만 하는 자판기가 아니라 틀렸다고 말해 주는 편집자다.
  - → 자세히: [1장 양심을 가진 기계](01%EC%9E%A5%20%EC%96%91%EC%8B%AC%EC%9D%84%20%EA%B0%80%EC%A7%84%20%EA%B8%B0%EA%B3%84.md)
- **모델과 제품은 다르다**: Claude는 다음 토큰을 예측하는 LLM에 시스템 프롬프트, 도구, 안전 장치가 얹힌 제품이며, 못 하는 일은 제품에 연결되지 않은 경우가 많다.
  - *쉽게 말하면*: 엔진과 자동차는 다르다.
  - → 자세히: [1장 양심을 가진 기계](01%EC%9E%A5%20%EC%96%91%EC%8B%AC%EC%9D%84%20%EA%B0%80%EC%A7%84%20%EA%B8%B0%EA%B3%84.md)
- **Sonnet으로 시작하고 증거로 움직인다**: Opus는 가장 어려운 추론, Sonnet은 대부분의 업무, Haiku는 빠르고 싼 대량 작업에 맞는다.
  - *쉽게 말하면*: 일을 해낼 만한 가장 싼 모델에서 시작해 실패를 보면 올린다.
  - → 자세히: [2장 Opus·Sonnet·Haiku 모델 가족](02%EC%9E%A5%20Opus%C2%B7Sonnet%C2%B7Haiku%20%EB%AA%A8%EB%8D%B8%20%EA%B0%80%EC%A1%B1.md)
- **비용 레버는 라우팅과 캐싱이다**: 쉬운 건은 싼 모델, 어려운 건 큰 모델로 나누고, 반복 문맥은 캐싱하며, 모델 버전은 설정 한 곳에 둔다.
  - *쉽게 말하면*: 비싼 모델은 꼭 필요한 곳에만 쓴다.
  - → 자세히: [2장 Opus·Sonnet·Haiku 모델 가족](02%EC%9E%A5%20Opus%C2%B7Sonnet%C2%B7Haiku%20%EB%AA%A8%EB%8D%B8%20%EA%B0%80%EC%A1%B1.md)
- **"최고의 모델"은 없고 내 작업으로 시험한다**: 벤치마크는 대략적 필터일 뿐이고, 실제 과제 3개와 사전 기준으로 하는 15분 평가가 더 믿을 만하다.
  - *쉽게 말하면*: 리더보드보다 내 숙제로 채점하라.
  - → 자세히: [3장 Claude와 다른 AI 비교](03%EC%9E%A5%20Claude%EC%99%80%20%EB%8B%A4%EB%A5%B8%20AI%20%EB%B9%84%EA%B5%90.md)
- **여러 모델을 의도적으로 함께 쓴다**: 한 모델로 초안을 쓰고 다른 모델로 비판하며, 의견이 갈리는 곳을 검증 대상으로 삼고, 모델을 바꿀 때는 프롬프트를 재조정한다.
  - *쉽게 말하면*: 두 번째 눈이 첫 번째의 맹점을 찾는다.
  - → 자세히: [3장 Claude와 다른 AI 비교](03%EC%9E%A5%20Claude%EC%99%80%20%EB%8B%A4%EB%A5%B8%20AI%20%EB%B9%84%EA%B5%90.md)
- **요금제는 낮게 시작해 막힐 때 올린다**: 개인은 Free, Pro, Max, 조직은 Team, Enterprise이며, 개인 계단은 사용 여유를, 조직 계단은 관리를 산다.
  - *쉽게 말하면*: 불안해서 최상위를 사지 말고 실제 벽에 부딪히면 올린다.
  - → 자세히: [4장 시작하기 요금제·가격·개인정보·계정](04%EC%9E%A5%20%EC%8B%9C%EC%9E%91%ED%95%98%EA%B8%B0%20%EC%9A%94%EA%B8%88%EC%A0%9C%C2%B7%EA%B0%80%EA%B2%A9%C2%B7%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4%C2%B7%EA%B3%84%EC%A0%95.md)
- **구독과 API는 별개 계정이다**: 사람이 대화하면 구독, 프로그램이 호출하면 종량제 API이며, API는 코드를 쓰기 전에 지출 한도를 건다.
  - *쉽게 말하면*: 말로 쓰면 구독, 코드가 쓰면 API다.
  - → 자세히: [4장 시작하기 요금제·가격·개인정보·계정](04%EC%9E%A5%20%EC%8B%9C%EC%9E%91%ED%95%98%EA%B8%B0%20%EC%9A%94%EA%B8%88%EC%A0%9C%C2%B7%EA%B0%80%EA%B2%A9%C2%B7%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4%C2%B7%EA%B3%84%EC%A0%95.md)

## 2. 1부를 관통하는 질문

| 질문 | 1부가 보여 주는 답 |
|------|-------------------|
| Claude는 왜 아첨하지 않고 불확실성을 말하나? | 원칙 기반 훈련과 공익법인 구조의 결과라고 책은 본다 |
| 어떤 모델을 쓸까? | Sonnet에서 시작해 어려우면 Opus, 단순 대량이면 Haiku |
| 다른 AI와 어떻게 비교하나? | 여러 기준으로 보고, 내 작업으로 15분 평가 |
| 무슨 요금제로 시작하나? | Free에서 시작해 업무를 끊는 한도에 걸릴 때 올림 |
| 숫자와 정책은 어디서 확인하나? | 공식 문서(docs.claude.com, support.claude.com) |
