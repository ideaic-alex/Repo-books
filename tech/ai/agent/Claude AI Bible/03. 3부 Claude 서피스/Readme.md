# 3부 개요 (Part III) Claude 서피스

스티븐 클리어(Stephen Clear)의 『Claude AI Bible』 3부는 Claude를 실제로 만지는 "화면"들을 다루는 네 개 장이다. 9장은 웹, 데스크톱, 모바일, 음성 앱을, 10장은 폴더와 도구를 직접 다루는 데스크톱 오퍼레이터 Claude Cowork를, 11장은 브라우저 안에서 일하는 Claude in Chrome을, 12장은 스프레드시트 안에서 일하는 Claude in Excel을 설명한다. 뒤로 갈수록 Claude가 말만 하는 존재에서 파일, 웹 페이지, 셀을 직접 건드리는 존재로 바뀌므로, 권한 승인과 확인 습관이 점점 중요해진다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 기능 이름, 지원 플랫폼, 모델 이름, 제공 범위는 책이 쓴 시점 기준이며 노트가 검증하지 않았다. 책도 베타나 연구 프리뷰 기능은 공식 문서로 최신 상태를 확인하라고 거듭 말한다.

> **이 부를 한 문장으로**
> 같은 모델이 여러 입구와 도구로 나타나며, 도구가 직접 행동할수록 범위를 좁히고 확인창을 읽고 결과를 사람이 검증해야 한다.

---

## 0. 먼저 알아 둘 것

- **서피스(surface)**: 사용자가 Claude를 만나는 입구. 앱, Cowork, 브라우저 확장, Excel 통합 등.
- **베타와 연구 프리뷰**: 책은 Cowork를 연구 프리뷰로, Chrome과 Excel을 베타로 소개한다. 화면과 동작이 바뀔 수 있다.
- **안전 내용이 핵심**: 10~12장은 모두 파일, 웹, 셀을 직접 조작하므로 권한 범위, 확인 프롬프트, 프롬프트 인젝션, 민감 정보 주의가 반복해서 나온다.
- 1, 2부의 모델과 프롬프트 내용이 이어지지만, 이 부만 먼저 읽어도 흐름을 따라갈 수 있다.

## 2. 3부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 서피스 | Claude를 쓰는 입구(웹, 데스크톱, 모바일 등) |
| 전역 단축키 | 어떤 앱에서든 Claude 입력창을 띄우는 키 조합 |
| Cowork | 연결한 폴더에서 파일 작업과 예약 작업을 하는 데스크톱 오퍼레이터 |
| 연결 폴더 | Cowork가 보고 쓸 수 있도록 허용한 폴더. 밖은 보이지 않음 |
| MCP | Claude를 외부 도구와 데이터에 잇는 연결 규약 |
| Skill | 반복 업무의 절차를 담은 재사용 가능한 노하우 |
| 예약 작업 | 정해진 때에 사람이 시작하지 않아도 실행되는 작업 |
| 에이전틱 모드 | Claude가 브라우저를 직접 조작하는 모드 |
| 프롬프트 인젝션 | 웹 페이지 속 글이 에이전트에게 명령처럼 작용하도록 꾸며진 공격 |
| 확인 프롬프트 | 중요한 행동 전에 사용자의 승인을 묻는 창 |

## 3. 이 부의 흐름 요약

9장은 모델은 같고 입구만 다르다는 관점을 세우고 각 앱의 쓰임을 정한다. 10장에서는 Claude가 폴더 안에서 직접 일하게 되면서 울타리와 확인 경계라는 안전 개념이 등장한다. 11장은 같은 개념을 신뢰할 수 없는 웹으로 확장해 프롬프트 인젝션과 감독의 중요성을 다룬다. 12장은 스프레드시트에서 틀린 숫자가 오류 없이 지나가는 문제를 중심으로, 만드는 일은 맡기고 검증은 사람이 한다는 원칙으로 마무리한다.
