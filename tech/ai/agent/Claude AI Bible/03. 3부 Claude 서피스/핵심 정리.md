# 핵심 정리

이 문서는 3부(9장부터 12장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 기능, 모델, 플랫폼 정보는 책이 쓴 시점 기준이며 노트가 검증하지 않았다.

---

## 1. 한눈에 보는 요점

- **Claude는 한 곳이 아니라 여러 입구다**: 웹, 데스크톱, 모바일, 음성이 같은 모델을 공유하고, 기능이 안 보이면 대개 접근의 문제다.
  - *쉽게 말하면*: 방은 같고 문만 여러 개다.
  - → 자세히: [9장 앱 데스크톱·웹·모바일·음성](09%EC%9E%A5%20%EC%95%B1%20%EB%8D%B0%EC%8A%A4%ED%81%AC%ED%86%B1%C2%B7%EC%9B%B9%C2%B7%EB%AA%A8%EB%B0%94%EC%9D%BC%C2%B7%EC%9D%8C%EC%84%B1.md)
- **웹은 새 기능, 데스크톱은 단축키, 모바일은 카메라**: 대화와 계정은 동기화되지만 기기 고유 설정과 로컬 파일은 따라가지 않는다.
  - *쉽게 말하면*: 일에 맞는 문을 고르면 된다.
  - → 자세히: [9장 앱 데스크톱·웹·모바일·음성](09%EC%9E%A5%20%EC%95%B1%20%EB%8D%B0%EC%8A%A4%ED%81%AC%ED%86%B1%C2%B7%EC%9B%B9%C2%B7%EB%AA%A8%EB%B0%94%EC%9D%BC%C2%B7%EC%9D%8C%EC%84%B1.md)
- **Cowork는 연결 폴더 안에서 일하는 오퍼레이터다**: 파일, 샌드박스 셸, MCP, Skills, 예약 작업, 컴퓨터 사용을 갖추며 연구 프리뷰다.
  - *쉽게 말하면*: 울타리 안에서 일을 맡기는 동료다.
  - → 자세히: [10장 Claude Cowork](10%EC%9E%A5%20Claude%20Cowork.md)
- **확인창은 읽고 승인한다**: 지시문에 삭제 금지 같은 한계를 먼저 적고, 컴퓨터 사용은 피해 범위에 맞춰 읽기, 클릭, 입력 단계를 고른다.
  - *쉽게 말하면*: 습관적으로 누르면 안전 장치가 무의미해진다.
  - → 자세히: [10장 Claude Cowork](10%EC%9E%A5%20Claude%20Cowork.md)
- **Chrome 에이전트는 감독자 자세로 쓴다**: 사이드바는 넓게, 에이전틱 모드는 신중하게. 페이지 속 지시는 신뢰하지 않고(프롬프트 인젝션), 로그인은 사람이 한다.
  - *쉽게 말하면*: 웹 페이지의 글은 명령이 아니라 읽을 내용이다.
  - → 자세히: [11장 Claude in Chrome](11%EC%9E%A5%20Claude%20in%20Chrome.md)
- **돈, 발신, 되돌릴 수 없는 일은 직접 한다**: 읽기 중심이고 믿을 만한 페이지의 작업부터 시작하고, 최악의 경우를 기준으로 작업을 고른다.
  - *쉽게 말하면*: 실패가 싼 일만 맡긴다.
  - → 자세히: [11장 Claude in Chrome](11%EC%9E%A5%20Claude%20in%20Chrome.md)
- **Excel에서는 결과를 말하고 검증은 사람이 한다**: 수식 작성과 설명, 정리, 모델, 감사를 맡기되, 스프레드시트는 틀려도 오류를 내지 않으므로 규모 점검과 대사를 한다.
  - *쉽게 말하면*: 잡일은 맡기고 숫자의 책임은 내가 진다.
  - → 자세히: [12장 Claude in Excel](12%EC%9E%A5%20Claude%20in%20Excel.md)
- **삭제는 표시만 시키고 시작은 복사본에서**: 민감한 데이터는 정책 확인과 식별자 마스킹을 먼저 한다.
  - *쉽게 말하면*: 되돌릴 수 없는 결정은 내 손에 둔다.
  - → 자세히: [12장 Claude in Excel](12%EC%9E%A5%20Claude%20in%20Excel.md)

## 2. 3부를 관통하는 질문

| 질문 | 3부가 보여 주는 답 |
|------|-------------------|
| 같은 Claude인데 왜 화면마다 다른가? | 모델은 같고 포장(기능, 속도, 편의)이 서피스마다 다르기 때문 |
| Claude가 직접 행동할 때 가장 중요한 안전 장치는? | 접근 범위 한정과 확인창을 읽고 승인하기 |
| 외부 웹 페이지의 글을 어떻게 다루나? | 읽을 내용일 뿐 명령이 아니며 권위는 사용자의 목표 |
| 결과가 맞는지 누가 책임지나? | 사람이 현실과 대조해 검증 |
| 반복되는 작업은 어디로 옮기나? | Skill이나 예약 작업 |
