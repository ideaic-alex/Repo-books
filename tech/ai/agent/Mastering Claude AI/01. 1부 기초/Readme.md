# 1부 기초 (Part One: Foundations)

Cade Corwin의 『Mastering Claude AI』 1부는 다섯 개 장으로, 이후 모든 도구와 작업 흐름의 바탕이 되는 기초를 다룬다. 1장은 Claude가 무엇이고 어디까지 할 수 있는지, 2장은 작업 공간과 요금제와 이름 규칙을 세우는 법, 3장은 채팅 화면의 숨은 도구들, 4장은 첫 시도에서 좋은 결과를 얻는 프롬프트의 틀, 5장은 무엇을 Claude에게 줄지 고르는 컨텍스트 엔지니어링을 설명한다. 이 부는 14쪽부터 91쪽까지다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 모델 이름, 요금제, 화면 문구는 책이 쓰인 시점 기준이므로 내 계정의 현재 화면과 다를 수 있다.

---

## 1. 핵심 요점

- Claude는 언어, 주어진 자료에 대한 추론, 코드에 강한 대규모 언어 모델이다. 데이터베이스나 독심술사가 아니며, 구체적 사실에서는 자신 있게 틀릴 수 있다(환각).
- 같은 두뇌에 접근하는 길은 셋이다. 대화는 Claude.ai, 코드베이스 작업은 Claude Code, 제품에 넣는 일은 Claude API다.
- 모델 선택은 답의 깊이와 속도를 바꾼다. 복잡하거나 위험이 큰 일에는 더 능력 있는 모델이나 확장 사고를 쓴다.
- 요금제는 일주일의 실제 사용으로 고르고, 대화는 만들자마자 이름을 붙이며, 반복 업무는 프로젝트로 모은다.
- 프롬프트가 틀렸다면 편집하고, 답만 아쉽다면 다시 생성하고, 두 방향을 비교하려면 가지치기를 쓴다.
- 강한 프롬프트는 과제, 맥락, 형식과 제약, 예시의 네 재료로 이뤄지며, 큰 일은 작은 단계로 쪼갠다.
- 결과를 가르는 것은 문구보다 맥락이다. 컨텍스트 패킷으로 반복 업무를 표준화하고, 컨텍스트 부패는 요약 후 새로 시작해서 고친다.
