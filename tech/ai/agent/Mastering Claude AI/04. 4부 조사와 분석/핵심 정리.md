# 핵심 정리

4부(15장부터 18장)의 요점을 한곳에 모은 복습용 정리다. 도구 화면과 기능은 책이 쓰인 시점 기준이다.

---

## 1. 부 전체 흐름

| 장 | 다루는 일 | 한 줄 요약 |
|----|-----------|-----------|
| 15장 조사 | 질문 잡기부터 점검까지 | 네 단계로 나누고 점검을 건너뛰지 않는다 |
| 16장 데이터 | 가져오기부터 검증까지 | 정리하고 정밀하게 묻고 숫자를 직접 확인한다 |
| 17장 결정 | 기준부터 판단까지 | 기준을 먼저 정하고 최종 판단은 내가 한다 |
| 18장 검증 | 무엇을 얼마나 확인할지 | 위험도에 맞춰 확인하고 확신과 정확성을 분리한다 |

흐름은 이렇다. 15장이 정보를 믿을 만하게 모으는 법을, 16장이 숫자를 믿을 만하게 다루는 법을, 17장이 그 결과로 판단하는 법을 설명하고, 18장이 이 모두를 관통하는 검증 원칙을 한곳에 모은다.

## 2. 핵심 개념 정리

| 개념 | 뜻 | 예시 |
|------|----|------|
| 조사 네 단계 | 틀 잡기, 모으기, 종합하기, 점검하기 | 보조금 제안서에 쓸 통계 세 개를 직접 확인한다 |
| 출처 삼각검증 | 독립된 출처 여럿으로 주장을 대조 | 경쟁사 가격을 자사 사이트와 제3자 블로그로 대조한다 |
| 연구 브리프 | 질문, 확인된 사실, 남은 질문, 제외한 것 | 프로젝트에 두고 세션마다 갱신한다 |
| 데이터 정리 | 분석 전에 중복, 빈 값, 표기 불일치 처리 | California, CA, Calif.를 하나로 합친다 |
| 숫자 검증 네 가지 | 표본 점검, 과정 요구, 상식 점검, 교차 확인 | 월 400퍼센트 성장은 축하보다 의심 |
| 가중 기준 | 중요도가 다른 판단 요소 | 비기술 팀이면 학습 난이도에 큰 가중치 |
| 스틸맨 | 약한 선택지의 가장 강한 논거 | 최하위 선택지를 한 번 변호해 본다 |
| 닻 내림 | 초기 선호에 매여 평가가 치우침 | 선호를 밝히기 전에 기준부터 정한다 |
| 단계별 검증 | 위험도별 가벼움, 보통, 엄격, 최대 | 법률과 의료는 전문가 검토 필수 |
| 확신 대 정확성 | 말투의 확신은 정확함의 증거가 아님 | "확실해?"는 자기 재확인일 뿐이다 |

## 3. 자주 놓치는 점

- 점검 단계는 시간이 급할 때 가장 먼저 사라진다. 결정에 걸린 주장 두세 개만이라도 반드시 독립 확인한다.
- 깨끗하고 자신 있는 종합은 논쟁이 없다는 뜻이 아니다. 출처 불일치를 표시해 달라고 명시하지 않으면 매끄럽게 지워진다.
- Claude가 자신 없는 주장을 짚어 주는 것은 분류 도구이지 독립 검증이 아니다.
- 정리 단계의 처리 방법(빈 값을 뺄지, 0으로 볼지)은 내가 정할 판단이다. 분석 속에 묻어 자동으로 넘기지 않는다.
- 막연한 "분석해 줘"나 "차트 하나"는 일반적인 결과를 낳는다. 어떤 결정에 쓰고 무엇을 전할지 적는다.
- 틀의 1위가 찜찜하면 빠진 기준이 있다는 신호다. 무시하지 말고 기준을 추가해 다시 돌린다.
- 내가 듣고 싶던 주장일수록 검증을 건너뛰기 쉽다. 그런 주장이 오히려 우선 점검 대상이다.
- 검증은 매번 기억에 의존하지 말고 고위험 워크플로의 필수 단계로 고정한다.
