# 4부 조사와 분석 (Part IV)

『Mastering Claude AI』 4부는 Claude로 조사하고, 데이터를 분석하고, 결정을 내리고, 그 결과를 검증하는 네 개 장(15장부터 18장, PDF 210쪽부터 261쪽)으로 이루어진다. 네 장은 모두 같은 생각 위에 서 있다. Claude는 속도를 주지만 자신 있는 문체로 틀릴 수도 있으므로, 일을 단계로 나누고 마지막에 사람이 확인하는 절차를 넣어야 한다는 것이다.

이 노트는 번역이 아니라 책을 이해한 뒤 풀어 다시 정리한 학습 노트다. 도구와 화면 설명은 책이 쓰인 시점 기준이다.

---

## 1. 핵심 요점

- 조사는 틀 잡기, 모으기, 종합하기, 점검하기 네 단계로 나누고, 한 번에 "조사해 줘"라고 뭉치지 않는다.
- 여러 세션에 걸친 조사는 연구 브리프(질문, 확인된 사실, 남은 질문, 제외한 것)를 프로젝트에 두고 갱신한다.
- 데이터는 원본 파일로 올리고, 열 의미를 설명하고, 분석 전에 별도 정리 단계를 거친다.
- 숫자는 표본 점검, 과정 보여 달라, 상식 점검, 합계 교차 확인으로 검증한다. 깔끔한 표는 증거가 아니다.
- 의사결정은 기준과 가중치를 먼저 정하고, 점수마다 근거를 보게 하며, 닻 내림을 경계한다. 결정은 사람이 한다.
- 검증 깊이는 위험도에 맞춘 네 단계로 조절한다. Claude에게 "확실해?"라고 묻는 것은 검증이 아니다.
- 확신에 찬 말투와 정확성은 별개다. 검증은 상시 워크플로에 넣는다.
