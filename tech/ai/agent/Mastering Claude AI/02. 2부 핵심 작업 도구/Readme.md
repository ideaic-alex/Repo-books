# 2부 개요 (Part II) 핵심 작업 도구

Cade Corwin의 『Mastering Claude AI』 2부는 6장부터 10장까지 다섯 개 장으로, Claude를 매일 쓰는 데 필요한 핵심 도구를 하나씩 다룬다. 프로젝트는 반복되는 일의 집이 되고, 메모리는 일반 선호를 이어 주며, 아티팩트는 대화를 바로 쓰는 결과물로 바꾼다. 지식 관리는 정보를 알맞은 문으로 들여오는 법을, 긴 문서 분석은 중요한 것을 놓치지 않고 읽는 구조를 알려 준다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 화면 이름, 기능 범위, 요금제별 차이는 책이 쓰인 시점 기준이며 자주 바뀌므로 지금 내 계정에서 확인한다.

---

## 1. 핵심 요점

- 프로젝트는 프로젝트 지식, 사용자 지침, 관련 대화를 한 지붕에 묶어 반복 설명을 없애고, 기본적으로 다른 프로젝트와 격리된다.
- 프로젝트 지식은 많이가 아니라 엄선해서 넣고, 사용자 지침은 지킬 수 있을 만큼 구체적으로 쓴다.
- 메모리는 일반 대화 전반의 선호와 반복 사실을 이어 주지만 낡거나 맥락 사이로 샐 수 있어 정기 점검이 필요하다.
- 메모리, 프로젝트 지식, 이번 프롬프트는 넓은 층에서 좁은 층으로 서로 보완하며, 세부가 중요한 일은 명시적 맥락이 먼저다.
- 아티팩트는 크고 독립적인 결과를 반복 수정이 가능한 패널에 만들며, 구체적 피드백으로 고치고 공유 전에 직접 시험한다.
- 정보는 성격에 따라 붙여넣기, 첨부, 웹 검색, 프로젝트 지식, 지난 대화 참조 중 알맞은 방법으로 들여오고, 검색형 일과 추론형 일을 구분한다.
- 긴 문서는 구간별 분석, 전용 추출, 교차 비교로 나눠 읽고, 중대한 결정은 요약을 원문과 표본 대조한다.
