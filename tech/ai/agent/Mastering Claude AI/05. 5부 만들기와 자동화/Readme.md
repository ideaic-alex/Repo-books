# 5부 개요 (Part Five) 만들기와 자동화

Cade Corwin의 『Mastering Claude AI』 5부는 19장부터 25장까지 일곱 개 장으로, 글과 분석을 넘어 "쓸 수 있는 물건"을 만드는 단계다. 코드 없이 도구와 웹페이지를 만드는 법(19장), 반복 작업을 자동화하고 커넥터를 다루는 법(20장), MCP를 쉬운 말로 이해하는 법(21장), 코딩을 시작하는 길(22장)을 거쳐, 코드 폴더에서 스스로 일하는 Claude Code(23장), 오류를 체계적으로 풀어 가는 디버깅(24장), 그리고 채팅 창 너머의 Claude API(25장)로 끝난다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 도구, 기능, 요금, 화면 이름은 책이 쓰인 시점 기준이며 이후 바뀔 수 있으니 공식 문서로 다시 확인한다.

---

## 1. 핵심 요점

- 설명만으로 도구를 만들 수 있지만, 입력, 출력, 논리, 경계 사례까지 적은 기능 명세가 결과의 질을 정한다.
- 반복 작업이라고 다 자동화하지 않는다. 빈도, 일관성, 개인 판단의 필요를 따지고, 권한은 가장 좁게 주고 작게 시작한다.
- MCP는 AI와 외부 도구가 공통 방식으로 연결되게 하는 열린 표준이며, 사용자는 그 위에 만들어진 개별 커넥터를 쓴다.
- 코딩은 "대신 짜 달라"와 "배우고 싶다" 중 목표를 먼저 밝히고, 모르는 코드는 실행 전에 쉬운 말로 설명을 받는다.
- Claude Code 같은 에이전트형 작업은 범위, 버전 관리, 실제 변경 검토라는 가드레일 위에서만 맡긴다. "완료" 보고는 검증이 아니다.
- 디버깅은 정확한 오류, 코드, 기대와 실제를 주고 재현, 최소 재현, 가설, 한 가지 변경 순으로 좁히며, 뿌리 원인을 이해한다.
- Claude API는 자동 대규모 실행, 제품 내 기능이 필요할 때의 도구이며 사용량 기반 요금이다. 구현은 개발자에게 맡겨도 의도와 검증은 내가 쥔다.
