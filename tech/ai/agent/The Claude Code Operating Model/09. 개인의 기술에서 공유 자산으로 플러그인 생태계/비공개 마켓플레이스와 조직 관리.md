# 비공개 마켓플레이스와 조직 관리

저장소 주소를 하나씩 건네는 방식은 플러그인이 늘거나 팀이 많아지면 한계에 닿는다. 무엇이 있는지 아무도 말하지 못하게 되기 때문이다. 이를 위해 플러그인 시스템은 비공개 마켓플레이스(private marketplace)를 지원한다. 카탈로그 하나, 항목을 추가하거나 퇴출하는 장소 하나, 목록 자체의 버전 관리를 제공한다. 마켓플레이스는 그저 Git 저장소라서 따로 살 것이 없다.

이 문서는 비공개 마켓플레이스를 만들고 쓰는 방법, 그리고 기업 환경의 조직 수준 플러그인 관리를 다룬다.

---

## 1. 비공개 마켓플레이스 만들기

비공개 마켓플레이스도 표준 Git 저장소다. 매니페스트는 플러그인 매니페스트와 같은 곳인 `.claude-plugin/marketplace.json`에 둔다. 저장소 루트가 아니다. 앞서 본 플러그인 물리 구조 규칙과 같은 관례다. 루트에 두면 마켓플레이스가 발견되지 않는다.

원서의 구조 예시를 말로 풀면 이렇다.

- 최상위에 `name`(예: `our-company`), `description`(예: 사내 플러그인 마켓플레이스)이 있다.
- `plugins` 배열에 항목이 들어간다. 각 항목은 `name`, `description`, `repository`, `version`을 가진다.
- 예시 항목은 `team-toolkit`(팀 표준 개발 도구 모음, 버전 2.0.0)과 `db-tools`(데이터베이스 운영 도구 모음, 버전 1.2.0)다.

```json
{ "name": "our-company", "description": "Internal Plugin Marketplace",
  "plugins": [
    {"name": "team-toolkit", "repository": "https://github.com/our-company/team-toolkit", "version": "2.0.0"},
    {"name": "db-tools", "repository": "https://github.com/our-company/db-tools", "version": "1.2.0"} ] }
```

참고(노트 작성자): 위는 원서 예시에서 항목별 `description`을 생략해 줄인 것이다. 원서 코드에는 빈 줄이 어색하게 낀 곳이 있어 추출 과정의 흔적으로 보고 무시했다.

## 2. 비공개 마켓플레이스 사용하기

팀원은 명령 한 줄로 사내 마켓플레이스를 로컬 설정에 추가한다.

```
/plugin marketplace add our-company/claude-plugins
/plugin install team-toolkit@our-company
```

등록이 끝나면 전체 저장소 주소를 기억할 필요 없이 `플러그인이름@마켓플레이스출처` 형식으로 설치한다. 앞 문서의 "마켓플레이스를 먼저 추가해야 설치할 수 있다"는 설명이 여기서 실제로 적용된다.

## 3. 조직 수준 플러그인 관리

기업용(Enterprise) 버전에서는 관리자가 조직 수준에서 플러그인을 미리 설치할 수 있다. 한 번 설정하면 모든 구성원이 수동 작업 없이 바로 쓴다. 세 가지 핵심 능력이 있다.

| 능력 | 내용 |
|---|---|
| 통일 배포 | 관리자가 백엔드에서 설정만 하면 모든 구성원 환경에 자동 배포된다. 보안 검사 훅이나 통일된 코드 리뷰 기준처럼 팀 표준을 강제할 때 특히 중요하다 |
| 버전 통제 | 조직 수준 플러그인을 특정 버전에 고정할 수 있다. 구성원이 호환되지 않는 새 버전으로 마음대로 올려 팀 워크플로를 깨는 것을 막는다. 업데이트와 버전 승격 권한은 관리자에게만 있다 |
| 감사 가시성 | 조직 수준 플러그인의 설치 상태와 사용 내역을 완전히 추적해 기업의 컴플라이언스 감사와 보안 모니터링 요구를 충족한다 |

### 3-1. 세 단계로 보는 배포 범위

참고(노트 작성자): 아래는 이 장 전체 내용을 노트 작성자가 정리한 비교다.

| 범위 | 방식 | 누가 통제하나 |
|---|---|---|
| 팀 | 저장소 주소 직접 설치 | 저장소 읽기 권한 |
| 조직 내 여러 팀 | 비공개 마켓플레이스 | 마켓플레이스 저장소의 관리자 |
| 전사 | 조직 수준 플러그인(기업용) | 조직 관리자가 배포, 버전 고정, 감사 |

---

## 4. 핵심 정리

- 비공개 마켓플레이스는 `.claude-plugin/marketplace.json`을 가진 일반 Git 저장소이며, 루트에 두면 발견되지 않는다.
- 사용은 `/plugin marketplace add` 후 `/plugin install 이름@마켓플레이스`다.
- 조직 수준 관리는 통일 배포, 버전 고정, 감사 가시성의 세 능력을 준다. 팀 표준을 강제해야 하는 보안 훅 등에 중요하다.
