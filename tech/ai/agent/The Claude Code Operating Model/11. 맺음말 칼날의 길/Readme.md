# 맺음말 칼날의 길

맺음말은 Jia Huang이 원고를 마친 뒤 목차를 돌아보다가 발견한 우연에서 출발한다. 책의 장 구성(맥락 주입, 도구 등록, 실행 환경, 통제)이 그대로 하니스의 네 요소와 겹친다는 것이다. 저자는 이어서 2025년에서 2026년 사이 AI 지원 개발의 경쟁 초점이 모델에서 하니스로 옮겨 갔다고 진단하고, 오픈소스 사례로 이를 뒷받침한다.

그 다음 에이전틱 루프를 뫼비우스의 띠에 비유하며 '하니스 엔지니어링은 행동을 프로그래밍하는 것이 아니라 제약하는 것'이라는 결론을 내리고, 이어 읽을 저자의 두 책을 소개한 뒤 '칼날'의 비유로 마무리한다. 분량은 5쪽 안팎으로 짧다.

---

## 1. 핵심 요점

- 책의 구성은 하니스와 같은 모양이다. 1~2장은 맥락, 3~6장은 도구, 7~9장은 실행 환경, 10장은 통제다.
- 업계의 질문이 2025년 '어느 모델이 가장 강한가'에서 2026년 '같은 모델이 어떻게 더 잘 해낼 수 있는가'로 바뀌었다. 답은 정교한 하니스 설계에 있다.
- Superpowers, Compound Engineering, grill-me, Trellis 같은 오픈소스는 새 모델이 아니라 하니스 설계로 성과를 냈고, 모두 CLAUDE.md, 스킬, 서브에이전트, 훅, MCP 위에 서 있다.
- 컴포넌트는 상수이고 조합은 무한하다. 책은 부품을 주고 조합은 독자의 판단이다.
- 에이전틱 루프(추론, 도구 호출, 결과 피드백, 재추론)에서 복잡한 행동이 창발한다. 엔지니어는 인지(도구 허용 목록), 기억(CLAUDE.md와 컨텍스트 관리), 행동(권한), 정지(max-turns와 훅)의 경계 조건을 설계한다.
- 후속 독서는 SDD in Practice(사양 주도 개발, 중국어판)와 Designing AI Agents(28개 설계 패턴)다.
- Claude Code는 칼, 프로젝트는 소다. 이 책은 뼈의 방향과 틈의 위치를 가르친다.
