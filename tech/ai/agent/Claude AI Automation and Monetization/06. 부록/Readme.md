# 부록 개요 (Appendices) 보너스 장과 참조 자료, 템플릿, 점검표

에슬람 와흐바(Eslam Wahba)의 『Claude AI Automation & Monetization』은 24개 장과 맺음말을 마친 뒤 보너스 장 하나와 부록 A부터 K까지를 붙였다. 보너스 장은 여섯 가지 AI 시스템의 설계도를 소개하고, 부록은 책에 흩어져 있던 프레임워크, 빠른 시작 안내, 도구 목록, 용어, 일정표, 템플릿, 사례, 점검표를 한곳에 모은 참고 자료다. 본문을 읽은 뒤 책상 옆에 두고 필요할 때 꺼내 쓰라는 구성이다. 책의 마지막 쪽에는 "시작하는 결정은 읽는 사람의 몫"이라는 취지의 맺음 글이 놓여 있다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 우리말로 풀어 쓴 학습 노트다. 부록에는 프롬프트, 템플릿, 점검표 같은 "그대로 베껴 쓰는 글"이 많은데, 노트는 그 본문을 옮기지 않고 구조와 용도와 쓰는 순서만 정리하고 필요한 곳에는 새 예시를 직접 썼다.

> **이 부를 한 문장으로**
> 배운 것을 바로 일에 쓰도록, 시스템 설계도와 참조표와 템플릿과 점검표를 모아 둔 실행용 자료다.

> **참고(노트 작성자)** 부록의 가격, 월 수익 목표, 사례의 숫자, 도구와 요금제는 모두 책의 주장이거나 책이 쓰인 시점의 정보이며 노트 작성자가 검증하지 않았다. 수익과 시간은 책의 사례이고 결과는 개인과 시장에 따라 크게 다르다. 계약, 세금, 개인정보에 걸린 판단은 전문가 확인이 필요하다.

## 3. 부록의 공통 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 청사진(blueprint) | 만들기 전에 단계, 입력, 출력, 품질 기준을 적어 둔 시스템 설계도 |
| 프롬프트 시스템(prompt system) | 한 번 쓰는 질문이 아니라 여러 층과 단계로 짜서 반복 사용하는 프롬프트 묶음 |
| 파이프라인(pipeline) | 앞 단계의 출력이 다음 단계의 입력이 되는 연결된 처리 흐름 |
| 마이크로 SaaS(micro SaaS) | 좁은 용도에 맞춘 작은 구독형 소프트웨어 서비스 |
| 에이전시(agency) | 고객 일을 대신 처리해 주는 작은 서비스 회사 |

## 4. 이 부의 흐름 요약

보너스 장은 시스템을 직접 만들 때 따라갈 설계도를, 부록 A부터 D까지는 찾아보는 참조표를 준다. E부터 H까지는 시간표와 계획서와 점검 틀로 실행을 도우며, I는 결과물의 합격선을 세우게 한다. J는 배움을 이어 가는 방식을, K는 출시 직전의 마지막 확인을 맡는다. 여러 문서를 관통하는 메시지는 세 가지다. 먼저 작게 만들어 검증하고, 사람이 품질을 끝까지 책임지며, 점검은 정직하게 한다.
