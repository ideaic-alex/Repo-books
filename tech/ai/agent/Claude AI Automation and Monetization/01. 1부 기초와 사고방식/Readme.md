# 1부 개요 (Part I) 기초와 사고방식

Eslam Wahba의 『Claude AI Automation & Monetization』 1부는 머리말과 네 개 장으로, 이후 모든 수익 모델의 바탕이 되는 관점과 설계 기초를 다룬다. 머리말은 프롬프트를 다듬는 사용자에서 시스템을 짓는 설계자로 관점을 옮기라고 권한다. 1장은 인지 자본과 승수라는 경제적 근거를, 2장은 Claude 시스템의 3층 구조를, 3장은 프롬프트를 엔지니어링 대상으로 다루는 기법을, 4장은 실제 운영에서 버티는 워크플로 설계를 설명한다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책의 수익, 가격, 사례, 효과 수치는 모두 저자의 주장이며 노트 작성자가 검증하지 않았다. 도구와 모델 이름도 책이 쓰인 시점 기준이다.

> **이 부를 한 문장으로**
> AI의 이득은 잘 쓴 프롬프트 한 줄이 아니라 입력, 처리, 출력을 설계하고 단계별로 점검하는 시스템에서 나온다.

---

## 0. 먼저 알아 둘 것

- **설계자 관점**: 같은 일을 두 번 이상 하면 시스템으로 만들 수 있는지 묻는다.
- **수치는 책의 주장**: 사례의 시간 단축과 매출 변화는 책의 서술이며 결과는 개인과 시장에 따라 크게 다르다.
- **이 부는 이후의 바탕**: 2부 이후의 수익 모델은 모두 여기서 배운 3층 모델, 프롬프트 스택, 워크플로 패턴을 전제로 한다.

## 2. 1부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 인지 자본(cognitive capital) | 생각, 분석, 창작을 확장해 주는 능력과 시스템 |
| 승수(multiplier) | 같은 노력으로 더 큰 결과를 내게 하는 배수 효과 |
| 시스템 프롬프트 | 세션 내내 유지되는 상시 지침 |
| 프롬프트 스택 | 기반부터 제약 수정자까지 다섯 층으로 쌓는 프롬프트 구조 |
| 사고의 사슬(chain-of-thought) | 결론 전에 단계별로 추론하게 하는 방식 |
| 프롬프트 체인 | 앞 단계 결과를 다음 단계 입력으로 잇는 구조 |
| 프로덕션 | 실제 고객과 업무에 쓰이는 운영 환경 |
| 워크플로(workflow) | 일의 단계별 흐름 |
| 우아한 성능 저하 | 입력이 부족할 때 멈추지 않고 부분 결과와 표시를 내는 설계 |

## 3. 이 부의 흐름 요약

머리말은 사용자에서 설계자로 전환하는 태도를 세운다. 1장은 그 전환이 왜 경제적으로 큰지를 속도, 일관성, 규모의 세 층으로 설명한다. 2장은 시스템을 입력, 처리, 출력으로 나누고 품질이 입력에서 결정된다고 본다. 3장은 프롬프트를 스택으로 쌓고 버전을 관리하는 방법을 더하며, 4장은 이것을 단계 지도, 패턴, 오류 처리로 묶어 실제 운영에서 무너지지 않는 워크플로로 완성한다.
