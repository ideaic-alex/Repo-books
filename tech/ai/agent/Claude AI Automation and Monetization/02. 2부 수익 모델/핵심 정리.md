# 핵심 정리

이 문서는 2부(5장부터 8장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 수익 수치, 도구, 모델 이름은 책이 쓰인 시점 기준의 책의 주장이며 노트가 검증하지 않았다. 결과는 개인과 시장에 따라 크게 다르다.

---

## 1. 한눈에 보는 요점

- **수익 모델은 최소 여덟 가지다**: 완성품 납품, 정기 계약, 자동화 컨설팅, 디지털 상품, AI 에이전시, 마이크로 SaaS, 콘텐츠 사업, 교육. 하나를 고르기 전에 전체를 본다.
  - *쉽게 말하면*: 가게를 열기 전에 업종 지도를 먼저 펼친다.
  - → 자세히: [5장 AI 비즈니스 모델 전체 분석](05%EC%9E%A5%20AI%20%EB%B9%84%EC%A6%88%EB%8B%88%EC%8A%A4%20%EB%AA%A8%EB%8D%B8%20%EC%A0%84%EC%B2%B4%20%EB%B6%84%EC%84%9D.md)
- **서비스형은 빠르고, 제품·청중형은 늦지만 상한이 높다**: 내 여유 기간 안에 첫 수익이 나오는지가 먼저다.
  - *쉽게 말하면*: 당장 생활비가 필요하면 빨리 돈이 되는 쪽부터 간다.
  - → 자세히: [5장 AI 비즈니스 모델 전체 분석](05%EC%9E%A5%20AI%20%EB%B9%84%EC%A6%88%EB%8B%88%EC%8A%A4%20%EB%AA%A8%EB%8D%B8%20%EC%A0%84%EC%B2%B4%20%EB%B6%84%EC%84%9D.md)
- **하나를 익힌 뒤 두 번째를 붙인다**: 처음부터 여러 모델을 동시에 돌리면 힘이 흩어지고, 어떤 모델이든 영업은 필요하다.
  - *쉽게 말하면*: 한 우물을 판 뒤에 두 번째를 판다.
  - → 자세히: [5장 AI 비즈니스 모델 전체 분석](05%EC%9E%A5%20AI%20%EB%B9%84%EC%A6%88%EB%8B%88%EC%8A%A4%20%EB%AA%A8%EB%8D%B8%20%EC%A0%84%EC%B2%B4%20%EB%B6%84%EC%84%9D.md)
- **프리미엄은 가격이 아니라 범주다**: 구체성, 증거, 체계, 속도의 네 기둥으로 다른 종류의 사람이 된다.
  - *쉽게 말하면*: 같은 일을 비싸게 파는 것이 아니라 다른 일을 하는 사람이 되는 것이다.
  - → 자세히: [6장 Claude로 프리랜싱하기](06%EC%9E%A5%20Claude%EB%A1%9C%20%ED%94%84%EB%A6%AC%EB%9E%9C%EC%8B%B1%ED%95%98%EA%B8%B0.md)
- **패키지와 정기 계약으로 시간 대신 가치를 판다**: AI로 생긴 효율은 시간당 과금을 유지하면 사라진다. 고객 확보는 반복 가능한 절차로 하고 AI 사용 고지는 계약과 규정에 맞춘다.
  - *쉽게 말하면*: 빨라진 시간이 내 이익이 되게 가격 방식을 바꾼다.
  - → 자세히: [6장 Claude로 프리랜싱하기](06%EC%9E%A5%20Claude%EB%A1%9C%20%ED%94%84%EB%A6%AC%EB%9E%9C%EC%8B%B1%ED%95%98%EA%B8%B0.md)
- **콘텐츠는 다섯 층의 엔진으로 만든다**: 전략, 아이디어, 생산, 편집, 배포. 작가의 벽은 재고 문제이므로 매주 아이디어를 쌓는다.
  - *쉽게 말하면*: 글 한 편이 아니라 공장 라인을 만든다.
  - → 자세히: [7장 콘텐츠 엔진](07%EC%9E%A5%20%EC%BD%98%ED%85%90%EC%B8%A0%20%EC%97%94%EC%A7%84.md)
- **편집이 평범한 초안을 구별되게 만든다**: 일곱 요소 브리프로 초안을 뽑고, 사람이 경험과 구체성을 더하고, 한 편을 여러 채널용으로 재가공한다.
  - *쉽게 말하면*: AI가 뼈대를, 사람이 목소리를 만든다.
  - → 자세히: [7장 콘텐츠 엔진](07%EC%9E%A5%20%EC%BD%98%ED%85%90%EC%B8%A0%20%EC%97%94%EC%A7%84.md)
- **자동화 시스템은 4층으로 설계한다**: 트리거, 처리(Claude), 라우팅, 전달. 비개발자는 Zapier, 복합 흐름은 Make, 최대 유연성은 직접 API가 맞는다.
  - *쉽게 말하면*: 주문이 오면 저절로 요리하고 저절로 배달되게 만든다.
  - → 자세히: [8장 Claude와 자동화 도구 연결](08%EC%9E%A5%20Claude%EC%99%80%20%EC%9E%90%EB%8F%99%ED%99%94%20%EB%8F%84%EA%B5%AC%20%EC%97%B0%EA%B2%B0.md)
- **연결 시스템은 안전하게 만든다**: API 키는 보관함에, 오류 처리를 만들고, 초기 실행을 직접 감시하며, 고객과 닿는 결과는 초안으로 끝낸다.
  - *쉽게 말하면*: 처음에는 사람이 옆에서 지켜본다.
  - → 자세히: [8장 Claude와 자동화 도구 연결](08%EC%9E%A5%20Claude%EC%99%80%20%EC%9E%90%EB%8F%99%ED%99%94%20%EB%8F%84%EA%B5%AC%20%EC%97%B0%EA%B2%B0.md)

## 2. 2부를 관통하는 질문

| 질문 | 2부가 보여 주는 답 |
|------|-------------------|
| 무엇으로 돈을 벌까? | 여덟 모델 중 내 자산과 여유 기간에 맞는 하나로 시작 |
| 비싸게 받는 근거는? | 범주가 다르다는 것을 구체성, 증거, 체계, 속도로 보여 줌 |
| 반복되는 생산은 어떻게 안정시키나? | 층을 나눈 체계와 브리프, 사람의 편집 |
| 사람이 없는 시간에도 돌리려면? | 트리거-처리-라우팅-전달 구조로 연결하고 감시 |
| 어떤 결과든 누가 책임지나? | 사람이 검수하고 고객과 관계를 맺음 |
