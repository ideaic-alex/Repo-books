# 핵심 정리

이 문서는 5부(19장부터 24장과 맺음말)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 가격, 수익, 시장 전망은 책의 주장이며 노트가 검증하지 않았다. 법, 의료, 금융 관련 내용은 전문가 확인이 필요하다.

---

## 1. 한눈에 보는 요점

- **물량과 복잡도가 커지면 n8n과 API 체인으로 간다**: 실행당 요금이 없고 맞춤 코드와 데이터 통제가 되지만, 서버 운영의 부담이 따른다.
  - *쉽게 말하면*: 조립식 장난감에서 내가 설계한 라인으로 옮긴다.
  - → 자세히: [19장 고급 자동화(n8n, API 체인, 커스텀 연동)](19%EC%9E%A5%20%EA%B3%A0%EA%B8%89%20%EC%9E%90%EB%8F%99%ED%99%94%28n8n%2C%20API%20%EC%B2%B4%EC%9D%B8%2C%20%EC%BB%A4%EC%8A%A4%ED%85%80%20%EC%97%B0%EB%8F%99%29.md)
- **대량 처리에는 재시도, 속도 제한, 모니터링, 비용 계산이 필수다**: 조용한 실패와 예산 폭탄을 막는다.
  - *쉽게 말하면*: 자동화는 고장 났을 때 알려 주는 장치까지 만들어야 끝난다.
  - → 자세히: [19장 고급 자동화(n8n, API 체인, 커스텀 연동)](19%EC%9E%A5%20%EA%B3%A0%EA%B8%89%20%EC%9E%90%EB%8F%99%ED%99%94%28n8n%2C%20API%20%EC%B2%B4%EC%9D%B8%2C%20%EC%BB%A4%EC%8A%A4%ED%85%80%20%EC%97%B0%EB%8F%99%29.md)
- **AI 교육의 목표는 행동 변화다**: 인식, 기초, 적용, 통합 네 단계로 설계하고 실제 업무의 변화로 성공을 잰다.
  - *쉽게 말하면*: 강의가 끝난 뒤 일하는 방식이 달라져야 한다.
  - → 자세히: [20장 교육과 강의](20%EC%9E%A5%20%EA%B5%90%EC%9C%A1%EA%B3%BC%20%EA%B0%95%EC%9D%98.md)
- **틈새는 전문성으로 경쟁한다**: 법률, 의료, 부동산, 금융, 전자상거래, 채용·인사에서 규제가 큰 곳일수록 AI는 초안, 판단은 사람이다.
  - *쉽게 말하면*: 한 업종의 언어를 아는 사람이 같은 도구로 더 가치 있다.
  - → 자세히: [21장 틈새시장 심층 분석](21%EC%9E%A5%20%ED%8B%88%EC%83%88%EC%8B%9C%EC%9E%A5%20%EC%8B%AC%EC%B8%B5%20%EB%B6%84%EC%84%9D.md)
- **고객이 중요하게 여길 사실이면 AI 사용을 밝히고, 물으면 언제나 정직하다**: 검토하지 않은 AI 결과를 내보내는 것은 신뢰 위반이다.
  - *쉽게 말하면*: 초안은 AI가, 책임은 사람이.
  - → 자세히: [22장 윤리·투명성·전문가 기준](22%EC%9E%A5%20%EC%9C%A4%EB%A6%AC%C2%B7%ED%88%AC%EB%AA%85%EC%84%B1%C2%B7%EC%A0%84%EB%AC%B8%EA%B0%80%20%EA%B8%B0%EC%A4%80.md)
- **프롬프트는 같은 뼈대의 견본으로 쓴다**: 역할, 입력 칸, 출력 항목, 형식 제한을 갖추고 "모르면 확인 필요로 표시"를 넣는다.
  - *쉽게 말하면*: 견본을 베끼지 말고 내 상황에 맞춰 고치고 이력을 남긴다.
  - → 자세히: [23장 실전 프롬프트 라이브러리](23%EC%9E%A5%20%EC%8B%A4%EC%A0%84%20%ED%94%84%EB%A1%AC%ED%94%84%ED%8A%B8%20%EB%9D%BC%EC%9D%B4%EB%B8%8C%EB%9F%AC%EB%A6%AC.md)
- **오래가려면 복리 자산에 투자한다**: 전문성, 관계, 콘텐츠, 평판, 시스템은 쌓일수록 불어나고, 단순 AI 실행은 범용화된다.
  - *쉽게 말하면*: 남들이 못 쓰는 도구의 이점은 사라지지만 쌓은 신뢰는 남는다.
  - → 자세히: [24장 긴 게임 복리 가치 쌓기](24%EC%9E%A5%20%EA%B8%B4%20%EA%B2%8C%EC%9E%84%20%EB%B3%B5%EB%A6%AC%20%EA%B0%80%EC%B9%98%20%EC%8C%93%EA%B8%B0.md)
- **하나를 골라 지금 실행한다**: 더 준비하기보다 실제 입력과 고객 반응에서 배운다.
  - *쉽게 말하면*: 완벽한 계획보다 작은 실행.
  - → 자세히: [맺음말](%EB%A7%BA%EC%9D%8C%EB%A7%90.md)

## 2. 5부를 관통하는 질문

| 질문 | 5부가 보여 주는 답 |
|------|-------------------|
| 자동화가 커지면 무엇이 달라지나? | 비용, 통제, 오류 처리가 핵심이 되어 n8n과 일괄 처리 구조로 옮긴다 |
| 내 경험을 어떻게 가르치는 상품으로 만드나? | 좁은 청중, 4단계 설계, 행동 변화 지표 |
| 규제가 큰 산업에서 AI는 어디까지? | 초안과 요약까지, 판단과 자문은 전문가 |
| AI 사용을 밝혀야 하나? | 고객에게 중요한 사실이면 밝히고, 물으면 정직하게 |
| 기술이 발전해도 남는 것은? | 관계, 평판, 커뮤니티, 도메인 깊이 |

> 자동화는 더 깊게, 시장은 더 좁게, 윤리는 더 단단하게, 시간은 더 길게 보고, 마지막에는 하나를 골라 실행한다.
