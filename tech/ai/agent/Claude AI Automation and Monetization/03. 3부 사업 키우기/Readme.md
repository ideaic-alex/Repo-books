# 3부 개요 (Part III) 사업 키우기

Eslam Wahba의 『Claude AI Automation & Monetization』 3부는 혼자 하는 일에서 규모가 있는 사업으로 넘어가는 네 개 장이다. 9장은 AI 에이전시, 10장은 디지털 상품과 수동 소득, 11장은 마이크로 SaaS, 12장은 월 1만 달러라는 목표를 구조로 푸는 방법을 설명한다. 2부가 수익 모델을 고르고 도구를 연결하는 단계였다면, 3부는 그 모델을 반복 가능한 사업 구조로 키우는 단계다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책의 수익 수치, 가격, 고객 수, 기간, 성공 사례는 모두 책의 주장이며 노트가 검증하지 않았다. 결과는 개인의 역량과 시장에 따라 크게 다르고, 이 부는 수익을 보장하거나 권유하지 않는다. 도구와 요금제는 책이 쓰인 시점 기준이다.

> **이 부를 한 문장으로**
> 서비스는 시스템과 소수의 사람으로, 상품은 가격 층과 출시 설계로, 소프트웨어는 검증 후 구축으로 키우고, 어느 쪽이든 목표를 단가 곱하기 고객 수로 쪼개 단계별로 간다.

---

## 0. 먼저 알아 둘 것

- **네 장이 서로 다른 성장 경로**: 서비스형(에이전시), 상품형(디지털 상품), 구독형(마이크로 SaaS)을 보여 주고, 12장이 이를 한 목표 아래 합친다.
- **공통 원칙은 검증 먼저**: 고객 인터뷰, 수동 시제품, 소규모 출시처럼 만들기 전에 돈을 낼 사람이 있는지 확인하는 순서가 반복된다.
- **사례의 성격**: 사례는 대부분 이미 분야 지식과 청중이 있던 사람의 이야기이므로 같은 결과를 기대하는 근거로 쓰면 안 된다.
- **전문가 확인**: 계약, 세금, 광고 규정, 개인정보와 결제 정보 처리는 각자 전문가에게 확인해야 한다.

## 2. 3부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 에이전시(agency) | 여러 고객에게 서비스를 납품하는 사업체 |
| 리테이너(retainer) | 매달 정액을 받는 지속 계약 |
| 수동 소득(passive income) | 만든 뒤에는 투입 시간이 적게 드는 수입. 홍보와 유지는 필요 |
| 마이크로 SaaS(micro SaaS) | 작은 시장과 팀을 의도한 구독형 소프트웨어 |
| MRR | 월간 반복 매출. 구독으로 매달 들어오는 매출 |
| MVP | 가치를 검증할 수 있는 최소 기능 제품 |
| 이탈률(churn) | 일정 기간에 구독을 그만두는 고객 비율 |
| 수입원 분산 | 성격이 다른 수입원을 여럿 두어 한 곳의 충격을 줄이는 구성 |

## 3. 이 부의 흐름 요약

9장은 시스템이 먼저고 고객이 나중이라는 순서와 리테이너 중심 가격을 세운다. 10장은 같은 독자에게 가격이 다른 상품을 층층이 파는 방식과 출시 일정을 다룬다. 11장은 아이디어를 다섯 기준으로 거른 뒤 코드 없는 시제품으로 수요를 확인하는 구독 제품 만들기를 설명한다. 12장은 앞의 세 경로를 단가와 고객 수의 곱으로 비교하고, 단계별 로드맵과 수입원 분산으로 목표를 유지하는 방법으로 마무리한다.
