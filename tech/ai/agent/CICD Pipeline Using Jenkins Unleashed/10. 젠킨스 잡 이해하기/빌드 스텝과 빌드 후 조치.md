# 빌드 스텝과 빌드 후 조치

잡 설정 페이지의 아래쪽에는 실제 일을 하는 빌드 스텝(Build Step)과 일이 끝난 뒤의 처리를 정하는 빌드 후 조치(Post-build Actions) 섹션이 있다. 이 문서는 두 섹션에서 무엇을 설정하는지 정리한다.

요리 레시피로 보면 빌드 스텝은 "재료를 썰고, 볶고, 담는" 조리 순서이고 빌드 후 조치는 "다 됐으면 손님에게 알리고 접시를 치우는" 마무리다. 레시피는 위에서 아래로 차례대로 진행된다.

---

## 1. Build Step

잡은 이 섹션에 설정된 스텝을 실행해서 맡은 일을 한다. 스텝은 배치 파일 실행일 수도 있고 어떤 빌드 도구의 골(goal)을 실행하는 것일 수도 있다.

윈도우 DOS 명령을 실행하는 스텝을 추가하는 절차는 다음과 같다.

1. Add build step 드롭다운을 클릭한다.
2. Execute Windows batch command 옵션을 고른다.
3. Command 칸에 실행할 DOS 명령을 적는다.
4. 스텝을 지우고 싶으면 스텝 옆의 빨간 X 표시를 누른다.

한 잡에 스텝을 여러 개 넣을 수 있다. 스텝은 위에서부터 순서대로 실행된다. 따라서 앞 스텝의 결과를 뒤 스텝이 쓰는 구성이 가능하다.

| 작업 | 방법 |
|---|---|
| 스텝 추가 | Add build step 드롭다운에서 종류 선택 |
| 윈도우 명령 실행 | Execute Windows batch command, Command 칸에 입력 |
| 스텝 삭제 | 스텝 옆 빨간 X |
| 실행 순서 | 위에서 아래로 순차 실행 |

## 2. Post-build Actions

여기서는 잡의 작업이 끝난 뒤에 할 일을 정한다. 대표적인 것이 이메일 알림이다. Add post-build action을 눌러 원하는 항목을 고르고, 여러 개를 추가할 수 있다. 이 섹션의 실제 설정은 이후 장에서 다룬다.

| 비교 | Build Step | Post-build Actions |
|---|---|---|
| 역할 | 잡의 본 작업 | 본 작업이 끝난 뒤의 처리 |
| 추가 방법 | Add build step | Add post-build action |
| 예시 | Windows 배치 명령 실행 | 이메일 알림 |
| 개수 | 여러 개, 순서대로 실행 | 여러 개 추가 가능 |

처음 소개한 세 가지 지시와 연결하면, 트리거는 Build Triggers 섹션, 빌드 스텝은 Build Step 섹션, 빌드 후 조치는 Post-build Actions 섹션에 각각 대응한다.

| 지시 | 설정 위치 |
|---|---|
| 언제 | Build Triggers |
| 무엇을 | Build Step |
| 끝나고 | Post-build Actions |
