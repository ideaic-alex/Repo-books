# 요약과 핵심 개념

이 장은 Global Tool Configuration 페이지에서 Maven과 JDK를 설정하는 방법을 다뤘다. 이 문서는 장의 결론과 핵심 개념을 한곳에 모아 정리한다.

---

## 1. 장의 결론

Jenkins 잡이 Maven이나 JDK 같은 도구를 필요로 하는데 잡을 실행하는 머신에 그 도구가 없으면 잡은 실패한다. 그래서 Jenkins는 등록해 둔 설치 방법(installer)으로 도구를 자동 설치하는 기능을 제공한다. 책은 이 기능을 Jenkins의 매우 중요한 특징으로 꼽는다.

| 질문 | 답 |
|---|---|
| 도구 설정은 어디서 하는가 | Manage Jenkins의 Global Tool Configuration 페이지 |
| 도구가 서버에 이미 있으면 | 자동 설치를 해제하고 설치 경로(MAVEN_HOME, JAVA_HOME)를 적는다 |
| 도구가 서버에 없으면 | 자동 설치를 켜고 설치 방법을 설정한다 |
| 도구 없이 잡을 돌리면 | 그 도구가 필요한 잡이 실패한다 |

## 2. 핵심 개념 정리

| 개념 | 한 줄 설명 |
|---|---|
| Global Tool Configuration | Jenkins에서 쓸 도구의 이름, 위치, 설치 방법을 등록하는 페이지 |
| 글로벌 settings.xml | `${maven.home}\conf`에 있는 Maven 공통 설정 파일 |
| 사용자 settings.xml | `{user.home}/.m2`에 있는 사용자별 Maven 설정 파일. 같은 설정이 겹치면 이쪽이 우선 |
| Default Settings Provider | 사용자 settings.xml의 위치를 고르는 드롭다운 |
| Default Global Settings Provider | 글로벌 settings.xml의 위치를 고르는 드롭다운 |
| Name | 도구 설정의 이름. Maven은 숫자, 공백, 특수문자를 쓰지 않는다 |
| MAVEN_HOME / JAVA_HOME | 각각 Maven, Java가 설치된 디렉터리 |
| Install Automatically | 서버에 도구가 없을 때 Jenkins가 설치하게 하는 체크박스 |
| Extract *.zip/*.tar.gz | 압축 파일을 내려받아 푸는 설치 방식 |
| Subdirectory of Extracted Archive | 압축을 푼 뒤 Maven이 들어 있는 폴더 이름 |

## 3. 기억할 점

- Maven 설정은 settings.xml 위치 지정과 Maven 설치 구성, 두 부분으로 나뉜다.
- settings.xml이 기본 위치에 있으면 기본 옵션을 그대로 두고, 다른 위치에 있으면 파일 시스템 옵션을 골라 경로를 적는다.
- 자동 설치는 도구가 없는 머신에서 잡을 처음 돌릴 때 한 번만 일어난다.
- Maven 하위 디렉터리 값을 맞게 적어야 Jenkins가 bin 폴더의 mvn 명령을 찾을 수 있다.
- JDK도 같은 방식이다. 이미 있으면 Name과 JAVA_HOME, 없으면 자동 설치다.
