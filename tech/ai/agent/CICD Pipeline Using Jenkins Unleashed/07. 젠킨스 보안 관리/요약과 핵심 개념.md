# 요약과 핵심 개념

이 장은 Configure Global Security 화면의 설정들과, Jenkins를 LDAP와 연동해야 하는 이유를 다뤘다. 원서의 요약은 이 장을 읽으면 필요한 보안 설정을 직접 할 수 있다는 내용이다. 여기서는 장 전체를 한 장으로 되짚는다.

---

## 1. 설정 항목 한눈에 보기

| 항목 | 위치 | 한 줄 요약 | 원서 권장 |
|---|---|---|---|
| Disable remember me | 로그인 옵션 | Keep Me Signed In 체크박스를 숨긴다 | 따로 언급 없음 |
| Delegate to servlet container | Security Realm | 서블릿 컨테이너의 사용자를 쓴다 | 따로 언급 없음 |
| Jenkins' own user database | Security Realm | Jenkins가 사용자를 직접 관리한다 | 외부 서비스에 의존하지 않고 쓸 때 |
| Allow users to sign up | Security Realm | 누구나 계정을 만들 수 있게 한다 | 켜지 않음 |
| None | Security Realm | 인증 없이 익명으로 취급한다 | 따로 언급 없음 |
| LDAP | Security Realm | 회사 디렉터리의 계정을 쓴다 | 회사 계정 연동 시 |
| Anyone can do anything | Authorization | 익명 포함 모두 전체 권한 | 권장하지 않음 |
| Legacy mode | Authorization | Admin만 전체 권한, 나머지 읽기 전용 | 권장하지 않음 |
| Logged-in users can do anything | Authorization | 로그인한 사용자만 전체 권한 | 따로 언급 없음 |
| TCP port for inbound agents | Agents | 에이전트 통신 포트를 정한다 | 분산 빌드가 아니면 Disable, 방화벽이 있으면 Fixed |
| CSRF protection | 보안 항목 | crumb로 위조 요청을 막는다 | 켜 둔다 |
| API Token | 보안 항목 | REST API와 CLI의 인증 | Legacy 옵션은 deprecated |
| SSH Server | 보안 항목 | CLI의 SSH 접근 | 안 쓰면 Disable, 쓰면 Fixed |

표에서 권장하지 않음으로 적힌 항목은 편하지만 제어를 느슨하게 하는 것들이고, 켜지 않음으로 적힌 항목은 외부 사람이 스스로 권한을 얻을 수 있는 것들이다. CSRF 보호를 켜 두라는 줄은 원서가 항목을 설명만 하고 끄라고 하지 않으므로, 켜 둔 상태를 전제로 한 정리다.

---

## 2. 핵심 개념

- 인증은 정상 사용자만 로그인하게 하는 일이고, 권한 부여는 사용자 종류별로 허용 범위를 나누는 일이다.
- 서블릿 컨테이너는 Jenkins를 실행하는 Java 웹 실행 환경이다. 기본은 Jetty다.
- 익명 사용자는 로그인하지 않은 접속자다. None이나 Logged-in users can do anything에서 이들의 접근 범위를 정한다.
- crumb는 CSRF를 막기 위해 사용자 이름, 웹 세션 ID, IP 주소, Jenkins 고유 솔트로 만든 해시 토큰이다.
- 에이전트 포트와 SSH 포트는 Fixed로 두면 방화벽 인바운드 규칙을 만들 수 있다.
- LDAP는 사용자 이름과 비밀번호를 중앙에서 관리하는 프로토콜이고, Jenkins는 LDAP 플러그인으로 이를 쓴다.

---

## 3. 이 장 설정을 따라 하는 순서

1. 대시보드에서 Configure Global Security를 연다.
2. Security Realm에서 사용자 출처를 정한다. 자체 데이터베이스라면 Manage Jenkins → Manage Users에서 사용자를 만든다.
3. Allow users to sign up은 끈 상태로 둔다.
4. Authorization에서 Logged-in users can do anything을 고르고 익명 읽기를 허용할지 결정한다.
5. 분산 빌드와 CLI를 쓰는지에 따라 에이전트 포트와 SSH 서버를 Fixed 또는 Disable로 정한다.
6. 회사 계정을 쓴다면 LDAP 플러그인을 설치하고 Security Realm에서 LDAP를 선택해 IT 부서와 값을 맞춘다.
