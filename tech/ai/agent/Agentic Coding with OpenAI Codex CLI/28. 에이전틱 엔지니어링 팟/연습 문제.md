# 연습 문제

원서의 연습 문제 일곱 개를 자기 말로 풀어 쓰고, 각각 풀이 방향을 한두 문장 덧붙였다. 모두 자기 팀의 실제 상황에 적용하는 과제다.

---

## 1. 역할 대응표 만들기

지금 팀에서 팟의 세 역할을 실제로 누가 하고 있는지 짝지어 보고, 비어 있거나 흐릿한 역할을 찾는다. 사람마다 주 산출물을 한 문단으로 적는다. 컨텍스트 아키텍트는 AGENTS.md, 밸류 엔지니어는 브리프의 질, 퀄리티 엔지니어는 게이트의 성숙도다. 가장 약한 산출물을 골라 첫 개선안을 초안으로 쓴다.

풀이 방향. 직함이 아니라 세 질문(왜, 어떻게, 신뢰)을 실제로 누가 답하는지로 짝을 짓는다. 주인 없는 질문이 곧 약한 산출물의 후보다.

## 2. 브리프 다시 쓰기

팀이 지금 만드는 기능 하나를 골라 설명을 높은 신호의 밸류 엔지니어 브리프로 다시 쓴다. 의도, 제약, 명시적 인수 조건, 실패 시나리오, 범위 밖 경계, 관련 AGENTS.md 절 참조를 갖춘다. Codex 세션에 돌려 보고, 팀의 평소 설명 방식으로 돌린 세션과 결과 품질을 비교한다.

풀이 방향. 같은 기능을 두 가지 설명으로 각각 돌리고, 에이전트가 추측으로 채운 결정 지점의 수와 사람의 방향 수정 횟수를 비교하면 차이가 보인다.

## 3. 자율성 사다리 평가

네 단계 사다리(보조, 승인 필요, 정책 한정, 자가 치유)로 코드베이스의 현재 변경 범주를 분류한다. 범주마다 다음 단계로 올릴 근거가 될 현재의 증거가 무엇인지, 무엇이 모자란지 찾는다.

풀이 방향. 모듈이 아니라 변경 범주(읽기 경로, 쓰기 경로, 스키마, 인프라 등)로 분류한다. 증거는 테스트 커버리지, 리뷰 이력, 감사 로그에서 찾고, 확신이나 느낌은 증거로 치지 않는다.

## 4. 게이트 감사

현재 CI/CD 파이프라인의 모든 자동 검사를 나열한다. 검사마다 누가 작성했는지, 마지막으로 언제 검토했는지, 우회된 적이 있는지, 팀이 겪은 가장 최근 운영 사고를 잡았을지 적는다. 이 감사를 바탕으로 퀄리티 엔지니어의 검증 백로그 초안을 쓴다.

풀이 방향. 마지막 질문, 즉 최근 사고를 잡았을지가 가장 값지다. 잡지 못했을 검사가 많다면 그 빈틈이 백로그 맨 위가 된다.

## 5. 팟 모의 실험

백로그의 범위가 정해진 기능 하나를 골라 에이전트 없이 세 역할 팟을 시뮬레이션한다. 컨텍스트 아키텍트가 AGENTS.md 갱신과 인수 조건을, 밸류 엔지니어가 높은 신호 브리프와 구현 계획을, 퀄리티 엔지니어가 검증 체크리스트와 적대적 테스트 하나를 쓴다. 시간이 얼마나 걸리는가, 맥락이나 명세의 어떤 빈틈이 드러나는가를 본다.

풀이 방향. 에이전트가 없어도 각 역할의 산출물이 나오는지가 핵심이다. 막히는 지점이 곧 에이전트가 들어와도 막힐 지점이다.

## 6. 플러그인으로 패키징

연습 1~4에서 나온 팟 설정(역할 TOML, 훅, AGENTS.md 템플릿)을 Codex 플러그인으로 묶는다. `plugin.json` 매니페스트를 쓰고, 앞에서 본 플러그인 디렉터리 구성을 따라 구조를 짜고, 역할별 플러그인마다 알맞은 설치 정책을 넣은 `marketplace.json` 항목을 정의한다. `codex plugin add`로 설치를 시험하고 샘플 세션에서 훅이 발동하는지 확인한다.

풀이 방향. 단일형으로 먼저 시작한다. 본문의 `marketplace.json` 예시는 퀄리티 엔지니어와 밸류 엔지니어 플러그인 모두에 `INSTALLED_BY_DEFAULT`를 준다. 이를 참고하되, 훅이 실제로 발동하는지는 일부러 규칙 위반 변경을 만들어 확인한다.

## 7. 속도를 정하는 제약으로서의 검증

한 스프린트 동안 팀의 생성 속도(만들어진 기능이나 변경)와 검증 속도(완전히 리뷰하고 테스트하고 출시 승인까지 끝난 변경)를 잰다. 검증되지 않은 작업이 어디에 쌓이는지, 지금은 무엇이 팀에게 검증이 따라잡을 때까지 생성을 늦추라고 알려 주는지 찾는다. 그 신호를 명시적으로 만들어야 하는지, 누가 맡을지 정한다.

풀이 방향. 두 속도의 차이가 곧 쌓이는 재고다. 대기열 크기 상한처럼 눈에 보이는 신호를 하나 정하고, 그 신호를 보고 생성을 멈출 권한이 퀄리티 엔지니어와 밸류 엔지니어 중 누구에게 있는지 정해 둔다.
