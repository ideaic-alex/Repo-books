# 연습 문제

2장 끝에 있는 연습 문제 세 개를 정리한다. 문제의 취지를 풀어 쓰고, 어떻게 접근하면 좋은지 한두 문장씩 덧붙인다. 모두 직접 해 보는 실습이다.

---

## 1. 연습 2-1: 도움말에서 새 플래그 찾기

**문제 취지.** Codex CLI를 설치하고 `codex --help`를 실행한다. 목록에서 몰랐던 플래그 세 개를 골라, 각각 어떤 상황에서 쓸지 한 문장으로 적는다.

**풀이 방향.** 단순히 이름을 옮기는 게 아니라 '이럴 때 쓴다'는 상황이 핵심이다. 자기 작업 흐름(예: CI, 설정 덮어쓰기, 자동화)에 비추어 쓰면 기억에 오래 남는다. 이 장에서 본 `-c` / `--config`나 `codex exec`의 `--json` 같은 플래그가 목록에 어떻게 나오는지 함께 찾아봐도 좋다.

## 2. 연습 2-2: 최소 AGENTS.md 만들기

**문제 취지.** 'AGENTS.md 1분 소개'의 최소 예시를 참고해서, 지금 작업 중인 프로젝트에 AGENTS.md를 만든다. 테스트 명령어, 코딩 컨벤션 하나, 수정 금지 디렉터리 하나를 넣는다. 그다음 세션을 돌려서 지시가 실제로 반영되는지 관찰한다.

**풀이 방향.** 반영 여부는 확인하기 쉬운 방식으로 검증한다. 예를 들어 금지 디렉터리 안의 파일을 고치라고 시켜 보고 에이전트가 거절하거나 피하는지 본다. 전체 패턴은 4장에서 다룬다.

## 3. 연습 2-3: codex exec와 대화형 비교

**문제 취지.** 범위가 정해진 과제 하나를 `codex exec`로 실행한다. 예시는 "모든 TODO 주석을 찾아서 목록을 TODOS.md에 쓰라"는 것이다. 같은 과제를 대화형으로도 돌리고, 대화형 세션이 보여 준 것 중 `codex exec`가 보여 주지 않은 것이 무엇인지 비교한다.

**풀이 방향.** 중간 과정(어떤 파일을 읽었는지, 어떤 명령을 실행했는지, 승인 요청 여부)이 얼마나 보였는지에 주목한다. 결과물은 같아도 과정이 보이는 정도와 개입할 수 있는 지점이 다르다는 점이 요점이다.
