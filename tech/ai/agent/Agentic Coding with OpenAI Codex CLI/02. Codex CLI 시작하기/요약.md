# 요약

2장의 핵심을 여덟 가지로 다시 묶어 정리한다. 각 항목 끝에는 자세한 내용이 있는 문서를 적어 두었다.

---

## 1. 장 요약

1. **CLI는 Codex의 네 표면 중 하나다.** CLI, 데스크톱 앱, IDE 확장, 클라우드가 같은 지능 계층, 설정, 메모리를 공유한다. ('설치와 사전 준비')
2. **시스템 요구 사항.** Node.js 22 이상이 필요하고, macOS, Windows(네이티브 또는 WSL2), Linux에서 돌아간다. ('설치와 사전 준비')
3. **설치하고 확인한다.** `npm install -g @openai/codex`, `brew install --cask codex`, 바이너리 직접 내려받기 중 하나를 쓰고, `codex --version`으로 확인한다. ('설치와 사전 준비')
4. **쉘 자동 완성은 매일 쓰는 속도를 높인다.** 프롬프트를 쓰기 시작하기 전에 bash, zsh, fish 중 쓰는 쉘에 설정해 둔다. ('설치와 사전 준비')
5. **인증 방법은 세 가지다.** 구독은 디바이스 코드 방식, API 접근은 `OPENAI_API_KEY`, 관리형 배포는 기업용 설정이다. ('인증 방법')
6. **대화형 REPL과 스크립트용 exec.** `codex`는 매일 쓰는 대화형 REPL이고, `codex exec`는 스크립트와 CI/CD를 위한 헤드리스(화면 없는) 모드다. ('codex와 codex exec')
7. **설정은 계층으로 해석된다.** 수준이 세 단계 있고 해석 순서가 정해져 있어서, 가까운 설정이 먼 설정을 덮어쓴다. ('설정 위치와 환경 변수')
8. **AGENTS.md는 프로젝트 규칙 파일이다.** Codex가 세션 시작 때 자동으로 읽는 마크다운 파일이며, 프로젝트 컨벤션, 테스트 명령어, 건드리면 안 되는 파일을 적는다. 4장에서 깊이 다룬다. ('AGENTS.md 1분 소개')

## 2. 한 번 더 확인할 점

- 에이전트가 처음에 틀리는 것은 정상이고, 테스트가 그것을 잡아 준다. ('첫 세션 미리보기')
- 승인을 묻는 것은 고장이 아니라 승인 모드다. ('첫 세션 실행과 첫 주 실수')
- 요약 7번의 "세 단계"는 사용자 수준 파일, 프로젝트 수준 파일, 명령줄 플래그에 해당한다. 내장 기본값까지 합치면 해석 순서는 네 단계로 보인다.
