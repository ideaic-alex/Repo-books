# 수렴 계층: 도구 사이를 오가는 표준

경쟁이 치열해 보이지만, 그 밑에서는 도구들이 몇 가지 공통 표준으로 모이고 있다. 원서는 이것이 개별 벤치마크 점수보다 중요하다고 말한다. 종속(lock-in)이 얼마나 심한지를 결정하기 때문이다. 이 문서에서는 도구 경계를 넘나드는 세 가지 표준과 그것이 도구 선택에 어떤 뜻을 갖는지 정리한다.

---

## 1. 세 가지 공통 표준

지금은 세 가지 표준이 도구의 경계를 넘어 쓰인다.

1. **AGENTS.md: 이식 가능한 지침 파일.** Codex CLI를 설정하는 프로젝트 지침(4장)을 점점 더 많은 경쟁 에이전트가 기본으로 읽는다. 파일 하나로 여러 도구의 동작을 중복 없이 잡아 줄 수 있다.
2. **Agent Skills: 이식 가능한 기능 묶음.** SKILL.md가 든 디렉터리(10장)를 인식하는 에이전트가 늘고 있다. 한 번 쓴 스킬을 여러 도구에서 부를 수 있다.
3. **MCP: 이식 가능한 도구 계층.** Model Context Protocol 서버(8장)는 같은 도구를 MCP를 지원하는 어떤 에이전트에도 노출한다. 만들어 둔 연동이 한 벤더에 묶이지 않는다.

## 2. 구매자에게 주는 의미

원서는 수렴을 이 장에서 가장 반가운 소식이라고 부른다. 결정이 거의 전부 아니면 전무일 필요가 없어지기 때문이다. AGENTS.md 파일, 스킬 디렉터리, MCP 서버 설정을 스택 안의 여러 도구가 공유할 수 있으니 멀티 도구 작업 환경을 싸게 만들고 싸게 바꿀 수 있다. 종속이 가장 아팠을 계층에서 오히려 먼저 약해지고 있는 셈이다.

이 점은 뒤에 나오는 마이그레이션 문서와 멀티 도구 패턴 문서의 전제가 된다. 설정이 이식 가능하다면 도구를 바꾸는 비용이 작고, 작업 성격에 따라 도구를 나눠 쓰는 일도 부담이 적다.

## 3. 이 문서에서 기억할 것

- AGENTS.md, Agent Skills, MCP가 도구를 가로지르는 세 표준이다.
- 이 세 가지가 공유되므로 도구를 바꾸거나 함께 쓰는 비용이 낮다.
- 선택은 점수 비교보다 종속 정도로 판단하는 편이 더 오래간다.
