# 요약

1장의 내용을 네 가지 흐름으로 다시 정리한다. 앞 문서들을 읽은 뒤 복습용으로 쓰거나, 처음부터 읽을 시간이 없을 때 전체 그림을 잡는 용도로 쓴다.

---

## 1. 연구 모델에서 자동완성으로

2021년의 원조 OpenAI Codex는 코드로 추가 학습한 언어 모델이 설명만 보고 구현을 만들어 낼 수 있음을 보여 줬다. 같은 해 나온 GitHub Copilot은 자동완성을 개발자 손에 쥐여 줬지만, 그 한계도 함께 드러냈다. 자동완성은 반응형이고 국소적이어서 테스트를 돌리지도, 여러 파일에 걸쳐 추론하지도 못한다.

## 2. 대화와 에이전트로의 전환

2022년의 ChatGPT가 상호작용을 대화로 바꿨다. 2023년에서 2024년 사이의 에이전트형 전환은 모델에게 도구 접근을 주어, 여러 단계의 작업을 스스로 끝낼 수 있게 했다.

## 3. Codex CLI는 에이전트형 터미널 클라이언트다

2025년 4월에 공개된 OpenAI의 오픈 소스(Apache 2.0) 터미널 에이전트다. 다음 성질을 갖는다.

- 헤드리스 실행(`codex exec`)을 지원한다.
- 커널 수준 샌드박스로 보호된다.
- AGENTS.md를 인식한다.
- 저장소를 읽고, 테스트를 돌리고, 커밋을 만들고, 프로젝트별 지침을 따르도록 만들어졌다.

## 4. 터미널이어서 얻는 것

터미널 도구는 Unix와 조합되고, CI/CD 파이프라인에 들어가며, 셸이 있는 모든 환경에서 동작한다.
