# 연습 문제

1장에는 다섯 개의 연습 문제가 있다. 모두 정답이 정해진 문제가 아니라, 자기 환경에 개념을 대입해 보며 감각을 키우는 과제다. 각 문제의 취지를 풀어 쓰고, 풀이 방향을 한두 문장으로 덧붙인다.

---

## 연습 1-1. 지금 쓰는 도구 지도 그리기

최근 6개월 동안 쓰고 있거나 써 본 AI 코딩 도구를 모두 적는다. 도구마다 세 가지를 따진다. 범주(IDE 에이전트, 터미널 에이전트, 클라우드 에이전트), 주된 상호작용 방식(자동완성, 채팅, 에이전트), 오픈 소스 여부다. 'AI 코딩 도구 지형' 문서의 비교표를 틀로 삼아 내 도구들을 행으로 추가한다. 그다음 이미 쓰는 도구들과 비교해 Codex CLI가 어디에 놓이는지 생각한다. Claude Code를 쓰고 있다면 두 도구가 공유하는 설계 결정 세 가지와 갈라지는 결정 세 가지를 적는다.

**풀이 방향.** 공통점으로는 터미널 우선, 지침 파일(CLAUDE.md와 AGENTS.md), 샌드박스, MCP 지원을 떠올릴 수 있다. 차이점으로는 모델 계열, 서브에이전트 구조, 생태계를 비교한다.

## 연습 1-2. 자동완성으로는 안 되는 작업 찾기

지난 한 달 동안 한 가장 복잡한 코딩 작업을 떠올린다. 여러 파일을 읽어야 했거나, 테스트를 반복해서 돌려야 했거나, 코드베이스 여러 곳을 맞춰 고쳐야 했던 일이 좋다. 그 작업을 한 문단으로 적고, 그중 어느 단계가 자동완성의 손이 닿지 않는 부분이었는지, 왜 그런지 밝힌다. 이 문제는 에이전트 방식이 이전 도구가 줄 수 없던 가치를 더하는 지점을 직관으로 익히는 데 목적이 있다.

**풀이 방향.** 테스트 실패를 보고 원인을 추적하는 단계나 여러 파일에 걸친 변경의 일관성 확인처럼, 환경에서 결과를 관찰해야 하는 단계를 고르면 자동완성의 한계(한 시점, 한 파일)와 연결하기 쉽다.

## 연습 1-3. AGENTS.md 표준 읽기

4장에서 첫 AGENTS.md를 쓰기 전에 agents.md의 현재 명세를 읽는다. 어떤 필드가 필수이고 어떤 필드가 선택인지, 비교표의 도구 중 어느 것이 어떤 필드를 지원하는지 메모한다. 그리고 지금 프로젝트에서, 소스 코드만 봐서는 알 수 없지만 신입 팀원이나 AI 에이전트가 일을 잘하려면 알아야 하는 것 다섯 가지를 적는다. 이 목록이 4장 AGENTS.md의 씨앗 내용이 된다.

**풀이 방향.** 일반론("깨끗하게 써라")이 아니라 테스트 실행 명령, 환경 활성화 방법, 건드리면 안 되는 스크립트처럼 구체적이고 눈에 띄지 않는 사항을 고른다.

## 연습 1-4. 에이전트 루프에 대입하기

이 장에서 설명한 4단계 에이전트 루프(읽기, 계획, 실행, 검증)는 Codex CLI가 일하는 방식의 바탕이다. 현재 프로젝트 백로그에서 손으로 하면 15분에서 60분쯤 걸릴 작업을 하나 고른다. 네 단계마다, 그 작업에서 Codex CLI가 무엇을 할지 한 문장씩 쓴다. 그런 다음 어느 단계가 토큰(컨텍스트)을 가장 많이 쓸지, 어느 단계가 잘못될 위험이 가장 클지 어림해 본다. 3장에서 효과적인 프롬프트를 쓰는 준비 과정이다.

**풀이 방향.** 정해진 답은 없고 고른 작업에 따라 달라진다. 저장소를 넓게 읽어야 하는 작업이면 읽기 단계에서 토큰이 많이 들 수 있고, 여러 파일을 고치는 작업이면 실행 단계의 위험이 클 수 있다. 검증 단계에서 쓸 테스트를 미리 정해 두면 위험을 줄이는 데 도움이 된다.

## 연습 1-5. 샌드박스 모델 조사하기

사용하는 플랫폼에 따라 macOS Seatbelt나 Linux bubblewrap 중 하나의 문서를 찾아 기술 개요를 읽는다. 그리고 두 문단을 쓴다. 첫째, 기본 샌드박스가 Codex CLI에게 막는 작업의 종류는 무엇인가. 둘째, 기본 샌드박스가 너무 엄격해서 Codex CLI가 과제를 끝낼 수 없게 되는 작업 범주를 하나 든다. 5장에서 승인 모드를 다루는 논의의 준비 과정이다.

**풀이 방향.** 막는 것은 파일 시스템과 네트워크 접근 제한을 중심으로 정리한다. 너무 엄격한 예로는 외부 네트워크에서 패키지를 내려받아야 하는 작업을 생각해 볼 수 있다. 정확한 기본 동작은 읽은 문서에서 확인해 적는다.
