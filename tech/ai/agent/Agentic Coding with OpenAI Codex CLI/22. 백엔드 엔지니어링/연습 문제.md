# 연습 문제

22장 끝의 연습 문제 다섯 개를 풀이 방향과 함께 정리한다. 모두 내 프로젝트나 Run or Relax에 직접 해 볼 수 있는 실습이다.

---

## 1. 기준선 점검

내가 맡은 Python 프로젝트 하나를 골라, 이 장의 관례에 맞춰 루트 AGENTS.md를 쓴다. 그다음 Codex CLI에서 `/init`을 실행해 생성된 파일과 내 파일을 비교한다. 어디가 다르며, 그 차이는 Codex CLI가 스스로 추론할 수 있는 관례와 반드시 말로 적어야 하는 관례에 대해 무엇을 알려 주는가.

풀이 방향: 두 파일을 diff로 놓고, 테스트 경로, 린트 도구, 패키지 매니저처럼 서로 다르게 적힌 항목을 목록으로 만든다. 생성본이 추측으로 틀리게 적은 항목이 곧 명시가 필요한 관례다. 생성본이 맞게 적은 항목은 코드에서 읽힌다는 뜻이므로 굳이 길게 쓰지 않아도 된다.

## 2. 커버리지 확장

테스트 커버리지가 80% 미만인 모듈을 찾는다. AGENTS.md의 픽스처 관례를 활용해 커버리지를 95%까지 올리는 Codex CLI 프롬프트를 쓴다. 생성된 테스트를 리뷰한다. 동작을 단언하는가, 아니면 현재 출력을 그대로 단언할 뿐인가. 의도한 계약이 아니라 우연한 동작을 단언하는 테스트는 고친다.

풀이 방향: 프롬프트에 픽스처 이름과 마커, 목 사용 금지 방침을 넣는다. 리뷰할 때는 각 테스트에서 "이 단언이 틀린 구현을 잡아낼 수 있는가"를 묻는다. 현재 결과를 그냥 베낀 단언이면 기대값을 계약에서 다시 도출해 바꾼다.

## 3. 훅 파이프라인

이 장의 훅 세 개(PostToolUse 린트, Stop 테스트 게이트, UserPromptSubmit 낡은 명령 차단)를 `.codex/hooks.json`에 구현한다. 모듈에 새 함수를 추가하는 Codex CLI 세션을 돌리며 어떤 훅이 언제 발동하는지 관찰한다. 그다음 Stop 훅 명령이 테스트 실패 때 0이 아닌 코드로 끝나게 고치고, Codex CLI가 오류를 어떻게 보고하는지 본다.

풀이 방향: 일부러 실패하는 테스트를 하나 넣어 Stop 게이트가 멈춤을 막는지 확인한다. Stop 명령이 pytest 출력을 표준 오류로 보내고 `{}`를 표준 출력에 찍는 이유(JSON 파싱)와 `--no-sync`, `UV_CACHE_DIR`의 역할을 떠올리며 관찰 결과를 해석한다.

## 4. 타입 어노테이션 확장

함수의 30% 이상에 타입 어노테이션이 없는 Python 모듈을 찾는다. AGENTS.md의 관례(Python 3.10+이므로 `Optional[str]`이 아니라 `str | None`)를 따라 타입 없는 모든 함수에 어노테이션을 달아 주는 Codex 프롬프트를 쓴다. 작업이 끝나면 mypy나 ty를 strict 모드로 돌려, 나오는 타입 오류를 리뷰한다. 오류가 새 어노테이션에서 나왔는지, 어노테이션 덕분에 드러난 기존의 타입 문제인지 구분해 적는다.

풀이 방향: 작업 전후의 mypy 오류 수를 비교한다. 새로 생긴 오류 중 어노테이션이 틀린 것은 어노테이션을 고치고, 원래 코드의 문제가 드러난 것은 별도 이슈로 분리한다. `Any`가 쓰였다면 설명 주석이 있는지 확인한다.

## 5. Run or Relax API 만들기

FastAPI와 비동기 관례가 담긴 Python AGENTS.md를 바탕으로, Codex CLI에게 시드 시간표를 쓰는 `GET /departures` 엔드포인트를 만들게 한다. 판정은 순수 함수로, 테스트는 시계를 읽지 않고 주입하는 방식으로 하게 한다. 그다음 문 앞에서 승강장까지 걸리는 시간 규칙을 프롬프트에서 일부러 빼고 다시 생성한다. 에이전트가 0과 비교해서, 놓칠 열차를 타라고 문밖으로 내보내는가. 규칙을 AGENTS.md에 추가하고, 이를 못 박는 테스트가 있는지 확인하고, 계약은 그대로 둔다. 23장에서 이 계약에 맞춰 프론트엔드를 만든다.

풀이 방향: 규칙을 뺀 버전의 결과를 저장해 두고, 규칙을 넣은 버전과 `verdict` 함수의 비교 기준(0 대 `WALK_MINUTES`)을 대조한다. 경계값 바로 위와 아래(예: 14분 전후)를 단언하는 테스트를 추가하면 규칙이 문서가 아닌 코드로 고정된다.
