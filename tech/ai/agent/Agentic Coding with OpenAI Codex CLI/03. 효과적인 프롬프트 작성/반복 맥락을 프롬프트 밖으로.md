# 반복 맥락을 프롬프트 밖으로

매번 프롬프트에 같은 규칙을 적고 있다면, 그 규칙은 프롬프트 밖으로 옮길 때가 된 것이다. 이 문서는 모든 세션에 적용되는 AGENTS.md와, 필요할 때만 켜는 프로필로 지속되는 맥락을 나눠 두는 방법을 정리한다.

---

## 1. AGENTS.md

AGENTS.md는 세션을 시작할 때마다 자동으로 읽힌다. 규칙, 제약, 빌드 명령, 건드리면 안 되는 파일을 여기에 적는다. 원서의 예시는 이렇다.

```markdown
# Project: Payment Service
## Build and test
npm run build && npm test
## Conventions
- async/await throughout; no .then() chains
- Error messages in sentence case, no trailing periods
- All monetary amounts stored as integers (pence), not floats
## Do not modify
- src/legacy/chargebee.ts (deprecated; read-only)
- Any file matching *.generated.ts
```

규칙의 종류가 구분되어 있다. 빌드와 테스트 명령, 코딩 규약, 수정 금지 대상이다. 금액을 정수(펜스 단위)로 저장한다는 규칙처럼 프로젝트마다 다른 결정이 여기에 들어간다.

### 파일이 합쳐지는 방식

AGENTS.md는 여러 층으로 합성된다. ~/.codex/AGENTS.md가 개인 기본값을 정하고, 저장소 루트의 파일이 프로젝트 기본값을 정하며, 하위 디렉터리의 파일이 앞의 둘을 덮어쓴다. 이 계층적 해석 순서는 AGENTS.md 공식 문서에 명시되어 있다.

### /init을 쓸 때의 주의

세션 안에서 /init 슬래시 명령을 쓰면 시작용 파일이 만들어진다. 출발하기엔 쉽지만 결과가 가장 좋은 경우는 드물다. 자동 생성 파일은 뻔한 것을 장황하게 쓰고, 에이전트 행동을 실제로 바꾸는 프로젝트 고유의 결정은 덜 쓰는 경향이 있다. 따라서 출력은 그대로 커밋할 파일이 아니라 가지치기할 초안으로 취급한다. AGENTS.md의 패턴과 함정은 4장에서 자세히 다룬다.

## 2. 프로필로 지시를 바꾸기

AGENTS.md는 그 프로젝트의 모든 세션에 적용된다. 반면 프로필은 우리가 요청할 때만 적용된다. 이 차이는 작업 모드가 여러 개일 때 중요하다. 같은 저장소에서 오전에는 버그를 고치고, 오후에는 아키텍처를 검토하고, 릴리스 전에는 보안 감사를 할 수 있다. 모드마다 필요한 추론 태도, 출력 방식, 상시 지시가 다르다. 프로필이 없으면 그 태도를 매번 프롬프트에서 다시 세워야 한다.

이름 붙인 프로필은 ~/.codex/<이름>.config.toml 파일로 정의하고, model_instructions_file 키로 사용자 지정 지시 파일을 가리킨다.

```toml
# ~/.codex/bugfix.config.toml
model_instructions_file = "~/.codex/prompts/bugfix.md"
model_reasoning_effort = "high"
```

`codex --profile bugfix`로 켠다. 지시 파일(bugfix.md)에는 다음과 같은 내용이 들어갈 수 있다. 꼼꼼한 디버거 역할을 맡기고, 근본 원인을 한 문장으로 말하게 하고, 회귀 테스트를 포함하게 하고, 추측성 변경을 금지하는 내용이다.

## 3. AGENTS.md와 프로필 구분

| 구분 | AGENTS.md | 프로필 |
|---|---|---|
| 적용 범위 | 프로젝트의 모든 세션 | 요청한 세션만 |
| 켜는 방법 | 세션 시작 시 자동 | codex --profile 이름 |
| 담는 내용 | 빌드 명령, 규약, 수정 금지 파일 | 모드별 추론 태도, 출력 스타일, 상시 지시 |
| 위치 | 저장소, 홈 디렉터리, 하위 디렉터리 | ~/.codex/<이름>.config.toml |

판단 기준은 간단하다. 어떤 작업을 하든 지켜야 하는 규칙이면 AGENTS.md에, 특정 작업 모드에서만 필요한 태도라면 프로필에 둔다.
