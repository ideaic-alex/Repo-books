# 출력 제어와 비용 설정

프롬프트는 모델에게 무엇을 말하느냐뿐 아니라, 모델이 무엇을 돌려 말하게 하느냐도 포함한다. config.toml의 여러 키가 말의 길이, 추론 과정의 노출, 토큰 관리 방식을 정한다. 작업 지시 자체는 건드리지 않고 에이전트의 소통 방식을 바꾸는 장치들이다.

---

## 1. 말의 길이: model_verbosity

model_verbosity 키는 세 값을 받는다.

```toml
model_verbosity = "low"    # Code-focused, minimal prose
model_verbosity = "medium" # Balanced (default)
model_verbosity = "high"   # Detailed walkthroughs, architecture commentary
```

- low: 코드 중심이고 설명은 최소한이다. 코드 출력만 필요한 자동화 파이프라인에 쓴다.
- medium: 균형 잡힌 기본값이다.
- high: 자세한 해설과 아키텍처 논평이 나온다. 모델이 추론을 글로 설명해 주길 바라는 아키텍처 탐색 세션에 쓴다.

### 비용에 미치는 영향

verbosity는 비용을 직접 조절하는 수단이기도 하다. 출력 토큰은 입력 토큰보다 단가가 높고, 설명 글이 딸린 코드보다 길어지기 쉽다. 하루에 수백 번 도는 CI 작업에 low를 걸면 모델의 군더더기가 결과를 내는 데 필요한 최소한으로 줄어서, 비용이 흘러가는 서술이 아니라 입력 프롬프트로 대부분 정해진다.

긴 세션에는 부차적인 효과도 있다. 어시스턴트의 모든 턴은 다음 턴에 다시 보내지는 대화 기록의 일부가 된다. 그래서 앞쪽 턴이 장황하면 이후 모든 호출의 앞부분(prefix)이 계속 커진다. 정리하면 글 자체가 산출물인 곳에서는 verbosity를 높게 두고, 그렇지 않은 곳에서는 낮춘다.

## 2. 추론 요약과 노출

model_reasoning_summary 키는 모델의 내부 추론 과정을 출력에 요약해서 보여 줄지 정한다. 여기에 두 키가 더해진다.

- hide_agent_reasoning: 추론 표시를 완전히 숨긴다.
- show_raw_agent_reasoning: 가공하지 않은 추론 원문을 보여 준다.

세 키를 조합하면 추론의 가시성을 완전히 숨김, 요약, 원문 순으로 조절할 수 있다.

## 3. 토큰 예산 관리

에이전트가 자기 컨텍스트를 얼마나 적극적으로 관리할지에 영향을 주는 키가 둘 있다.

| 키 | 하는 일 |
|---|---|
| tool_output_token_limit | 도구 결과 하나가 쓸 수 있는 토큰의 상한을 정한다 |
| model_auto_compact_token_limit | 자동 압축이 시작되는 기준선을 정한다 |

tool_output_token_limit을 낮추면 큰 파일 하나를 읽은 결과가 컨텍스트 윈도의 불균형하게 큰 몫을 차지하는 일을 막는다. 여러 파일에 걸친 작업을 시킬 때 특히 의미가 있다.

## 4. 용도별 프로필 예시

원서는 세 가지 프로필을 보여 준다.

```toml
# ~/.codex/ci.config.toml — terse automation
model_verbosity = "low"
hide_agent_reasoning = true
model_reasoning_effort = "low"
tool_output_token_limit = 8000

# ~/.codex/explore.config.toml — verbose exploration
model_verbosity = "high"
show_raw_agent_reasoning = true
model_reasoning_effort = "high"
```

```toml
# ~/.codex/budget.config.toml — cost-conscious long session
model_verbosity = "medium"
model_reasoning_effort = "medium"
model_auto_compact_token_limit = 80000
tool_output_token_limit = 12000
```

| 프로필 | 목적 | 핵심 설정 |
|---|---|---|
| ci | 간결한 자동화 | 말 적게, 추론 숨김, 추론 강도 low, 도구 출력 8000 토큰 제한 |
| explore | 상세한 탐색 | 말 많이, 추론 원문 노출, 추론 강도 high |
| budget | 비용에 민감한 긴 세션 | 중간 verbosity와 추론 강도, 자동 압축 80000 토큰, 도구 출력 12000 토큰 제한 |

`codex --profile ci`처럼 켠다. 이 출력 프로필은 모델 선택 프로필과도 함께 쓸 수 있다. 예를 들어 ci 출력 프로필에 빠른 모델을 조합하면 비용 효율을 최대로 높일 수 있다.
