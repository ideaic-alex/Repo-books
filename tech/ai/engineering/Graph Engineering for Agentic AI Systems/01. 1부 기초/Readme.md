# 1부 개요 (Part I) 기초 (Foundations)

켄 황(Ken Huang)의 『Graph Engineering for Agentic AI Systems』(2026)는 에이전트 AI 시스템을 그래프로 설계, 운영, 보안, 검증하는 방법을 14개 장으로 다룬다. 1부는 네 추천인의 머리말과 세 개 장으로, 책 전체가 쓰는 말의 뜻을 정한다. 그래프 엔지니어링이 무엇인지, "그래프"라는 낱말이 가리키는 서로 다른 대상이 무엇인지, 하네스라는 우산 아래에서 그래프가 어디에 서는지를 다룬다. 이후의 설계, 구현, 운영, 보안 장은 모두 이 구분 위에 서 있다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책이 소개하는 도구, 제품, 날짜, 수치는 책이 서술한 시점(2026년경) 기준이며 노트가 검증하지 않았으므로 바뀔 수 있다.

> **이 부를 한 문장으로**
> 그래프 엔지니어링은 에이전트가 갈 수 있는 길을 직접 그려 소유하는 일이고, 실행 그래프와 지식 그래프를 섞지 않으며, 대부분의 일은 루프로 충분하다는 거절 기준에서 출발한다.

---

## 0. 먼저 알아 둘 것

- **같은 낱말, 다른 대상**: 책은 그래프를 실행 그래프(일이 돌아가는 구조), 지식 그래프(기억하는 사실), 학습된 그래프(훈련된 모델)로 나눈다. 이 구분을 놓치면 이후 모든 논의가 어긋난다.
- **루프는 그래프의 한 점**: 루프는 노드 하나와 자기 엣지를 가진 그래프다. 그래프는 루프를 대체하지 않고 품는다.
- **사회 소동은 소재일 뿐**: 1장은 2026년 7월의 SNS 논쟁에서 출발하지만 목적은 사건의 재구성이 아니라 어휘 정리와 증거 규율이다.
- **책의 주장과 노트의 해설**: 저자 자신의 틀(하네스는 패러다임, 나머지는 형제)은 저자의 합성이라고 책이 밝힌다. 노트의 보충은 `참고(노트 작성자)`로 구분한다.

## 2. 1부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 토폴로지(topology) | 노드와 엣지가 이루는 연결 구조 |
| 실행 그래프(execution graph) | 노드가 일하고 엣지가 다음 단계를 정하는 그래프. 기호 G_A |
| 지식 그래프(knowledge graph) | 개체와 유형·시간·출처가 있는 사실의 그래프. 기호 G_K |
| 학습된 그래프(learned graph) | GNN 등 오프라인에서 훈련되는 모델. 기호 G_L |
| 하네스(harness) | 모델 바깥의 환경 전체. 에이전트는 모델과 하네스의 합 |
| 팬아웃(fan-out)과 조인 | 일을 여럿으로 갈랐다가 다시 합치는 동작. 루프가 못 하는 것 |
| 상태(state) | 한 번의 실행 동안 노드들이 공유하는 기록 |
| 게이트(gate) | 테스트, 정책, 예산, 사람처럼 경로 위에서 통과를 확인하는 지점 |

## 3. 이 부의 흐름 요약

머리말은 네 추천인이 같은 문제, 곧 토폴로지의 주인이 없다는 문제를 서로 다른 자리에서 짚는다고 소개한다. 1장은 그 문제를 루프와 그래프의 차이로 풀고, 팬아웃이 그래프를 정당화하는 유일한 동작이라고 보인다. 2장은 "그래프"라는 한 낱말 아래 섞인 세 대상을 갈라 놓고, 루프를 실행 그래프의 한 점으로 정리한다. 3장은 프롬프트, 컨텍스트, 루프, 메모리가 그래프와 형제임을 보이고, 이 일에 그래프가 필요한지 네 질문으로 묻는다.
