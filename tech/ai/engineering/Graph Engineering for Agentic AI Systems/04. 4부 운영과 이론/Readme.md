# 4부 개요 (Part IV) 운영과 이론

Ken Huang의 『Graph Engineering for Agentic AI Systems』 4부는 두 개 장이다. 9장은 이미 배포된 에이전트 그래프를 운영하는 법을, 10장은 그 그래프가 어떤 오래된 컴퓨터 과학 위에 서 있는지를 다룬다. 앞의 장이 "배포한 다음 날 아침"의 이야기라면 뒤의 장은 "왜 그렇게 동작하는가"의 이야기다. 9장에서 만난 슈퍼 스텝, 재개 시 노드 재실행, 조인 같은 현상이 10장에서 Pregel, 멱등성, 페트리 넷이라는 이름을 얻는다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책이 소개하는 도구, 버전, 수치(LangGraph의 재귀 한도 등)는 2026년경 기준이며 노트가 검증하지 않았다.

> **이 부를 한 문장으로**
> 운영의 어려움은 대부분 모델이 아니라 상태, 재개, 버전에서 오고, 그 해법은 이미 오래된 컴퓨터 과학에 있으며, 새로운 것은 노드가 확률적이라는 세 가지 점이다.

---

## 0. 먼저 알아 둘 것

- **재개와 재생**: 재개는 같은 스레드를 이어 가며 노드가 처음부터 다시 실행된다. 재생은 과거 체크포인트에서 갈라져 다시 돌리는 포크다.
- **멱등성**: 같은 작업을 여러 번 해도 결과가 한 번과 같음. 9장의 중심 개념이다.
- **선행 이론**: 10장은 DAG, 상태 기계, 페트리 넷, 워크플로 엔진, 액터, Pregel을 쉬운 비유로 소개한다. 수학 지식은 필요 없다.
- 이 부는 LangGraph 용어를 많이 쓰지만 개념은 다른 프레임워크에도 적용된다.

## 2. 4부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 상태 드리프트 | 노드마다 같은 키의 의미나 모양이 조금씩 어긋나는 현상 |
| 리듀서 | 여러 노드의 업데이트를 상태 한 키에 합치는 함수 |
| 슈퍼 스텝 | 병렬 노드가 한 번에 돌고 쓰기를 확정하는 실행 단위 |
| 멱등성 | 여러 번 실행해도 한 번과 같은 결과 |
| 폭발 반경 | 나쁜 쓰기가 닿는 노드와 외부 시스템의 범위 |
| 위상 정렬 | 모든 의존을 지키며 노드를 줄 세우는 방법 |
| 토큰(페트리 넷) | 통제 흐름의 단위. 모여야 합류가 일어남 |
| 허용 목록 | 선언된 엣지의 집합. 모델은 그 안에서만 고를 수 있음 |

## 3. 이 부의 흐름 요약

9장은 그래프가 프로세스가 되는 순간부터 시작해 재개 때 노드가 다시 도는 문제, 사람 승인, 비용, 버전, 장애 격리를 순서대로 다루고 열두 항목의 운영 체크리스트로 끝난다. 10장은 그 체크리스트의 뿌리를 찾아 올라가, 위상은 오래된 것이고 확률적인 노드 때문에 흔들리는 가정은 세 가지뿐임을 보인다. 결국 같은 결론으로 돌아온다. 비결정성은 재생할 수 있는 상자에 가두고, 나머지는 결정적으로 만든다.
