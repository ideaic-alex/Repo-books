# 2부 개요 (Part II) 설계

켄 황(Ken Huang)의 『Graph Engineering for Agentic AI Systems』 2부는 에이전트 그래프를 실제로 설계하는 세 개 장이다. 4장은 그래프를 노드, 엣지, 상태, 시간으로 분해해 부품 이름을 붙이고, 5장은 그 그래프를 만들지 말아야 할 때를 점수표와 측정으로 가려내며, 6장은 거절을 통과한 일에 쓸 수 있는 패턴 언어를 정리한다. 1부가 그래프라는 관점을 세웠다면 이 부는 "무엇으로 만들고, 언제 만들지 말고, 만들면 어떤 모양으로 만드는가"에 답한다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책이 인용하는 제품, 날짜, 수치는 2026년경 시점 기준이며 노트 작성자가 원문을 모두 다시 검증한 것은 아니다.

> **이 부를 한 문장으로**
> 유형이 있는 노드와 엣지로 허용 목록을 구조에 새기되, 일이 정말 쪼개질 때와 되돌릴 수 없는 행동 앞에서만 그래프를 만들고, 만들었다면 독립 검증과 정지 규칙으로 지킨다.

---

## 0. 먼저 알아 둘 것

- **다섯 요소 튜플**: 에이전트 그래프는 노드, 엣지, 상태, 후보 중 모델의 선택, 시간으로 이루어진다. 앞의 세 가지가 설계의 뼈대다(4장).
- **퇴화한 그래프**: 루프는 노드 하나짜리 그래프다. 대부분의 시스템은 거기서 멈춘다(5장).
- **작성자와 검사자의 분리**: 검사자는 쓰기 잠금이 없고 새 컨텍스트에서 본다. 이 원칙이 4장의 평가자 노드, 5장의 독립 검증자, 6장의 메이커/체커로 이어진다.
- **앞 장과의 연결**: 1부 2장의 실행 그래프와 3장의 하네스(harness) 개념 위에서 읽으면 된다. 이 부의 마지막 6장은 3부 7장의 프레임워크로 넘어가는 다리다.

## 2. 2부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 에이전트 그래프(agent graph) | 에이전트, 도구, 평가자, 사람이 이름 붙은 길로 이어진 조직 |
| 리듀서(reducer) | 여러 노드가 같은 상태 키에 쓸 때 합치는 규칙 |
| 슈퍼스텝(super-step) | 준비된 노드를 한꺼번에 돌리고 갱신을 합치는 한 박자 |
| 체크포인트(checkpoint) | 슈퍼스텝 경계마다 저장되는 상태, 정지와 재개의 근거 |
| 인터럽트(interrupt) | 실행을 멈추고 값이 올 때까지 기다리는 연산 |
| 멱등성(idempotency) | 같은 부작용을 두 번 실행해도 한 번과 같게 만드는 성질 |
| 허용 목록(allowlist) | 모델이 갈 수 있는 길과 쓸 수 있는 도구를 구조로 제한한 것 |
| 팬아웃, 팬인 | 한 노드에서 여러 일로 나누고 다시 합치는 동작 |
| 메이커/체커 | 작성자는 쓰고 검사자는 읽기만 하는 구조 |
| 핸드오프(handoff) | 제어를 다른 전문가에게 넘기고 수신자가 소유하는 구조 |

## 3. 이 부의 흐름 요약

4장은 그래프를 유형으로 분해해 "상자와 화살표마다 이름을 말할 수 있어야 한다"는 기준을 세운다. 5장은 곧바로 그 기준을 거절의 도구로 뒤집는다. 여섯 신호표와 베이크오프로 대부분의 일은 루프로 남기고, 되돌릴 수 없는 행동 앞의 사람 관문 하나만 예외로 인정한다. 6장은 거절을 통과한 일을 위한 패턴 카탈로그다. 다이아몬드, 메이커/체커, 오케스트레이터-워커를 노드가 이어지는 방식으로 소개하고, 가짜 엣지를 지우는 삭제 점검표와 정지 규칙으로 마무리한다. 세 장 모두 "닮은 검토자는 한 의견"이라는 경고와 "허용 목록은 구조"라는 원칙을 공유한다.
