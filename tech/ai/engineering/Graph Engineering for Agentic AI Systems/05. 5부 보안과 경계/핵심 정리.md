# 핵심 정리

이 문서는 5부(11장과 12장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 책이 소개하는 프레임워크와 날짜는 2026년경 시점 기준이다.

---

## 1. 한눈에 보는 요점

- **실행 그래프는 이미 보안 산출물이다**: 노드는 누가 행동하는지, 엣지는 누가 누구에게 일을 넘기는지를 정한다.
  - *쉽게 말하면*: 환불 방으로 가는 문이 아예 없으면 속은 직원도 환불을 못 한다.
  - → 자세히: [11장 에이전트 그래프의 보안·신원·거버넌스](11%EC%9E%A5%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EA%B7%B8%EB%9E%98%ED%94%84%EC%9D%98%20%EB%B3%B4%EC%95%88%C2%B7%EC%8B%A0%EC%9B%90%C2%B7%EA%B1%B0%EB%B2%84%EB%84%8C%EC%8A%A4.md)
- **허용 목록은 프롬프트가 아니라 표다**: 노드-도구, 노드-라벨, 생성 규칙, 재개 정책을 생성자 인자로 두면 PR 단계에서 테스트로 막을 수 있다.
  - *쉽게 말하면*: 벽에 붙인 안내문이 아니라 잠금장치로 통제한다.
  - → 자세히: [11장 에이전트 그래프의 보안·신원·거버넌스](11%EC%9E%A5%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EA%B7%B8%EB%9E%98%ED%94%84%EC%9D%98%20%EB%B3%B4%EC%95%88%C2%B7%EC%8B%A0%EC%9B%90%C2%B7%EA%B1%B0%EB%B2%84%EB%84%8C%EC%8A%A4.md)
- **신원은 별도의 그래프이고 승인은 매개변수에 묶인다**: 노드는 주체로 실행되고, 재개는 may_resume 경로여야 하며, 승인은 금액·대상·그래프 버전의 해시에 결합된다.
  - *쉽게 말하면*: "누가 승인했나"와 "무엇을 승인했나"가 둘 다 기록돼야 한다.
  - → 자세히: [11장 에이전트 그래프의 보안·신원·거버넌스](11%EC%9E%A5%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EA%B7%B8%EB%9E%98%ED%94%84%EC%9D%98%20%EB%B3%B4%EC%95%88%C2%B7%EC%8B%A0%EC%9B%90%C2%B7%EA%B1%B0%EB%B2%84%EB%84%8C%EC%8A%A4.md)
- **도달 가능성으로 게이트 우회를 CI에서 잡는다**: 민감 작업으로 가는 모든 단순 경로가 휴먼 승인 노드를 지나야 하고, 폭발 반경은 R(v)와 도구·주체·상태로 계산한다.
  - *쉽게 말하면*: 화살표 하나 추가로 생긴 뒷문을 지도에서 찾아낸다.
  - → 자세히: [11장 에이전트 그래프의 보안·신원·거버넌스](11%EC%9E%A5%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EA%B7%B8%EB%9E%98%ED%94%84%EC%9D%98%20%EB%B3%B4%EC%95%88%C2%B7%EC%8B%A0%EC%9B%90%C2%B7%EA%B1%B0%EB%B2%84%EB%84%8C%EC%8A%A4.md)
- **사람 상자가 있다고 통제가 있는 것은 아니다**: 피로, 연극(자동 승인·막지 않는 인터럽트), 우회로, 재바인딩이 있으면 게이트가 아니다.
  - *쉽게 말하면*: 문이 있는 그림이 있어도 문이 잠기는지는 따로 확인해야 한다.
  - → 자세히: [11장 에이전트 그래프의 보안·신원·거버넌스](11%EC%9E%A5%20%EC%97%90%EC%9D%B4%EC%A0%84%ED%8A%B8%20%EA%B7%B8%EB%9E%98%ED%94%84%EC%9D%98%20%EB%B3%B4%EC%95%88%C2%B7%EC%8B%A0%EC%9B%90%C2%B7%EA%B1%B0%EB%B2%84%EB%84%8C%EC%8A%A4.md)
- **LLM이 엣지를 고르는 것은 GNN이 아니다**: 전자는 허용 목록 안의 샘플이고 후자는 입력 그래프 위의 학습된 함수라 메커니즘이 다르다.
  - *쉽게 말하면*: 이름이 비슷하다고 같은 기계가 아니다.
  - → 자세히: [12장 그래프 인텔리전스는 런타임이 아니다](12%EC%9E%A5%20%EA%B7%B8%EB%9E%98%ED%94%84%20%EC%9D%B8%ED%85%94%EB%A6%AC%EC%A0%84%EC%8A%A4%EB%8A%94%20%EB%9F%B0%ED%83%80%EC%9E%84%EC%9D%B4%20%EC%95%84%EB%8B%88%EB%8B%A4.md)
- **학습된 그래프는 점수와 순위만 맡는다**: 트레이스 위의 실패 분기 예측, G_K 위의 검색 재순위가 허용된 두 문이며, E_A를 고쳐 쓰거나 출처를 대체하면 안 된다.
  - *쉽게 말하면*: 교통 통계는 알려 주되 도로를 만들지는 않는다.
  - → 자세히: [12장 그래프 인텔리전스는 런타임이 아니다](12%EC%9E%A5%20%EA%B7%B8%EB%9E%98%ED%94%84%20%EC%9D%B8%ED%85%94%EB%A6%AC%EC%A0%84%EC%8A%A4%EB%8A%94%20%EB%9F%B0%ED%83%80%EC%9E%84%EC%9D%B4%20%EC%95%84%EB%8B%88%EB%8B%A4.md)

## 2. 5부를 관통하는 질문

| 질문 | 5부가 보여 주는 답 |
|------|-------------------|
| 프롬프트 인젝션의 피해는 무엇이 정하나? | 시스템 프롬프트의 엄격함이 아니라 E_A와 노드-도구 행렬이 정한다 |
| 휴먼 게이트가 우회되지 않음을 어떻게 보이나? | 모든 단순 경로가 승인 노드를 지나는지 CI에서 검사한다 |
| 승인한 일과 실제 일이 달라지면? | 인터럽트 페이로드에 매개변수 해시를 묶고 부작용 노드가 재검증한다 |
| 침해가 퍼지는 범위는? | R(v), 권한 합집합, 읽을 수 있는 상태 키, 생성 가능 워커로 계산한다 |
| GNN을 쓰려면 어디에 두나? | 런타임 옆의 읽기 전용 점수기나 재순위기, 허용 목록은 건드리지 않는다 |
| 인과 그래프는 감사 기록이 되나? | 아니다. 계보는 누가 주장했는가, 트레이스는 무엇이 발화했는가를 말한다 |

---

> **5부 한 줄 요약**
> 구조로 막을 수 있는 것은 엣지·권한·경로 검사로 막고, 학습된 그래프는 그 구조를 대체하지 않는 점수와 순위의 보조 역할에만 둔다.
