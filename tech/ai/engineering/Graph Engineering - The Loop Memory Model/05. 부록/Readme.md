# 부록 개요 (Appendices) 한 장 요약, 스키마, 프롬프트

볼로디미르 파블리신(Volodymyr Pavlyshyn)의 『Graph Engineering — The Loop Memory Model』 뒷부분은 본문을 읽은 뒤 책상 옆에 두고 꺼내 보는 참고 자료다. 부록 A는 책 전체를 한 장으로 접은 요약이고, 부록 B는 7장이 설명한 스키마를 조회용으로 모은 표이며, 부록 C는 그래프를 운영하는 여섯 개의 프롬프트다. 본문의 1부가 논증을, 2부가 구조를, 3부가 메커니즘을, 4부가 판단을 다뤘다면, 부록은 그 모두를 필요할 때 바로 찾아 쓰도록 압축해 둔 자리다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 스키마는 표로 재구성했고, 프롬프트는 본문을 옮기지 않고 용도와 입력, 출력, 제약만 정리했다.

> **이 부를 한 문장으로**
> 본문의 어휘와 스키마와 프롬프트를 한곳에 모아, 만들고 점검할 때 바로 꺼내 쓰는 참고 자료다.

> **참고(노트 작성자)** 책은 2026년경 에이전트 워크플로를 전제로 하며, 부록의 `lat` 명령, 파일 배치, CI 예시는 그 시점의 설계이고 이 노트가 실행해 검증하지 않았다.

## 0. 먼저 알아 둘 것

- **부록의 성격**: 순서대로 읽는 글이 아니라 찾아 쓰는 자료다. 처음에는 A로 전체를 훑고, 구현할 때 B와 C를 펼친다.
- **전제 지식**: 부록은 본문의 용어(지식 평면, 작업 평면, 브리지, 래티스 등)를 설명 없이 쓴다. 낯설면 2부(4~7장)로 돌아가면 된다.
- **본문 연결**: A는 전 장의 요약, B는 7장의 조회판, C는 8~10장과 11장의 파이프라인이 쓰는 프롬프트에 해당한다.

## 2. 부록 한눈에 보기

| 부록 | 형태 | 핵심 |
|------|------|------|
| A 한 장 요약 | 압축 표 모음 | 주장, 시험, 사다리, 두 그래프, 불변식, 철칙 |
| B 스키마 참조 | 조회용 표 | 노드 타입, 술어, 층, 색인, 검색 정책, CLI |
| C 프롬프트 | 용도·입력·출력·제약 | 조정, 컨텍스트 조립, 평가, 추출, 해소, 약속 |

## 3. 부록 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 효력 집합(in-force set) | 지금 유효한 노드들의 모음 |
| 재화(reification) | 간선을 노드처럼 다뤄 속성을 붙이는 방식 |
| 출처 블록(Provenance) | 어느 실행과 변경에서 어떤 근거로 만들었는지 적은 구획 |
| 약속 선언(promise declaration) | 일꾼이 하기 전에 자기 행동의 범위를 밝히는 것 |
| 컨텍스트 조립(context assembly) | 일꾼에게 줄 정보를 한정된 부분 그래프로 고르는 일 |
| 근거 기반 평가자(grounded evaluator) | 지지 경로나 빠진 간선을 대며 심사하는 평가자 |

## 4. 이 부의 흐름 요약

부록 A에서 책의 주장과 어휘와 철칙을 한 번에 익히고, 부록 B에서 그 어휘가 스키마로 어떻게 쓰이는지 표로 확인한다. 부록 C는 그 스키마 위에서 일하는 여섯 프롬프트를 소개하며, 새 노드 만들기와 컨텍스트 조립과 평가가 모두 근거와 되돌림을 전제로 한다는 점을 보여 준다. 여러 부록에 일관되게 흐르는 메시지는 두 가지다. 파생 관계는 제안할 뿐 결정하지 않으며, 의심스러우면 덜 합친다.
