# AI 통합 프로세스 개요

2장은 저자가 만든 AI 통합 프로세스(AI Unified Process, AIUP)를 세부로 들어가기 전에 한 번에 훑어 보여 준다. 다섯 가지 원칙, 세 가지 핵심 산출물, Markdown과 Git으로 하는 버전 관리, 식별자로 만드는 추적성, 다섯 활동의 수명주기, 그리고 RUP와의 비교와 지금 통하는 이유를 다룬다.

---

## 1. 핵심 요점

- AI 통합 프로세스는 단순한 산출물과 AI의 도움으로 스펙을 개발의 토대로 만드는 가벼운 방법이며, 무거운 모델링을 버린 RUP의 현대판이다.
- 원칙은 실행 가능한 스펙, 최소주의, 설계된 추적성, AI 협업, 모든 것의 버전 관리 다섯 가지다.
- 핵심 산출물은 요구사항 카탈로그(FR, NFR, C), 엔터티 모델, 시스템 유스케이스(UC) 세 가지이며 고정된 순서로 다룬다.
- 사용자 스토리는 의도를 표현하고 시스템 유스케이스는 동작을 정의한다.
- 모든 산출물은 Markdown 파일로 Git에 두며, 유스케이스 하나가 파일 하나다.
- 추적성은 유스케이스의 요구사항 ID, 엔터티 이름 참조, 코드와 테스트의 유스케이스 ID 링크로 만든다.
- 수명주기는 명세, 생성, 검증, 검토, 정제의 짧은 반복이며 단계와 인계가 없다.
- AI가 구조화된 자연어를 이해하고, 자동화가 흔해지고, 가벼운 도구가 있어서 지금 이 방식이 통한다.
