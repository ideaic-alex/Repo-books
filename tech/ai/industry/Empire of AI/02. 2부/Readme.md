# 2부: 6장 승천, 7장 갇힌 과학, 8장 상업의 새벽, 9장 재난 자본주의

카렌 하오의 『Empire of AI』 2부는 OpenAI가 '규모의 경쟁'과 '상용화'를 선택하는 과정을 따라간다. 샘 올트먼이 1등과 속도를 앞세워 회사를 이끌고(6장), 그 흐름이 학계와 기업 연구의 개방성을 무너뜨리며(7장), 제품화가 시작되어 윤리와 안전의 구멍이 드러나고(8장), 마지막에는 그 모든 것을 떠받치는 저임금 노동의 현실이 나온다(9장).

이 문서들은 번역이 아니라 내용을 풀어 쓴 학습 노트다. 사실 주장은 책이 서술한 범위로 한정했고, 인물의 행동과 평가는 '저자에 따르면', '책은 ...라고 쓴다'처럼 출처를 밝혔다.

> **2부를 한 문장으로**
> 가장 빨리 크게 만들겠다는 결정은 회사 안의 안전 논쟁을 이기고, 연구의 공개성을 줄였으며, 결국 보이지 않는 노동자들의 비용 위에 서게 되었다.

---

## 0. 먼저 알아 둘 것: 2부의 큰 그림

1부가 OpenAI의 탄생과 '규모가 답'이라는 믿음을 다뤘다면, 2부는 그 믿음이 현실의 제도와 사람들에게 닿으며 생기는 결과를 다룬다. 쉽게 말하면, '모델을 키운다'는 한 줄의 전략이 회사 안의 권력 다툼, 업계의 연구 문화, 서비스의 안전, 그리고 지구 반대편 노동자의 하루를 차례로 바꾸어 놓는 이야기다.

| 장 | 무대 | 한 줄 요약 |
|:---:|------|-----------|
| 6장 | OpenAI 내부 | 올트먼의 상용화 노선이 안전파를 밀어내고 Anthropic 분열로 이어진다 |
| 7장 | 구글과 학계 | 거대 모델을 비판한 논문이 막히고, 업계가 연구 공개를 접는다 |
| 8장 | OpenAI와 MS | 규모와 제품을 묶은 로드맵, 오남용 사례, Codex와 Copilot |
| 9장 | 케냐와 베네수엘라 등 | 필터와 RLHF를 위한 데이터 노동과 그 착취 구조 |

## 1. 핵심 요점

- **속도와 독점이 목표가 되었다**: 올트먼은 YC의 승자독식 사고를 OpenAI에 옮겼고, 이는 상용화와 비공개 쪽으로 방향을 틀었다.
- **안전 논쟁은 상업 논리에 졌다**: GPT-3 API 공개와 MS 독점 라이선스로 안전파가 밀렸고 아모데이 일행이 Anthropic을 세웠다.
- **공개 연구가 후퇴했다**: 구글의 '확률적 앵무새' 논문 철회 사건 이후 업계는 모델 정보를 영업 비밀로 걸어 잠그게 되었다고 저자는 본다.
- **서비스를 먼저 열고 규칙은 나중에 만들었다**: 즉흥적 콘텐츠 규칙, 선택형 필터, 오남용 사건이 이를 보여 준다.
- **AI의 깨끗함은 노동이 만든다**: 케냐 노동자의 필터 작업과 RLHF 노동은 위기 국가의 값싼 인력에 기댄다는 것이 저자의 분석이다.

## 3. 용어 정리

| 용어 | 쉬운 설명 |
|------|-----------|
| AGI | 사람 수준의 범용 인공지능. OpenAI가 내세우는 최종 목표다. |
| 컴퓨트(compute) | AI 학습에 쓰는 계산 자원. 칩(GPU)과 전력, 서버를 합쳐 부르는 말이다. |
| 파라미터 | 모델 안에서 학습으로 조정되는 숫자. 개수가 모델 크기의 척도다. |
| 스케일링 법칙 | 모델, 데이터, 컴퓨트를 키울수록 성능이 예측 가능하게 오른다는 경험 법칙. |
| 가중치(weights) | 학습이 끝난 모델의 핵심 정보 파일. 이것이 있으면 모델을 복제할 수 있다. |
| API | 외부 프로그램이 서비스 기능을 호출해 쓰는 접점. 모델 자체를 넘기지 않고 기능만 빌려 준다. |
| RLHF | 사람이 모델의 답에 점수를 매기고 그 결과로 모델을 다듬는 방법. 사람 노동이 필수다. |
| 콘텐츠 필터 | 해로운 출력을 걸러 내는 장치. 학습에는 사람이 분류한 예시가 필요하다. |
| 레드팀 | 시스템을 일부러 공격해 약점을 찾는 점검 활동. 원래는 보안 업계 용어다. |
| 데이터 라벨링 | AI가 배울 자료에 사람이 정답이나 이름표를 붙이는 일. |
| 글로벌 사우스 | 대체로 경제적으로 덜 부유한 남반구와 개발도상국 지역을 묶어 부르는 말. |
