# 핵심 정리

이 문서는 2부(6~9장)의 내용을 한곳에 모아 풀어 쓴 것이다. 각 장에서 따로 다룬 내용을 열 가지 요점으로 묶어, 읽은 뒤 빠르게 복습할 때 쓰도록 했다. 모든 서술은 저자 카렌 하오가 책에서 밝힌 범위에 기반하며, 인물에 대한 평가는 저자의 시각이다.

각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 내용을 다룬 문서로 이동한다.

## 1. 한눈에 보는 요점

- **올트먼은 YC의 승자독식 전략을 OpenAI에 옮겼다**: 10배 좋은 기술, 10배 빠른 개선, 모든 분야 1등이라는 목표를 세웠고, 2019년 말 비전 문서는 MS 협력, 상용화, 공개 축소를 방향으로 제시했다.
  - *쉽게 말하면*: 여러 선두 중 하나가 아니라 유일한 선두가 되겠다는 선언이다.
  - → 자세히: [6장 승천](06%EC%9E%A5%20%EC%8A%B9%EC%B2%9C.md)
- **세 부족과 응용 부서가 균열을 키웠다**: 탐구 연구, 안전, 스타트업이라는 세 집단이 있었고 2020년 초 응용 부서가 생기며 대립이 구체화되었다.
  - *쉽게 말하면*: 같은 회사 안에서 '천천히 안전하게'와 '빨리 내놓고 배우자'가 정면으로 부딪쳤다.
  - → 자세히: [6장 승천](06%EC%9E%A5%20%EC%8A%B9%EC%B2%9C.md)
- **GPT-3 API 공개는 경쟁 불안 속에서 결정되었다**: 구글이 비슷한 모델을 낼지 모른다는 소문이 안전 쪽의 지연 주장을 눌렀다. 이후 MS가 독점 라이선스를 받았다.
  - *쉽게 말하면*: 상대가 먼저 달릴까 두려워서 먼저 출발선을 넘었다.
  - → 자세히: [6장 승천](06%EC%9E%A5%20%EC%8A%B9%EC%B2%9C.md)
- **안전파의 퇴장이 Anthropic이 되었다**: 아모데이 일행은 올트먼이 결정을 기정사실로 만든다고 보았고 2020년 말 떠나 2021년 5월 Anthropic을 공개했다. 저자는 이를 안전 문제이자 권력 문제로 본다.
  - *쉽게 말하면*: 이혼 이유는 원칙의 차이이기도 했고 누가 운전대를 잡느냐의 문제이기도 했다.
  - → 자세히: [6장 승천](06%EC%9E%A5%20%EC%8A%B9%EC%B2%9C.md)
- **거대 모델의 비용은 환경과 사회에 먼저 닿는다**: 스트루벨의 연구가 에너지·탄소 비용을 보였고, 게브루와 벤더의 논문은 환경, 데이터, 검증, 의미 착각의 네 가지 위험을 경고했다.
  - *쉽게 말하면*: 큰 모델은 큰 전기 요금과 큰 책임을 함께 가져온다.
  - → 자세히: [7장 갇힌 과학](07%EC%9E%A5%20%EA%B0%87%ED%9E%8C%20%EA%B3%BC%ED%95%99.md)
- **불편한 논문을 막은 일이 업계의 문을 닫았다**: 구글이 철회를 요구하고 게브루가 해고된 뒤 업계는 핵심 기술 정보를 비공개로 돌렸고, 저자는 학습·시험 데이터를 분리하는 딥러닝의 전제가 흔들린다고 경고한다.
  - *쉽게 말하면*: 시험지를 볼 수 없으면 점수가 실력인지 암기인지 알 수 없다.
  - → 자세히: [7장 갇힌 과학](07%EC%9E%A5%20%EA%B0%87%ED%9E%8C%20%EA%B3%BC%ED%95%99.md)
- **2021년 로드맵은 규모와 제품을 한 고리로 묶었다**: A100 1만 8천 장으로 10배 확대, 컴퓨트 효율 25배, 데이터 개선, 그리고 제품 사용을 통한 데이터 플라이휠이 골자였다.
  - *쉽게 말하면*: 키우고, 팔고, 쓰는 사람에게서 배워 다시 키운다.
  - → 자세히: [8장 상업의 새벽](08%EC%9E%A5%20%EC%83%81%EC%97%85%EC%9D%98%20%EC%83%88%EB%B2%BD.md)
- **서비스는 먼저 열렸고 안전 장치는 따라왔다**: 즉흥적 규칙, 선택형 필터, 레드팀에 대한 비판, Replika와 Latitude의 오남용 사례가 이어졌다.
  - *쉽게 말하면*: 가게를 먼저 열고 안전 수칙은 사고가 난 뒤에 썼다.
  - → 자세히: [8장 상업의 새벽](08%EC%9E%A5%20%EC%83%81%EC%97%85%EC%9D%98%20%EC%83%88%EB%B2%BD.md)
- **Codex와 Copilot은 협력 성과이자 갈등의 씨앗이었다**: OpenAI는 공이 MS와 GitHub로 돌아가는 것과 통제력 손실을 불편해했고 자체 소비자 제품의 필요를 느꼈다.
  - *쉽게 말하면*: 파트너 덕에 크게 팔렸지만 가게 간판은 남의 것이 되었다.
  - → 자세히: [8장 상업의 새벽](08%EC%9E%A5%20%EC%83%81%EC%97%85%EC%9D%98%20%EC%83%88%EB%B2%BD.md)
- **AI의 안전은 보이지 않는 노동 위에 서 있다**: 케냐 노동자들이 유해 텍스트를 분류해 필터를 만들었고, Scale AI 등은 위기 국가에서 값싼 인력을 모았다가 보수를 낮추고 떠나는 방식을 되풀이했다고 책은 서술한다. RLHF 노동은 이후 챗봇 시대의 표준이 되었다.
  - *쉽게 말하면*: 깨끗해 보이는 답 뒤에서 누군가가 가장 더러운 글을 대신 읽었다.
  - → 자세히: [9장 재난 자본주의](09%EC%9E%A5%20%EC%9E%AC%EB%82%9C%20%EC%9E%90%EB%B3%B8%EC%A3%BC%EC%9D%98.md)

## 2. 스스로 점검해 보기

1. 올트먼의 '10배 규칙'과 '네 분야 1등' 목표는 무엇이었나? (6장)
2. 응용 쪽과 안전 쪽은 GPT-3 API 공개를 두고 각각 무엇을 주장했나? (6장)
3. '확률적 앵무새' 논문이 경고한 네 가지는 무엇인가? (7장)
4. 2021년 로드맵의 세 갈래와 '데이터 플라이휠'은 어떤 뜻인가? (8장)
5. Sama 프로젝트와 Scale AI의 사례에서 저자가 말하는 구조적 문제는 무엇인가? (9장)

1. 경쟁 제품보다 10배 나은 기술과 세대마다 10배 개선을 추구했고, 기술 성과, 컴퓨트, 자금, 대비 태세에서 1등이 되자는 목표였다.
2. 응용 쪽은 API가 통제된 공개 방식이며 데이터와 수익을 얻는다고 보았고, 안전 쪽은 준비 시간이 줄어든다며 지연을 요구했다.
3. 환경 부담, 오염된 데이터, 검증의 어려움, 출력의 의미를 착각하는 문제다.
4. 규모 확대, 컴퓨트 효율, 데이터 개선이다. 플라이휠은 제품 사용 데이터가 모델 개선으로 이어져 스스로 속도가 붙는 순환을 말한다.
5. AI 기업이 하청을 통해 책임을 멀리하고, 위기 국가의 절박한 노동자를 값싸게 쓰고 버리는 구조가 반복된다는 점이다. 회사 측은 일부 서술을 부인한다.
