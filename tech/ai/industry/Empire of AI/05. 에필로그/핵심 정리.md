# 핵심 정리

이 문서는 에필로그의 요점을 한곳에 모아 복습용으로 정리한 것이다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 내용을 다룬 문서로 이동한다.

---

## 1. 한눈에 보는 요점

- **언어를 잃는 일은 지식과 정체성을 잃는 일이다**: 저자는 대형 언어 모델이 데이터가 풍부한 소수 언어에 쏠려 있어 소수 언어의 소멸을 가속할 수 있다고 본다.
  - *쉽게 말하면*: AI가 쓰는 말이 곧 인터넷의 중심 언어가 되고, 나머지 언어는 밀려난다.
  - → 자세히: [에필로그 - 제국은 어떻게 무너지는가](%EC%97%90%ED%95%84%EB%A1%9C%EA%B7%B8%20-%20%EC%A0%9C%EA%B5%AD%EC%9D%80%20%EC%96%B4%EB%96%BB%EA%B2%8C%20%EB%AC%B4%EB%84%88%EC%A7%80%EB%8A%94%EA%B0%80.md)
- **Te Hiku Media는 합의, 호혜, 주권을 지켰다**: 공동체 동의를 먼저 구하고, 필요한 쓸모를 듣고, 자체 장비로 학습하며 데이터를 공동체의 수호 아래 두었다.
  - *쉽게 말하면*: 데이터를 퍼 가는 대신 주인의 허락 아래 빌려 쓴 셈이다.
  - → 자세히: [에필로그 - 제국은 어떻게 무너지는가](%EC%97%90%ED%95%84%EB%A1%9C%EA%B7%B8%20-%20%EC%A0%9C%EA%B5%AD%EC%9D%80%20%EC%96%B4%EB%96%BB%EA%B2%8C%20%EB%AC%B4%EB%84%88%EC%A7%80%EB%8A%94%EA%B0%80.md)
- **작고 특화된 모델도 성과를 낸다**: 310시간의 음성과 GPU 두 개로 정확도 86퍼센트의 마오리어 음성 인식 모델을 만들었다고 책은 쓴다.
  - *쉽게 말하면*: 모든 걸 하려는 거대 모델이 유일한 길은 아니다.
  - → 자세히: [에필로그 - 제국은 어떻게 무너지는가](%EC%97%90%ED%95%84%EB%A1%9C%EA%B7%B8%20-%20%EC%A0%9C%EA%B5%AD%EC%9D%80%20%EC%96%B4%EB%96%BB%EA%B2%8C%20%EB%AC%B4%EB%84%88%EC%A7%80%EB%8A%94%EA%B0%80.md)
- **저항은 이미 세계 곳곳에서 진행 중이다**: DAIR, Data Workers' Inquiry, 케냐 데이터 노동자 조직, 우루과이 환경 활동가가 대표 사례다.
  - *쉽게 말하면*: 대안은 상상이 아니라 이미 작동 중인 작은 실험들이다.
  - → 자세히: [에필로그 - 제국은 어떻게 무너지는가](%EC%97%90%ED%95%84%EB%A1%9C%EA%B7%B8%20-%20%EC%A0%9C%EA%B5%AD%EC%9D%80%20%EC%96%B4%EB%96%BB%EA%B2%8C%20%EB%AC%B4%EB%84%88%EC%A7%80%EB%8A%94%EA%B0%80.md)
- **질문을 '좋은가'에서 '권력이 어디로 가는가'로 바꾼다**: 좋음은 보는 사람마다 다르지만, 권력이 집중되는지 분산되는지는 따져 볼 수 있다.
  - *쉽게 말하면*: 'AI가 착한가'보다 'AI가 누구의 힘을 키우는가'를 묻는다.
  - → 자세히: [에필로그 - 제국은 어떻게 무너지는가](%EC%97%90%ED%95%84%EB%A1%9C%EA%B7%B8%20-%20%EC%A0%9C%EA%B5%AD%EC%9D%80%20%EC%96%B4%EB%96%BB%EA%B2%8C%20%EB%AC%B4%EB%84%88%EC%A7%80%EB%8A%94%EA%B0%80.md)
- **권력의 세 축은 서로를 강화한다**: 지식, 자원, 영향력을 한꺼번에 쥐고 있어서 제국이 단단하다. 그래서 재분배도 세 축 모두에서 필요하다.
  - *쉽게 말하면*: 한 곳만 고쳐서는 나머지 둘이 다시 끌어올린다.
  - → 자세히: [에필로그 - 제국은 어떻게 무너지는가](%EC%97%90%ED%95%84%EB%A1%9C%EA%B7%B8%20-%20%EC%A0%9C%EA%B5%AD%EC%9D%80%20%EC%96%B4%EB%96%BB%EA%B2%8C%20%EB%AC%B4%EB%84%88%EC%A7%80%EB%8A%94%EA%B0%80.md)
- **재분배 수단은 투명성, 독립 연구, 노동 보호, 교육이다**: 학습 데이터와 공급망 공개, 외부 평가자 지원, 모든 노동자 보호, 대중의 AI 이해가 제시된다.
  - *쉽게 말하면*: 보이게 하고, 따로 연구하게 하고, 노동자를 보호하고, 시민이 알게 한다.
  - → 자세히: [에필로그 - 제국은 어떻게 무너지는가](%EC%97%90%ED%95%84%EB%A1%9C%EA%B7%B8%20-%20%EC%A0%9C%EA%B5%AD%EC%9D%80%20%EC%96%B4%EB%96%BB%EA%B2%8C%20%EB%AC%B4%EB%84%88%EC%A7%80%EB%8A%94%EA%B0%80.md)

## 2. 기억해 둘 숫자

| 숫자 | 의미(책의 서술) |
|------|----------------|
| 90퍼센트에서 12퍼센트 | 마오리인 가운데 마오리어 사용자 비율의 하락 |
| 15개 언어(0.2퍼센트) | OpenAI 시험에서 GPT-4가 80퍼센트 넘는 정확도를 내는 언어 수 |
