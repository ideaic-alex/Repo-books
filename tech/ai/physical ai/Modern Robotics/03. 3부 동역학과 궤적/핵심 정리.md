# 핵심 정리

이 문서는 3부(8장부터 9장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 수식은 OCR 텍스트와 표준 지식으로 복원했으니 원서 식과 대조하기를 권한다.

---

## 1. 한눈에 보는 요점

- **운동 방정식의 기본 꼴**: $\tau=M(\theta)\ddot\theta+c(\theta,\dot\theta)+g(\theta)$. 라그랑주 방법($L=K-P$)으로 유도한다.
  - *쉽게 말하면*: 토크는 관성, 속도 효과, 중력 세 가지를 이기는 데 쓰인다.
  - → 자세히: [8장 개연쇄 동역학](08%EC%9E%A5%20%EA%B0%9C%EC%97%B0%EC%87%84%20%EB%8F%99%EC%97%AD%ED%95%99.md)
- **강체는 트위스트와 렌치로**: $\mathcal{F}=\mathcal{G}\dot{\mathcal{V}}-\mathrm{ad}_{\mathcal{V}}^T\mathcal{G}\mathcal{V}$. 뉴턴과 오일러 방정식을 한 식으로 묶은 것이다.
  - *쉽게 말하면*: 힘과 모멘트를 한 묶음(렌치)으로 다룬다.
  - → 자세히: [8장 개연쇄 동역학](08%EC%9E%A5%20%EA%B0%9C%EC%97%B0%EC%87%84%20%EB%8F%99%EC%97%AD%ED%95%99.md)
- **뉴턴-오일러 알고리즘**: 앞으로 속도와 가속도를 전파하고 뒤로 렌치를 전파해 관절 토크를 구한다. 계산량은 관절 수에 비례한다.
  - *쉽게 말하면*: 팔 끝까지 갔다가 되돌아오며 토크를 모은다.
  - → 자세히: [8장 개연쇄 동역학](08%EC%9E%A5%20%EA%B0%9C%EC%97%B0%EC%87%84%20%EB%8F%99%EC%97%AD%ED%95%99.md)
- **역동역학과 순동역학**: 역동역학은 움직임에서 토크를, 순동역학은 토크에서 가속도를 구한다. 순동역학을 적분하면 시뮬레이션이 된다.
  - *쉽게 말하면*: 같은 식을 어느 쪽으로 푸느냐의 차이다.
  - → 자세히: [8장 개연쇄 동역학](08%EC%9E%A5%20%EA%B0%9C%EC%97%B0%EC%87%84%20%EB%8F%99%EC%97%AD%ED%95%99.md)
- **작업 공간과 구속 동역학, 모터와 기어**: 겉보기 관성 $\Lambda=J^{-T}MJ^{-1}$, 라그랑주 승수 $\lambda$, 반영 관성 $G^2J_m$을 알아 둔다.
  - *쉽게 말하면*: 식은 같고 보는 좌표와 조건이 달라진다.
  - → 자세히: [8장 개연쇄 동역학](08%EC%9E%A5%20%EA%B0%9C%EC%97%B0%EC%87%84%20%EB%8F%99%EC%97%AD%ED%95%99.md)
- **경로와 궤적**: 경로 $\theta(s)$ 위에 시간 스케일링 $s(t)$를 얹은 것이 궤적이다. $\dot\theta=\theta'\dot s$.
  - *쉽게 말하면*: 지도 위의 선에 시간표를 붙인다.
  - → 자세히: [9장 궤적 생성](09%EC%9E%A5%20%EA%B6%A4%EC%A0%81%20%EC%83%9D%EC%84%B1.md)
- **시간 스케일링 고르기**: 3차, 5차 다항식, 사다리꼴, S자 곡선 중에서 속도, 가속도, 저크의 연속성에 맞춰 선택한다.
  - *쉽게 말하면*: 부드러울수록 계산이나 시간이 더 든다.
  - → 자세히: [9장 궤적 생성](09%EC%9E%A5%20%EA%B6%A4%EC%A0%81%20%EC%83%9D%EC%84%B1.md)
- **경유점과 최단시간**: 구간별 3차 다항식으로 경유점을 지나고, 토크 한계에서는 위상 평면의 최대 가속과 최대 감속으로 최단시간 해를 구한다.
  - *쉽게 말하면*: 한계까지 밀어붙이다가 마지막에 급제동하는 시간표다.
  - → 자세히: [9장 궤적 생성](09%EC%9E%A5%20%EA%B6%A4%EC%A0%81%20%EC%83%9D%EC%84%B1.md)

## 2. 3부를 관통하는 질문

| 질문 | 3부가 보여 주는 답 |
|------|-------------------|
| 로봇에 필요한 토크는 어떻게 구하나? | 뉴턴-오일러 역동역학 알고리즘 |
| 토크를 주면 로봇은 어떻게 움직이나? | 순동역학을 풀고 적분(시뮬레이션) |
| 같은 경로를 더 부드럽게 지나려면? | 5차 다항식이나 S자 곡선 등으로 시간 스케일링 |
| 토크 한계가 있을 때 가장 빠른 방법은? | 위상 평면에서 최대 가속과 최대 감속을 번갈아 사용 |

---

> **3부 한 줄 요약**
> 동역학은 토크와 움직임의 관계를 주고, 궤적 생성은 그 관계가 허락하는 범위 안에서 경로에 시간표를 입힌다.
