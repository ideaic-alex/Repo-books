# 3부 개요 (Part III) 동역학과 궤적

케빈 린치(Kevin M. Lynch)와 프랭크 박(Frank C. Park)의 『Modern Robotics』 3부는 2부까지의 기구학에 "힘"과 "시간"을 더하는 두 개 장이다. 8장은 관절 토크와 로봇의 가속도를 연결하는 동역학을, 9장은 정해진 경로 위에 시간표를 입혀 실제로 실행할 수 있는 궤적을 만드는 방법을 설명한다. 8장이 "이 움직임에 어떤 토크가 필요한가"에 답한다면, 9장은 "토크 한계 안에서 어떻게 움직일 것인가"에 답한다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 수식은 OCR 텍스트와 표준 지식으로 복원한 것이므로 원서와 대조하기를 권한다.

> **이 부를 한 문장으로**
> 로봇의 운동 방정식은 토크를 관성, 속도 항, 중력의 합으로 나타내고, 이를 이용해 토크 한계를 지키는 시간 스케일링과 최단시간 궤적을 만들 수 있다.

---

## 0. 먼저 알아 둘 것

- **선행 지식**: 1부의 트위스트, 렌치, 어저전트와 2부의 자코비안, 정역학이 이어진다. 특히 8장은 스크류 축 표기를 그대로 쓴다.
- **8장이 가장 길다**: 라그랑주 공식, 뉴턴-오일러 알고리즘, 작업 공간·구속 동역학, 모터와 기어까지 담았으니 앞부분(1~3절)을 먼저 확실히 하면 된다.
- **9장은 4부와 이어진다**: 경로를 정하는 일은 10장의 모션 플래닝이, 궤적을 따라가게 하는 일은 11장의 제어가 맡는다.

## 2. 3부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 질량 행렬 | 자세에 따라 달라지는 관절 공간의 관성 |
| 역동역학 | 원하는 움직임에서 필요한 토크를 구하는 계산 |
| 순동역학 | 주어진 토크에서 가속도를 구하는 계산(시뮬레이션) |
| 공간 관성 행렬 | 질량과 회전 관성을 6x6으로 묶은 행렬 |
| 반영 관성 | 기어를 거쳐 관절에서 느끼는 모터 관성 |
| 경로(path) | 시간과 무관한 기하학적 곡선 |
| 시간 스케일링 | 경로 위의 진행을 시간 함수로 정하는 것 |
| 궤적(trajectory) | 경로에 시간 스케일링을 곱한 것 |
| 뱅뱅 해 | 최대 가속과 최대 감속만 번갈아 쓰는 최단시간 해 |

## 3. 이 부의 흐름 요약

8장은 라그랑주 방법으로 $\tau=M\ddot\theta+c+g$라는 기본 꼴을 만들고, 이를 뉴턴-오일러 재귀 알고리즘으로 효율적으로 계산하는 법을 보인다. 이 알고리즘의 두 방향 활용이 역동역학과 순동역학이다. 9장은 그 동역학이 만든 토크 한계를 시간표에 반영해 최단시간 궤적을 구한다. 두 장을 지나면 경로와 시간표를 따라가는 로봇의 모습이 그려지고, 4부는 경로를 찾고 그 궤적을 실제로 추종하는 제어로 넘어간다.
