# 2부 개요 (Part II) 기구학과 정역학

케빈 린치(Kevin M. Lynch)와 프랭크 박(Frank C. Park)의 『Modern Robotics』 2부는 로봇의 움직임을 "힘 없이 모양만" 다루는 네 개 장이다. 4장은 관절 각도에서 손끝 자세를 구하는 순기구학을, 5장은 관절 속도와 손끝 속도, 힘의 관계를 이어 주는 자코비안과 정역학을, 6장은 거꾸로 손끝 목표에서 관절 각도를 구하는 역기구학을, 7장은 고리 모양으로 이어진 폐연쇄 메커니즘을 설명한다. 1부에서 배운 스크류, 트위스트, 행렬 지수가 여기서 모두 실제 로봇 계산에 쓰인다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 수식은 OCR 텍스트와 표준 지식으로 복원했으므로 원서와 대조하기를 권한다. 소프트웨어, 파일 형식 정보는 책이 쓴 시점 기준이다.

> **이 부를 한 문장으로**
> 로봇의 "자세, 속도, 힘"을 각도에서 손끝으로 옮기는 순방향 계산(4, 5장)과 손끝에서 각도로 되돌리는 역방향 계산(6장), 그리고 고리 구조에서 그 계산이 어떻게 뒤집히는지(7장)를 배운다.

---

## 0. 먼저 알아 둘 것

- **영 자세(home position)**: 모든 관절 각도가 0일 때의 자세. 지수 곱 공식(PoE)의 기준이다.
- **스크류 축(screw axis)**: 관절 하나의 운동을 나타내는 6차원 벡터. 1부 3장의 개념이 그대로 쓰인다.
- **자코비안(Jacobian)**: 관절 속도를 손끝 트위스트로 바꾸는 행렬. 5장부터 6, 7장까지 계속 나온다.
- **특이점(singularity)**: 자코비안의 랭크가 줄어 어떤 방향으로 움직일 수 없는 자세.
- **개연쇄와 폐연쇄**: 사슬이 한 줄(개)인가 고리(폐)인가. 7장에서 계산 난이도가 뒤바뀐다.

## 2. 2부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 순기구학 (forward kinematics) | 관절 각도에서 손끝 자세를 구하는 계산 |
| 역기구학 (inverse kinematics) | 손끝 자세에서 관절 각도를 구하는 계산 |
| 지수 곱 공식 (PoE) | $T=e^{[\mathcal{S}_1]\theta_1}\cdots e^{[\mathcal{S}_n]\theta_n}M$ 꼴의 순기구학 공식 |
| 어저전트 (adjoint) | 트위스트를 다른 좌표계로 바꿔 주는 6×6 행렬 |
| 자코비안 (Jacobian) | 관절 속도를 말단 트위스트로 바꾸는 행렬 |
| 렌치 (wrench) | 힘과 모멘트를 한데 묶은 6차원 벡터 |
| 조작도 타원체 | 관절 속도 단위 구가 말단 속도 공간에서 이루는 타원체 |
| 유사역행렬 (pseudoinverse) | 정방이 아니거나 특이한 행렬에 쓰는 일반화된 역행렬 |
| 그뤼블러 공식 | 링크와 관절 개수로 자유도를 세는 공식 |

## 3. 이 부의 흐름 요약

4장이 순기구학의 틀(영 자세와 스크류 축)을 세우면, 5장은 그 틀을 미분해 자코비안을 만들고 같은 행렬의 전치로 정역학까지 얻는다. 6장은 이 자코비안을 이용한 뉴턴-랩슨 반복으로 일반 로봇의 역기구학을 풀고, 7장은 고리 구조에서 이 모든 계산이 어떻게 달라지는지를 보여 준다. 3부 동역학은 이 기구학 위에 힘과 관성을 올려놓는다.
