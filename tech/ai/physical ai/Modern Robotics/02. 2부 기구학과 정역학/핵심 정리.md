# 핵심 정리

이 문서는 2부(4장부터 7장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 수식은 OCR과 표준 지식으로 복원했으니 원서와 대조하기 바란다.

---

## 1. 한눈에 보는 요점

- **순기구학은 영 자세와 스크류 축으로 쓴다**: $T(\theta)=e^{[\mathcal{S}_1]\theta_1}\cdots e^{[\mathcal{S}_n]\theta_n}M$.
  - *쉽게 말하면*: 펴진 기준 자세에서 관절을 하나씩 돌려 가며 손끝을 따라간다.
  - → 자세히: [4장 순기구학](04%EC%9E%A5%20%EC%88%9C%EA%B8%B0%EA%B5%AC%ED%95%99.md)
- **공간 형식과 물체 형식은 같은 자세의 두 서술이다**: $\mathcal{B}_i=[\mathrm{Ad}_{M^{-1}}]\mathcal{S}_i$로 오간다.
  - *쉽게 말하면*: 베이스에서 본 축과 손끝에서 본 축을 어저전트가 번역해 준다.
  - → 자세히: [4장 순기구학](04%EC%9E%A5%20%EC%88%9C%EA%B8%B0%EA%B5%AC%ED%95%99.md)
- **자코비안은 속도를 옮기는 행렬이다**: $\mathcal{V}=J(\theta)\dot\theta$이고 열은 관절 하나가 만드는 말단 트위스트이다.
  - *쉽게 말하면*: 관절 속도를 넣으면 손끝 속도가 나오는 변환표다.
  - → 자세히: [5장 속도 기구학과 정역학](05%EC%9E%A5%20%EC%86%8D%EB%8F%84%20%EA%B8%B0%EA%B5%AC%ED%95%99%EA%B3%BC%20%EC%A0%95%EC%97%AD%ED%95%99.md)
- **정역학은 전치로 얻는다**: $\tau=J^{T}\mathcal{F}$.
  - *쉽게 말하면*: 같은 표를 뒤집어 읽으면 손끝 힘이 관절 토크로 바뀐다.
  - → 자세히: [5장 속도 기구학과 정역학](05%EC%9E%A5%20%EC%86%8D%EB%8F%84%20%EA%B8%B0%EA%B5%AC%ED%95%99%EA%B3%BC%20%EC%A0%95%EC%97%AD%ED%95%99.md)
- **특이점에서는 한 방향 속도를 낼 수 없다**: 자코비안 랭크가 줄고, 조작도 타원체가 납작해진다.
  - *쉽게 말하면*: 팔이 완전히 펴지면 길이 방향으로는 더 못 뻗는다.
  - → 자세히: [5장 속도 기구학과 정역학](05%EC%9E%A5%20%EC%86%8D%EB%8F%84%20%EA%B8%B0%EA%B5%AC%ED%95%99%EA%B3%BC%20%EC%A0%95%EC%97%AD%ED%95%99.md)
- **역기구학은 해가 없거나 여럿일 수 있다**: 단순 구조는 해석적으로, 일반 구조는 뉴턴-랩슨으로 푼다.
  - *쉽게 말하면*: 간단한 팔은 정답을 바로 계산하고, 복잡한 팔은 정답 근처에서 조금씩 고쳐 간다.
  - → 자세히: [6장 역기구학](06%EC%9E%A5%20%EC%97%AD%EA%B8%B0%EA%B5%AC%ED%95%99.md)
- **역속도는 유사역행렬로 푼다**: $\dot\theta=J^{\dagger}\mathcal{V}_d$는 최소 노름 해 또는 최소제곱 해를 준다.
  - *쉽게 말하면*: 여러 방법이 있으면 가장 덜 움직이는 방법을 고른다.
  - → 자세히: [6장 역기구학](06%EC%9E%A5%20%EC%97%AD%EA%B8%B0%EA%B5%AC%ED%95%99.md)
- **폐연쇄는 난이도가 뒤바뀐다**: 병렬 메커니즘은 역기구학이 쉽고 순기구학이 어렵고, 특이점이 세 종류로 갈라진다.
  - *쉽게 말하면*: 여러 다리가 한 판을 잡고 있어서 판의 자세가 곧 모든 다리 길이를 정해 준다.
  - → 자세히: [7장 폐연쇄 기구학](07%EC%9E%A5%20%ED%8F%90%EC%97%B0%EC%87%84%20%EA%B8%B0%EA%B5%AC%ED%95%99.md)

## 2. 2부를 관통하는 질문

| 질문 | 2부가 보여 주는 답 |
|------|-------------------|
| 로봇을 수학적으로 기술하는 최소 정보는? | 영 자세 M과 관절별 스크류 축 |
| 속도와 힘은 어떻게 이어지나? | 자코비안과 그 전치 |
| 특이점은 어떻게 알아내나? | 자코비안의 랭크 감소 |
| 역기구학은 어떻게 푸나? | 단순하면 해석적, 일반이면 뉴턴-랩슨 반복 |
| 폐연쇄는 개연쇄와 무엇이 다른가? | 고리 구속, 자유도 계산, 세 가지 특이점 |
