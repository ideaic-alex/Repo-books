# 부록 개요 (Appendices) 공식 요약, 회전의 다른 표현, D-H와 PoE, 최적화

케빈 린치(Kevin M. Lynch)와 프랭크 박(Frank C. Park)의 『Modern Robotics』 끝에는 본문의 수학 도구를 보충하는 부록 네 개가 있다. 부록 A는 장별 공식을 한곳에 모은 요약이고, 부록 B는 회전을 나타내는 다른 방법(오일러 각, 롤-피치-요, 단위 쿼터니언, 케일리-로드리게스)이며, 부록 C는 전통적인 데나빗-하텐버그(D-H) 매개변수와 본문의 PoE의 관계, 부록 D는 최적화와 라그랑주 승수를 다룬다. 본문을 읽다가 막히거나 다른 책과 용어를 맞춰 볼 때 꺼내 보는 참고 자료다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 부록은 공식 위주이므로 식은 표준 정의로 복원하고, 설명 문장과 예시는 새로 썼다.

> **이 부를 한 문장으로**
> 본문에서 쓴 수학 도구를 다시 찾아보고, 다른 표기법과 연결하기 위한 뒷받침 자료다.

> **참고(노트 작성자)** 부록의 수식은 OCR에서 많이 깨져 노트 작성자가 표준 지식으로 복원했다. 중요한 식은 원서 502~530쪽과 대조하라. 이 폴더에는 핵심 정리 문서를 따로 두지 않았다.

## 0. 먼저 알아 둘 것

- 부록 A는 새로운 내용이 아니라 요약이다. 증명과 직관은 해당 본문 장으로 돌아가서 확인한다.
- 부록 B의 핵심은 3변수 회전 표현은 어딘가에서 특이점이 생긴다는 사실이다.
- 부록 C는 책이 PoE를 선호하는 이유를 D-H와 비교해 정당화한다. 기존 자료를 읽기 위해 D-H도 알아 둔다.
- 부록 D는 6장 수치 역기구학, 8장 구속 동역학과 이어진다.

## 3. 부록 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 짐벌락(gimbal lock) | 오일러 각에서 두 회전축이 겹쳐 자유도 하나를 잃는 특이 자세 |
| 단위 쿼터니언 | 4개 숫자로 회전을 나타내는 방식으로, 특이점이 없다 |
| D-H 매개변수 | 링크 길이, 링크 비틀림, 링크 오프셋, 관절 각의 네 숫자 |
| 라그랑주 승수 | 제약이 최소점을 얼마나 세게 밀어내는지를 나타내는 계수 |

## 4. 이 부의 흐름 요약

부록 A에서 공식 지도를 얻고, 부록 B에서 회전을 다른 방식으로 말하는 법을 배운다. 부록 C는 순기구학의 두 문법을 이어 주고, 부록 D는 앞 장의 수치 해법과 구속 동역학이 기대는 최적화 이론을 정리한다.
