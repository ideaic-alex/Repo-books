# 핵심 정리

이 문서는 4부(10장과 11장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 수식은 OCR과 표준 지식으로 복원했으므로 원서와 대조하기를 권한다.

---

## 1. 한눈에 보는 요점

- **구성 공간에서는 로봇이 점이다**: 장애물을 로봇 크기만큼 부풀린 C-장애물로 바꾸면 경로 계획은 점이 금지 구역을 피해 가는 문제가 된다.
  - *쉽게 말하면*: 로봇의 몸집을 장애물에 미리 더해 놓는다.
  - → 자세히: [10장 모션 플래닝](10%EC%9E%A5%20%EB%AA%A8%EC%85%98%20%ED%94%8C%EB%9E%98%EB%8B%9D.md)
- **A*는 낙관적 추정으로 최단 경로를 보장한다**: 지금까지의 비용과 남은 비용 추정의 합이 가장 작은 노드를 먼저 탐색한다.
  - *쉽게 말하면*: 목표 쪽으로 눈치 빠르게 길을 찾되 과대 평가만 하지 않는다.
  - → 자세히: [10장 모션 플래닝](10%EC%9E%A5%20%EB%AA%A8%EC%85%98%20%ED%94%8C%EB%9E%98%EB%8B%9D.md)
- **격자는 저차원, 샘플링은 고차원**: 격자는 해상도 완전하나 차원에 지수적이고, RRT와 PRM은 확률적 완전하며 RRT*는 최적에 수렴한다.
  - *쉽게 말하면*: 칸을 다 세는 대신 무작위로 점을 찍어 길을 만든다.
  - → 자세히: [10장 모션 플래닝](10%EC%9E%A5%20%EB%AA%A8%EC%85%98%20%ED%94%8C%EB%9E%98%EB%8B%9D.md)
- **포텐셜 장은 빠르지만 갇힌다**: 인력과 척력의 합이 0인 지역 최소에서 멈출 수 있고, 내비게이션 함수는 이를 없애도록 설계한다. 계획 결과는 최적화나 분할 후 재연결로 매끄럽게 한다.
  - *쉽게 말하면*: 공이 굴러 내려가다 웅덩이에 빠질 수 있다.
  - → 자세히: [10장 모션 플래닝](10%EC%9E%A5%20%EB%AA%A8%EC%85%98%20%ED%94%8C%EB%9E%98%EB%8B%9D.md)
- **제어는 오차 동역학을 설계하는 일이다**: 2차 계에서 임계 감쇠가 오버슈트 없이 가장 빠르고, 안정성은 특성 방정식 근의 실수부가 음수인 것이다.
  - *쉽게 말하면*: 용수철과 댐퍼의 비율을 알맞게 맞춘다.
  - → 자세히: [11장 로봇 제어](11%EC%9E%A5%20%EB%A1%9C%EB%B4%87%20%EC%A0%9C%EC%96%B4.md)
- **PID와 계산 토크가 모션 제어의 중심이다**: 적분 항은 중력 같은 상수 외란의 정상 오차를 없애지만 상한이 있고, 계산 토크는 모델로 비선형 항을 상쇄해 선형 오차 동역학을 만든다.
  - *쉽게 말하면*: 모델이 맞으면 어려운 로봇도 단순한 선형 시스템처럼 다룬다.
  - → 자세히: [11장 로봇 제어](11%EC%9E%A5%20%EB%A1%9C%EB%B4%87%20%EC%A0%9C%EC%96%B4.md)
- **힘과 운동은 같은 방향에서 동시에 제어할 수 없다**: 하이브리드 제어는 사영 행렬로 운동 방향과 힘 방향을 나눈다.
  - *쉽게 말하면*: 어떤 방향은 밀고 어떤 방향은 움직인다.
  - → 자세히: [11장 로봇 제어](11%EC%9E%A5%20%EB%A1%9C%EB%B4%87%20%EC%A0%9C%EC%96%B4.md)
- **임피던스 제어는 운동을 재고 힘을 낸다**: 어드미턴스 제어는 힘을 재고 운동을 낸다. 각각 부드러운 환경과 단단한 환경 모사에 강하다.
  - *쉽게 말하면*: 로봇이 용수철처럼 굴게 만드는 두 가지 길이다.
  - → 자세히: [11장 로봇 제어](11%EC%9E%A5%20%EB%A1%9C%EB%B4%87%20%EC%A0%9C%EC%96%B4.md)

## 2. 4부를 관통하는 질문

| 질문 | 4부가 보여 주는 답 |
|------|-------------------|
| 장애물 피하기를 어떻게 단순화하나? | 구성 공간에서 점 로봇과 C-장애물 문제로 바꾼다 |
| 어떤 플래너를 골라야 하나? | 저차원이면 격자, 고차원이면 샘플링, 반응형이면 포텐셜 장 |
| 플래너 결과가 덜컹거리면? | 최적화나 분할 후 재연결로 스무딩 |
| 좋은 제어기의 기준은? | 작은 정상 오차, 작은 오버슈트, 짧은 정착 시간 |
| 모델이 부정확하면? | 피드백과 함께 쓰고 PD와 중력 보상 같은 단순화를 쓴다 |
| 접촉 작업은 어떻게 제어하나? | 하이브리드 모션-힘 제어 또는 임피던스와 어드미턴스 제어 |

---

> **4부 한 줄 요약**
> 구성 공간에서 장애물을 피하는 경로를 찾고, 피드백과 모델로 오차 동역학을 설계해 그 경로를 따라가며, 접촉 작업에서는 힘과 운동을 방향별로 나누거나 임피던스를 조절한다.
