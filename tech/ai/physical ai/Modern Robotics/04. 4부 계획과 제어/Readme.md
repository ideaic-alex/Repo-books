# 4부 개요 (Part IV) 계획과 제어

케빈 린치(Kevin M. Lynch)와 프랭크 박(Frank C. Park)의 『Modern Robotics: Mechanics, Planning, and Control』 4부는 로봇이 "어디로 어떻게 갈지 정하는 일"과 "정한 대로 실제로 움직이게 하는 일"을 다루는 두 개 장이다. 10장은 장애물을 피해 시작 상태에서 목표 상태에 이르는 운동을 찾는 모션 플래닝을, 11장은 그 운동이나 힘을 액추에이터 토크로 바꾸는 로봇 제어를 설명한다. 앞의 부들이 로봇의 몸(기구학, 동역학, 궤적)을 수학으로 세웠다면, 이 부는 그 몸을 지능적으로 움직이는 두뇌의 두 단계에 해당한다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 수식은 OCR 텍스트와 표준 지식으로 복원했으므로 원서의 식과 대조하기를 권한다. 책이 소개하는 소프트웨어와 사례는 책이 쓰인 시점 기준이다.

> **이 부를 한 문장으로**
> 구성 공간에서 장애물을 피하는 경로를 찾고(계획), 오차 동역학을 설계해 그 경로를 따라가거나 힘과 임피던스를 조절하는 것(제어)이 로봇을 움직이는 두 축이다.

---

## 0. 먼저 알아 둘 것

- **구성 공간 장애물**: 로봇의 모든 자세를 한 점으로 보고, 장애물을 그 점이 들어갈 수 없는 금지 구역으로 바꾼 개념이다(10장).
- **계획과 제어의 역할**: 계획은 기하와 제약을 고려해 "무엇을 따라갈지"를 정하고, 제어는 피드백으로 "얼마나 정확히 따라갈지"를 책임진다. 10장은 제어기가 있다고 가정하고, 11장은 계획된 궤적이 주어졌다고 본다.
- **앞 장과의 연결**: 10장은 3부 9장의 시간 스케일링으로 경로를 궤적으로 바꾸고, 11장은 8장의 동역학 모델과 6장의 역기구학, 5장의 자코비안과 정역학을 쓴다.
- **수식이 많은 편**: 11장은 미분 방정식의 안정성, 행렬 계산이 나오므로 천천히 읽는 것이 좋다.

## 2. 4부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 모션 플래닝 | 장애물과 제약을 피해 시작에서 목표까지의 운동을 찾는 문제 |
| 자유 구성 공간 | 장애물과 관절 한계에 걸리지 않는 배위의 집합 |
| A* | 실제 비용과 낙관적 남은 비용의 합이 작은 노드부터 탐색하는 최단 경로 알고리즘 |
| RRT, PRM | 무작위 표본으로 트리나 로드맵을 만드는 샘플링 기반 플래너 |
| 확률적 완전 | 시간이 무한대로 가면 해를 찾을 확률이 1로 가는 성질 |
| 포텐셜 장 | 목표는 끌어당기고 장애물은 밀어내는 가상의 힘의 장 |
| 오차 동역학 | 목표와 실제의 차이가 시간에 따라 변하는 규칙 |
| 감쇠비 | 응답이 진동하는 정도를 정하는 값. 1이면 임계 감쇠 |
| PID 제어 | 오차, 오차의 적분, 오차의 미분에 비례해 입력을 만드는 제어 |
| 계산 토크 제어 | 동역학 모델로 비선형 항을 상쇄하고 선형 오차 동역학을 만드는 제어 |
| 하이브리드 모션-힘 제어 | 방향에 따라 운동과 힘을 나누어 제어 |
| 임피던스 제어 | 끝점이 질량, 용수철, 댐퍼처럼 행동하게 하는 제어 |

## 3. 이 부의 흐름 요약

10장은 모든 자세를 구성 공간의 점으로 옮겨 장애물 피하기를 길 찾기로 바꾸고, 격자 탐색이 고차원에서 막히는 지점에서 샘플링 방법이 등장하는 흐름이다. 포텐셜 장과 최적화는 빠르거나 매끄럽다는 장점이 있지만 지역 최소의 약점이 있어, 계획 결과를 후처리하는 단계까지 이어진다. 11장은 한 관절의 오차 동역학에서 출발해 PID, 계산 토크로 쌓아 올리고, 힘 제어와 하이브리드 제어, 임피던스 제어로 확장한다. 두 장은 "경로를 정하고 따라간다"는 하나의 파이프라인으로 이어지며, 이후 5부의 파지와 이동 로봇에서 다시 쓰인다.
