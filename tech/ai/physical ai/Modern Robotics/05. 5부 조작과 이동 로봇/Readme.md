# 5부 개요 (Part V) 조작과 이동 로봇

케빈 린치(Kevin M. Lynch)와 프랭크 박(Frank C. Park)의 『Modern Robotics: Mechanics, Planning, and Control』 5부는 로봇이 세상과 만나는 두 가지 방식을 다루는 두 개 장이다. 12장은 로봇 손과 물체 사이의 접촉에서 출발해 파지와 조작을 분석한다. 13장은 바퀴로 굴러다니는 이동 로봇의 기구학, 계획, 제어, 오도메트리를 설명하고 팔을 얹은 이동 조작기로 마무리한다. 앞의 네 부가 로봇 자신을 다루었다면, 이 부는 물체와 바닥이라는 환경과의 상호작용으로 넘어간다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 수식은 OCR 텍스트와 표준 지식으로 복원했으므로 원서의 식과 대조하기 바란다.

> **이 부를 한 문장으로**
> 접촉의 기하와 마찰을 알면 손으로 물체를 쥐고 움직이는 문제를 도형과 선형계획으로 풀 수 있고, 바퀴의 구조를 알면 어느 방향으로 갈 수 있는지와 어떻게 제어하는지가 결정된다.

---

## 0. 먼저 알아 둘 것

- **접촉 모드(contact mode)**: 접촉이 구름, 미끄러짐, 떨어짐 중 어느 상태인지를 접촉마다 적은 것.
- **폐쇄(closure)**: 접촉이 물체의 움직임을 모두 막거나(형 폐쇄), 어떤 외력도 맞받을 수 있는(힘 폐쇄) 상태.
- **비홀로노믹(nonholonomic)**: 적분해서 위치 제약으로 바꿀 수 없는 속도 제약. 자동차가 옆으로 곧장 못 가는 것이 예다.
- **선수 지식**: 12장은 3장의 트위스트와 렌치, 8장의 동역학을 쓴다. 13장은 2장의 풀파프 제약, 10장의 계획, 11장의 제어, 5장의 자코비안과 이어진다.
- **이 부의 성격**: 12장은 그림과 선형계획 중심의 기하학이고, 13장은 행렬 계산과 비선형 제어 이론이 섞여 있다.

## 2. 5부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| 불침투 조건 | 두 강체가 서로 파고들지 않을 조건 |
| 회전 중심(CoR) | 평면 운동에서 순간적으로 정지해 있는 점 |
| 형 폐쇄 | 접촉 법선만으로 물체를 완전히 고정하는 것 |
| 마찰 원뿔 | 마찰을 고려해 한 접촉이 전달할 수 있는 힘의 집합 |
| 힘 폐쇄 | 마찰 접촉이 모든 외력 렌치를 맞받을 수 있는 상태 |
| 전방향 로봇 | 본체 속도에 제약이 없는 바퀴 로봇 |
| 리 브래킷 | 두 벡터장을 번갈아 따랐을 때 생기는 새 방향 |
| 오도메트리 | 바퀴 회전량으로 본체 위치를 추정하는 방법 |
| 이동 조작기 | 이동 플랫폼 위에 로봇 팔을 얹은 시스템 |

## 3. 이 부의 흐름 요약

12장은 접촉 하나가 허용하는 운동과 전달하는 힘을 정리한 뒤, 여러 접촉이 모이면 형 폐쇄와 힘 폐쇄가 되는 조건과 그것을 판정하는 선형계획을 보여 주고, 접촉 모드를 열거하는 방식으로 조작 문제를 푼다. 13장은 바퀴 종류에 따라 전방향과 비홀로노믹으로 나누어 모델을 세우고, 비홀로노믹 로봇이 속도 제약에도 어디든 갈 수 있는 이유를 리 대수로 설명한다. 이어 최단 경로, 추적 제어, 오도메트리를 다룬 뒤 바퀴와 팔을 하나의 자코비안으로 묶어 이동 조작기를 제어하며 책의 본문을 마친다.
