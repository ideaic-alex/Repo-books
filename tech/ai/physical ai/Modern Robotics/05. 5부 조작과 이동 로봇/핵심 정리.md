# 핵심 정리

이 문서는 5부(12장과 13장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 수식은 OCR 텍스트와 표준 지식으로 복원했으므로 원서와 대조하기 바란다.

---

## 1. 한눈에 보는 요점

- **접촉 문제는 세 요소로 푼다**: 접촉 운동학, 접촉 힘 모델(마찰), 강체 동역학.
  - *쉽게 말하면*: 어디로 움직일 수 있나, 어떤 힘이 전달되나, 실제로 어떻게 움직이나를 합친다.
  - → 자세히: [12장 파지와 조작](12%EC%9E%A5%20%ED%8C%8C%EC%A7%80%EC%99%80%20%EC%A1%B0%EC%9E%91.md)
- **불침투 조건과 접촉 라벨**: $F^T(\mathcal V_A-\mathcal V_B)\ge0$이고, 접촉은 구름 R, 미끄러짐 S, 떨어짐 B로 나뉜다.
  - *쉽게 말하면*: 파고들지 않는 움직임만 허용된다.
  - → 자세히: [12장 파지와 조작](12%EC%9E%A5%20%ED%8C%8C%EC%A7%80%EC%99%80%20%EC%A1%B0%EC%9E%91.md)
- **형 폐쇄는 평면 4개, 공간 7개의 점 접촉**: 렌치가 렌치 공간을 양의 생성하는지를 선형계획으로 검사한다.
  - *쉽게 말하면*: 마찰 없이 밀기만으로 가두려면 방향 수보다 하나 더 필요하다.
  - → 자세히: [12장 파지와 조작](12%EC%9E%A5%20%ED%8C%8C%EC%A7%80%EC%99%80%20%EC%A1%B0%EC%9E%91.md)
- **마찰 원뿔과 힘 폐쇄**: 마찰 접촉은 평면 2개, 공간 3개로 힘 폐쇄가 가능하고, 평면 2접촉은 서로 마찰 원뿔 안에서 보이면 된다.
  - *쉽게 말하면*: 마찰이 접촉 수를 줄여 준다.
  - → 자세히: [12장 파지와 조작](12%EC%9E%A5%20%ED%8C%8C%EC%A7%80%EC%99%80%20%EC%A1%B0%EC%9E%91.md)
- **조작은 접촉 모드를 열거해 푼다**: 동적 파지, 미터 자 묘기, 페그 삽입의 끼임과 쐐기가 예이며, 해가 없거나 여럿일 수 있다.
  - *쉽게 말하면*: 가능한 경우를 하나씩 넣어 보고 모순 없는 것을 고른다.
  - → 자세히: [12장 파지와 조작](12%EC%9E%A5%20%ED%8C%8C%EC%A7%80%EC%99%80%20%EC%A1%B0%EC%9E%91.md)
- **전방향 로봇은 $u=H(\phi)\dot q$**: 바퀴 3개 이상이고 $H$의 계수가 3이며, 속도 한계는 $2m$면 다면체다.
  - *쉽게 말하면*: 옆으로도 곧장 가므로 계획과 제어가 쉽다.
  - → 자세히: [13장 바퀴형 이동 로봇](13%EC%9E%A5%20%EB%B0%94%ED%80%B4%ED%98%95%20%EC%9D%B4%EB%8F%99%20%EB%A1%9C%EB%B4%87.md)
- **비홀로노믹 로봇은 $\dot q=G(q)u$**: 외바퀴, 차동 구동, 자동차는 제어 집합만 다르고, 연속 시불변 피드백으로 배위를 안정화할 수 없다.
  - *쉽게 말하면*: 옆으로 직접 못 가므로 돌아서 가야 한다.
  - → 자세히: [13장 바퀴형 이동 로봇](13%EC%9E%A5%20%EB%B0%94%ED%80%B4%ED%98%95%20%EC%9D%B4%EB%8F%99%20%EB%A1%9C%EB%B4%87.md)
- **리 대수로 제어 가능성을 판정**: 브래킷 방향 운동이 평행 주차이며, 리 대수 차원이 배위 차원과 같으면 STLA, 제어 집합이 양의 생성이면 STLC다.
  - *쉽게 말하면*: 번갈아 움직이면 새 방향이 생긴다.
  - → 자세히: [13장 바퀴형 이동 로봇](13%EC%9E%A5%20%EB%B0%94%ED%80%B4%ED%98%95%20%EC%9D%B4%EB%8F%99%20%EB%A1%9C%EB%B4%87.md)
- **최단 경로와 추적**: 두빈스(CSC, CCαC), 리즈-셰프(9개 부류), 차동 구동 최단 시간(40종). 추적은 오차 좌표 기반 비선형 법칙을 쓴다.
  - *쉽게 말하면*: 최적 경로는 최소 반경 호와 직선의 조합이다.
  - → 자세히: [13장 바퀴형 이동 로봇](13%EC%9E%A5%20%EB%B0%94%ED%80%B4%ED%98%95%20%EC%9D%B4%EB%8F%99%20%EB%A1%9C%EB%B4%87.md)
- **오도메트리와 이동 조작**: $\mathcal V_b=F\Delta\theta$를 적분해 배위를 갱신하고, 이동 조작기는 $J_e=[J_{base}\ J_{arm}]$로 말단을 제어한다.
  - *쉽게 말하면*: 바퀴 회전을 모으면 위치가 되지만 오차도 같이 쌓인다.
  - → 자세히: [13장 바퀴형 이동 로봇](13%EC%9E%A5%20%EB%B0%94%ED%80%B4%ED%98%95%20%EC%9D%B4%EB%8F%99%20%EB%A1%9C%EB%B4%87.md)

## 2. 5부를 관통하는 질문

| 질문 | 5부가 보여 주는 답 |
|------|-------------------|
| 물체를 확실히 쥐려면 접촉이 몇 개 필요한가? | 형 폐쇄는 평면 4, 공간 7. 마찰이 있으면 평면 2, 공간 3 |
| 1차 접촉 해석은 믿을 만한가? | 떨어짐과 파고듦은 정확하지만 곡률 때문에 구름 또는 미끄러짐 판정이 바뀔 수 있다 |
| 옴니와 메카넘이 일반 바퀴와 다른 점은? | 옆 미끄러짐을 허용해 속도 제약이 없어진다 |
| 자동차는 옆으로 못 가는데 왜 어디든 도달하나? | 리 브래킷 방향(평행 주차)으로 움직일 수 있어서 |
| 오도메트리만 믿어도 되나? | 짧은 시간만. 오차가 쌓이므로 다른 센서와 융합 |

> **5부 한 줄 요약**
> 접촉과 마찰의 기하로 파지와 조작을 분석하고, 바퀴의 구조로 이동 로봇의 가능한 움직임과 제어를 정하며, 이 둘을 합친 것이 팔을 얹은 이동 조작기다.
