# 09. 다이어그램 추론 이해를 위한 프레임워크

앞선 장들에서 다양한 다이어그램 표기법과 추론 방식을 살펴본 뒤, 이 마지막 장은 한 걸음 물러서 공통 원리와 품질 기준, 평가 방법, 분류 체계를 정리한다. 책의 결론으로서 다이어그램이 AI의 한계를 완화하고 기술을 투명하게 만드는 길임을 맺음말에서 강조한다.

---

## 핵심 요점

- **공통 원리**: 다이어그램은 평면 위치로 색인하는 시각 표현이며, 도형과 여섯 유형의 선(연결, 선행, 종류, 일부, 관련, 인과)으로 이루어진다.
- **내부와 외부 표현**: 멘탈 모델 같은 내부 표현은 한계가 많아서 외부 표현으로 옮겨 다듬고 보존한다.
- **좋은 다이어그램의 기준 다섯 가지**: 시스템 이해를 촉진하고, 모호하지 않고, 간결하고, 과제와 관련이 있고, 다층 기술을 지원한다.
- **정보력과 계산력**: 다이어그램의 진짜 힘은 정보를 더 담는 데 있지 않고 지각적 추론을 거의 공짜로 제공하여 계산력을 높이는 데 있다.
- **실험 증거**: 계층형 인터페이스는 정보적으로 동치인 평면형보다 문제 해결 정확도와 사용자 선호에서 앞섰다.
- **네 부류의 분류**: 구조와 정보의 동적 여부로 정적 표현, 전파 구조, 구성적 다이어그램, 정보 전파를 갖춘 구성적 다이어그램으로 나눈다.
- **맺음말**: 다이어그램은 상식 추론의 네 요소(여러 표현, 오류 처리, 자기 성찰, 효율적 검색)를 보완하고 블랙박스를 글래스 박스로 바꾼다.
