# 5장. 규칙 기반 전문가 시스템

초기의 범용 문제 해결기가 한계를 보이자 AI 연구는 특정 영역의 지식을 활용하는 전문가 시스템으로 방향을 틀었다. 이 장은 전문가 시스템의 등장 배경과 인간 전문성의 성격을 짚고, 지식을 IF-THEN 규칙으로 표현하는 규칙 기반 전문가 시스템의 구조와 추론 방식을 설명한다.

CLIPS 도구로 규칙을 구현하는 방법과 주식 선정 예제, 그리고 XCON 사례와 전문가 시스템의 한계를 함께 다룬다. 한계 중 신뢰와 설명 능력의 문제는 다음 장에서 다이어그램으로 보완하는 방안으로 이어진다.

---

## 핵심 요점

- 전문가 시스템은 좁은 영역에서 인간 전문가의 의사결정을 모방하며, 범용 문제 해결기의 한계를 넘어 도메인 지식에 의존한다.
- 전문가는 휴리스틱, 과거 경험, 분류 체계, 모델, 패턴 인식, 직관의 여섯 가지 방식으로 추론하며, 규칙 기반 시스템은 그중 휴리스틱에 해당한다.
- 규칙은 `IF (조건) THEN (행동)` 형태이고, 객체-값 쌍과 변수, 연산자로 표현한다.
- 시스템은 지식 베이스, 추론 엔진, 작업 메모리, 사용자 인터페이스로 구성된다.
- 전방향 추론은 데이터 주도, 후방향 추론은 목표 주도이며, 진단형 문제에는 후방향이 자연스럽다.
- 규칙 충돌은 규칙 조정, 우선순위, 제어 전략(메타규칙), 규칙 특성(구체성)으로 해결한다.
- CLIPS는 사실 목록, 규칙, 전방향 추론 엔진으로 이루어진 도구이며 `assert`, `defrule`, `test`, `salience` 등을 제공한다.
- XCON은 구성 오류율을 35%에서 2%로 낮춘 성공 사례이지만, 전문가 시스템에는 학습 불가, 경직성, 신뢰와 설명 부족 같은 한계가 있다.
