# 02. 멘탈 모델 - 마음의 눈으로 보는 다이어그램

사람은 자동차, 스프레드시트, 경제 이론처럼 복잡한 시스템을 다룰 때 머릿속에 내부 모델을 만들어 돌려 보며 시스템의 행동을 예측한다. 이 장은 멘탈 모델이 무엇이고 왜 유용한지, 그리고 다이어그램이 알맞은 멘탈 모델의 형성을 어떻게 돕는지를 살핀다. 시스템 구성 요소 사이의 내부 연결과, 사전 지식을 끌어오는 외부 연결이라는 두 축으로 여러 실험과 사례를 소개한다.

---

## 핵심 요점

- 멘탈 모델은 시스템의 구성 요소, 연결, 내부 과정에 대한 동적인 내부 표상이며, 돌려 봄으로써 예측, 설명, 기억을 돕는다.
- 사용자의 멘탈 모델은 대개 불완전하고 불안정하다. 설계자의 개념 모델을 다이어그램으로 제공하면 더 빠르고 풍부한 이해를 얻을 수 있다.
- 장치 모델 실험에서 시스템 위상과 흐름 정보를 받은 집단은 학습 시간, 기억, 지름길 사용에서 암기 집단을 앞섰다.
- 서모스탯 사례에서는 주석 달린 그림, 개념 모델, IF-THEN 규칙 기반의 인과 모델을 단계적으로 쌓고, 국소성 원리를 지키며 모델을 실행해 행동을 예측한다.
- 문제를 의미 있고 친숙한 맥락으로 제시하면 추론 성능이 크게 오른다. 와슨 과제 정답률은 15%에서 81%까지 달라졌다.
- 유추는 구조적 유사성에 기반해 기반 영역의 지식을 대상 영역에 사상한다. 둘 이상의 유추를 함께 쓰고 반례 유추까지 활용하면 이해가 깊어진다.
- 멘탈 모델을 완전히 포착하는 방법은 없으며, 발화 사고 분석 같은 기법도 한계가 있다.
