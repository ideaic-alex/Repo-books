# 멘탈 모델 - 마음의 눈으로 보는 다이어그램

2장은 사람이 복잡한 시스템을 이해할 때 머릿속에서 작은 모형을 만들어 돌려 본다는 멘탈 모델의 발상에서 출발한다. 저자는 사용자의 멘탈 모델과 설계자의 개념 모델을 구분하고, 적절한 다이어그램이 올바른 멘탈 모델을 만드는 데 도움이 된다고 주장한다. 멘탈 모델이 지식을 조직하는 방식은 두 가지로 나뉜다. 하나는 시스템 구성요소를 잇는 내부 연결이고, 다른 하나는 사용자의 사전 지식을 잇는 외부 연결이다. 내부 연결은 기기 모델 실험과 온도조절기의 인과 모델로, 외부 연결은 웨이슨 과제와 여러 유추 사례로 설명한다. 마지막으로 멘탈 모델을 포착하는 연구 방법의 한계를 짚는다.

---

## 이 장의 핵심

- 멘탈 모델은 시스템의 구성요소와 연결을 담은 내부 표상으로, 매개변수를 바꿔 가며 머릿속에서 실행해 예측, 설명, 기억에 쓰는 동적 구조이다.
- 사용자의 멘탈 모델은 불완전하고 변하기 쉬운 반면 설계자의 개념 모델은 정확하고 완전해야 하며, 이상적으로는 둘이 일치해야 한다.
- 멘탈 모델은 경험에 따라 일반화, 변별, 강화의 과정을 거쳐 발달하고, 학습자에게 개념 모델을 직접 제공하면 더 빠르고 풍부한 모델을 얻을 수 있다.
- 키러스와 보바이르의 실험에서, 구성요소의 연결 구조와 그 위를 흐르는 정보를 담은 장치 모델은 학습, 기억, 절차 추론을 개선했다. 효과의 원인은 공상 맥락이 아니라 토폴로지 정보였다.
- 온도조절기 사례는 개념 모델(구조), 영역 원리(근거), 인과 모델(IF-THEN 규칙, 국소성 원리), 모델 실행(사건 연쇄)이라는 멘탈 모델의 네 구성요소를 보여 준다.
- 같은 논리 문제라도 구체적이고 친숙한 맥락으로 틀짜기하면 훨씬 잘 풀린다. 웨이슨 과제와 봉투, 음주 연령 과제가 이를 보여 준다.
- 유추는 기반 영역의 지식을 대상 영역에 매핑해 옮기는 일이다. 표면이 아니라 구조가 비슷한지를 따지며, 본래 불완전하다.
- 전기 유추에서는 배터리에 수압 모형, 저항에 군중 이동 모형을 쓰는 식으로 유추를 여럿 병용하는 것이 효과적이었다.
- 종양 문제와 요새 문제에서는 구조 매핑으로 분산 해법이 한 문제에서 다른 문제로 옮겨 간다. 또 공간 다이어그램과 다른 유추가 창의적 해법의 길을 연다.
- 멘탈 모델은 면담, 발화 사고법, 비디오 회고 어느 방법으로도 완벽히 포착되지 않으며, 블랙박스는 끝내 완전히 투명해지지 않는다.
