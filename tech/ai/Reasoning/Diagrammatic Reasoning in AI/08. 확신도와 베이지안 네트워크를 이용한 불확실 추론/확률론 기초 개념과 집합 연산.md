# 확률론 기초 개념과 집합 연산

이 문서는 베이지안 네트워크를 이해하기 위한 준비로 8장이 제시하는 확률론의 기초를 다룬다. 확률의 두 가지 해석, 실험과 표본 공간, 사건의 확률을 세는 방법, 세 가지 공리, 합집합·교집합·여집합과 덧셈 규칙을 예제와 함께 정리한다. 이 개념들은 뒤에 조건부 확률과 베이즈 정리, 그리고 베이지안 네트워크에서 확률이 전파되는 방식을 이해하는 토대가 된다.

---

## 1. 확률론을 왜 먼저 보는가

확률의 개념은 일상 언어에 스며 있다. "11월 시애틀에는 비가 올 가능성이 매우 높다", "내가 승진할 가능성은 반반이다", "그가 우리를 찾아오는 일은 아주 드물다" 같은 문장은 모두 어떤 일이 일어날 가능성을 말하는 확률적 표현이다.

확률적 직관은 오래되었지만 확률의 수학은 인류사에서 비교적 최근에 시작되었다. 17세기 프랑스 수학자 블레즈 파스칼이 도박 문제의 정확한 확률을 계산하는 방법을 고안했을 때 비로소 확률론이 하나의 학문으로 이해되기 시작했다. 이후 그 중요성이 꾸준히 커져서 오늘날 경영, 의학, 공학 같은 여러 분야에서 품질 관리, 위험 평가, 예측 등의 문제를 푸는 도구로 쓰인다.

이 역사에서 특히 중요한 것은 18세기 영국의 목사이자 수학자 토머스 베이즈(1702-1761)가 정식화한 베이즈 정리다. 이것은 조건부 확률, 곧 사건 B가 일어났다는 조건에서 사건 A가 일어날 확률을 계산하기 위한 정리이며, 베이지안 네트워크의 이론적 토대가 된다. 저자는 이 절에서 베이즈 정리와 관련된 확률론을 복습하여, 독자가 확률 특히 조건부 확률의 의미를 파악하고 기본 확률을 계산하도록 돕겠다고 밝힌다. 이 개념들은 나중에 베이지안 네트워크의 확률 전파를 이해할 때 다시 쓰인다.

---

## 2. 확률의 두 가지 해석

처음부터 구분해 둘 해석이 둘 있다.

- **객관적 해석(objective)**: 확률은 실험을 아주 많이 반복했을 때 어떤 결과가 나오는 빈도를 나타낸다. 공정한 주사위를 충분히 많이 굴리면 3이 나올 확률은 1/6이라는 식이다.
- **주관적 해석(subjective)**: 확률은 어떤 사건이 일어날 가능성에 대한 개인의 의견이며, 그 사람의 믿음과 최선의 판단에 근거한다. 예컨대 한 경제학자가 "내년에 경제가 나아질 가능성이 높다(50% 이상)"고 말하는 경우다. 주관주의자는 '참인 확률'이 하나만 있는 것은 아니라고 본다.

저자는 두 해석 모두 전문가 시스템과 베이지안 네트워크의 발전에 중요하며, 이는 장의 뒷부분에서 확인된다고 덧붙인다.

---

## 3. 기본 개념: 실험, 표본 공간, 사건

확률은 어떤 종류의 실험을 수행할 때 한 결과가 나올 가능성으로 떠올리면 편하다. 확률론에서 실험(experiment)은 결과를 미리 확실히 알 수 없는 모든 과정을 가리킨다. 본문은 세 가지 상황을 든다.

1. 공정한 동전을 10번 던져서 앞면이 6번 이상 나올 확률을 알고 싶다.
2. 잘 섞은 52장 카드에서 2장을 뽑아 블랙잭(에이스 하나와 10점짜리 카드 하나로 합 21)이 나올 확률을 구한다.
3. 두 상자에 빨간 공의 비율이 다르다. 상자 1은 10개 중 8개(80%), 상자 2는 10개 중 2개(20%)가 빨갛다. 빨간 공이 뽑혔을 때 상자 1에서 뽑았을 확률을 구하고 싶다.

세 예 모두 전통적 의미의 실험을 실제로 하지는 않는다. 확률론의 힘은 실험을 실제로 하지 않고도 이런 확률을 계산할 수 있다는 데 있다.

### 3.1 표본 공간과 집합 언어

실험에서 가능한 모든 결과의 모음을 표본 공간(sample space)이라 하고 `S`로 쓴다. 표본 공간은 가능한 결과의 집합이고 각 결과는 그 집합의 원소다. 이런 관례 덕분에 집합론의 언어와 개념이 확률을 이해하는 편리한 틀이 된다.

공정한 주사위를 굴리는 경우 표본 공간은 `S = {1, 2, 3, 4, 5, 6}`이다. 모든 결과가 같은 확률로 나오면 단순 표본 공간(simple sample space)이라고 한다. 사건(event)은 표본 공간의 부분집합 `A ⊆ S`이고, 그 확률을 `P(A)`로 쓴다. 주사위에서 짝수가 나오는 사건은 `A = {2, 4, 6}`이다.

### 3.2 개수 세기 공식

사건 A에 결과가 m개 있고 표본 공간에 결과가 n개 있다면(단순 표본 공간일 때) 다음과 같다.

```
P(A) = m / n          (식 8.1)
짝수 예: P(A) = 3/6 = 0.5
```

## 4. 예제: 동전 세 번 던지기

공정한 동전을 세 번 던질 때 (1) 앞면이 정확히 두 번 나올 확률, (2) 앞면이 적어도 두 번 나올 확률을 구한다.

표본 공간은 8개의 결과로 이루어진다.

```
S = {HHH, THH, HTH, HHT, TTH, THT, HTT, TTT}
```

- 정확히 두 번 앞면인 사건 A는 `{THH, HTH, HHT}`로 결과가 3개다. 표본 공간이 8개이므로 `P(A) = 3/8`이다.
- 적어도 두 번 앞면인 사건 B는 앞의 세 가지에 HHH를 더한 `{HHH, THH, HTH, HHT}`로 4개이므로 `P(B) = 4/8`이다.

이때 8개 결과가 모두 같은 확률이라는 점이 개수 세기 공식을 쓸 수 있는 근거다.

## 5. 확률의 공리

수학자들은 모든 확률 해석이 만족해야 하는 세 공리를 정해 확률을 형식적으로 정의한다.

- **공리 1**: 어떤 사건 A에 대해서도 `P(A) ≥ 0`. 확률은 음수가 될 수 없다.
- **공리 2**: `P(S) = 1`. 반드시 일어나는 사건의 확률은 1이다.
- **공리 3**: 서로 배반인 사건들의 합집합 확률은 각 확률의 합이다(아래 7절에서 다룬다).

공리 1과 2를 합치면 다음 결과가 나온다.

```
0 ≤ P(A) ≤ 1          (식 8.2)
```

확률의 범위는 0에서 1 사이의 실수다. 불가능한 사건은 확률 0, 확실한 사건은 확률 1을 갖고, 둘 사이의 값들은 결과에 대한 불확실성의 다양한 정도를 나타낸다. 앞서 본 확신도가 -1에서 +1을 쓰는 것과 달리 확률은 0에서 1 사이에 있다는 점이 구별된다.

## 6. 집합 연산: 합집합, 교집합, 여집합

공리 3을 말하기 전에 확률 계산에 유용한 세 집합 연산을 본다. 그림 8.8은 이 연산들을 벤 다이어그램(Venn diagram)으로 보여 준다.

- **합집합(union)** `A ∪ B`: A에만, B에만, 또는 둘 모두에 속하는 결과를 담은 사건.
- **교집합(intersection)** `A ∩ B` 또는 간단히 `AB`: A와 B 둘 모두에 속하는 결과를 담은 사건.
- **여집합(complement)** `¬A`: 표본 공간 중 A에 속하지 않는 결과. 'A가 아님'이라고도 읽는다.

### 6.1 예제: 카드 한 장 뽑기

52장 표준 덱(2부터 10, 잭, 퀸, 킹, 에이스의 13개 숫자 각각이 하트·다이아몬드·클럽·스페이드 네 무늬)에서 한 장을 무작위로 뽑는다. 표본 공간은 52개 결과다. 세 사건을 정의한다.

1. A: 그림 카드(킹, 퀸, 잭)가 뽑힌다.
2. B: 하트 퀸이 뽑힌다.
3. C: 2가 뽑힌다.

확률은 `P(A) = 3/13`, `P(B) = 1/52`, `P(C) = 1/13`이다. 이를 써서 다음을 얻는다.

```
P(A ∪ B) = P(그림 카드 또는 하트 퀸) = P(그림 카드) = 3/13
P(A ∪ C) = P(그림 카드 또는 2) = 3/13 + 1/13 = 4/13
P(AB)    = P(그림 카드이면서 하트 퀸) = P(하트 퀸) = 1/52
P(AC)    = P(그림 카드이면서 2) = P(공집합) = 0
```

하트 퀸은 이미 그림 카드에 포함되므로 A와 B의 합집합은 A와 같고, 그림 카드이면서 2인 카드는 없어 교집합이 공집합이다.

---

## 7. 여집합 공식과 덧셈 규칙

### 7.1 여집합의 확률

여집합의 확률은 1에서 해당 사건의 확률을 빼면 된다.

```
P(¬A) = 1 - P(A)      (식 8.3)
P(그림 카드가 아님) = 1 - 3/13 = 10/13
```

### 7.2 배반 사건과 공리 3

두 사건 A1, A2가 공통 결과를 갖지 않을 때, 곧 `A1A2 = ∅`일 때 둘을 상호 배타적(mutually exclusive, 서로소)이라고 한다. 이 경우 `P(A1 ∪ A2) = P(A1) + P(A2)`이다. 공리 3은 이를 k개의 사건으로 일반화한 것이다. 서로 배타적인 사건 A1, ..., Ak 중 적어도 하나가 일어날 확률, 곧 합집합의 확률은 각 확률의 합과 같다.

### 7.3 배타적이지 않은 경우의 합집합

두 사건이 배타적이지 않아 `A1A2 ≠ ∅`이면 겹치는 부분이 이중으로 더해지므로 이를 한 번 빼 주어야 한다.

```
P(A1 ∪ A2) = P(A1) + P(A2) - P(A1A2)      (식 8.4)
```

세 사건의 합집합 공식은 훨씬 복잡하다. 세 확률의 합에서 쌍별 교집합 확률의 합을 빼고, 세 사건 모두의 교집합 확률을 더한다.

### 7.4 예제로 확인

앞 예제에서 `P(A ∪ C)`를 `P(A) + P(C)`로 계산할 수 있었던 것은 그림 카드와 2가 동시에 나올 수 없어 서로 배타적이기 때문이다. 반면 그림 카드(A)와 하트 퀸(B)은 하트 퀸이 그림 카드이기도 하므로 배타적이지 않고 `P(A ∪ B) ≠ P(A) + P(B)`다. 식 8.4를 쓰면 다음과 같다.

```
P(A ∪ B) = 3/13 + 1/52 - 1/52 = 3/13
```

다른 예로 A를 그림 카드, B를 스페이드 카드가 나오는 사건이라 하자. 그림 카드이면서 스페이드인 카드는 3장이므로 `P(AB) = 3/52`이고 식 8.4에 따라 다음이 된다.

```
P(A ∪ B) = 3/13 + 1/4 - 3/52 = 22/52
```

여기까지가 확률의 기본 공리와 집합 연산, 덧셈 규칙이며, 이어지는 조건부 확률과 베이즈 정리의 바탕이 된다.
