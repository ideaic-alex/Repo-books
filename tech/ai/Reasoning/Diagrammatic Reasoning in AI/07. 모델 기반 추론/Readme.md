# 7장. 모델 기반 추론

모델 기반 추론(model-based reasoning)은 시스템의 구조와 행동을 모델로 표현하고 그 구조를 분석해 문제를 푸는 AI 기법이다. 규칙 기반 전문가 시스템이 증상과 원인의 연관에만 의존하는 한계를 보완하며, 다이어그램이 단순한 설명 도구를 넘어 추론의 재료가 됨을 보여 준다. 이 장은 고장 진단과 물류 네트워크 설계(LogNet)라는 두 응용으로 이를 설명한다.

---

## 핵심 요점

- **구조와 행동**: 다이어그램은 구조만, 휴리스틱은 행동만 기술하지만 모델 기반 추론은 둘 다 기술한다.
- **모델 구성 요소**: 물질, 부품, 도관(연결)으로 이루어지며 인접 원리에 따라 직접 연결된 부품끼리만 작용한다.
- **모델 기반 진단**: 예측과 관찰의 불일치에서 출발해 다섯 규칙으로 용의자를 좁히고 탐침과 재시험으로 확정한다. 결함 은폐를 조심해야 한다.
- **LogNet**: 공장, 창고, 고객 지역으로 이루어진 네트워크 모델을 비용과 고객 서비스 수준으로 평가한다.
- **통합과 분산**: 세 가지 통합 절차와 네 가지 분산 절차가 비용과 서비스 사이의 균형을 서로 다르게 잡는다.
- **휴리스틱 탐색**: 조합 폭발을 줄이는 대신 최적해를 보장하지 않는다.
- **한계와 결합**: 모델 기반 추론은 만능이 아니며 규칙 기반 추론과 결합할 수 있다.
