# 다이어그램을 이용한 논리 추론

논리 추론은 AI의 출발점부터 이어진 오래된 주제이며, 전문가 시스템의 추론 엔진도 사실에서 결론을 이끌어 내는 논리에 기대고 있다. 4장은 형식 논리의 타당성 판정에 다이어그램을 쓸 수 있는지를 묻고, 논증 다이어그램과 오일러 그래프를 거쳐 벤 다이어그램으로 나아간다. 저자는 Shin의 Venn-I에 바탕을 둔 동적 벤 다이어그램이 정언 삼단논법의 증명을 시각적으로 구성할 수 있음을 보인다. 마지막에는 같은 삼단논법을 1차 논리와 벤 다이어그램으로 각각 증명해 두 표현 체계의 장단점과 한계를 비교한다.

---

## 이 장의 핵심

- **논증과 타당성**: 논증은 전제로 결론을 뒷받침하는 구조이고, 결론이 전제에서 따라 나오면 타당하다. 형식 논리는 개별 내용이 아니라 논증 형식을 연구한다.
- **논증 다이어그램**: 진술에 번호를 붙이고 화살표로 잇는다. `+`로 묶이면 모두 필요한 결합 전제, 각자 화살표를 가지면 독립적인 수렴 논증이다.
- **오일러 그래프의 두 한계**: 표현할 수 있는 관계가 네 가지 정언 진술뿐이고, 두 전제의 정보를 한 그림에 합칠 수 없다.
- **벤 다이어그램의 표기**: 음영은 빈 구획, ⊗는 비지 않은 구획을 뜻하며, 선으로 이은 ⊗의 사슬(x-열)이 선언 정보를 나타낸다.
- **부분 겹침 규칙**: 새 원은 기존 모든 구획과 한 번씩만 겹쳐야 하므로 집합이 n개면 구획은 `2^n`개이다.
- **지식의 점진적 누적**: 벤 다이어그램은 전제를 하나씩 덧붙여 하나의 그림으로 합칠 수 있어 삼단논법에 알맞다.
- **변환 규칙**: 객체의 삭제(I), 추가(II), 두 다이어그램의 통합(III)으로 구성된다. 정보를 더하지 않는 방향의 변환만 허용한다.
- **타당성 판정 절차**: 전제를 통합한 `D_P`를 변환 규칙만으로 결론 `D_C`로 바꿀 수 있으면 타당하고, 바꿀 수 없으면 부당하다.
- **1차 논리와의 비교**: 같은 삼단논법을 여섯 줄 증명과 두 번의 다이어그램 조작으로 증명하며, 다이어그램은 배우기 쉽고 직관적이다.
- **한계**: 이 기법은 정언 진술로 된 삼단논법에만 통하고, 선언이나 부정 정보를 일반적으로 나타내지는 못한다.
