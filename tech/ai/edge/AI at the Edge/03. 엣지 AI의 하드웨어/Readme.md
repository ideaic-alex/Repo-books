# 3장. 엣지 AI의 하드웨어

엣지 AI 제품을 기획할 때 필요한 기본 구성 요소, 즉 데이터를 공급하는 센서와 그 데이터를 처리하는 하드웨어를 개관하는 장이다. 센서가 내놓는 데이터 형식과 종류를 먼저 보고, 마이크로컨트롤러부터 SoC, 딥러닝 가속기, 맞춤 칩, 엣지 서버까지 프로세서의 스펙트럼을 비교한다. 마지막으로 여러 장치를 조합하는 시스템 구성을 살펴본다.

---

## 핵심 요점

- 센서 데이터는 시계열, 오디오, 이미지, 비디오 같은 형식으로 나뉘며, 시계열이 가장 흔하다.
- 센서는 음향·진동, 시각, 움직임·위치, 힘·촉각, 광학·전자기, 환경·생체·화학 모달리티로 묶어 볼 수 있다.
- 장치 로그 같은 내부 상태와 API·네트워크 같은 외부 데이터도 AI의 입력이 된다.
- 고사양 마이크로컨트롤러는 비용, 에너지, 연산 능력의 균형이 좋아 임베디드 머신러닝의 최적 지점이다.
- SoC는 운영체제와 익숙한 도구 덕에 쓰기 쉽지만 MCU보다 에너지 효율이 낮다.
- 딥러닝 가속기는 유연성을 일부 포기하는 대신 속도와 효율을 얻으며, MCU나 SoC와 짝으로 쓰는 경우가 많다.
- FPGA와 ASIC은 최고의 성능과 효율을 줄 수 있지만 개발 부담이 크다.
- 개발 보드로 알고리즘을 실제 하드웨어에서 시험해 성능, 에너지, 비용의 균형을 찾는다.
- 멀티 디바이스와 이종 연산을 쓰면 에너지, 비용, 프라이버시 문제를 나눠 해결할 수 있다.
