# 3장. 엣지 AI의 하드웨어

엣지 AI 제품을 기획할 때 알아야 할 기본 구성 요소를 훑어보는 장이다. 하나는 데이터를 만들어 주는 센서이고, 다른 하나는 그 데이터를 처리하는 하드웨어다. 먼저 센서가 내놓는 데이터의 형식과 종류를 살펴본다. 이어서 마이크로컨트롤러에서 SoC, 딥러닝 가속기, 맞춤 칩, 엣지 서버까지 프로세서를 차례로 비교한다. 마지막으로 여러 장치를 묶어 하나의 시스템으로 구성하는 방법을 다룬다.

---

## 핵심 요점

- 센서 데이터는 시계열, 오디오, 이미지, 비디오 같은 형식으로 나뉘며, 이 가운데 시계열이 가장 흔하다.
- 센서는 음향·진동, 시각, 움직임·위치, 힘·촉각, 광학·전자기, 환경·생체·화학이라는 여섯 가지 모달리티로 묶어 볼 수 있다.
- 장치 로그 같은 내부 상태와 API·네트워크에서 오는 외부 데이터도 AI의 입력이 된다.
- 고사양 마이크로컨트롤러는 비용, 에너지, 연산 능력의 균형이 가장 좋아서 임베디드 머신러닝에 알맞다.
- SoC는 운영체제와 익숙한 도구를 쓸 수 있어 개발하기 편하지만, MCU보다 에너지 효율이 떨어진다.
- 딥러닝 가속기는 유연성을 조금 내주는 대신 속도와 효율을 얻는다. MCU나 SoC와 함께 쓰는 경우가 많다.
- FPGA와 ASIC은 성능과 효율을 가장 높일 수 있지만 개발 부담이 크다.
- 개발 보드로 알고리즘을 실제 하드웨어에서 돌려 보면서 성능, 에너지, 비용의 균형점을 찾는다.
- 여러 장치를 함께 쓰고 연산을 나누어 맡기면, 에너지, 비용, 프라이버시 문제를 나누어 풀 수 있다.
