# 실제 제품 사례

기술을 이해하는 가장 좋은 방법은 현장에서 쓰이는 모습을 보는 것이다. 책은 엣지 AI로 만든 실제 제품 세 가지를 소개하고 각각을 BLERP 틀로 분석한다. 이 문서는 세 사례의 구조와 엣지 AI가 맞는 이유를 정리한다.

---

## 1. Izoelektro RAM-1: 송전선 고장 감지로 산불 예방

- **문제**: 송전선은 유럽의 오래된 숲 같은 광대한 야생 지대를 지나고, 설비 고장이 식생에 불을 붙여 산불로 이어질 수 있다. 외진 곳에 철탑이 수천 마일 이어져 있어 감시가 어렵다.
- **구성**: 각 철탑에서 온도, 기울기, 전압 등을 감시하는 센서 묶음이 있고, 딥러닝 분류 모델이 고장이 생기는 중인지 판별한다. 기술자가 위험해지기 전에 방문해 수리할 수 있다. 극한 날씨를 수년간 견디는 견고한 구조다.
- **핵심 이유 1(연결)**: 외딴 곳의 수천 철탑에서 원시 센서 데이터를 실시간 전송하는 것은 비용이 너무 크다. 현장에서 해석하고 고장이 예측될 때만 보내며, 월 최대 약 250킬로바이트 수준이다. 덜 중요한 정보는 주기적으로 묶어 보낸다.
- **핵심 이유 2(전력)**: 철탑에 달려 있지만 배터리로 동작해 송전선 고장 때도 작동하고 설치 비용과 복잡도가 줄어든다. 불필요한 무선 전송을 피한 덕분에 배터리가 20년 간다.

| BLERP | 평가 |
| --- | --- |
| 대역폭 | 설치 지역의 연결이 제한적 |
| 지연 시간 | 주기적 전송을 기다리지 않고 고장 즉시 파악해야 함 |
| 경제성 | 불필요한 통신을 줄여 비용 절감, 배터리 구동으로 설치 비용 감소 |
| 신뢰성 | 배터리 구동 가능으로 신뢰성 향상 |
| 프라이버시 | 이 사례에서는 큰 고려 사항 아님 |

## 2. SlateSafety BioTrac Band: 소방관을 위한 지능형 웨어러블

- **문제**: 소방관은 고온에 노출되어 장기 건강에 영향을 받는다. FEMA에 따르면 순직 원인 1위는 급성 심장 사건이다.
- **구성**: 극한 환경의 작업자를 위한 웨어러블로, 열 스트레스와 과로로 이어질 상황을 개인과 팀에 조기 경고한다. 임베디드 머신러닝 모델과 휴리스틱 알고리즘을 함께 써서 착용자 몸에서 나오는 신호를 포함한 여러 센서 데이터를 분석하고 부상 직전을 예측한다. 2021년 Time지 100대 발명품에 올랐다.
- **엣지 AI가 맞는 이유**: 응급 상황에서 연결이 제한되거나 끊겨도 온디바이스 분석으로 계속 경고한다. 불필요한 전송을 피해 에너지와 배터리를 아끼고, 기기 크기와 무게를 최소로 유지하며 비용도 낮춰 더 널리 보급될 수 있다.

| BLERP | 평가 |
| --- | --- |
| 대역폭 | 소방 현장 같은 극한 환경은 연결이 제한적 |
| 지연 시간 | 건강 문제는 시간이 중요해 즉시 파악해야 함 |
| 경제성 | 원시 데이터 스트리밍에는 값비싼 고대역폭 연결이 필요 |
| 신뢰성 | 연결이 끊겨도 경고하고 작은 배터리로 오래 동작 |
| 프라이버시 | 생체 신호 원시 데이터는 장치에 두고 핵심 정보만 전송 |

## 3. ElephantEdge: 스마트 칼라로 코끼리 행동 이해

- **문제**: 서식지 압박으로 야생 코끼리와 사람의 접촉이 늘고, 밀렵이나 농민과의 갈등으로 코끼리가 다치거나 죽는 일이 잦다. 연구자들은 위험한 만남으로 이어지는 조건을 알고 싶어 한다.
- **구성**: 오픈소스 추적 칼라 프로젝트다. 목에 거는 칼라가 임베디드 센서와 머신러닝 모델로 위치, 건강, 활동 정보를 제공하고 과학 연구와 갈등 방지용 경보에 쓰인다. 모델은 시민 과학자 커뮤니티가 공개 데이터셋으로 프로토타입을 만들었다.
- **에너지 절약**: 야생 코끼리에 달린 장치는 배터리 교체가 어렵다. 원시 센서 데이터 대신 걷기, 먹기, 마시기 같은 고수준 활동 정보만 보낸다.
- **통신**: 낮은 대역폭 덕분에 초저전력 무선 기술인 LoRa를 쓸 수 있다. 하루에 한 번 지나가는 LoRa 위성에 지난 활동 요약을 보내며, 전통적 연결이 없는 곳에서도 동작하고 배터리는 약 5년으로 추정된다.

| BLERP | 평가 |
| --- | --- |
| 대역폭 | 연결이 제한적이며 온디바이스 분석이 저에너지 무선 사용을 가능하게 함 |
| 지연 시간 | 하루 한 번 전송이어도 수동 다운로드 방식의 기존 칼라보다 훨씬 빈번함 |
| 경제성 | 노동 집약적인 기존 모니터링을 대체해 비용 절감 |
| 신뢰성 | 드문 전송으로 배터리가 수년 가고 위성 활용이 경제적이라 범위 확대 |
| 프라이버시 | 카메라로 활동을 감시하는 안보다 지역 주민에게 덜 침해적 |

---

## 4. 세 사례의 공통점

- **연결이 약한 환경**: 모두 외딴 곳이거나 극한 환경이어서 원시 데이터 전송이 어렵다.
- **현장 해석 후 요약 전송**: 중요한 결과만 보내 통신 에너지를 줄이고 배터리 수명을 늘린다.
- **BLERP의 적용 방식**: 다섯 항목이 모두 해당될 필요는 없다. 사례마다 프라이버시처럼 비중이 작은 항목이 있다.
