# 실제 제품 사례

기술을 이해하는 가장 좋은 방법은 현장에서 쓰이는 모습을 보는 것이다. 책은 엣지 AI로 만든 실제 제품 세 가지를 소개하고, 각각을 BLERP 틀로 분석한다. 이 문서는 세 사례의 구조와, 이 제품들에 엣지 AI가 맞는 이유를 정리한다.

---

## 1. Izoelektro RAM-1: 송전선 고장 감지로 산불 예방

- **문제**: 송전선은 유럽의 오래된 숲 같은 넓은 야생 지대를 지나간다. 설비가 고장 나면 식생에 불이 붙어 산불로 번질 수 있다. 외진 곳에 철탑이 수천 마일씩 이어져 있어 일일이 감시하기 어렵다.
- **시스템 구성**: 철탑마다 온도, 기울기, 전압 등을 감시하는 센서 묶음이 달려 있고, 딥러닝 분류 모델이 고장이 생기고 있는지 판단한다. 덕분에 기술자는 상황이 위험해지기 전에 찾아가 수리할 수 있다. 극한 날씨를 수년간 견디는 견고한 구조다.
- **핵심 이유 1(연결)**: 외딴 곳에 있는 수천 개 철탑에서 원시 센서 데이터를 실시간으로 보내려면 비용이 너무 많이 든다. 그래서 현장에서 데이터를 해석하고, 고장이 예측될 때만 전송한다. 전송량은 월 최대 약 250킬로바이트 수준이다. 덜 중요한 정보는 주기적으로 묶어서 보낸다.
- **핵심 이유 2(전력)**: 철탑에 달려 있지만 배터리로 동작하므로 송전선이 고장 났을 때도 작동하고, 설치 비용과 복잡도도 줄어든다. 불필요한 무선 전송을 피한 덕분에 배터리가 20년 간다.

| BLERP | 평가 |
| --- | --- |
| 대역폭 | 설치 지역의 연결이 제한적이다 |
| 지연 시간 | 주기적 전송을 기다리지 않고 고장을 즉시 파악해야 한다 |
| 경제성 | 불필요한 통신을 줄여 비용을 아끼고, 배터리로 동작해 설치 비용도 줄인다 |
| 신뢰성 | 배터리로 동작할 수 있어 신뢰성이 높아진다 |
| 프라이버시 | 이 사례에서는 크게 고려할 사항이 아니다 |

## 2. SlateSafety BioTrac Band: 소방관을 위한 지능형 웨어러블

- **문제**: 소방관은 고온에 노출되어 장기적으로 건강을 해친다. FEMA에 따르면 순직 원인 1위는 급성 심장 질환이다.
- **시스템 구성**: 극한 환경에서 일하는 작업자를 위한 웨어러블이다. 열 스트레스와 과로로 이어질 수 있는 상황을 개인과 팀에 미리 경고한다. 임베디드 머신러닝 모델과 휴리스틱 알고리즘을 함께 써서, 착용자의 몸에서 나오는 신호를 포함한 여러 센서 데이터를 분석하고 부상 직전의 상태를 예측한다. 2021년 Time지 선정 100대 발명품에 올랐다.
- **엣지 AI가 맞는 이유**: 응급 상황에서 연결이 약하거나 끊겨도 온디바이스 분석으로 계속 경고할 수 있다. 불필요한 전송을 피해 에너지와 배터리를 아끼고, 기기의 크기와 무게를 최소로 유지하며 비용도 낮춰서 더 널리 보급될 수 있다.

| BLERP | 평가 |
| --- | --- |
| 대역폭 | 소방 현장 같은 극한 환경에서는 연결이 제한적이다 |
| 지연 시간 | 건강 문제는 시간이 중요하므로 즉시 파악해야 한다 |
| 경제성 | 원시 데이터를 스트리밍하려면 값비싼 고대역폭 연결이 필요하다 |
| 신뢰성 | 연결이 끊겨도 경고하고, 작은 배터리로 오래 동작한다 |
| 프라이버시 | 생체 신호 원시 데이터는 장치에 두고 핵심 정보만 전송한다 |

## 3. ElephantEdge: 스마트 칼라로 코끼리 행동 이해

- **문제**: 서식지가 줄어들면서 야생 코끼리와 사람이 마주치는 일이 늘었다. 밀렵이나 농민과의 갈등으로 코끼리가 다치거나 죽는 일도 잦다. 연구자들은 어떤 조건에서 위험한 만남이 생기는지 알고 싶어 한다.
- **시스템 구성**: 오픈소스 추적 칼라 프로젝트다. 목에 거는 칼라에 임베디드 센서와 머신러닝 모델이 들어 있어 위치, 건강, 활동 정보를 제공하고, 과학 연구와 갈등 방지용 경보에 쓰인다. 모델은 시민 과학자 커뮤니티가 공개 데이터셋으로 프로토타입을 만들었다.
- **에너지 절약**: 야생 코끼리에 달린 장치는 배터리를 교체하기 어렵다. 그래서 원시 센서 데이터 대신 걷기, 먹기, 마시기 같은 상위 수준의 활동 정보만 보낸다.
- **통신**: 전송량이 적으니 초저전력 무선 기술인 LoRa를 쓸 수 있다. 하루에 한 번 지나가는 LoRa 위성에 지난 활동 요약을 보낸다. 기존 통신망이 없는 곳에서도 동작하고, 배터리는 약 5년 가는 것으로 추정된다.

| BLERP | 평가 |
| --- | --- |
| 대역폭 | 연결이 제한적이고, 온디바이스 분석 덕분에 저전력 무선을 쓸 수 있다 |
| 지연 시간 | 하루 한 번 전송이라도, 데이터를 수동으로 내려받던 기존 칼라보다 훨씬 자주 받는다 |
| 경제성 | 인력이 많이 드는 기존 모니터링을 대체해 비용을 아낀다 |
| 신뢰성 | 전송이 드물어 배터리가 수년 가고, 위성을 쓰면 경제적이라 범위를 넓힐 수 있다 |
| 프라이버시 | 카메라로 활동을 감시하는 방식보다 지역 주민에게 덜 침해적이다 |

---

## 4. 세 사례의 공통점

- **연결이 약한 환경**: 모두 외딴 곳이거나 극한 환경이어서 원시 데이터를 전송하기 어렵다.
- **현장 해석 후 요약 전송**: 중요한 결과만 보내서 통신에 드는 에너지를 줄이고 배터리 수명을 늘린다.
- **BLERP 적용 방식**: 다섯 항목이 모두 중요할 필요는 없다. 사례에 따라 프라이버시처럼 비중이 작은 항목도 있다.
