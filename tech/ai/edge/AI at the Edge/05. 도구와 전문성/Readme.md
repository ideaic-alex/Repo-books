# 5장. 도구와 전문성

엣지 AI 개발에는 매우 기술적인 작업이 많아 전문가들이 모은 기술과 경험이 필요하다. 이 장은 먼저 프로젝트를 현실로 만들 팀을 어떻게 꾸릴지 다루고, 이어서 엣지 AI에 필요한 핵심 기술 도구를 훑는다. 초기 단계라면 세부는 가볍게 보고, 구체적 아이디어가 생긴 뒤 참고 자료로 다시 활용하면 된다.

---

## 핵심 요점

- **최소 팀**: 도메인 전문가와 임베디드 엔지니어 두 역할이 최소선이며, 도메인 전문성이 가장 본질적이다.
- **다양성과 이해관계자**: 다양한 관점과 이해관계자 참여가 숨은 문제와 사회적 피해를 막는 방어책이다.
- **역할과 채용**: 지식, 기획, 알고리즘, 제품 엔지니어링, 기술 지원 역할이 있고, 엣지 AI 경력자는 드물어 DSP 엔지니어 등 인접 인력을 키우는 방법이 유효하다.
- **소프트웨어 도구**: Python은 알고리즘 개발, C++는 임베디드용이며 의존성 관리와 컨테이너화가 큰 과제다.
- **알고리즘 개발**: NumPy, pandas, SciPy, scikit-learn, Jupyter와 TensorFlow가 중심이며 엣지 AI에서는 배포 생태계 때문에 TensorFlow가 유리하다.
- **MLOps**: 실험 추적, AutoML, ML 파이프라인으로 반복 개발을 체계화하며 엣지 AI는 장치 관련 업무가 추가된다.
- **온디바이스 실행**: 인터프리터, 코드 생성, 바이트코드 컴파일러, 가상 머신 등으로 추론을 실행하고, 최적화된 커널 유무가 지연 시간을 좌우한다.
- **임베디드 개발**: 디버그 프로브, 개발 보드, 에뮬레이터, 자동화 하드웨어 테스트가 필요하다.
- **엔드투엔드 플랫폼**: 대부분의 프로젝트에 가장 좋은 출발점이며, 개방성과 외부 도구 통합 여부를 살핀다.
