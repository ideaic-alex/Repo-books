# 5장. 도구와 전문성

엣지 AI 개발에는 기술적으로 까다로운 작업이 많아서, 여러 전문가의 기술과 경험이 필요하다. 이 장은 먼저 프로젝트를 현실로 만들 팀을 어떻게 꾸릴지 다룬다. 이어서 엣지 AI에 필요한 핵심 기술 도구를 훑어본다. 초기 단계라면 세부 내용은 가볍게 읽고, 구체적인 아이디어가 생긴 뒤에 참고 자료로 다시 찾아보면 된다.

---

## 핵심 요점

- **최소 팀**: 도메인 전문가와 임베디드 엔지니어, 이 두 역할이 최소 구성이다. 이 중에서도 도메인 전문성이 가장 본질적이다.
- **다양성과 이해관계자**: 다양한 관점을 가진 사람들과 이해관계자를 개발에 참여시키면, 눈에 띄지 않는 문제와 사회적 피해를 미리 막을 수 있다.
- **역할과 채용**: 역할은 지식, 기획, 알고리즘, 제품 엔지니어링, 기술 지원으로 나뉜다. 엣지 AI 경력자는 드물기 때문에, DSP 엔지니어처럼 가까운 분야의 인력을 키우는 방법이 효과적이다.
- **소프트웨어 도구**: 알고리즘 개발에는 Python, 임베디드에는 C++를 쓴다. 의존성 관리와 컨테이너화가 큰 과제다.
- **알고리즘 개발**: NumPy, pandas, SciPy, scikit-learn, Jupyter, TensorFlow가 중심이다. 엣지 AI에서는 배포 생태계가 잘 갖춰진 TensorFlow가 유리하다.
- **MLOps**: 실험 추적, AutoML, ML 파이프라인으로 반복 개발을 체계적으로 관리한다. 엣지 AI에서는 장치와 관련된 업무가 더 붙는다.
- **온디바이스 실행**: 인터프리터, 코드 생성, 바이트코드 컴파일러, 가상 머신 같은 방식으로 추론을 실행한다. 최적화된 커널이 있는지에 따라 지연 시간이 크게 달라진다.
- **임베디드 개발**: 디버그 프로브, 개발 보드, 에뮬레이터, 자동화된 하드웨어 테스트가 필요하다.
- **엔드투엔드 플랫폼**: 대부분의 프로젝트에서 가장 좋은 출발점이다. 선택할 때는 플랫폼이 얼마나 개방적이고 외부 도구와 연동되는지를 살핀다.
