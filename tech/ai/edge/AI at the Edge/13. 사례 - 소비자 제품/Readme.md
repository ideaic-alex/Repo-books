# 사례 - 소비자 제품

엣지 ML은 소비자 기기가 클라우드 전송 없이 센서 데이터를 바로 판단하게 해 속도, 배터리, 프라이버시 면에서 이점을 준다. 이 장은 반려동물, 자전거, 장난감, 가전 같은 접근법과 윤리 고려사항을 살피고, 가속도 센서로 자전거 운전자의 급정지와 이상 움직임을 감지하는 모델을 구현한다.

---

## 핵심 요점

- 소비자 제품은 지연과 대역폭, 데이터 프라이버시 문제 때문에 엣지 추론의 효과가 크다.
- 접근법은 반려동물 모니터, 자전거 모니터, 어린이 장난감, 가전제품 등이며 목표별로 필요한 센서가 다르다.
- 설계 단계에서 사용자, 악용 가능성, 데이터 저장 위치, 사용자 고지를 점검하고 FIRST 체크리스트를 활용한다.
- 실습은 스마트폰 또는 Nordic Thingy:53의 가속도 센서로 `idle`, `sudden stop`, `nominal`을 분류한다.
- 충돌 데이터를 직접 만들 수 없으므로 분류와 함께 이상 감지(K-Means)를 병용한다.
- DSP는 Spectral Analysis를 쓰고, 정기 평가와 능동 학습, 데이터 확대로 반복 개선한다.
