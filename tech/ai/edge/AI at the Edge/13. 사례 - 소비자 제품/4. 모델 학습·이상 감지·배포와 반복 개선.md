# 모델 학습·이상 감지·배포와 반복 개선

가속도 데이터에서 스펙트럼 특징을 뽑아 분류 모델을 학습한다. 여기에 처음 보는 상황을 잡아내는 이상 감지 블록을 더하고, 테스트와 배포까지 진행하는 과정을 정리한다. 마지막에는 개선 방향을 다룬다.

---

## 1. 임펄스 설계(Impulse design)

- **구성**: 원시 데이터 블록, DSP 블록, 학습 블록이 차례로 이어지고, 출력은 클래스(idle, sudden stop, nominal)다. 주파수가 서로 다른 데이터는 다운샘플링이나 업샘플링으로 맞출 수 있다.
- **설정값**: 데이터는 시계열이다. 윈도우 크기는 5,000 ms, 윈도우 증가는 250 ms, 주파수는 62.5Hz로 하고 제로 패딩을 사용한다.
- **블록 선택**: 처리 블록은 Spectral Analysis를 쓴다. 학습 블록은 두 개로, Classification (Keras)와 Anomaly detection (K-Means)이다.

---

## 2. 신호 처리(DSP) 블록: Spectral Analysis

- **Spectral Analysis**: Edge Impulse가 기본으로 제공하는 블록이며 무료로 쓰고 배포할 수 있다. 코드는 GitHub `processing-blocks`에 있다.
- **필터**: Scale axes는 1, Type은 none으로 둔다.
- **스펙트럼 파워**: FFT 길이는 16으로 하고, 스펙트럼 로그 취하기와 FFT 프레임 겹치기를 켠다.
- **특징 중요도(feature importance)**: Generate features 화면에서 Calculate feature importance를 체크해야 이상 감지의 고급 기능을 쓸 수 있다. 특징을 생성한 뒤에는 특징 탐색기와 중요도 목록을 확인한다.

---

## 3. 분류 모델 학습

- **학습 방식**: 시각적(Visual) 모드가 가장 쉽다. Keras에 익숙하다면 전문가(Expert) 모드를 쓴다. 로컬에서 편집하는 방법은 앞선 장의 설명을 참고하라고 안내한다.
- **설정**: 학습 주기는 30, 학습률은 0.0005, 검증 세트는 20%로 하고 자동 균형은 끈다.
- **구조**: 밀집층(Dense) 두 개로, 뉴런이 각각 20개와 10개다.
- **결과**: Model 화면의 Last training performance에서 확인한다.

---

## 4. 이상 감지(anomaly detection)

- **필요한 이유**: 신경망은 학습한 범위 안의 패턴을 알아보는 데는 강하지만, 처음 보는 데이터는 제대로 분류하지 못한다.
- **방법**: Anomaly detection 탭에서 Select suggested axes 버튼을 눌러, 특징 중요도를 바탕으로 추천된 축을 고른다. 그다음 Start training을 누르면 이상 탐색기(Anomaly explorer)가 나온다.
- **K-Means**: 이 학습 블록은 K-Means를 기반으로 한다. 충돌 같은 희귀한 이벤트를 직접 수집하기 어려운 이 사례에 알맞은 방식이다.

---

## 5. 테스트와 배포

- **실시간 분류**: 연결해 둔 Thingy:53에서 샘플을 바로 분류해 볼 수 있다. 이미 있는 테스트 샘플을 불러와서 예측 결과를 봐도 된다.
- **모델 테스트**: Classify all를 실행해서 혼동 행렬을 확인한다. 데이터가 적어서 결과가 실제로 쓸 만큼 좋아 보이지는 않지만, 데이터를 늘릴수록 나아진다. 실전 수준의 모델은 9장에서 다룬다.
- **배포**: Deployment 탭에서 공식 지원 플랫폼을 고르고 Build한다. EON Compiler는 켜고 끌 수 있다. 빌드로 나온 펌웨어는 드래그 앤 드롭하거나 화면 안내에 따라 보드에 플래시한다.
- **소스 코드**: 공개 프로젝트의 배포 라이브러리와 완성된 코드는 GitHub 저장소에 있다.

---

## 6. 반복 개선과 피드백 루프

- **하드웨어 개선**: 더 민감한 센서나 성능이 높은 CPU를 쓰면 충돌 감지 감도를 높일 수 있다.
- **능동 학습(active learning)**: DSP와 신경망 알고리즘을 개선한다. 이를 위한 전략은 9장과 10장에 더 나온다.
- **데이터 확대**: 기존 클래스의 데이터를 늘리고 새 클래스를 추가한다.
- **정기 평가**: 모델은 학습 데이터를 수집한 장소와 환경에서만큼만 좋은 성능을 낸다. 그러므로 주기적으로 성능을 평가한다.
- **변형 실험**: 가속도 센서 대신 핸들바에 카메라를 달아 보거나, 장치 위치를 핸들바에서 머리로 옮겨 본다.
