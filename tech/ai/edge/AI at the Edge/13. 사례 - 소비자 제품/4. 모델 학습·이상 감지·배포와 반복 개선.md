# 모델 학습·이상 감지·배포와 반복 개선

가속도 데이터에서 스펙트럼 특징을 뽑아 분류 모델을 학습하고, 처음 보는 상황을 위한 이상 감지 블록을 더한 뒤 테스트하고 배포하는 과정을 정리한다. 마지막에 개선 방향을 다룬다.

---

## 1. 임펄스 설계(Impulse design)

- **구성**: 원시 데이터 블록, DSP 블록, 학습 블록, 출력 클래스(idle, sudden stop, nominal)로 이어진다. 주파수가 다른 데이터는 다운샘플링·업샘플링할 수 있다.
- **설정값**: 시계열 데이터, 윈도우 크기 5,000 ms, 윈도우 증가 250 ms, 주파수 62.5Hz, 제로 패딩 사용.
- **블록 선택**: 처리 블록 Spectral Analysis, 학습 블록 두 개인 Classification (Keras)와 Anomaly detection (K-Means).

---

## 2. 신호 처리(DSP) 블록: Spectral Analysis

- **Spectral Analysis**: Edge Impulse 기본 제공 블록으로 무료 사용·배포가 가능하며 코드는 GitHub `processing-blocks`에 있다.
- **필터**: Scale axes 1, Type none.
- **스펙트럼 파워**: FFT 길이 16, 스펙트럼 로그 취하기 사용, FFT 프레임 겹치기 사용.
- **특징 중요도(feature importance)**: Generate features 화면에서 Calculate feature importance를 체크해야 이상 감지의 고급 기능을 쓸 수 있다. 생성 후 특징 탐색기와 중요도 목록을 확인한다.

---

## 3. 분류 모델 학습

- **학습 방식**: 시각적(Visual) 모드가 가장 쉽고, Keras에 익숙하면 전문가(Expert) 모드를 쓴다. 로컬 편집은 앞선 장의 설명을 참고하라고 안내한다.
- **설정**: 학습 주기 30, 학습률 0.0005, 검증 세트 20%, 자동 균형 해제.
- **구조**: 밀집층(Dense) 20 뉴런과 10 뉴런.
- **결과**: Model: Last training performance 화면에서 확인한다.

---

## 4. 이상 감지(anomaly detection)

- **필요성**: 신경망은 학습한 범위의 패턴 인식에는 강하지만, 처음 보는 데이터는 제대로 분류하지 못한다.
- **방법**: Anomaly detection 탭에서 Select suggested axes 버튼으로 특징 중요도 기반 추천 축을 고르고 Start training을 누르면 이상 탐색기(Anomaly explorer)가 나온다.
- **K-Means**: 학습 블록은 K-Means 기반이다. 충돌 같은 희귀 이벤트를 직접 수집하기 어려운 이 사례에 알맞다.

---

## 5. 테스트와 배포

- **실시간 분류**: 연결한 Thingy:53에서 샘플을 바로 분류하거나 기존 테스트 샘플을 불러 예측을 본다.
- **모델 테스트**: Classify all로 혼동 행렬을 본다. 분량이 적은 데이터라 결과가 실전용으로는 좋아 보이지 않지만, 데이터를 늘릴수록 개선된다. 실전 수준의 모델은 9장에서 다룬다.
- **배포**: Deployment 탭에서 공식 지원 플랫폼을 고르고 Build한다. EON Compiler를 켜고 끌 수 있다. 결과 펌웨어를 드래그 앤 드롭이나 안내에 따라 플래시한다.
- **소스 코드**: 공개 프로젝트의 배포 라이브러리와 완성 코드는 GitHub 저장소에 있다.

---

## 6. 반복 개선과 피드백 루프

- **하드웨어 개선**: 더 민감한 센서나 고성능 CPU로 충돌 감도를 높인다.
- **능동 학습(active learning)**: DSP와 신경망 알고리즘을 개선한다. 9장과 10장에 전략이 더 있다.
- **데이터 확대**: 기존 클래스 데이터를 늘리고 새 클래스를 추가한다.
- **정기 평가**: 모델은 학습 데이터를 수집한 장소와 환경만큼만 좋으므로 주기적으로 성능을 평가한다.
- **변형 실험**: 가속도 센서 대신 핸들바 카메라를 쓰거나, 장치 위치를 핸들바에서 머리로 옮겨 본다.
