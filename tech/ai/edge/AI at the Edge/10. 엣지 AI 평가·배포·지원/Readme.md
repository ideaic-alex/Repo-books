# 10. 엣지 AI 평가·배포·지원

이 장은 이론 파트의 마지막으로, 엣지 AI 애플리케이션을 평가(evaluation)하고 배포(deployment)하고 지원(support)하는 과정을 다룬다. 세 활동은 서로 긴밀하게 얽혀 있어 반복 개발 속에서 개발 내내 병행된다. 평가 지표와 기법, 단계적 배포 절차, 배포 후 모니터링과 장기 윤리까지 하나의 흐름으로 정리한다.

---

## 핵심 요점

- 평가는 개발 전(기존 솔루션·기준선 측정)부터 최적화 전후, 실제 하드웨어, 제한적 배포, 배포 후까지 전 단계에서 이뤄진다.
- 구성 요소 평가, 통합 평가, 모사 실환경 시험, 실환경 시험(QA·사용성)을 상황에 맞게 조합한다.
- 정확도 하나로는 부족하며 혼동 행렬, 정밀도·재현율, 신뢰도 임계값, ROC/AUC, 회귀 오차 지표, mAP를 목적에 맞게 고른다.
- 엣지에서는 알고리즘 성능과 함께 RAM/ROM, 지연 시간, 듀티 사이클, 에너지, 열을 함께 관리한다.
- 테스트 데이터셋은 마지막에만 쓰고, 교차 검증과 하위 그룹 분석, 합성 데이터, 성능 보정으로 평가를 보강한다.
- 배포는 목표·지표·위험·복구 계획을 문서화하고 단계적 롤아웃과 진행/중단 결정을 거치는 반복 과정이다.
- 운영 후에는 데이터 샘플, 분포 변화, 애플리케이션 지표, 결과, 사용자 보고로 피드백을 모으고, 여러 버전이 공존하는 현장을 추적한다.
- 책임 있는 설계는 중단 기준, 수명 종료 계획, 변화하는 문화·법적 기준까지 포함한 전 수명주기를 책임지는 것이다.
