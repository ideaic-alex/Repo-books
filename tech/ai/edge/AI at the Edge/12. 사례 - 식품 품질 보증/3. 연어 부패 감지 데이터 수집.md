# 연어 부패 감지 데이터 수집

이 장의 실습은 가스 센서로 연어 필렛이 신선한지 상했는지 분류하는 모델을 만드는 것이다. 이 문서는 클래스 설계, 하드웨어 선택, 데이터 수집 펌웨어와 업로드 절차, 데이터셋 정리까지 다룬다.

---

## 1. 실습 개요

- **목표**: 구매 직후(신선)의 연어와 상한 연어를 구별한다.
- **클래스 3개**: `spoiled`(상함), `purchase_date`(구매일, 신선), `ambient`(주변 환경)다. 주변 환경 클래스를 따로 두는 이유는 연어가 없을 때의 공기를 연어와 구별하기 위해서다.
- **동작 방식**: 장치가 가스 센서의 원본 샘플을 계속 읽고, 모델이 이를 추론한다. 상했다고 판단하면 결과와 가스 신호를 네트워크로 보내거나 장치에 저장해 두고, 이후 처리는 사람이나 클라우드가 맡는다.
- **플랫폼**: Edge Impulse 무료 계정이 필요하다. 이 장에서 만든 공개 프로젝트도 제공된다.
- **데이터 확보 전략**: 공개된 연구 데이터셋을 가져다 쓰거나, Kaggle 같은 커뮤니티의 센서 데이터를 활용하거나, 동료와 함께 프로젝트에 샘플을 모은다.

---

## 2. 하드웨어와 센서

- **Arduino Nicla Sense ME**: Edge Impulse가 공식 지원하는 개발 키트다.
- **Bosch BME688**: 이 보드에 내장된 가스 센서다. 휘발성 유기화합물(VOC), 휘발성 황화합물(VSC), 일산화탄소, 수소 등을 ppb 단위로 감지한다.
- **정확도를 높이는 추가 센서**: 암모니아, 메탄, 산소 같은 다른 가스 센서와 온도, 압력, 습도, 레이더, 공기질 센서를 더할 수 있다.
- **센서 퓨전(sensor fusion)**: 서로 다른 센서의 데이터를 결합해서 환경을 더 정확하게 파악하는 임베디드 기법이다.

---

## 3. 데이터 수집 펌웨어

- **스케치 구성**: 새 폴더 `food`에 `food.ino`를 만든다. 이 스케치는 `Arduino_BHY2.h`를 쓰고, 샘플링 주파수 `FREQUENCY_HZ`를 10으로 둔다. 시리얼은 115200 baud로 설정해서 가스 값을 한 줄씩 출력한다.
- **Arduino CLI**: 코어와 라이브러리를 설치한 뒤 컴파일하고 업로드한다.

```
arduino-cli core install arduino:mbed_nicla
arduino-cli lib install Arduino_BHY2
arduino-cli compile --fqbn arduino:mbed_nicla:nicla_sense --output-dir . --verbose
arduino-cli upload --fqbn arduino:mbed_nicla:nicla_sense --input-dir . --verbose
```

---

## 4. Edge Impulse로 업로드

- **데이터 포워더(data forwarder)**: `edge-impulse-data-forwarder`를 실행해서 로그인하고, 장치와 프로젝트를 고른다. 주파수 10Hz는 자동으로 감지되고, 축 이름은 `gas`로 지정한다.
- **샘플링 설정**: Data acquisition 탭에서 레이블(`spoiled`, `purchase_date`, `ambient`), 길이 1,200,000 ms(20분), 센서(1축 gas), 주파수 10Hz를 설정하고 Start sampling을 누른다.
- **수집량**: 학습용과 테스트용을 합쳐서 클래스마다 최소 20~60분 분량을 목표로 한다.
- **자동 샘플링 요령**: 브라우저 개발자 콘솔에서 JavaScript로 `input-start-sampling` 버튼을 22분(1,320,000 ms)마다 자동으로 클릭하게 만들 수 있다.
- **장치 배치**: 상한 음식, 신선한 음식, 또는 방 안의 주변 공기 가까이에 보드를 둔다.

---

## 5. 데이터셋 정리와 법적 확인

- **샘플 분할(Split sample)**: 20분짜리 샘플은 내용을 파악하기 어려우므로 약 30,000 ms(29,880 ms) 길이의 하위 샘플로 나눈다. 샘플 하나에서 보통 4개쯤 나오며, `+ Add sample`로 구간을 추가한다.
- **자르기(Crop sample)**: 샘플 메뉴에서 필요 없는 구간을 잘라 낼 수 있다.
- **라이선스(licensing)**: 직접 수집한 데이터는 문제가 없다. 하지만 공개된 출처의 가스 데이터를 섞어 쓴다면, 먼저 사용 규칙과 출처 표기 요건을 확인해야 한다.
