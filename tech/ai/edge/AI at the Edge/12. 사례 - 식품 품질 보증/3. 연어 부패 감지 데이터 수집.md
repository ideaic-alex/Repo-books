# 연어 부패 감지 데이터 수집

이 장의 실습은 가스 센서로 연어 필렛이 신선한지 상했는지 분류하는 모델을 만드는 것이다. 이 문서는 클래스 설계, 하드웨어 선택, 데이터 수집 펌웨어와 업로드 절차, 데이터셋 정리까지 다룬다.

---

## 1. 실습 개요

- **목표**: 구매 직후(신선)인 연어와 상한 연어를 구별한다.
- **클래스 3개**: `spoiled`(상함), `purchase_date`(구매일, 신선), `ambient`(주변 환경). 주변 환경 클래스를 두어 연어가 없을 때의 공기와 구별되게 한다.
- **동작 방식**: 장치가 가스 센서의 원시 샘플을 계속 읽고 모델이 추론한다. 상했다고 판단하면 결과와 가스 신호를 네트워크로 보내거나 장치에 저장해 사람이나 클라우드가 이어서 처리한다.
- **플랫폼**: Edge Impulse 무료 계정이 필요하고, 장의 공개 프로젝트도 제공된다.
- **데이터 확보 전략**: 공개 연구 데이터셋 결합, Kaggle 같은 커뮤니티 센서 데이터, 동료와 함께 프로젝트에 샘플 수집.

---

## 2. 하드웨어와 센서

- **Arduino Nicla Sense ME**: Edge Impulse가 공식 지원하는 개발 키트.
- **Bosch BME688**: 보드에 내장된 가스 센서. 휘발성 유기화합물(VOC), 휘발성 황화합물(VSC), 일산화탄소, 수소 등을 ppb 단위로 감지한다.
- **정확도를 높일 추가 센서**: 암모니아·메탄·산소 등 다른 가스, 온도, 압력, 습도, 레이더, 공기질.
- **센서 퓨전(sensor fusion)**: 서로 다른 센서의 데이터를 결합해 환경을 더 정확히 파악하는 임베디드 기법.

---

## 3. 데이터 수집 펌웨어

- **스케치 구성**: 새 폴더 `food`에 `food.ino`를 만든다. `Arduino_BHY2.h`를 쓰며 샘플링 주파수는 `FREQUENCY_HZ` 10, 시리얼은 115200 baud로 가스 값을 한 줄씩 출력한다.
- **Arduino CLI**: 코어와 라이브러리를 설치한 뒤 컴파일·업로드한다.

```
arduino-cli core install arduino:mbed_nicla
arduino-cli lib install Arduino_BHY2
arduino-cli compile --fqbn arduino:mbed_nicla:nicla_sense --output-dir . --verbose
arduino-cli upload --fqbn arduino:mbed_nicla:nicla_sense --input-dir . --verbose
```

---

## 4. Edge Impulse로 업로드

- **데이터 포워더(data forwarder)**: `edge-impulse-data-forwarder`를 실행해 로그인하고 장치와 프로젝트를 고른다. 주파수 10Hz가 자동 감지되고, 축 이름은 `gas`로 지정한다.
- **샘플링 설정**: Data acquisition 탭에서 라벨(`spoiled`, `purchase_date`, `ambient`), 길이 1,200,000 ms(20분), 센서(1축 gas), 주파수 10Hz로 설정하고 Start sampling을 누른다.
- **수집량**: 훈련과 테스트를 합쳐 클래스당 최소 20~60분 분량을 목표로 한다.
- **자동 샘플링 요령**: 브라우저 개발자 콘솔의 JavaScript로 `input-start-sampling` 버튼을 22분(1,320,000 ms)마다 자동 클릭하게 만들 수 있다.
- **장치 배치**: 상한 음식, 신선한 음식, 또는 방 안 주변 공기 가까이에 보드를 둔다.

---

## 5. 데이터셋 정리와 법적 확인

- **샘플 분할(Split sample)**: 20분짜리 샘플을 내용 파악이 쉽도록 약 30,000 ms(29,880 ms) 하위 샘플로 나눈다. 한 샘플에서 보통 4개 정도를 얻으며 `+ Add sample`로 구간을 추가한다.
- **자르기(Crop sample)**: 샘플 메뉴에서 불필요한 구간을 잘라낼 수 있다.
- **라이선스(licensing)**: 직접 수집한 데이터라 문제가 없다. 공개 출처 가스 데이터를 섞는다면 사용 규칙과 출처 표기 요건을 먼저 확인해야 한다.
