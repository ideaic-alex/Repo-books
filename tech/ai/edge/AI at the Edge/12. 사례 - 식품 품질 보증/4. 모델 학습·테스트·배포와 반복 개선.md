# 모델 학습·테스트·배포와 반복 개선

수집한 가스 데이터에서 신호 처리(DSP)로 특징을 뽑고, 신경망을 학습해서 테스트한 뒤 Nicla Sense ME에 배포하는 과정을 정리한다. 끝부분에서는 개선 아이디어와 심화 사례인 완벽한 토스트 기계를 다룬다.

---

## 1. 임펄스 설계(Impulse design)

- **임펄스 설계**: Edge Impulse에서 DSP와 머신러닝 학습 파이프라인을 부르는 이름이다. 원본 데이터 블록, DSP 블록, 학습 블록, 출력(클래스) 순으로 이어진다.
- **원본 데이터 블록**: 데이터를 수집한 주파수가 서로 다르면 다운샘플링이나 업샘플링도 이 블록에서 할 수 있다.
- **설정값**: 시계열 데이터, 윈도우 크기 10,000 ms, 윈도우 증가 500 ms, 주파수 10Hz로 두고 제로 패딩을 사용한다.
- **블록 선택**: 처리 블록은 Flatten, 학습 블록은 Classification (Keras)을 고른다. 설정을 마치면 Save Impulse를 누른다.

---

## 2. 신호 처리(DSP) 블록: Flatten

- **Flatten**: Edge Impulse가 기본으로 제공하는 블록이다. 무료로 쓰고 배포할 수 있으며, 코드는 GitHub의 `processing-blocks`에 공개되어 있다. 직접 만든 커스텀 DSP 블록을 쓸 수도 있다.
- **스케일(Scale axes)**: 0.001로 둔다.
- **통계 방법**: 평균, 최소, 최대, RMS(제곱평균제곱근), 표준편차는 선택하고, 왜도(skewness)와 첨도(kurtosis)는 선택하지 않는다.
- **특징 생성**: Save parameters를 누른 뒤 Generate features를 누르면 특징 탐색기(feature explorer)에서 클래스가 얼마나 잘 갈라지는지 볼 수 있다.

---

## 3. 머신러닝 블록

- **학습 방식**: 가장 쉬운 방법은 시각적(Visual) 모드다. TensorFlow/Keras에 익숙하다면 전문가(Expert) 모드에서 코드를 올리거나 로컬에서 고칠 수 있다.
- **학습 설정**: 학습 주기(epoch)는 50, 학습률은 0.0005, 검증 세트는 20%로 두고, 데이터셋 자동 균형 맞추기는 끈다.
- **구조**: 밀집층(Dense) 8 뉴런, 밀집층 4 뉴런, 평탄화층(Flatten layer)으로 구성한다.
- **층의 역할**: 밀집층은 모든 뉴런이 서로 연결된 완전 연결층으로, 가장 단순한 형태다. DSP 출력처럼 이미 가공한 데이터에 쓴다. 평탄화층은 다차원 데이터를 1차원으로 바꾼다.
- **결과 확인**: 학습이 끝나면 Model: Last training performance 화면에서 성능을 본다.

---

## 4. 테스트

- **실시간 분류(Live classification)**: 연결해 둔 Nicla Sense ME의 샘플을 바로 분류해 볼 수 있다. 기존 테스트 샘플을 골라서 추출한 특징과 예측 결과를 확인할 수도 있다.
- **모델 테스트(Model testing)**: Classify all를 누르면 전체 테스트 데이터셋을 한꺼번에 분류하고, 그 결과를 혼동 행렬(confusion matrix)로 보여 준다.

---

## 5. 배포(deployment)

- **사전 빌드 바이너리**: 공식 지원 플랫폼을 고르고 Build한다. EON Compiler는 켜거나 끌 수 있다.
- **이 실습의 선택**: Arduino 라이브러리로 배포한다. 내려받은 ZIP을 Arduino IDE로 가져온(Import) 뒤, Nicla Sense용 예제 `nicla_sense_fusion.ino`를 저장한다.
- **플래시**: IDE에서 바로 올리거나 CLI로 컴파일하고 업로드한다. 그다음 시리얼 터미널(115200 baud)에서 추론 결과를 확인한다.

```
cd nicla_sense_fusion
arduino-cli compile --fqbn arduino:mbed_nicla:nicla_sense --output-dir . --verbose
arduino-cli upload --fqbn arduino:mbed_nicla:nicla_sense --input-dir . --verbose
```

## 6. 반복 개선과 피드백 루프

- **클래스 확장**: 다른 종류의 식품이나 구매일 이후 경과 일수를 구분하는 클래스를 추가한다.
- **케이스 제작**: 식품 오염물이 센서 값에 영향을 주지 않도록 장치를 감싸는 케이스를 만든다.
- **센서 추가**: 온도나 습도 축을 센서 퓨전으로 입력에 더한다.
- **다중 모델**: 부패 감지와 알레르겐 감지처럼 목표가 비슷한 모델 여러 개를 병렬로, 또는 근처에 있는 다른 장치에서 함께 돌린다.

---

## 7. 심화 사례: 완벽한 토스트 기계

- **Shawn Hymel의 토스터**: Edge Impulse를 써서, 빵의 두께와 조성, 시작 온도와 상관없이 완벽한 토스트를 만든다.
- **방식**: 여러 가스 센서의 데이터로 회귀(regression) 모델을 학습해서 빵이 타는 시점을 예측한다. 마이크로컨트롤러가 냄새 데이터를 계속 추론하다가, 타기 45초 전에 가열을 멈춘다.
- **의의 1**: 타이머와 감에 의존하지 않고 센서로 요리하는 주방 가전의 가능성을 보여 주고, 너무 익혀서 버리는 음식을 줄인다.
- **의의 2**: 예지 정비(predictive maintenance)의 예시이기도 하다. 토스트를 기계 부품으로 바꿔 놓고 보면 고장 나기 전에 부품의 이상을 예측하는 문제와 같고, 이는 산업 장비의 가동 중단 비용을 줄이는 일로 이어진다.
