# 사례 - 식품 품질 보증

엣지 AI로 식품의 부패와 오염을 일찍 찾아내서 식품 폐기를 줄이고 소비자와 작업자의 안전을 높이는 사례를 다룬다. 이 장은 접근법을 폭넓게 살펴본 뒤, 가스 센서와 마이크로컨트롤러로 연어의 신선도를 분류하는 모델을 처음부터 배포까지 구현한다.

---

## 핵심 요점

- 식품 품질 보증은 범위가 넓어서, 가정 주방, 제조 라인, 마트 보관으로 좁혀 폐기 방지에 집중한다.
- 접근법은 부패 감지, 위생 규정 준수 모니터링, 생산 품질 관리, 교차 오염·알레르겐 감지 등으로 나뉘며, 목표마다 센서와 클래스가 다르다.
- 데이터를 구하기 얼마나 어려운지, 장치를 어디에 둘지, 전원, 환경 내구성, 센서 수명과 예열 같은 현실 조건을 설계 초기에 따져 봐야 한다.
- 실습에서는 Arduino Nicla Sense ME의 BME688 가스 센서로 `spoiled`, `purchase_date`, `ambient` 세 클래스를 분류한다.
- 신호 처리(DSP)에는 Flatten 블록을, 학습에는 작은 밀집 신경망(Keras)을 쓰고, Arduino 라이브러리로 배포한다.
- 클래스 확장, 센서 퓨전, 케이스 제작 등으로 반복해서 개선하며, 토스트 기계 사례는 예지 정비로 이어진다.
