# 데이터셋 확보와 Edge Impulse 준비

이 장의 튜토리얼은 Edge Impulse Studio에서 진행하며, 데이터는 현장 촬영 대신 시민 과학 플랫폼 iNaturalist의 라벨된 이미지를 내려받아 만든다. 이 문서는 플랫폼과 하드웨어 선택, 데이터 수집 경로, iNaturalist 쿼리와 다운로드, 데이터의 한계와 라이선스, 업로드 방법을 정리한다.

---

## 1. 데이터셋 확보 전략

- **공개 데이터 결합**: 연구용 공개 데이터셋을 조합하고, 동물이 없는 환경 이미지를 여러 곳에서 모아 대상 종 이미지와 합친다.
- **대형 이미지 데이터셋 활용**: COCO(common objects in context) 같은 기존 대규모 데이터셋을 이용할 수 있다.
- **관련 없어 보이는 데이터의 활용**: 같은 지역의 다른 종 데이터를 비대상 클래스로 쓰면 되고, 그 안에 대상 종이 섞여 있어도 학습 후 모델이 찾아낼 수 있다.

---

## 2. Edge Impulse와 하드웨어

- **Edge Impulse Studio**: 데이터 수집·라벨링, DSP 특징 추출, 모델 설계·학습, 테스트, SDK를 통한 라이브러리 배포까지 한곳에서 하는 무료 클라우드 플랫폼이다. 무료 계정이 필요하다.
- **공개 프로젝트**: 장마다 공개 프로젝트가 있고 Clone 버튼으로 데이터와 모델, 배포 옵션까지 통째로 복제할 수 있다.
- **기기 중립**: 비영리 용도를 가정해 접근성이 좋은 개발 키트를 쓰며, 이 장은 RGB 카메라가 달린 OpenMV Cam H7 Plus를 가정한다. 공식 지원 보드가 아니어도 배포된 C++ 라이브러리를 직접 통합하면 쓸 수 있다.
- **Raspberry Pi 비교**: 단일 현장 기기는 개발이 빠르고 저렴할 수 있지만 전력 요구가 크고, 대량 배치 시에는 MCU와 통합 센서 조합보다 비싸다.
- **이 구성의 한계**: 주간에만 안정적이고, 먼 거리의 동물은 화질이 부족할 수 있으며, 배터리 소모가 클 수 있고, 특정 색 동물을 그레이스케일로 잡으면 예측이 부정확하다.
- **개선 옵션**: 고화질·저화질 카메라, 적외선·열화상, 그레이스케일 대 RGB, 렌즈 초점거리, 입력 해상도.

---

## 3. Edge Impulse 데이터 수집 경로

- **Studio 업로더**: 웹에서 파일을 올리고 파일명으로 자동 라벨링할 수 있다.
- **CLI 업로더**: 터미널에서 업로드한다.
- **수집 API(ingestion API)**: 프로젝트 API 키로 스크립트에서 타이머·트리거 기반 업로드를 한다.
- **데이터 소스**: 클라우드 버킷과 연동하며, 액티브 러닝(active learning)으로 모델을 개선할 때 유용하다.
- **기기 직접 연결**: 공식 지원 보드는 펌웨어 가이드를 따르고, 비지원 기기는 포팅 가이드 또는 CLI serial data forwarder를 쓴다. 휴대폰이나 컴퓨터 카메라로도 Devices 탭에서 바로 올릴 수 있다.

---

## 4. iNaturalist에서 데이터 받기

1. iNaturalist 내보내기 사이트에서 대상 종 이름으로 쿼리해 CSV를 받는다. 열은 `id`, `user_login`, `quality_grade`, `license`, `url`, `image_url`이다.
2. 같은 열로 네덜란드(place ID 7506)의 unknown 이미지 쿼리를 한 번 더 해 CSV를 받는다.
3. 파이썬 스크립트로 CSV의 `url`을 읽어 이미지를 내려받고, 파일명을 `id.user_login.확장자`로 만들어 업로더를 표기한다. 스크립트는 클래스마다 한 번씩 돌려 `/animal/`과 `/unknown/`에 나눠 저장한다.

```
q=Callosciurus+finlaysonii&search_on=names&has%5B%5D=photos
  &quality_grade=any&identifications=any
```

- **분량**: 쿼리 결과는 4,000건 이하를 권장하며, 연구 등급(research grade)이나 특정 place ID로 줄일 수 있다.
- **URL 쿼리 문자열**: 이미지 URL에 쿼리가 붙으면 확장자 추출 시 `url.split("?")[0]`로 제거한다.

## 5. 데이터셋의 한계와 법적 의무

- **개체 중복 문제**: 표식 없는 동물은 여러 개체인지 한 개체가 반복 진입한 것인지 구분할 수 없다.
- **근접 촬영 편향**: iNaturalist는 크게 찍힌 동물 사진이 많아 배경이 적고, 모델이 동물이 늘 가까이 있다고 기대할 수 있다.
- **액티브 러닝으로 보완**: 부족한 모델을 먼저 배포해 새 이미지를 모으고, 확인·라벨링 후 학습 데이터에 추가해 재학습·재배포한다.
- **Edge Impulse 약관**: 개인정보 정책, 이용약관, Responsible AI 라이선스, DMCA 정책을 따라야 하며, 책 집필 시점(2022)에는 무료 사용자도 배포 대수 제한 없이 무료로 배포할 수 있었다. 자기 데이터의 지식재산권은 유지된다.
- **제3자 데이터**: iNaturalist 등에서 받은 데이터는 재배포·상업 이용이 가능한지 확인해야 하고, Creative Commons나 Apache 같은 라이선스를 판단해야 하며, 의심되면 소유자나 사이트에 문의한다.

---

## 6. 정제와 업로드

- **정제**: iNaturalist 이미지는 이미 라벨이 있어 추가 정제가 거의 필요 없다.
- **데이터 탐색기(data explorer)**: 라벨된 소량과 라벨 없는 대량이 있을 때, 사전 학습 모델이나 학습된 impulse로 대량 라벨링을 돕는다. 종 이름은 MobileNetV2 같은 ImageNet 사전 학습에 없으므로 먼저 소규모로 학습해야 한다. 차원 축소는 t-SNE(소규모에 적합)와 PCA(모든 규모) 중 선택한다.
- **업로드**: 웹 GUI 또는 CLI를 쓰며, 둘 다 학습/테스트를 80/20으로 자동 분할할 수 있다.

```
edge-impulse-uploader --api-key [your-api-key] --label [label] --category split [directory]/*
```
