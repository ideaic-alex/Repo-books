# 데이터셋 확보와 Edge Impulse 준비

이 장의 튜토리얼은 Edge Impulse Studio에서 진행한다. 데이터는 현장에서 직접 찍지 않고, 시민 과학 플랫폼 iNaturalist에서 레이블이 달린 이미지를 내려받아 만든다. 이 문서는 플랫폼과 하드웨어 선택, 데이터 수집 경로, iNaturalist 쿼리와 다운로드, 데이터의 한계와 라이선스, 업로드 방법을 정리한다.

---

## 1. 데이터셋 확보 전략

- **공개 데이터 조합**: 연구용으로 공개된 데이터셋을 조합한다. 동물이 없는 환경 이미지는 여러 곳에서 모아서 대상 종 이미지와 합친다.
- **대형 이미지 데이터셋 활용**: COCO(common objects in context) 같은 기존 대규모 데이터셋을 이용할 수 있다.
- **관련 없어 보이는 데이터 활용**: 같은 지역에 사는 다른 종의 데이터를 비대상 클래스로 쓰면 된다. 그 안에 대상 종이 섞여 있어도, 학습이 끝난 모델이 찾아낼 수 있다.

---

## 2. Edge Impulse와 하드웨어

- **Edge Impulse Studio**: 데이터 수집과 레이블링, DSP 특징 추출, 모델 설계와 학습, 테스트, SDK를 통한 라이브러리 배포까지 한곳에서 할 수 있는 무료 클라우드 플랫폼이다. 무료 계정이 필요하다.
- **공개 프로젝트**: 장마다 공개 프로젝트가 있다. Clone 버튼을 누르면 데이터, 모델, 배포 옵션까지 통째로 복제된다.
- **특정 장치에 묶이지 않음**: 비영리 용도를 가정해서 구하기 쉬운 개발 키트를 쓴다. 이 장은 RGB 카메라가 달린 OpenMV Cam H7 Plus를 쓴다고 가정한다. 공식 지원 보드가 아니어도 배포된 C++ 라이브러리를 직접 통합하면 쓸 수 있다.
- **Raspberry Pi와 비교**: 현장 장치가 하나뿐이라면 개발이 빠르고 저렴할 수 있다. 하지만 전력을 많이 쓰고, 대량으로 설치할 때는 MCU에 센서를 통합한 구성보다 비싸다.
- **이 구성의 한계**: 낮에만 안정적으로 동작한다. 먼 거리의 동물은 화질이 부족할 수 있고, 배터리 소모가 클 수 있다. 특정 색의 동물을 그레이스케일로 찍으면 예측이 부정확하다.
- **개선 옵션**: 고화질 또는 저화질 카메라, 적외선과 열화상, 그레이스케일과 RGB 중 선택, 렌즈 초점거리, 입력 해상도를 바꿔 볼 수 있다.

---

## 3. Edge Impulse 데이터 수집 경로

- **Studio 업로더**: 웹에서 파일을 올린다. 파일명으로 자동 레이블링할 수도 있다.
- **CLI 업로더**: 터미널에서 업로드한다.
- **수집 API(ingestion API)**: 프로젝트 API 키를 써서 스크립트에서 업로드한다. 타이머나 트리거에 맞춰 올리는 식으로 쓴다.
- **데이터 소스**: 클라우드 버킷과 연동한다. 액티브 러닝(active learning)으로 모델을 개선할 때 유용하다.
- **장치 직접 연결**: 공식 지원 보드는 펌웨어 가이드를 따른다. 지원하지 않는 장치는 포팅 가이드나 CLI의 serial data forwarder를 쓴다. 휴대폰이나 컴퓨터 카메라는 Devices 탭에서 바로 올릴 수 있다.

---

## 4. iNaturalist에서 데이터 받기

1. iNaturalist 내보내기 사이트에서 대상 종 이름으로 쿼리해 CSV를 받는다. 열은 `id`, `user_login`, `quality_grade`, `license`, `url`, `image_url`이다.
2. 같은 열로 네덜란드(place ID 7506)의 unknown 이미지를 쿼리해 CSV를 한 번 더 받는다.
3. 파이썬 스크립트로 CSV의 `url`을 읽어 이미지를 내려받는다. 파일명은 `id.user_login.확장자`로 만들어 업로더를 표기한다. 스크립트는 클래스마다 한 번씩 돌려서 `/animal/`과 `/unknown/` 폴더에 나눠 저장한다.

```
q=Callosciurus+finlaysonii&search_on=names&has%5B%5D=photos
  &quality_grade=any&identifications=any
```

- **분량**: 쿼리 결과는 4,000건 이하를 권장한다. 연구 등급(research grade)이나 특정 place ID로 범위를 줄일 수 있다.
- **URL 쿼리 문자열**: 이미지 URL 뒤에 쿼리 문자열이 붙어 있으면 확장자를 뽑을 때 방해가 된다. `url.split("?")[0]`로 쿼리 문자열을 제거한다.

## 5. 데이터셋의 한계와 법적 의무

- **개체 중복 문제**: 표식이 없는 동물은 서로 다른 개체인지, 한 개체가 여러 번 찍힌 것인지 구분할 수 없다.
- **근접 촬영 편향**: iNaturalist에는 동물이 크게 찍힌 사진이 많아 배경이 적다. 그래서 모델이 동물이 늘 가까이 있다고 기대하게 될 수 있다.
- **액티브 러닝으로 보완**: 부족한 모델을 먼저 배포해 새 이미지를 모은다. 이 이미지를 확인하고 레이블링해서 학습 데이터에 추가한 뒤, 다시 학습하고 재배포한다.
- **Edge Impulse 약관**: 개인정보 정책, 이용약관, Responsible AI 라이선스, DMCA 정책을 따라야 한다. 책을 쓴 시점(2022)에는 무료 사용자도 배포 대수 제한 없이 무료로 배포할 수 있었다. 자기 데이터의 지식재산권은 그대로 유지된다.
- **제3자 데이터**: iNaturalist 등에서 받은 데이터는 재배포와 상업적 이용이 가능한지 확인해야 한다. Creative Commons나 Apache 같은 라이선스가 무엇을 허용하는지 직접 판단해야 하고, 확실하지 않으면 소유자나 사이트에 문의한다.

---

## 6. 정제와 업로드

- **정제**: iNaturalist 이미지에는 이미 레이블이 있어서 따로 정제할 일이 거의 없다.
- **데이터 탐색기(data explorer)**: 레이블이 있는 데이터는 적고 없는 데이터가 많을 때, 사전 학습 모델이나 학습된 impulse를 이용해 대량 레이블링을 돕는다. 종 이름은 MobileNetV2 같은 ImageNet 사전 학습 모델이 알지 못한다. 그러므로 먼저 소규모로 학습해야 한다. 차원 축소 방법은 t-SNE(소규모 데이터에 적합)와 PCA(모든 규모에 적합) 중에서 고른다.
- **업로드**: 웹 GUI나 CLI로 올린다. 둘 다 학습용과 테스트용을 80/20으로 자동 분할할 수 있다.

```
edge-impulse-uploader --api-key [your-api-key] --label [label] --category split [directory]/*
```
