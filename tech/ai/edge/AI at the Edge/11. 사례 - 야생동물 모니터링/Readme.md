# 11장. 사례 - 야생동물 모니터링

이 장은 멸종위기종 보호를 목표로 카메라 트랩(camera trap)에 엣지 AI를 결합하는 첫 번째 사례를 다룬다. 문제 탐색부터 데이터셋 확보, Edge Impulse Studio에서의 학습과 EON Tuner 최적화, 기기 배포와 반복 개선까지 9장의 개발 워크플로를 그대로 따라간다.

---

## 핵심 요점

- **엣지 AI의 가치**: 인터넷 없는 외진 곳에서도 현장에서 추론하고, 확률이 높은 이미지만 전송해 인력과 통신 부담을 줄인다.
- **책임 있는 문제 설정**: 멸종위기종이나 사람을 직접 겨냥하면 악용 위험이 크므로, 침입종(핀레이슨 다람쥐)을 탐지하는 방향을 택한다.
- **환경·윤리 고려**: 전원, 통신, 날씨뿐 아니라 기기가 동물과 지역 주민에게 미치는 영향까지 설계에 포함한다.
- **데이터 확보**: iNaturalist의 라벨된 이미지를 내려받아 대상 동물과 unknown 두 클래스로 만들고, 편향과 라이선스를 확인한다.
- **개발 파이프라인**: Image DSP 블록과 MobileNetV2 전이 학습으로 76.3%, EON Tuner로 약 89%를 달성하되 RAM·ROM 제약 안에서 고른다.
- **배포와 개선**: C++ 라이브러리, 휴대폰 WebAssembly, OpenMV 등으로 배포하고 액티브 러닝으로 계속 개선한다.
