# 7장. 데이터셋 구축 방법

데이터셋은 엣지 AI 프로젝트의 토대다. 어떤 알고리즘을 고를지, 하드웨어가 어느 정도 사양이어야 하는지, 현장에서 성능이 얼마나 나오는지 확인하는 일까지 모든 작업의 난이도와 위험이 데이터셋에 달려 있다. 머신러닝을 쓰지 않더라도 신호 처리(DSP) 기법을 고르고 테스트하려면 데이터가 필요하다. 이 장은 데이터셋을 수집하고 다듬고 키워 가는 모범 사례를 다루며, 책 전체에서 가장 중요한 부분으로 꼽힌다.

---

## 핵심 요점

- 이상적인 데이터셋은 관련성, 대표성, 균형, 신뢰성, 형식 일관성, 문서화, 적정 크기를 갖춘다.
- 데이터셋에는 도메인 전문성이 담긴다. 전문성이 없는 분야에서는 실제로 쓸 제품을 만들지 않는다.
- 데이터 중심 ML은 알고리즘 튜닝보다 데이터 품질을 높이는 데 집중한다.
- 필요한 데이터 양은 선례를 조사하고, 데이터를 조금씩 늘려 가며 학습 곡선을 그려 보는 실험으로 가늠한다.
- 엣지에서 데이터를 모을 때는 연결 상태, 브라운필드·그린필드 하드웨어, 센서 차이, 레이블 확보가 주된 난관이다.
- 샘플 단위 메타데이터는 데이터셋이 대표성을 갖췄는지, 하위 그룹별 성능이 어떤지 파악하는 핵심 수단이다.
- 대표성, 레이블 노이즈, 흔한 오류, 오류가 한쪽에 몰리는 문제, 드리프트를 계속 점검한다.
- 레이블링은 가장 비싼 작업이며 편향을 관리해야 하고 사람이 직접 개입해야 한다.
- 학습·검증·테스트 데이터를 엄격히 분리하고, 증강은 학습 데이터에만 적용한다.
- 재현 가능한 데이터 파이프라인을 갖춰 새 데이터를 계속 추가한다.
