# 7장. 데이터셋 구축 방법

데이터셋은 엣지 AI 프로젝트의 토대이며, 알고리즘 선택부터 하드웨어 요구 파악, 현장 성능 평가까지 모든 작업의 난이도와 위험을 좌우한다. 머신러닝을 쓰지 않는 경우에도 신호 처리(DSP) 기법 선정과 테스트에 데이터가 필요하다. 이 장은 데이터셋을 수집하고 다듬고 키워 가는 모범 사례를 다루며, 책 전체에서 가장 중요한 부분으로 꼽힌다.

---

## 핵심 요점

- 이상적인 데이터셋은 관련성, 대표성, 균형, 신뢰성, 형식 일관성, 문서화, 적정 크기를 갖춘다.
- 데이터셋은 도메인 전문성이 담긴 산물이며, 전문성이 없는 분야에서는 실사용 제품을 만들지 않는다.
- 데이터 중심 ML은 알고리즘 튜닝보다 데이터 품질 개선에 집중한다.
- 필요한 데이터 양은 선례 조사와 단계적 학습 곡선 실험으로 가늠한다.
- 엣지에서는 연결성, 브라운필드·그린필드 하드웨어, 센서 차이, 레이블 확보가 수집의 주요 난관이다.
- 샘플 단위 메타데이터는 대표성과 하위 그룹별 성능을 파악하는 핵심 수단이다.
- 대표성, 레이블 노이즈, 흔한 오류, 오류의 불균등 분포, 드리프트를 지속적으로 점검한다.
- 레이블링은 가장 비싼 작업이며 편향 관리와 사람의 개입이 필요하다.
- 훈련·검증·테스트를 엄격히 분리하고 증강은 훈련 데이터에만 적용한다.
- 재현 가능한 데이터 파이프라인을 갖춰 새 데이터를 계속 추가한다.
