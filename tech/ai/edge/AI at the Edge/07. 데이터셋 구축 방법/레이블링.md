# 레이블링

레이블은 입력 데이터가 무엇을 뜻하는지 알려 주는 정보이고, 신뢰할 만한 알고리즘은 고품질 레이블을 필요로 한다. 이 문서는 레이블을 붙이는 방식, 레이블이 필요 없는 경우, 적은 레이블로 데이터를 활용하는 기법, 레이블링 편향, 도구를 정리한다. 레이블링은 AI 프로젝트 작업 시간의 큰 비중을 차지한다.

---

## 1. 레이블링 방식

한 프로젝트가 여러 방식을 섞어 쓰기도 한다.

- **특성을 이용한 레이블링(labeling using features)**: 데이터셋 자신의 특성이 레이블이 된다.
  - 가상 센서(virtual sensor) 예: 값싼 센서 여러 개의 신호로 비싼 고품질 센서의 출력을 예측한다. 이때 데이터셋에 비싼 센서의 측정값을 함께 넣어 레이블로 쓴다.
  - 가공해서 쓰기도 한다. 낮과 밤을 예측하는 모델이라면 타임스탬프와 현지 일출·일몰 정보로 낮/밤 레이블을 만든다.
- **수동 레이블링(manual labeling)**: 대부분의 데이터셋은 사람이 직접 레이블한다. 특정 사건 중에 수집하면 쉽다(차량에 타서 "주행"과 "정지"를 수집하는 경우). 아니면 사람이 레코드를 하나씩 보며 판단하는 지루한 작업이 된다. 훈련이나 숙련이 필요할 수 있고 전문가끼리도 의견이 갈린다(의료 영상). 수동 레이블링은 품질 문제의 가장 흔한 원인이며 발견·수정 비용도 가장 크다.
- **자동 레이블링(automated labeling)**: 정확하지만 너무 커서 임베디드에 못 올리는 모델로 레이블을 붙여 사람 노력을 줄인다. 오류가 있다고 가정하고 점검·수정 절차를 두어야 한다. 큰 모델의 레이블 체계와 목표 모델의 체계가 다를 수 있다(큰 모델이 종 단위로 분류하고 목표는 새/포유류라면 매핑이 필요).
- **보조 레이블링(assisted labeling)**: 수동과 자동의 혼합. 컴퓨터 비전 모델이 관심 영역을 강조해 주면 사람이 판단해 바운딩 박스를 그리는 식이다.

---

## 2. 레이블이 필요 없는 경우

- 지도 학습(supervised)은 입력에서 레이블을 예측하도록 배우고, 비지도 학습(unsupervised)은 데이터의 표현을 배워 다른 작업에 쓴다. 비지도 알고리즘은 레이블이 필요 없다.
- 이상 탐지용 군집화 알고리즘은 레이블 없는 데이터의 고유한 성질을 학습한다. 다만 정상 데이터만 담도록 데이터셋을 신중히 선별해야 하므로 레이블이 암묵적(implicit)으로 존재한다고 볼 수 있다.
- 비지도로 풀릴 가능성이 있으면 초기에 실험해 본다. 비용·시간·위험을 크게 아낄 수 있다. 하지만 대부분의 문제는 지도 학습이 필요하다.
- 비지도를 쓰더라도 테스트용으로는 레이블된 데이터가 보통 필요하다. 이상 탐지라면 정상과 비정상 예제를 모두 레이블해서 성능을 평가해야 한다.

---

## 3. 준지도 학습과 능동 학습

레이블 없는 대량 데이터(예: 오랫동안 쌓은 IoT 데이터)와 소량의 레이블 데이터가 있을 때, 부분 학습된 모델로 더 많은 레이블링을 돕는 두 기법이다.

- **준지도 학습(semi-supervised learning)**
  1. 큰 비레이블 데이터에서 일부만 레이블하고 모델을 학습한다.
  2. 모델로 비레이블 레코드 묶음을 예측해 레이블로 삼는다(일부는 틀려도 괜찮다).
  3. 새로 레이블된 레코드를 기존 데이터와 합쳐 새 모델을 학습한다. 새 모델은 조금 더 나아진다.
  4. 모델이 충분해질 때까지 반복한다.
- **능동 학습(active learning)**: 초기 모델 학습은 같지만, 모델이 레이블하면 가장 유용할 레코드를 골라 도메인 전문가에게 레이블을 요청하고 그 결과로 다시 학습한다. 정보 이득(information gain)을 최대화하도록 고르며 두 전략이 대표적이다.
  - **불확실성 샘플링(uncertainty sampling)**: 모델이 자신 없어 하는 레코드는 비슷한 샘플을 못 본 것이므로 레이블 가치가 높다.
  - **다양성 샘플링(diversity sampling)**: 샘플 간 유사도를 정량화해 기존 레이블 데이터와 가장 다른 샘플을 고른다.
- 둘은 따로 또는 함께 쓰며, 선택·재학습을 필요한 만큼 반복한다.
- 주의: 능동 학습 도구는 레이블링 편향의 원천이 될 수 있다. 무작위로 고른 샘플을 레이블한 결과와 비교해 어떤 모델이 만들어지는지 파악한다.

---

## 4. 레이블링 편향

- 레이블링 과정의 편향이 레이블 노이즈의 주요 원천이다. 데이터셋이 실제 상황이 아니라 레이블하는 사람과 도구의 편향을 반영하게 된다.
- **사례(품질 관리 시스템)**: 제품 이미지를 "불량"과 "정상"으로 나누는데, 도메인 전문가가 입사한 지 얼마 안 돼 최신 제품만 잘 알고 오래된 제품은 확신이 낮다. 그 제품의 레이블이 더 틀려 시스템도 그 제품의 불량을 잘 못 잡고, 정상품을 불량으로 오판하기도 한다. 둘 다 비용이다.
- 이런 문제는 거의 불가피하고 데이터셋이 평가 도구이기도 해서 발견하기 어렵다.
- **대응 절차**
  - 해당 분야에 깊은 경험이 있는 진짜 도메인 전문가를 쓴다.
  - 전문가가 정한 문서화된 레이블링 프로토콜을 따른다.
  - 여러 레이블러가 서로 점검한다.
  - 레이블된 데이터를 표본으로 품질 평가한다.
- 이는 비용과 복잡도를 높인다. 고품질 데이터셋의 비용을 감당할 수 없다면 프로젝트가 현재 예산에서는 실현 불가능할 수 있으며, 해로운 시스템을 배포하느니 중단하는 편이 낫다.
- 자동 레이블링도 마찬가지다. 대형 사전 학습 모델의 성능이 하위 그룹마다 고르지 않으면 레이블이 같은 편향을 갖는다.

---

## 5. 레이블링 도구

- **주석 도구(annotation tools)**: 사람이 레이블하거나 검토하려면 UI가 필요하다. 이미지 분류는 단순하지만 객체 탐지는 바운딩 박스를 그려야 하고, 시계열 센서 데이터는 전문가가 이해할 수 있게 시각화하는 더 정교한 도구가 필요하다. 레이블 편집과 시각화에도 필수적이다. 선택 기준은 다음과 같다.
  - 다루는 데이터 유형 지원
  - 풀려는 문제 유형 지원(분류 대 회귀 등)
  - 여럿이 함께 작업하는 협업 기능
  - 자동화 기능
- **크라우드소싱(crowdsourced labeling)**: 내부 인력이 감당 못 하는 양을 일반인에게 맡긴다(유료 또는 자원봉사). 큰 데이터를 빠르게 레이블할 수 있다. 반면 도메인 전문성에 기댈 수 없어 고난도 과제는 어렵고 품질 문제가 많으며, 과제를 명확히 정의하고 교육하는 부담이 있다. 민감·비공개 정보가 있으면 쓸 수 없고 악의적 조작 가능성도 있다.
- **보조·자동 레이블링 도구**: 간단히는 DSP로 관심 구간을 강조하거나 레이블을 제안하고, 정교하게는 ML 모델을 쓴다. 책은 Edge Impulse의 예를 든다.
  - 객체 추적 알고리즘으로 연속 프레임에서 이미 레이블한 대상을 따라가며 바운딩 박스 작업을 돕는 도구
  - 군집화로 유사 샘플을 가깝게 시각화해 인접 샘플을 근거로 빠르게 레이블하는 데이터 탐색기(data explorer)
  - 공개 데이터셋으로 사전 학습한 객체 탐지 모델로 80개 클래스를 자동 레이블
  - 자동 시스템은 완벽하지 않으므로 사람이 루프 안에 있어야(human in the loop) 한다.
- **준지도·능동 학습 도구**: 소량만 수동 레이블하고 나머지는 자동 레이블하게 한다. Edge Impulse 데이터 탐색기는 부분 학습된 모델 출력으로 비레이블 데이터를 군집으로 보여 주며, 군집이 뚜렷하고 각 군집에 레이블된 샘플이 있게 하는 방향으로 레이블링을 안내한다.
