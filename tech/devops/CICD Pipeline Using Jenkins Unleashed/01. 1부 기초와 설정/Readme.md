# 1부 개요 (Part I) 기초와 설정

프라노데이 프라모드 딩가레(Pranoday Pramod Dingare)의 『CI/CD Pipeline Using Jenkins Unleashed』(Apress, 2022)는 Jenkins로 CI/CD 파이프라인을 만드는 방법을 다룬 기술서다. 1부는 여섯 개 장으로, CI/CD가 왜 필요한지부터 시작해 Jenkins를 설치하고, 서버를 켜고, 플러그인과 전역 도구를 설정해 "잡을 만들 준비"를 마치는 과정이다.

이 노트는 번역이 아니라 책의 내용을 이해한 뒤 풀어 다시 정리한 학습 노트다. 책의 Jenkins 버전과 화면은 2021년경(책은 2.289를 사용) 기준이므로 최신 버전의 화면과 다를 수 있다.

> **이 부를 한 문장으로**
> 자주, 조금씩 통합하고 자동으로 검증하는 CI/CD를 Jenkins로 실현하기 위해, 설치부터 플러그인과 도구 등록까지 기본 환경을 갖추는 과정이다.

---

## 0. 먼저 알아 둘 것

- **애자일과 스프린트**: 요구사항을 우선순위별로 나눠 짧은 기간(보통 1~3주)에 한 묶음씩 구현하는 개발 방식과 그 기간.
- **Git 같은 소스 관리 도구와 Maven 같은 빌드 도구**: Jenkins가 직접 하는 일이 아니라 플러그인으로 연결해 부르는 대상이다.
- **Windows 중심**: 책의 설치와 설정 예시는 주로 Windows 기준이고, Linux와 Docker는 일부만 짧게 다룬다.

## 2. 1부 용어

| 용어 | 쉬운 설명 |
|------|-----------|
| CI | 변경을 자주, 조금씩 병합하고 그때마다 컴파일·테스트하는 방식 |
| 지속적 전달/배포 | 검증된 변경을 운영 환경에 자주 올려 환경 차이로 인한 문제를 일찍 찾는 방식 |
| TDD | 테스트를 먼저 쓰고 그것을 통과하도록 코드를 만드는 방식 |
| 아티팩트 | 빌드 결과물. 예: .WAR, .JAR |
| 잡(job) | 빌드 수명주기 단계를 순서대로 수행하는 일의 묶음 |
| 파이프라인 | 단계 순서를 정의한 Jenkins 스크립트. 앞 단계 결과를 다음 단계가 받음 |
| 플러그인 | Jenkins를 외부 도구와 연결하는 부품 |
| JENKINS_HOME | Jenkins의 설정, 플러그인, 잡, 빌드 이력이 모이는 폴더 |
| Plugin Manager | 플러그인을 설치, 갱신, 삭제, 비활성화하는 관리 화면 |
| Global Tool Configuration | Maven, JDK 등 잡이 쓸 도구의 위치와 설치 방식을 등록하는 화면 |

## 3. 이 부의 흐름 요약

1장은 CI/CD의 개념을 계산기 앱 사례로 보여 주고, 2장은 이 흐름을 자동으로 돌려 주는 Jenkins를 소개한다. 3장에서 Jenkins를 설치하고 `JENKINS_HOME` 구조를 이해하면, 4장에서 서버를 시작해 로그인하고 기본 설정과 계정 복구 방법을 익힌다. 5장에서는 Git, Maven, 이메일 같은 외부 도구를 잇는 플러그인을 관리하고, 6장에서는 Maven과 JDK를 전역 도구로 등록해 2부 이후의 잡 작업을 위한 환경을 마무리한다.
