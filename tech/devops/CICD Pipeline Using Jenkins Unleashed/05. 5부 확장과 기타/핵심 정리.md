# 핵심 정리

이 문서는 5부(17장부터 20장)의 요점을 한곳에 모은 복습용 정리다. 각 요점 끝의 **→ 자세히** 링크를 따라가면 해당 장으로 이동한다. 화면과 설정은 2021년경 기준이며, 값은 자리표시자로 다뤘다.

---

## 1. 한눈에 보는 요점

- **분산 빌드는 컨트롤러가 나누고 에이전트가 실행한다**: 한 대로는 빌드 시간, 소프트웨어 설치, 장애, 다양한 환경 테스트가 문제가 되는데, 컨트롤러가 단계를 여러 에이전트에 나누어 해결한다.
  - *쉽게 말하면*: 일을 맡기는 한 명과 일하는 여러 명으로 역할을 나눈다.
  - → 자세히: [17장 분산 빌드](17%EC%9E%A5%20%EB%B6%84%EC%82%B0%20%EB%B9%8C%EB%93%9C.md)
- **에이전트 연결은 방향이 다른 두 방식이다**: SSH는 컨트롤러가 에이전트로, JNLP는 에이전트가 컨트롤러로 접속한다. 접근이 막힌 쪽을 기준으로 고른다.
  - *쉽게 말하면*: 누가 먼저 문을 두드리느냐의 차이다.
  - → 자세히: [17장 분산 빌드](17%EC%9E%A5%20%EB%B6%84%EC%82%B0%20%EB%B9%8C%EB%93%9C.md)
- **job은 라벨로 실행할 노드를 정한다**: `Restrict where this project can be run`과 `Label Expression`으로 특정 노드나 라벨에서만 돌게 한다.
  - *쉽게 말하면*: 이 일은 이 일꾼에게만 시킨다고 표시한다.
  - → 자세히: [17장 분산 빌드](17%EC%9E%A5%20%EB%B6%84%EC%82%B0%20%EB%B9%8C%EB%93%9C.md)
- **EC2 배포는 서버 준비, SSH 설정, 보안 그룹, scp가 한 세트다**: 인스턴스에 IIS와 OpenSSH를 준비하고 보안 그룹에서 SSH, HTTP를 열어야 파일 복사와 접속이 된다.
  - *쉽게 말하면*: 빌린 컴퓨터에 길과 문을 열어 주어야 파일이 들어간다.
  - → 자세히: [18장 AWS 연동](18%EC%9E%A5%20AWS%20%EC%97%B0%EB%8F%99.md)
- **배포 job에 테스트 job을 이어 붙인다**: `scp` 배포 뒤 downstream으로 Selenium 테스트를 실행하고, 테스트 대상 주소(`ApplicationURL`)를 인스턴스로 바꾼다.
  - *쉽게 말하면*: 배포가 끝나면 곧바로 배포본을 검사하게 만든다.
  - → 자세히: [18장 AWS 연동](18%EC%9E%A5%20AWS%20%EC%97%B0%EB%8F%99.md)
- **CLI는 인증이 필수이며 API 토큰이나 SSH 키를 쓴다**: 인증 없이는 anonymous 권한 오류가 난다. `build`의 `-c`, `-s`, `-v` 같은 옵션과 `list-jobs`, `get-job`, `create-job`으로 작업 이전도 자동화한다.
  - *쉽게 말하면*: 명령줄로도 신분을 밝혀야 하고, 반복 작업은 스크립트로 묶을 수 있다.
  - → 자세히: [19장 기타 주제 1](19%EC%9E%A5%20%EA%B8%B0%ED%83%80%20%EC%A3%BC%EC%A0%9C%201.md)
- **REST API와 python-jenkins로 프로그램이 Jenkins를 제어한다**: `curl`로 설정 조회, 작업 생성, 빌드 실행을 하고, python-jenkins로 같은 일을 파이썬 코드로 처리한다.
  - *쉽게 말하면*: 사람이 누르던 버튼을 프로그램이 대신 누른다.
  - → 자세히: [20장 기타 주제 2](20%EC%9E%A5%20%EA%B8%B0%ED%83%80%20%EC%A3%BC%EC%A0%9C%202.md)
- **공유 라이브러리는 파이프라인 중복을 없앤다**: `vars` 폴더의 Groovy 파일 `call` 함수에 공통 단계를 두고 `Global Pipeline Libraries`에 등록해 `@Library`로 가져다 쓴다.
  - *쉽게 말하면*: 같은 레시피를 한 번만 적어 두고 여러 요리에 쓴다.
  - → 자세히: [20장 기타 주제 2](20%EC%9E%A5%20%EA%B8%B0%ED%83%80%20%EC%A3%BC%EC%A0%9C%202.md)

## 2. 5부를 관통하는 질문

| 질문 | 5부가 보여 주는 답 |
|------|-------------------|
| 빌드가 느리고 환경이 한 곳에 묶일 때는? | 에이전트를 두고 단계를 나누어 실행한다 |
| 에이전트에 닿을 수 없을 때는? | 에이전트가 먼저 접속하는 JNLP 방식을 쓴다 |
| 클라우드 서버에 배포하려면? | 인스턴스 준비, SSH와 보안 그룹, `scp`, 후속 테스트 job |
| 화면 없이 Jenkins를 다루려면? | CLI, REST API, python-jenkins |
| 파이프라인이 중복될 때는? | 공유 라이브러리로 묶는다 |

---

> **5부 한 줄 요약**
> Jenkins를 여러 머신과 클라우드로 넓히고, 명령줄·API·파이썬·공유 라이브러리로 자동화하고 재사용하는 방법을 배운다.
