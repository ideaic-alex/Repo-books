# 잡 실행과 관리

잡을 만들고 설정했다면 이제 실행해 보고 결과를 확인해야 한다. 이 문서는 잡을 수동으로 실행하는 방법, 진행 상태와 빌드 기록과 콘솔 출력을 보는 방법, 잡을 수정하고 삭제하는 방법, 작업 공간을 보고 비우는 방법을 다룬다.

자동차에 비유하면 시동을 걸고(실행), 계기판을 보고(진행 상태), 주행 기록을 열어 보고(빌드 기록과 콘솔 출력), 필요하면 정비소에 맡기고(수정), 폐차하고(삭제), 트렁크를 비우는(작업 공간 정리) 일이다.

---

## 1. 잡 실행과 결과 확인

잡을 만들고 설정하고 저장하면 대시보드에 그 잡이 나타난다. 실행하는 방법은 두 가지다. 직접 실행하려면 그 잡 항목의 시계 아이콘을 누른다. 또는 잡 설정의 트리거 조건에 맞아 저절로 시작될 수도 있다.

1. 대시보드에서 잡 항목의 시계 모양 아이콘을 눌러 실행한다.
2. 실행이 시작되면 대시보드의 Build Executor Status 섹션에서 진행 상태를 본다. 진행 막대(progress bar)가 보인다.
3. 잡이 끝나면 대시보드 왼쪽의 Build History 링크를 눌러 실행 이력을 본다.
4. Build History of Jenkins 페이지에 표가 나온다. 원서 저자는 잡을 여덟 번 실행해서 Build #1부터 #8까지 나왔다. 실행 횟수에 따라 보이는 기록은 달라진다.
5. 자세한 로그가 필요하면 표에서 해당 빌드 줄의 Console Output을 누른다. 예를 들어 Build #8의 Console Output 아이콘을 누르면 #8의 상세 콘솔 출력이 나온다.

| 보고 싶은 것 | 가는 곳 |
|---|---|
| 지금 도는 빌드의 진행 상황 | 대시보드의 Build Executor Status |
| 지난 실행 목록 | 대시보드 왼쪽의 Build History |
| 특정 빌드의 상세 로그 | Build History 표의 Console Output |

빌드가 실패하거나 결과가 이상할 때 가장 먼저 볼 곳이 콘솔 출력이다. 빌드 번호별로 따로 저장되므로 어느 실행에서 문제가 생겼는지 정확히 짚을 수 있다.

## 2. 잡 수정

기존 잡을 고치는 절차는 다음과 같다.

1. 대시보드에서 해당 잡의 드롭다운을 연다.
2. Configure 옵션을 클릭한다.
3. 잡 설정 페이지가 열리면 필요한 부분을 고친다.
4. Save 버튼을 눌러 저장한다.

## 3. 작업 공간 확인과 비우기

작업 공간은 잡의 빌드가 실행되고 내려받은 코드가 놓이는 디렉터리라고 앞 문서에서 설명했다. 젠킨스 화면에서도 그 안을 볼 수 있다.

### 작업 공간 보기

1. 대시보드에서 잡 항목을 클릭해서 잡 페이지로 들어간다.
2. 페이지 왼쪽의 Workspace 링크를 누른다.
3. 작업 공간의 파일과 폴더 목록이 열린다.

### 작업 공간 비우기

1. 위와 같이 잡 페이지로 들어가 Workspace 링크를 누른다.
2. Wipe Out Current Workspace 링크를 누른다.

작업 공간을 비우면 이전 빌드가 남긴 파일이 지워진다. 원서는 이 동작의 부작용까지 설명하지 않지만, 일반적으로 이전 빌드의 찌꺼기를 없애고 싶을 때 쓰는 기능이다.

## 4. 잡 삭제

1. 대시보드에서 해당 잡 항목의 드롭다운을 연다.
2. Delete Project 옵션을 클릭한다.
3. 확인 창(Confirmation alert)에서 OK를 누른다.

## 5. 관리 작업 정리

| 하고 싶은 일 | 시작 위치 | 누를 곳 |
|---|---|---|
| 잡 수정 | 대시보드의 잡 드롭다운 | Configure 그리고 Save |
| 작업 공간 보기 | 잡 페이지 | 왼쪽 Workspace |
| 작업 공간 비우기 | 잡 페이지의 Workspace | Wipe Out Current Workspace |
| 잡 삭제 | 대시보드의 잡 드롭다운 | Delete Project 그리고 OK |

잡 이름을 눌러 들어가는 잡 페이지와 대시보드의 드롭다운 메뉴, 이 두 곳이 관리 작업의 출발점이다. 삭제는 확인 창이 한 번 더 나오지만 되돌릴 수 있는지는 원서에 언급이 없으므로, 삭제 전에 잡 설정을 확인해 두는 것이 안전하다.
