# 요약과 핵심 개념

이 장은 젠킨스의 Plugin Manager로 플러그인을 설치, 갱신, 삭제하는 방법을 다뤘다. 설치 중에 만날 수 있는 오류와 그 해결책도 함께 살폈다. 이 문서는 장 전체를 한 번에 되짚을 수 있게 핵심 개념을 표로 모았다.

---

## 1. 장 요약

- 젠킨스는 플러그인으로 Git, Maven 같은 외부 도구와 연결된다.
- Plugin Manager는 Manage Jenkins → Manage Plugins로 들어가며 Updates, Available, Installed, Advanced 네 탭으로 이루어진다.
- 설치는 Available 탭, 갱신은 Updates 탭, 삭제와 비활성화는 Installed 탭에서 한다.
- 프록시 뒤에서 젠킨스를 쓰면 Advanced 탭에 프록시 정보를 넣어야 한다.
- 설치 오류는 크게 SHA-1 불일치와 SSL 인증서 경로 오류가 있고, 각각 동기화, 프록시 설정, URL 변경, Java 버전 조정으로 푼다.
- 다음 장은 Global Tool Configuration 페이지에서 Maven, Git, Java 같은 도구를 설정하는 방법을 다룬다.

## 2. 핵심 개념 정리

| 개념 | 설명 |
| --- | --- |
| 플러그인 | 젠킨스에 특정 기능을 더하는 확장 부품 |
| Plugin Manager | 플러그인을 갱신, 설치, 삭제하는 관리 화면 |
| Update Center | 플러그인을 내려받는 서버. 주소는 Advanced 탭에 나온다 |
| .HPI 파일 | 플러그인 파일. 수동 설치 때 올리고, 삭제 때 JENKINS_HOME/plugins에서 지운다 |
| 비활성화 | 설치는 유지하되 시작하지 않아 기능이 보이지 않게 한다 |
| 프록시 | 인터넷 요청을 대신 전달하는 중간 서버 |

## 3. 작업별 위치 정리

| 하고 싶은 일 | 가는 곳 |
| --- | --- |
| 새 플러그인 설치 | Available 탭 |
| 새 버전으로 갱신 | Updates 탭 |
| 삭제 또는 비활성화 | Installed 탭 |
| 프록시 설정 | Advanced 탭의 HTTP Proxy Configuration |
| 특정 버전 설치 | Advanced 탭의 Upload Plugin |
| Update Center와 동기화 | Advanced 탭 Update Site의 Check Now |

## 4. 오류별 대응 정리

| 오류 | 먼저 해 볼 일 |
| --- | --- |
| SHA-1 불일치 | Check Now로 동기화한 뒤 서버 재시작, 그래도 안 되면 프록시 설정 |
| 인증서 경로 오류 | Update Center URL을 http로 바꾸거나 Java를 최신으로 올림 |

인증서 오류를 최신 Java로 풀었다면 설치 후 JDK 1.8 또는 1.11로 되돌려야 파이프라인 잡이 정상 동작한다.
