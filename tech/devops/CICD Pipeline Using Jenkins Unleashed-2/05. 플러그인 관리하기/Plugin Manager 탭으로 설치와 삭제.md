# Plugin Manager 탭으로 설치와 삭제

Plugin Manager는 젠킨스 플러그인을 갱신하고 설치하고 지우는 화면이다. 화면 위쪽에는 Updates, Available, Installed, Advanced 네 개의 탭이 있다. 스마트폰의 앱 스토어에 비유하면 이해가 빠르다. 업데이트 탭, 새 앱을 찾는 탭, 내 폰에 깔린 앱 목록 탭, 설정 탭이 따로 있는 것과 닮았다.

이 문서는 앞의 세 탭(Updates, Available, Installed)을 다룬다. Advanced 탭은 프록시 설정 때문에 내용이 길어서 다음 문서로 넘긴다.

---

## 1. 네 탭 한눈에 보기

| 탭 | 역할 |
| --- | --- |
| Updates | 이미 설치한 플러그인 중 새 버전이 나온 것을 보여 주고 갱신한다 |
| Available | 설치할 수 있는 플러그인을 검색해서 새로 설치한다 |
| Installed | 설치된 플러그인과 버전을 보여 주고 삭제하거나 끈다 |
| Advanced | 프록시 설정, 수동 업로드, 업데이트 센터 URL을 다룬다 |

플러그인을 새로 깔 때는 Available, 이미 깔린 것을 정리할 때는 Installed, 버전을 올릴 때는 Updates라고 기억하면 된다.

## 2. Updates 탭

이 탭은 설치된 플러그인 가운데 내려받을 수 있는 새 버전이 있는 것만 모아서 보여 준다. 갱신하는 방법은 단순하다.

1. 갱신하려는 플러그인의 체크박스를 선택한다.
2. Download Now and Install After Restart 버튼을 누른다.

버튼 이름이 알려 주듯, 새 버전은 지금 내려받지만 설치는 젠킨스 서버를 다시 시작한 뒤에 끝난다. 원서의 Figure 5-2는 갱신 대상 플러그인이 목록에 올라온 모습을 보여 준다.

## 3. Available 탭

이 탭에는 내려받아 설치할 수 있는 플러그인 목록이 나온다. 원서는 JUnit 플러그인을 예로 든다.

1. Available 탭으로 간다.
2. Search 필드에 `Junit`을 입력한다.
3. 목록 맨 위에 JUnit 플러그인 항목이 나타난다. 그 항목의 체크박스를 선택한다(Figure 5-3).
4. 아래 두 버튼 중 하나를 누른다.

### 3.1 설치 버튼 두 가지 비교

| 버튼 | 내려받기 | 설치 시점 |
| --- | --- | --- |
| Install Without Restart | 바로 시작 | 내려받은 직후 바로 설치 |
| Download Now and Install After Restart | 바로 시작 | 젠킨스 서버를 다시 시작할 때 설치 |

두 버튼의 차이는 설치가 언제 끝나느냐다. 바로 쓰고 싶으면 앞의 버튼, 서버를 어차피 다시 켤 예정이면 뒤의 버튼이 알맞다. 원서 설명으로는 뒤의 버튼은 내려받기만 하고 설치는 하지 않은 상태로 둔다.

### 3.2 Install Without Restart를 눌렀을 때

버튼을 누르면 내려받기가 시작되고, 다 받으면 곧바로 설치된다. 플러그인 항목의 설치 상태가 초록색 Success로 바뀔 때까지 기다리면 된다. 인터넷 속도에 따라 시간이 걸릴 수 있다. Success가 보이면 그 플러그인을 쓸 준비가 된 것이다.

## 4. Installed 탭

이 탭은 젠킨스 서버에 설치된 모든 플러그인과 각 플러그인의 설치 버전을 보여 준다. 삭제와 비활성화도 여기서 한다.

### 4.1 삭제하는 방법

1. Installed 탭의 Search 필드에 지우려는 플러그인 이름을 입력한다.
2. 해당 플러그인의 체크박스를 선택한다.
3. Uninstall 버튼을 누른다.

다른 방법도 있다. JENKINS_HOME/plugins 디렉터리에서 그 플러그인에 해당하는 .HPI 파일을 지워도 삭제된다. .HPI는 젠킨스 플러그인을 담은 파일 형식이다.

### 4.2 비활성화로 보류하기

플러그인을 아예 지우지 않고 은퇴시키는 방법이 비활성화(disable)다. 비활성화하면 젠킨스는 그 플러그인을 설치된 것으로 여기지만 시작하지는 않고, 플러그인이 제공하던 확장 기능도 화면에 보이지 않는다. Manage Jenkins의 Installed 탭에서 해당 플러그인의 체크박스를 해제하면 된다.

| 방법 | 설치 상태 | 기능 사용 |
| --- | --- | --- |
| Uninstall 버튼 | 제거됨 | 불가 |
| .HPI 파일 삭제 | 제거됨 | 불가 |
| 체크박스 해제(비활성화) | 설치된 채로 유지 | 시작되지 않아 불가 |

삭제와 비활성화의 차이는 파일이 남아 있느냐다. 나중에 다시 쓸 가능성이 있으면 비활성화가 안전한 선택이다.
