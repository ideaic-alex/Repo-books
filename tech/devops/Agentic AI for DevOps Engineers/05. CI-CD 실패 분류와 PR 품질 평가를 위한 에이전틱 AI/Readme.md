# CI-CD 실패 분류와 PR 품질 평가를 위한 에이전틱 AI

이 장은 에이전틱 AI를 DevOps에 적용하는 첫 실전 단계다. 범위를 좁게 정한 도구 사용 에이전트를 CI/CD 워크플로 안에 넣되, 코드와 배포와 운영 시스템에 대한 무제한 권한은 주지 않는다. 에이전트가 일반 AI 어시스턴트와 어떻게 다른지, 구성 요소가 어떻게 맞물리는지를 배운 뒤 두 가지 안전한 자동화 패턴, 즉 CI 로그의 실패 분류와 코드 변경의 풀 리퀘스트(PR) 품질 평가를 만든다.

그 과정에서 결정론적 검증을 더하고, 운영에서 흔한 실패 모드를 살펴보고, 점진적 자율성으로 에이전트가 관찰만 할지, 제안할지, 게이트가 있는 행동까지 할지를 정한다. 목표는 DevOps 엔지니어를 대체하는 것이 아니라 사람의 검토, 검증, 거버넌스를 유지하면서 수작업 조사를 줄이는 것이다. 실습 값(모델 이름, 버전, 임계값)은 원서의 예시를 따른다.

---

## 1. 핵심 요점

- 에이전트는 환경을 인식하고, 추론하고, 계획하고, 도구로 행동하는 자율 시스템이다. 구성 요소는 추론 엔진, 계획 계층, 메모리, 도구 연동, 자기 비판이다.
- CI/CD는 자동, 고빈도, 프로덕션 영향, 보호 브랜치 영향 때문에 위험하다. 실패 분류, 테스트 요약, PR 초안 제안, 문서 생성은 안전하고, 자동 병합, 프로덕션 자동 배포, 테스트 비활성화, 보안 정책 수정은 금지다.
- 가드레일은 스키마 검증, 최소 권한, 허용 목록, 사람 검토를 기본으로 하고, 최종 통과 여부는 결정론적 정책 게이트가 정한다.
- 실패 분류 에이전트는 .NET 10 파일 기반 C# 앱이다. 실패 마커로 신호를 추출하고, 다섯 필드 JSON을 내며, 코드가 JSON을 검증하고 실패하면 대체 JSON을 낸다.
- 운영 실패의 다섯 유형은 맥락 손실, 약한 계획, 도구 취약성, 프롬프트 민감성, 과신이다.
- 자율성은 관찰, 제안, 통제된 행동, 준자율 실행의 네 수준이다. 대부분은 수준 2에서 멈추고, 승격은 수락률과 오탐률 같은 측정값으로 정한다.
- PR 품질 평가 에이전트는 MCP 서버를 통제된 경계로 쓰고, 모델에는 도구 세 개만 보인다. 프롬프트는 diff를 신뢰할 수 없는 데이터로 다룬다.
- PR 워크플로는 분석 JSON을 아티팩트로 올리고, 숨은 표지로 댓글 하나를 갱신하며, high 위험과 신뢰도 0.70 이상일 때만 리스크 게이트를 실패시킨다.
