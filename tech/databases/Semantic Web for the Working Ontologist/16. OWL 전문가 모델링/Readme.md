# OWL 전문가 모델링

이 장은 지금까지 배운 RDFS-Plus와 OWL만으로 부족한 경우를 위해 OWL 2의 고급 기능과 그 배경을 소개한다. OWL 2가 OWL 1.0과 호환된다는 점에서 출발해, 하위 집합(프로파일)을 나누는 이유가 모델링 철학의 차이라는 점을 설명하고, 메타모델링, 다중 부분 속성, 복수 키를 차례로 본다. 마지막으로 OWL이 풀기 어려운 문제를 보완하는 규칙과 RIF를 다룬다.

이 장은 OWL 2의 전체 기능 목록이 아니라 가장 중요한 몇 가지의 안내서다. 자세한 내용은 W3C의 OWL 2 권고안 문서에서 찾아볼 수 있도록 배경지식을 주는 데 목적이 있다.

---

## 1. 핵심 요점

- OWL 2는 OWL 1.0과 완전히 하위 호환이어서, 지금까지 배운 모델링 방식이 모두 그대로 유효하다.
- OWL 2의 네 하위 집합(DL, EL, QL, RL)은 같은 구성 요소를 쓴다. 차이는 어떤 용어가 있느냐가 아니라, 어떤 처리 기술에 맞춰 사용 조건을 제한하느냐에 있다.
- 모델링 철학은 두 가지다. 증명 가능한 모델은 판정 가능성을 중시하고, 실행 가능한 모델은 프로그램처럼 디버깅하며 다양한 처리기를 쓴다.
- OWL 2 DL은 기술 논리를 바탕으로 판정 가능성을 지키며, 타블로 알고리즘이 모든 함의를 유한 시간 안에 찾는다.
- 메타모델링은 클래스를 개체처럼 다루는 것이다. OWL 2는 펀닝을 허용하지만, 책은 클래스-개체 거울 패턴을 권한다.
- 다중 부분 속성은 속성을 이어 붙여 새 관계를 만들고, owl:hasKey는 여러 속성 값이 모두 같으면 같은 개체로 본다.
- OWL 2 QL은 SQL, EL은 큰 온톨로지, RL은 규칙 시스템에 맞춘 하위 집합이며, 모두 RDF 수준에서 서로 호환된다.
- 규칙과 RIF는 OWL의 한계를 보완하며, OWL 2 RL이 둘을 잇는다.
