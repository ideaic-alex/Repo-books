# 맺음말과 앞으로의 과제

이 장은 책 전체를 돌아보며 시맨틱 웹이 옛 지식 모델링 기술과 무엇이 다른지, 왜 웹의 일부여야 하는지를 정리한다. 클래스, 속성, 개체 같은 낯익은 부품에 웹의 규모와 개방성이 더해졌다는 것이 핵심 답이다.

이어서 전역 식별자, 열린 세계 가정, 모델의 역할, 실제 활용 사례를 짚고, 개인 데이터 통제를 다루는 Solid와 딥러닝, 속성 그래프, 사물 인터넷 같은 앞으로의 과제로 끝맺는다. 이 장에는 별도의 요약이나 연습 문제 절이 없다.

---

## 1. 핵심 요점

- 시맨틱 웹의 부품은 낯익다. 새로운 것은 부품이 놓이는 무대인 월드 와이드 웹이다.
- "조금의 시맨틱스만으로도 멀리 간다." 단순한 언어와 작은 모델로도 웹 규모에서는 큰 효과가 난다.
- 목표는 기계가 전문가를 대신하는 것이 아니라, 흩어진 정보를 모아 사람이 전문가처럼 일하게 하는 것이다.
- IRI는 웹 전체에서 통하는 이름이어서, 따로 만든 모델도 한 문장으로 합쳐진다. 링크드 데이터는 이름 붙은 전역 링크 위에 선다.
- 개방성 때문에 끊어진 링크와 새 정보에 견딜 수 있도록 추론은 열린 세계 가정에 따라 보수적으로 한다.
- AAA 슬로건, 비유일 이름 짓기 가정, 열린 세계 가정이 RDF, RDFS, OWL의 설계를 이끌었다. 필요한 데이터만 모아 쓰면 되므로 전체를 한 곳에 담을 필요가 없다.
- 모델은 여러 출처의 정보 관계를 설명하는 중개자이고, SKOS, QUDT, OBO, 지식 그래프, 정부 공개 데이터, DBpedia, Wikidata가 실제 활용 사례다.
- 개인 데이터는 Solid처럼 소유자가 통제하면서 통합하는 방향을 찾고 있고, 딥러닝, 속성 그래프, 새로운 논리, 사물 인터넷이 앞으로의 과제다.
