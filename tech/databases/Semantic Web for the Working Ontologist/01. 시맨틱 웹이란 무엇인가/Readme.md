# 시맨틱 웹이란 무엇인가

이 장은 시맨틱 웹(Semantic Web)이 무엇이고 왜 필요한지를 다룬다. 웹이 어떤 아이디어 위에 세워졌는지 돌아본 뒤, 식당 영업시간부터 의학 연구, 금융 상품까지 여러 사례로 "데이터를 기계가 읽고 합칠 수 있게 공개해야 하는 이유"를 보여 준다. 이어서 웹을 웹답게 만든 AAA 슬로건과 네트워크 효과, 의견 충돌, 이름 문제, 열린 세계 가정을 차례로 설명한다.

이 장에는 코드가 없고 개념 설명이 중심이다. 이후 장의 RDF, OWL, SPARQL이 왜 지금의 모양인지 이 장의 네 가지 성질로 거슬러 올라가 이해할 수 있다.

---

## 1. 핵심 요점

- 이 책은 시맨틱 웹을 홍보하는 책이 아니라, W3C가 만든 표준 언어를 실제로 다루는 모델링 기술을 가르치는 책이다.
- 시맨틱 웹은 페이지끼리가 아니라 데이터 항목끼리 URI로 링크하는, 데이터 수준의 분산 웹이다. 웹의 기본 구조(주소, 통신 규약, 표현 언어)를 확장한다.
- 영업시간, 호텔 지점, 실험 데이터, 금융 상품 조건 같은 정보는 데이터 제공자가 직접 기계가 읽을 수 있게 공개하는 것이 모두에게 이익이다. 소셜 데이터는 공유와 통제의 균형이 문제이고, 데이터 과학은 여러 출처의 정렬된 데이터가 필요하다.
- AAA 슬로건(Anyone can say Anything about Any topic)은 웹의 성격이다. 이 개방성이 데이터 황무지와 네트워크 효과의 선순환을 함께 낳는다.
- 웹의 정보는 의견 차이, 속임, 실수, 낡은 정보 때문에 어긋나며 이는 일시적 상태가 아니다. 시맨틱 웹은 모두를 합의시키는 것이 아니라 합의하지 않는 세상에서 상호 운용성을 얻으려는 것이다.
- 같은 대상을 다른 이름으로 부를 수 있으므로, URI가 다르다고 다른 대상이라고 가정하면 안 된다(비고유 이름 가정).
- 웹은 열린 세계라서 가진 정보가 전부라고 가정할 수 없다. 대부분의 데이터 시스템이 따르는 닫힌 세계 가정은 필요할 때 쓸 수 있게 따로 제공된다.
- 시맨틱 웹, 데이터의 웹, 링크드 데이터, 링크드 오픈 데이터, 지식 그래프는 같은 기술의 서로 다른 측면을 가리키는 이름이다. 모델은 수로, 데이터는 물에 비유된다.
