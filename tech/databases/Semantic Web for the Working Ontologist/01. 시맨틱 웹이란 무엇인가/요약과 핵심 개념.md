# 요약과 핵심 개념

이 문서는 1장의 마무리 절과 "Fundamental concepts"를 정리한다. 하이퍼텍스트 웹에서 이미 성립하던 네 가지 성질이 시맨틱 웹에서는 더 거칠게 나타난다는 점, 그 혼란을 다루는 사람이 온톨로지스트라는 점, 그리고 모델이 데이터에 대해 하는 일을 책의 표지에 빗댄 비유로 설명한다.

이 장의 모든 개념이 한곳에 모이므로 복습용으로 쓰기 좋다. 표를 먼저 훑고 본문으로 돌아가면 빠르다.

---

## 1. 네 가지 성질은 이미 웹에 있다

이 장에서 설명한 AAA 슬로건, 네트워크 효과, 비고유 이름, 열린 세계 가정은 하이퍼텍스트 웹에서도 이미 성립한다. 그 결과 오늘의 웹은 출처, 조직, 정보 스타일이 매우 다양한 다소 제멋대로인 곳이다. 검색 엔진을 효과적이고 창의적으로 쓰는 것이 일종의 기술이 되었다. 질서를 만들려는 노력은 커뮤니티 차원(소셜 북마크, 커뮤니티 백과사전)에서 자동화된 방법(통계적 상관, 퍼지 유사도 매칭)까지 있다.

| 성질 | 한 줄 설명 | 문서 |
|---|---|---|
| AAA 슬로건 | 누구나 어떤 주제에 대해서든 무엇이든 말할 수 있다 | AAA 슬로건과 네트워크 효과 |
| 네트워크 효과 | 참여자가 많을수록 새 참여가 더 매력적이다 | AAA 슬로건과 네트워크 효과 |
| 비고유 이름 | 같은 대상이 여러 이름으로 불릴 수 있다 | 의견 충돌과 이름 문제 |
| 열린 세계 가정 | 지금 가진 정보가 전부라고 가정하지 않는다 | 열린 세계 가정과 여러 이름 |

표의 네 성질이 시맨틱 웹의 모든 설계 판단의 출발점이다.

## 2. 시맨틱 웹은 더 거친 정글이다

시맨틱 웹은 개별 진술 수준이라는 더 미세한 층에서 작동하므로 상황이 더 거칠다. 하이퍼텍스트 웹에서는 사람이 중간에 있어서 모순과 불일치를 관찰과 상식으로 처리할 수 있다. 기계가 정보를 합칠 때는 어떻게 질서를 세울까. 여러 출처를 합친 정보를 어떻게 믿을 수 있을까.

하이퍼텍스트 웹이 제멋대로인 곳이라면 시맨틱 웹은 정글이다. 길 안내도, 색인도, 지침도 없는 풍부하고 서로 연결된 정보 덩어리다.

| 비교 | 하이퍼텍스트 웹 | 시맨틱 웹 |
|---|---|---|
| 작동 층 | 문서(페이지) | 데이터에 대한 개별 진술 |
| 모순 처리 | 사람이 관찰과 상식으로 | 기계가 합치므로 질서를 세울 방법이 필요하다 |
| 비유 | 제멋대로인 곳 | 정글 |

표의 마지막 행처럼, 사람이 빠지면 혼란은 더 커진다.

## 3. 온톨로지스트의 일

이 혼란이 쓸모 있게 되려면 어떻게 해야 할까. 이것이 일하는 온톨로지스트가 맞닥뜨리는 과제다. 그들의 매체는 분산된 데이터 웹이고, 도구는 아래 시맨틱 웹 언어들이다. 그들의 기술은 이 매체에서 합리적이고 쓸 만하고 오래가는 정보 자원을 만드는 것이다. 이 기술을 모델링(modeling)이라 부르며 책의 중심이다.

| 도구 | 풀이 |
|---|---|
| RDF | 데이터 모델. 데이터를 트리플로 나타낸다(3장) |
| RDFS (RDF Schema) | RDF용 스키마 언어 |
| SPARQL | 질의 언어 |
| SKOS (Simple Knowledge Organization System) | 간단한 지식 조직 체계 |
| SHACL (Shapes Constraint Language) | 데이터 형태에 대한 제약 조건 언어 |
| OWL (Web Ontology Language) | 웹 온톨로지 언어 |

각 도구의 역할을 이 장은 이름만 소개하고, 이후 장에서 하나씩 다룬다. 표의 풀이 중 "트리플로 나타낸다"는 앞 문서의 설명을 이어 붙인 것이고, 나머지는 이름이 뜻하는 바를 옮긴 것이다. 이 표의 짧은 한국어 설명은 이 장 본문에 없는 정리이므로, 정확한 정의는 해당 장에서 확인해야 한다.

## 4. 표지 비유: 물과 수로

책 표지에는 물이 흐르는 수로 체계가 그려져 있다. 물을 웹의 데이터로 생각하면 수로가 모델이다.

| 요소 | 혼자 있을 때 | 둘이 합쳐졌을 때 |
|---|---|---|
| 모델 없는 데이터(물) | 체계적으로 흐르지 못하고 구분 없는 넓은 물이 있을 뿐이다 | 데이터가 질서 있게 흐른다 |
| 데이터 없는 모델(수로) | 움직이는 부품이 없어 역동성이 없다 | 수로의 구조가 정한 대로 물이 흐르는 역동적 시스템이 된다 |

모델이 없으면 구분 없는 데이터 덩어리일 뿐이고, 어떤 데이터가 다른 데이터와 상호작용해야 하거나 해도 되는지 알 방법이 없다. 모델은 그것이 설명할 데이터가 없으면 의미가 없다. 둘이 합쳐지면 데이터가 한 지점에서 다른 지점으로 원칙에 따라 체계적으로 흐르는 역동적 정보의 웹이 된다. 이것이 시맨틱 웹의 비전, 곧 정보가 한 곳에서 다른 곳으로 매끄럽지만 질서 있게 흐르는 전 세계적 조직 체계다.

## 5. 핵심 개념 복습

| 개념 | 정리 |
|---|---|
| AAA 슬로건 | Anyone can say Anything about Any topic. 웹 전반, 특히 시맨틱 웹의 기본 원칙 중 하나다. |
| 열린 세계 / 닫힌 세계 | AAA 슬로건의 결과로 누군가 새로 말할 수 있는 것이 항상 있다. 따라서 알 수 있는 정보가 더 있다고 가정해야 한다. |
| 비고유 이름 | 웹의 화자들이 이름 짓기를 꼭 조율하지는 않으므로, 같은 개체가 둘 이상의 이름으로 알려질 수 있다. |
| 네트워크 효과 | 웹이 유기적으로 자라게 하는 성질. 참여의 가치가 이미 참여한 사람 수에 따라 커져서 참여의 선순환이 생긴다. |
| 데이터 황무지 | 웹 데이터 대부분의 상태. 값진 정보가 있지만 질서나 쉬운 이해가 보장되지 않는다. |

복습할 때는 오른쪽 칸을 가리고 왼쪽 개념 이름만 보고 설명해 보는 방식이 좋다. 다섯 개념은 서로 이어져 있다. AAA 슬로건이 네트워크 효과와 데이터 황무지, 열린 세계, 비고유 이름을 모두 낳는다.
