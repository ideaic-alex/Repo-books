# 요약과 핵심 개념

이 문서는 13장의 마무리 부분이다. 장 전체를 되돌아보고 이 장에서 새로 나온 핵심 개념을 표로 정리한다.

이 책은 RDF에서 RDFS, OWL의 여러 단계로 나아가면서 단계마다 모델을 이해하는 새로운 관점을 소개해 왔다. 이 장에서 그 관점이 어디까지 왔는지, 그리고 다음 장이 무엇을 다루는지 정리한다.

---

## 1. 단계별로 본 시맨틱 웹 언어

| 단계 | 핵심 질문 | 중심 개념 |
|---|---|---|
| RDF | 한 대상에 대해 내가 아는 모든 정보를 한곳에 모으려면 어떻게 하나 | 데이터 공유와 연합(federation) |
| RDFS | 내 데이터에 대해 아는 것에서 무엇을 더 알아낼 수 있나 | 추론 |
| RDFS-Plus와 기본 OWL | 옛 정보에서 새 정보를 더 폭넓게 추론할 수 있나 | 더 풍부한 추론 기능 |
| 고급 OWL(이 장) | 데이터뿐 아니라 모델 자체에 대해서도 추론할 수 있나 | 개수 세기, 소거법, 클래스 추론 |

읽는 법은 이렇다. 모델의 의미를 추론에서 찾는다는 틀은 그대로이고, 추론의 범위가 데이터에서 모델 자체로 넓어졌다. 이 장 앞부분까지는 열린 세계 가정의 영향을 대체로 무시해도 되었다. 열거와 소거에 기반한 논증이 가능해진 고급 OWL 구성에서는 열린 세계의 영향이 눈에 띄게 드러난다.

이 장에서 배운 OWL 개념으로 이제 더 포괄적인 OWL 모델을 살펴볼 준비가 되었다. 모델링하는 사람이 OWL 구성을 사용해 서로 다른 출처의 데이터가 시맨틱 웹에서 어떻게 연합될지 서술하는 방법을 볼 수 있다. RDFS-Plus에서 봤듯이 모델은 아직 살펴보지 않은 출처의 정보도 연결해 줄 수 있다. 고급 OWL은 이를 더 강력하고 완전하게 해 준다.

---

## 2. 핵심 개념

| 개념 | 한 줄 정리 |
|---|---|
| owl:unionOf, owl:intersectionOf, owl:complementOf | 클래스에 적용하는 기본 집합 연산. 각각 하나 이상의 기존 클래스에서 새 클래스를 만든다 |
| 열린 세계 가정 | 1장에서 소개한 개념. 이 장에서는 특정 목적을 위해 세계를 닫는 전략을 소개했다 |
| owl:oneOf | 클래스가 나열한 멤버만으로 이루어졌음을 지정 |
| owl:differentFrom | 한 개체가 다른 개체와 owl:sameAs가 아님을 지정. 개수 세기 논증에 특히 유용 |
| owl:disjointWith | 두 클래스가 멤버를 공유할 수 없음을 지정. differentFrom을 클래스 단위로 한꺼번에 선언하는 용도로 쓰인다 |
| owl:AllDisjointClasses | 클래스 집합의 모든 쌍이 서로소임을 지정 |
| owl:cardinality, minCardinality, maxCardinality | 속성의 서로 다른 값의 개수를 지정. oneOf, differentFrom, disjointWith와 합치면 개수 세기 추론의 기반이 된다 |
| 모순 | 고급 OWL 구성으로 모델이 논리적으로 일관되지 않음을 표현할 수 있다 |
| 만족 불가능성 | 클래스가 멤버를 가질 수 없음을 추론할 수 있다. 그런 클래스는 만족 불가능하다 |

표의 위쪽은 클래스를 조합하는 도구, 가운데는 세계를 닫고 개체를 구별하는 도구, 아래쪽은 모델의 건전성을 알려 주는 개념이다.

## 3. 이 장 전체를 한눈에

| 하고 싶은 일 | 쓰는 도구 |
|---|---|
| 두 조건을 모두 만족하는 개체들 | owl:intersectionOf |
| 둘 중 하나라도 만족하는 개체들 | owl:unionOf |
| 이 클래스에 속하지 않는 것들 | owl:complementOf(보통 교집합과 함께) |
| 멤버가 이것들뿐이라고 닫기 | owl:oneOf |
| 이 둘은 다르다고 말하기 | owl:differentFrom |
| 이 목록의 개체들이 서로 모두 다르다고 말하기 | owl:AllDifferent + owl:distinctMembers |
| 이 클래스들은 겹치지 않는다고 말하기 | owl:disjointWith, owl:AllDisjointClasses |
| 값 개수를 제한하기 | owl:cardinality, owl:minCardinality, owl:maxCardinality |
| 특정 클래스의 값 개수를 제한하기 | 한정 기수(owl:onClass 사용, OWL 2.0) |
| 모델의 문제 찾기 | 모순과 만족 불가능한 클래스 확인 |
